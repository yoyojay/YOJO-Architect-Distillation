# YOJO 建筑师蒸馏计划

面向建筑、室内与空间设计工作流的建筑师经验 Skill 目录。

当前批次已完成 14 / 100 位建筑师。早鸟用户获得完整 100 位建筑师的持续解锁权益；后续新增 Skill 会继续放入本目录，并在 `CHANGELOG.md` 记录版本。

## 目录

每个建筑师目录是一份可独立交付的 Agent Skill，包含 `SKILL.md`、`agents/`、`assets/`、`references/`、`tests/`、运行清单和校验文件。

## 使用边界

这些 Skill 是建筑创作与工作流辅助资产，不替代建筑师的专业判断、项目审批、法规核验或现场责任。使用时请结合项目所在地法规、客户要求和实际工程条件复核。

## 当前批次

请先阅读对应目录的 `README.md` 和 `DELIVERY_NOTICE.md`，再按照 `SKILL.md` 的输入格式使用。
