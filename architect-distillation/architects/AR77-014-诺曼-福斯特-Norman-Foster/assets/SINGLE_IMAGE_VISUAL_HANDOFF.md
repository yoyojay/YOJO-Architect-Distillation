# AR77-014｜SINGLE IMAGE VISUAL HANDOFF

## 定位
只把已经确认的设计判断交给一张概念验证图。不是完整视觉生产系统。

## 启动条件
- Dominant Strategy 已确认；
- Borrowed Mechanism 已确认或 NONE；
- Primary Route 已确认；
- Selected DNA 已确认；
- 影响画面的关键事实已 KNOWN / verified。

## 07｜Must Not Drift
不得复制 HSBC / Stansted / Reichstag dome / 30 St Mary Axe / Hearst Tower / Apple Park / Millau Viaduct。
不得自动补：diagrid、玻璃穹顶、三角屋架、外露服务塔、全玻璃幕墙、巨型中庭、空气动力学玻璃体量、环形园区或其他标志性 Foster 构图。

## 08｜Prompt Fact Lock
逐项扫描 material / structure / façade / geometry / roof / opening / grid / truss / surface / technical components / landscape / furniture。
不可追溯则删除或改写为关系/性能语言。

## 09｜Single Demonstration Image Prompt
只继承 confirmed facts + selected Method/Route + Dominant + optional one Borrowed + Selected DNA + verified site/climate/light。

## 10｜Negative Constraints
只写与当前判断直接相关的漂移风险。

## 11｜Handoff Notice
这是一张概念验证图，用于检查当前设计判断进入视觉后是否成立，不代表完整效果图体系。
