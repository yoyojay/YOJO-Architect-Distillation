# AR77-014｜PROBLEM ROUTE RUNTIME

## R1｜INTEGRATED_SYSTEM
**Trigger:** architecture, structure, services and envelope are tightly coupled.
**Core Question:** how can technical systems reinforce spatial order instead of being added after form?
**Method:** define spatial/performance goals → map structural/service/envelope dependencies → develop integrated options → test interfaces, maintenance and change.
**Primary DNA:** D1 / D2 / D3 / D8.
**Boundary:** responsibility, procurement, tolerances, commissioning, replacement.
**Risk:** visible technology becoming aesthetic theater.
**Difference:** whole-system coordination leads.

## R2｜ENVIRONMENTAL_PERFORMANCE
**Trigger:** climate, daylight, energy, comfort or environmental targets materially shape architecture.
**Core Question:** what spatial/envelope/system arrangement meets verified performance with minimum unnecessary resource use?
**Method:** set measurable targets → climate analysis → passive-first spatial/envelope options → active-system coordination → simulate/test → revise.
**Primary DNA:** D1 / D4 / D7 / D8.
**Boundary:** climate data, controls, user behavior, glare, acoustics, fire.
**Risk:** green symbolism without measured performance.
**Difference:** environmental performance leads.

## R3｜LONG_LIFE_LOOSE_FIT
**Trigger:** program, tenancy, technology or organization is expected to change.
**Core Question:** what should remain stable and what should remain replaceable?
**Method:** separate long-life frame/infrastructure from changeable layers → establish generous/legible access and service logic → test future scenarios.
**Primary DNA:** D2 / D5 / D6 / D8.
**Boundary:** embodied carbon, oversizing, fire/acoustic zoning, lease/operations.
**Risk:** “flexibility” becoming expensive empty capacity.
**Difference:** future change leads.

## R4｜CONNECTIVE_INFRASTRUCTURE
**Trigger:** transport, campus, civic or large institutional projects depend on movement and public connection.
**Core Question:** how can circulation/infrastructure become a legible spatial and civic system?
**Method:** map flows/interchanges → reduce conflict → create shared orientation nodes → integrate daylight/environment/security → test peaks and accessibility.
**Primary DNA:** D1 / D6 / D7 / D2.
**Boundary:** safety, crowd flow, security, operations, weather.
**Risk:** monumental circulation disconnected from daily use.
**Difference:** movement/connectivity leads.

## R5｜RESOURCE_EFFICIENCY
**Trigger:** material, carbon, energy, construction or operational resources are primary constraints.
**Core Question:** where can the project achieve more performance with less material/energy/complexity?
**Method:** establish baseline → identify high-impact systems → compare structural/envelope/service options → prototype/simulate → select by whole-life value.
**Primary DNA:** D1 / D3 / D4 / D8.
**Boundary:** robustness, durability, supply chain, maintenance, resilience.
**Risk:** optimization of one metric degrading total performance.
**Difference:** resource economy leads.
