# AR77-031｜Boundaries & Contemporary Corrections Runtime

## 1｜Fit

### FIT
- 项目核心是复杂程序、用户流、时间变化、体验组织、跨专业性能或未来适应；
- diagram / design model 能真实改变平面、剖面与路径；
- 用户接受先解决组织问题、后锁定形态。

### PARTIAL FIT
- 项目只有部分复杂关系需要组织；
- 主要形式、结构或保护边界已固定，只能局部应用 Route / DNA；
- 数据不足但仍可做早期假设，必须标 NEED VERIFY。

### NOT FIT
- 用户只要求复制 Möbius House、Mercedes-Benz Museum、Arnhem Central、Erasmus Bridge 或其他代表作外形；
- 项目问题主要是一个与本 Method 无关的装饰 / 风格选择；
- 组织逻辑已完全固定且用户拒绝任何平面 / 剖面 / 路径调整。

## 2｜Contemporary Corrections

### Climate / Energy
复杂几何、连续空间或大体量共享区不自动等于可持续。核对朝向、热负荷、日照、自然 / 机械通风策略、能耗目标和局部气候数据。

### Accessibility
非线性路径、坡道、层间连续性必须提供真实可达、合理距离与等效体验；不得以“连续流线”为理由制造障碍。

### Fire
多层贯通、共享中庭、交叉路径和复杂疏散必须由当地消防专业验证。建筑判断只负责识别风险和可读性。

### Structure
Design Model 可以提出组织关系，但不得预设扭转、悬挑或复杂结构为必要。每个关键几何都要问：它是否由空间 / 结构因果共同支持。

### MEP
连续空间与混合程序常带来分区、竖井、检修和控制复杂度。技术系统必须在关键剖面中占据真实位置。

### Acoustics / Privacy
视觉连接、程序交叉与共享节点不等于声学或隐私兼容。对教育、办公、住宅、健康项目分别验证。

### Operations / Security
日夜时段、票务、后勤、清洁、安防和独立运营要能在组织模型中切换；不允许为了空间连续性破坏实际管理。

### Maintenance
复杂表皮、可动系统、长路径或高位空间必须评估检修可达性、替换周期与维护成本。

### Cost / Procurement
数字复杂度不等于可建造性。确认构件重复性、容差、施工顺序、供应链和本地能力；必要时简化几何而保留组织机制。

### Lifecycle / Adaptability
“future-proof” 必须用变化情景、拆装 / 改造路径和服务容量验证；不能只靠开放平面宣称灵活。

### Health / Wellbeing
以实际人群、活动和可测环境条件为依据；不因“人本”叙事自动推导材料、植物、透明度或技术配置。

## 3｜Architect-Specific Anti-Drift
- 不把 twist / loop / Möbius / helix 当默认几何。
- 不把参数化复杂性当作 Method 证据。
- 不为“未来感”自动添加玻璃、金属、白色表皮、连续曲面或大跨。
- 不把 movement 等同于更长的路；路径必须有使用收益。
- 不把 cross-programming 等同于取消所有边界。
