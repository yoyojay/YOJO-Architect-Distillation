# AR77-031｜项目分析输出模板

## 00｜MASTER FIRST IMPRESSION｜大师初印象
首次完整项目分析显示一次：
- 120–180 中文字符
- 3 个关键词
- 1 个“不要误读成”

## 01｜输入检查
KNOWN / UNKNOWN / NEED VERIFY / 是否足以概念判断

## 02｜项目适配
FIT / PARTIAL FIT / NOT FIT

## 03｜核心冲突
1 个 Main Conflict + 最多 3 个 Secondary Conflicts

## 04｜Route
Primary Route / Trigger / Core Question / Method / Boundary / Risk  
Secondary Route: NONE / one bounded mechanism

## 05｜Selected DNA
只选 2–4 个。每条：
项目冲突 → 空间操作 → 预期痕迹 → 边界 → Failure Mode → 验证

## 06｜Strategy A
Core Cause / Route-DNA Trace / Spatial Mechanism / Plan / Section / Movement / Program / Performance / Advantages / Risks / Need Verify / Next Test

## 07｜Strategy B
同上。

## 08｜Strategy C
同上。

## 09｜三案比较
Main Conflict / Route integrity / DNA integrity / plan-section-movement / operation / adaptability / performance / technical risk

## 10｜推荐方向
Dominant Strategy:
Borrowed Mechanism: NONE / one mechanism from one other strategy
Rejected for Recommendation:
Why:
Unresolved:
Need Verify:

## 11｜当代校正
climate / accessibility / fire / structure / MEP / acoustics / privacy / operations / maintenance / cost / procurement / lifecycle

## 12｜Architect Confirmation Point
### Keep
### Unresolved
### Next Drawings / Tests
### Architect Decision

## 13｜建筑初印象 Prompt
`建筑初印象 Prompt｜复制到你的图像生成工具即可`

只允许：
KNOWN + selected Route / Method + Dominant Strategy + optional one Borrowed Mechanism + Selected DNA + verified site / climate / light。

禁止：
Ben van Berkel / UNStudio style、代表作名称、Rejected Strategy、未选 DNA、未经支持的材料 / 结构 / 立面 / 几何 / 屋顶 / 开口 / 技术构件 / 景观 / 家具。

## Recommendation Compliance
- Positive strategy count = 1 or 2 only.
- 2 只允许 Dominant + one limited Borrowed Mechanism.
- 3 = HARD FAIL.
- Rejected Strategy 不回流。
- 未选 DNA 不回流。

## Prompt Fact Lock
输出 Prompt 前扫描 material / structure / façade / geometry / roof / openings / grid / truss / surface / technical components / landscape / furniture。无法追溯到允许来源的具体描述删除或改写为关系 / 性能语言。
