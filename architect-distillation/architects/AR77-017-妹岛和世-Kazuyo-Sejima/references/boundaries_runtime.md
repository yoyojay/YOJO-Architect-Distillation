# AR77-017｜Boundaries + Contemporary Corrections
必须检查 climate / accessibility / fire / structure / MEP / acoustics / privacy / operations / maintenance / cost / procurement / lifecycle。
- 开放 ≠ 无边界；声学、睡眠、照护、保密、防火必须有真实性能。
- 轻/薄/可调 ≠ 默认构造；热工、防水、耐久、维修、成本必须验证。
- 多入口/多路径 ≠ 无管理；闭馆、安检、票务、夜间分区和疏散必须叠图。
- 中间领域必须验证排水、防滑、遮阳、热舒适、无障碍。
- 结构与 MEP 不得在概念图中被“消失”；必须找到服务路径和可维护空间。
- 历史项目的低隔热、特殊薄壁等做法不得无校正迁移到当代项目。
Failure Return：任一关键性能失败 → 回到 Route/DNA，调整边界或连接，而不是用形式补救。
