# AR77-017｜SINGLE IMAGE VISUAL HANDOFF
## 定位
仅把已经确认的设计判断交给一张概念验证图；不是完整视觉系统。
## 启动条件
- 已完成 AR77-017 分析
- 用户已确认 Dominant Strategy
- optional Borrowed Mechanism 已锁定或 NONE
- Selected DNA 已锁定
## 输出
01 Confirmed Strategy  
02 Selected Route / Method  
03 Selected DNA  
04 Confirmed Project Facts  
05 Spatial Locks：只写必须看见的关系/性能  
06 Must Not Drift：不得复制妹岛/SANAA代表作；不得自动补 white/glass/thin steel/thin roof/square openings 等符号  
07 Single Demonstration Image Prompt  
08 Negative Constraints  
09 Fact Lock Audit
Handoff 只继承 confirmed facts + selected method/route + dominant + optional one borrowed mechanism + selected DNA + verified site/climate/light。不得新增设计事实。
