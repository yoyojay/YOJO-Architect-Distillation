# AR77-018｜西泽立卫 Method Runtime

## Evidence status
本 Runtime 只把可被权威资料直接支持的内容标为 KNOWN；由多个项目与本人访谈归纳出的可迁移机制标为 SUPPORTED INTERPRETATION。两者才可驱动设计。NEED VERIFY / UNKNOWN 不得进入方法结论。

## Method Kernel
核心链：
`真实生活/公共活动 → 场地与外部环境 → 室内外关系 → 空间单元与间隙 → 路径与距离选择 → 气候/季节体验 → 使用者再解释空间 → 工程与运营校正`

### M1｜从使用与外部环境同时开始
不要先画封闭体量。先问：内部需要怎样使用？建筑将创造怎样的外部环境？周边已有的街道、庭院、景观、气候是否能成为空间的一部分。

### M2｜把“房间”与“建筑整体”解耦
当项目需要不同亲密度、尺度、独立性或与城市接触程度时，可把功能拆成多个空间单元，以间隙、庭院、廊道或外部路径建立关系。拆分不是造型目的，必须换来可验证的生活/公共性价值。

### M3｜让非标准空间保留使用解释权
空间不必把每种行为预先定义到底。若安全、无障碍、运营允许，可保留一部分未被单一功能锁死的空间，使使用者自行发现停留、交往、独处或临时使用方式。

### M4｜室内外不是二元开关
开放不是“多玻璃”。应以距离、视线、门槛、遮蔽、季节、风雨与使用时段校准不同程度的接触；目标是让外部环境真正参与空间，而不是只提供景观。

### M5｜建筑可成为环境中的关系装置
在艺术、景观或公共项目中，建筑可退后为人与自然、艺术、城市发生关系的条件。形式只有在结构、地形、环境与体验共同要求时才成立。

## Anti-Premature-Form
在完成 Fit、Conflict、Route、Selected DNA 之前，禁止指定标志性几何、材料、屋顶、开口或“轻薄”构件。任何形式必须能回溯到项目事实和空间机制。
