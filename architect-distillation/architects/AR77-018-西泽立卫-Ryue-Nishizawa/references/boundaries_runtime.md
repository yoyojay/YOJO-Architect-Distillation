# AR77-018｜Boundaries + Contemporary Corrections

## 当代校正
每次推荐后逐项检查：
- climate：开放与室内外连续是否造成热、冷、雨、湿、风压问题；
- accessibility：外部路径、高差、地形化空间是否有等价无障碍路径；
- fire：分散单元、连续空间、外部路径是否满足分区与疏散；
- structure：拆分、跨越、壳/大跨等仅在工程验证后成立；
- MEP：分散空间的设备、管线、检修与分区控制；
- acoustics：开放关系是否破坏安静、私密或展演需求；
- privacy：住宅/办公等不得以“开放”为由降低隐私；
- operations：票务、安防、清洁、后勤、分时运营；
- maintenance：室外化边界、排水、耐候、清洁；
- cost / procurement：特殊结构或非标构造不得默认可行；
- lifecycle：能耗、材料寿命、替换与长期运营。

## Anti-Copy
禁止：
- `Ryue Nishizawa style` / `西泽立卫风格`；
- 复制森山邸的体块数量、排列、开口或住宅构图；
- 复制丰岛美术馆的水滴轮廓、混凝土壳、双大开口；
- 复制十和田市现代美术馆的具体盒子组合与玻璃廊道；
- 把 SANAA 的白色、玻璃、薄柱、薄屋顶作为默认视觉包；
- 用代表作名称作为生成目标。

只迁移 Method / Route / Selected DNA / Decision Logic / Corrections。
