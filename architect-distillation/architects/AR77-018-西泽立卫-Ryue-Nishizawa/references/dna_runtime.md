# AR77-018｜Design DNA Runtime

默认选择 **3–5 个必要 DNA**。少于 3 个通常不足以形成方法链；多于 5 个必须说明每个 DNA 对独立冲突的必要性。未选 DNA 不得回流。

## D1｜单元化而非整块化
- 判断含义：当不同活动需要不同尺度/独立性时，允许空间单元彼此分开。
- Trigger：多主体、多尺度、不同开放度。
- Spatial Operation：拆分房间/展室/活动单元，再设计它们之间的关系。
- 边界：结构、消防、后勤与面积效率。
- Failure Mode：碎片化成为形式游戏。
- 可验证痕迹：平面中单元差异与其间公共/外部空间有明确用途。

## D2｜间隙成为可用空间
- 判断含义：单元之间不是剩余缝，而可承担庭院、通行、停留、邻里接触或户外展示。
- Trigger：拆分后出现中间地带。
- Spatial Operation：给间隙明确的尺度、可达性与气候角色。
- 边界：安全、排水、维护、无障碍。
- Failure Mode：漂亮但不可用的空隙。
- 可验证痕迹：路径与活动图能证明间隙被真实使用。

## D3｜非标准空间的解释权
- 判断含义：部分空间不被单一用途完全命名，让使用者产生新用法。
- Trigger：项目需要弹性、偶遇、非正式活动。
- Spatial Operation：降低固定家具/隔断对行为的唯一规定，保留可占用余地。
- 边界：不能替代必须明确的功能、设备和安全要求。
- Failure Mode：模糊变成无功能。
- 可验证痕迹：至少两种合理使用情景无需改建即可发生。

## D4｜室内外连续关系
- 判断含义：外部环境参与日常空间体验。
- Trigger：街道、庭院、景观、季节具有价值。
- Spatial Operation：通过门槛、视线、路径、半室外或可达外部空间建立连续关系。
- 边界：气候、隐私、安防、能耗。
- Failure Mode：把透明度当开放度。
- 可验证痕迹：剖面/路径证明人在内外之间有实际关系，而非只看见。

## D5｜多向关系
- 判断含义：空间不必只朝一个正面或单一轴线组织。
- Trigger：周边多侧都有城市/景观/活动价值。
- Spatial Operation：校准多方向到达、视线或外部接触。
- 边界：入口识别、疏散与管理。
- Failure Mode：方向过多导致迷失。
- 可验证痕迹：到达图显示多向关系仍有清晰层级。

## D6｜距离调节亲密度
- 判断含义：公共/私密不是只有墙门二分，也可通过距离、错位与路径调节。
- Trigger：共居、邻里、共享空间。
- Spatial Operation：用间距、转折、视线和门槛建立亲密度梯度。
- 边界：声学、视觉隐私、安全。
- Failure Mode：隐私不足。
- 可验证痕迹：隐私剖面/视线图可说明不同位置的暴露程度。

## D7｜建筑—城市/自然互相延伸
- 判断含义：建筑创造的外部空间与周边已有环境形成连续公共关系。
- Trigger：公共文化或自然场地。
- Spatial Operation：让活动、路径或环境条件跨越建筑边界。
- 边界：产权、运营、气候、生态。
- Failure Mode：概念开放但实际被围栏/运营切断。
- 可验证痕迹：总平面能看到真实连续的活动/生态路径。

## D8｜时间与季节参与空间
- 判断含义：空间体验允许随光、风、声音、季节或使用时段变化。
- Trigger：环境变化是项目价值之一。
- Spatial Operation：在不预设具体构件的前提下，设计可响应的边界和使用时序。
- 边界：舒适、耐久、设备能耗、运营。
- Failure Mode：环境浪漫化导致不可用。
- 可验证痕迹：至少用夏/冬或日/夜场景验证性能与使用差异。

## DNA Selection Logic
`主冲突 → Primary Route → 候选 DNA → 每个 DNA 写出必要性 → 只保留 3–5 个 → 检查平面/剖面/路径痕迹`。
若某 DNA 不能改变可验证的空间决策，删除。
