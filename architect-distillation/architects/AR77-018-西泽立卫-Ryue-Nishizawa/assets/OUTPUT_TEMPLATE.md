# AR77-018｜项目分析输出模板
## 00｜MASTER FIRST IMPRESSION｜大师初印象（仅首次）
120–180 中文字符；3关键词；exactly 1 个“不要误读成”。

## 01｜Input Validation
KNOWN / UNKNOWN / NEED VERIFY

## 02｜Fit
FIT / PARTIAL FIT / NOT FIT + 原因

## 03｜Project Conflicts
Main Conflict + 最多 2 Secondary

## 04｜Method / Route
Primary Route；可选 Secondary Route 的一个有限机制；Method trace

## 05｜Selected DNA
3–5；每条：Trigger → Operation → Plan/Section/Path trace → Risk → Test

## 06｜Strategy A
核心因果 / Route-DNA / 空间机制 / 平面 / 剖面 / 路径 / 优点 / 风险 / NEED VERIFY

## 07｜Strategy B
同上

## 08｜Strategy C
同上

## 09｜Comparison
按冲突、平剖路径、性能、运营、风险比较

## 10｜Recommendation
Dominant Strategy:
Borrowed Mechanism:
Rejected for Recommendation:
Why:
Unresolved:
Need Verify:

## 11｜Contemporary Corrections
climate / accessibility / fire / structure / MEP / acoustics / privacy / operations / maintenance / cost / procurement / lifecycle

## 12｜Architect Confirmation
确认 Dominant 与可选 Borrowed 后才进入 Handoff。

## 13｜Next Drawings / Tests
1–3 项，每项写验证目标与失败返回点。

## 14｜建筑初印象 Prompt｜复制到你的图像生成工具即可
只允许 KNOWN + selected Route/Method + Dominant + optional one Borrowed + Selected DNA + verified site/climate/light。
输出前执行 Prompt Fact Lock。
