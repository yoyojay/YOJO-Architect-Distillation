# AR77-018｜SINGLE IMAGE VISUAL HANDOFF

## 定位
只把**已确认的设计判断**交给一张概念验证图；不是完整视觉生产系统。

## 启动条件
- 用户已确认 Dominant Strategy；
- optional Borrowed Mechanism 已确认或为 NONE；
- Primary Route 已确认；
- Selected DNA 已确认；
- 项目事实完成 Fact Lock。

## 输出
### 01｜Confirmed Facts
只列 KNOWN 与已验证 site/climate/light。

### 02｜Confirmed Strategy
Dominant + optional one Borrowed Mechanism。

### 03｜Selected Route / DNA
只列已选项。

### 04｜Spatial Locks
把方法翻译为必须看得见的关系：单元/间隙、门槛、距离、路径、环境参与等；不得新增形式事实。

### 05｜Must Not Drift
禁止代表作复制；禁止默认白色/玻璃/薄柱/混凝土壳/水滴几何/分散白盒；禁止 SANAA 视觉包。

### 06｜Single Demonstration Image Prompt
只使用 Confirmed Facts + Method/Route + Dominant + optional Borrowed + Selected DNA + verified site/climate/light。

### 07｜Negative Constraints
只写与当前判断直接相关的负向约束。

### 08｜Handoff Note
这是一张概念验证图，用于检查当前设计判断进入视觉后是否成立，不代表完整效果图体系。

## Fact Lock
生成前扫描材料、结构、立面、几何、屋顶、开口、柱网、桁架、表面、技术构件、景观、家具；不可追溯即删除或泛化。
