# AR77-010｜SINGLE IMAGE VISUAL HANDOFF

## 定位
本模块只负责把**已经确认的设计判断**交给一张概念验证图。

它不是完整效果图系统，不是多视角生产系统，也不是 Mies 风格生成器。

## 启动条件
必须全部满足：
- 已完成 AR77-010 项目分析；
- Dominant Strategy 已确认；
- optional Borrowed Mechanism 已确认；
- Selected DNA 已确认；
- 用户明确要求单张概念视觉验证。

## 01｜Confirmed Strategy
只写确认后的 Dominant Strategy。

## 02｜Borrowed Mechanism
NONE / one confirmed mechanism from one other strategy.

## 03｜Confirmed Route + Selected DNA
不得加入未选 Route / DNA。

## 04｜Confirmed Project Facts
只继承 KNOWN 与 verified site / climate / light。

## 05｜Spatial Locks
只写必须在图中能验证的关系，例如：
- primary order remains legible;
- changeable occupation does not destroy the stable framework;
- boundaries show intended degrees of relation;
- approach / ground relation is readable;
- section makes span / enclosure / occupation relation intelligible.

## 06｜Must Not Drift
禁止：
- `Mies style` / `Miesian`;
- Barcelona Pavilion / Farnsworth House / Crown Hall / Seagram / New National Gallery 作为视觉目标；
- 自动补 black steel / bronze / marble / travertine / full-height glass；
- 自动补 I-beam mullions / cruciform columns / floating roof / podium / plaza；
- 未确认的家具与景观；
- Rejected Strategy；
- 未选 DNA。

## 07｜Prompt Fact Lock
扫描：
material / structure / façade / geometry / roof / openings / wall / column-grid / truss / surfaces / technical components / landscape / furniture.

每一项必须追溯到：
KNOWN / confirmed Method-Route / Dominant / one Borrowed / Selected DNA / verified site-climate-light / verified professional constraint.

不可追溯 → 删除或改写为关系 / 性能语言。

## 08｜Single Demonstration Image Prompt
描述：
- current project type;
- confirmed spatial judgement;
- actual activity;
- verified site / climate / light;
- view that can reveal the selected spatial relation.

不要添加未经确认的物质事实。

## 09｜Handoff Notice
这是一张概念验证图，用于检查当前设计判断进入视觉后是否成立。它不代表完整效果图体系。
