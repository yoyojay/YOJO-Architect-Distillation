# AR77-010｜Mies van der Rohe Architect Skill

这是客户可调用 Runtime 包。

## 使用
1. 可直接用自然语言描述项目；
2. 或填写 `AR77_PROJECT_INPUT_FORM_v1.0.md`；
3. Runtime 会执行 Input Validation → Fit → Route → DNA → A/B/C → Recommendation → Corrections → Confirmation → Prompt Close；
4. 策略确认后，用户可明确要求 `Single Image Visual Handoff`。

## 重要边界
- 这是建筑判断工具，不是风格生成器。
- 不复制 Mies 代表作。
- UNKNOWN 不会自动补成设计事实。
- 结构、消防、规范、机电、幕墙、声学、成本等最终判断仍需相应专业人员确认。
