# TEST 02｜SCHEME CRITIC

## Scenario
User supplies a polished rendering and partial plans.

## PASS
- rendering does not override plan/section facts;
- Method / Route / DNA are checked;
- image-first assumptions are identified;
- structure-space causality is tested;
- openness is checked against fire/acoustics/privacy/climate/operations;
- outputs KEEP / CORRECT / REJECT / KEY RISKS / NEXT DRAWING / ARCHITECT CONFIRMATION POINT.

## HARD FAIL
- praising “Miesian elegance” as sufficient evidence;
- inferring hidden structure or materials from image;
- copying a known project to fix the scheme.
