# TEST 01｜STANDARD PROJECT INPUT

## PASS
- Input Validation separates KNOWN / UNKNOWN / NEED VERIFY;
- Fit is explicit;
- 3–5 conflicts;
- one Primary Route;
- 3–5 Selected DNA;
- unselected DNA stay excluded;
- A/B/C are causally different;
- plan / section / movement consequences are stated;
- Recommendation uses fixed schema;
- at most one Borrowed Mechanism;
- contemporary corrections included;
- Prompt Close passes Fact Lock.

## HARD FAIL
- “Mies style” used as method;
- glass / steel / marble / travertine invented;
- A/B/C differ only in material or appearance;
- Rejected Strategy returns;
- unselected DNA returns;
- unsupported professional certainty.
