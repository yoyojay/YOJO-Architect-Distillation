# AR77-010｜Problem Route Runtime

## Route Rule
Use project-problem Routes, not forced historical phases.

Select 1 Primary Route; optional 1 Secondary Route only if it addresses a separately named conflict.

## ROUTE U｜UNIVERSAL_FIELD
**Trigger:** changing program, shared learning/work/exhibition/assembly space, need for future reconfiguration.

**Core problem:** how a durable order can support changing use.

**Method:** establish span/structure/service order first; then test multiple occupation scenarios.

**Primary DNA:** D01, D02, D03, D04, D08.

**Boundary:** privacy-, acoustic- or clinical-heavy programs can make large undifferentiated fields unsuitable.

**Risk:** “flexibility” becomes empty space without anchors.

**Difference:** order is carried mainly by durable structural/service framework.

## ROUTE F｜FLOWING_RELATIONS
**Trigger:** continuity matters but program still needs partial distinction.

**Core problem:** how selective boundaries make rooms relate without erasing differences.

**Method:** use relational boundaries and spatial anchors; test movement, view and enclosure together.

**Primary DNA:** D01, D05, D06, D07, D08.

**Boundary:** fire, privacy, acoustics and climate may require stronger separation.

**Risk:** visual openness is confused with operational openness.

**Difference:** order is carried mainly by boundary relations, not one big universal room.

## ROUTE G｜GRID_AND_GROUND
**Trigger:** campus, institutional ensemble, repeated buildings, urban block.

**Core problem:** how a larger ordering field coordinates individual pieces and public ground.

**Method:** identify existing urban/site axes; establish a legible ordering system; allow program differences within it.

**Primary DNA:** D01, D02, D09, D10, D08.

**Boundary:** social fabric, heritage, ecology and pedestrian scale may demand deviations.

**Risk:** abstract order suppresses local life.

**Difference:** the primary design object is the system of relations across the site.

## ROUTE L｜LANDSCAPE_FRAME
**Trigger:** strong landscape, view, topography, horizon or exterior condition.

**Core problem:** how architectural order intensifies occupation-landscape relation.

**Method:** calibrate ground, boundary and viewing relation while protecting climate/privacy/performance.

**Primary DNA:** D01, D05, D07, D10, D08.

**Boundary:** flood, heat, glare, habitat, privacy and envelope requirements can dominate.

**Risk:** degenerates into “transparent pavilion.”

**Difference:** the landscape relation, not visual transparency, carries the route.
