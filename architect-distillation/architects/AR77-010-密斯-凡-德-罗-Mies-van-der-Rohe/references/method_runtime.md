# AR77-010｜Mies van der Rohe Method Runtime

## Purpose
Translate supported Miesian architectural judgement into contemporary project decisions without copying appearance.

## Evidence Status Used
Only `KNOWN` and `SUPPORTED INTERPRETATION` may drive this runtime.

### KNOWN institutional anchors
- Illinois Institute of Technology describes Crown Hall's column-free main floor as demonstrating Mies's concept of universal space adaptable to changing use.
- MoMA describes the Farnsworth House as expressing structural clarity and a deliberate relation among architecture, landscape and people.
- MoMA describes the IIT master plan as responding both to American steel technology and to the logic of Chicago's urban grid.
- MoMA characterizes Mies's European work through fluid space and his American work through structural clarity and exacting detail.
- MoMA's Convention Hall record identifies clear-span modern structure as enabling an open, column-free interior.

## Supported Interpretation
These recurring anchors support a transferable chain:

`essential task`
→ `legible order`
→ `structure as spatial enabler`
→ `stable framework / adaptable occupation`
→ `boundary as relation`
→ `site / city / landscape alignment`
→ `detail confirms the whole`

This chain is a design reasoning model, not a historical quote.

## Method Tests

### 1. Essential Task Test
Write the project in one sentence without style terms.
If the sentence cannot identify what must remain stable and what may change, the design problem is not yet distilled.

### 2. Order Test
Draw the ordering system without façade styling.
If it cannot explain span, movement, major program and site relation, the order is too weak.

### 3. Spatial Release Test
Ask whether structure releases the intended spatial field or merely appears “structural.”

### 4. Adaptability Test
Distinguish long-life elements from short-life occupation.

### 5. Boundary Test
For every major boundary, state what it controls:
movement / view / privacy / acoustics / climate / operations / fire.

### 6. Whole-to-Detail Test
A critical detail should be explainable as a consequence of the overall order.

### 7. Context Test
At urban or landscape scale, explain whether the building aligns, frames, resists or reorders existing conditions.

## Non-transferable visual residues
Do not treat these as Method:
- glass box;
- black steel;
- bronze façade;
- marble / travertine;
- I-beam mullion rhythm;
- cruciform columns;
- floating roof or floor;
- famous plaza proportions;
- iconic furniture.
