# AR77-005｜Runtime Boundaries

005 特别适合检查：身体舒适、停留时间、活动对应采光、声学意图、地形/水/树、半室外门槛、材料触感与老化、家具、小尺度公共性、标准化修正、大空间更新的人尺度。

必须谨慎：
- 不直接移植北欧气候假设；
- 温暖材料也可能在湿度、维护、碳、成本、工艺上失败；
- 声学意图不等于声学性能；
- 自然光也可能带来眩光和热；
- 人性化必须包含不同年龄、身体和感官需求；
- 曲线无因果即拒绝；
- 变化必须可建造、可维护、可理解；
- 亲近的公共性仍需安全、导向、隐私与运营。

不做最终：结构、消防、法规、机电、无障碍合规、环境性能、声学性能、造价、施工、采购结论。
