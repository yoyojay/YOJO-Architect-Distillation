## First Contact PASS
- [ ] 首次完整项目分析先出现约 150 字大师初印象
- [ ] 大师初印象来自 packaged method / DNA / Project-Problem Route，不写百科传记
- [ ] 有 3 个关键词 + 1 条“不要误读成”
- [ ] 不要求用户预先熟悉阿尔瓦·阿尔托或 AI 命令

- [ ] Critic / Handoff 不重复大师初印象

## Project Analysis PASS
- [ ] 使用标准项目表或等价自然语言项目资料
- [ ] 先做输入检查
- [ ] UNKNOWN 不补写
- [ ] Fit Check 正确
- [ ] 有 3–5 个核心人 / 空间冲突
- [ ] 只使用 Project-Problem Route
- [ ] Primary Route 1 条，Secondary 最多 1 条
- [ ] 不虚构历史 Period Route
- [ ] 只选 4–7 DNA
- [ ] 未选 DNA 不得后门回流
- [ ] BODY / LIGHT+SOUND / TERRAIN+TRANSITION / MATERIAL+TOUCH / FURNITURE+SMALL ELEMENTS 五层协调
- [ ] A/B/C 因果不同
- [ ] 推荐最多正向使用 2 个策略
- [ ] 推荐使用 Dominant / Borrowed / Rejected 固定结构
- [ ] 推荐保持 Route / DNA / Human Experience 一致
- [ ] 有当代校正 / 风险
- [ ] 有建筑师确认点
- [ ] 有下一步 1–2 张图 / 测试
- [ ] 不复制阿尔托作品
