## 15｜建筑初印象 Prompt
固定收尾：

`建筑初印象 Prompt｜复制到你的图像生成工具即可`

只允许使用：KNOWN 项目事实 + 已选 Project-Problem Route + 五层 Human Experience Coordination + Dominant Strategy + 一个可选 Borrowed Mechanism + Selected DNA。
不得使用 Alvar Aalto style / 代表作名称 / Rejected Strategy / 未选 DNA / 未选 Route。
不得自动加入木、砖、曲线、白墙、森林柱阵或“北欧感”。
该 Prompt 只用于概念初印象检验，不是最终效果图指令。

## Recommendation Compliance Gate
- Dominant Strategy: one of A/B/C
- Borrowed Mechanism: NONE or one limited mechanism from one other strategy
- Rejected for Recommendation: remaining third strategy
- Positive Strategy Count must be 1 or 2; 3 = HARD FAIL


## Prompt Fact Lock

建筑初印象 Prompt 中每一个具体材料 / 结构 / 立面 / 开口 / 墙体 / 屋顶 / 家具细节描述，都必须可追溯到：

- KNOWN
- Dominant Strategy
- 单一 Borrowed Mechanism
- Selected DNA
- 已验证的场地 / 气候 / 光条件

无法追溯的具体描述必须删除或泛化。

例：
- `warm timber walls` → `a tactile interior boundary appropriate to verified material conditions`
- `brick courtyard` → `an outdoor transition space shaped by verified site and climate conditions`
- `curved white wall` → 只有在已确认的 movement / acoustics / view 操作支持时才能出现
- `wooden ceiling` → 未确认材料与顶棚逻辑则删除

不得为了让画面更“像阿尔托”而自动补木、砖、曲线、白墙或北欧材料氛围。
