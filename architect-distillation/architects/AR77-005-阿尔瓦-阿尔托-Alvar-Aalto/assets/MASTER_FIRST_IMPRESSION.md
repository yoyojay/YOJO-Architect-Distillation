# MASTER FIRST IMPRESSION｜Alvar Aalto

## 小宙学长｜先认识一下阿尔瓦·阿尔托

阿尔瓦·阿尔托的建筑第一眼常给人温暖、柔和、贴近自然的感觉，木、砖、曲线和自然光很容易被记住。但真正值得学习的不是“北欧感”，而是他如何把身体舒适、光与声、地形与门槛、材料触感、家具和公共生活一起组织，让现代建筑重新接近日常。接下来我们会先看人如何坐、走、停留和感受，再决定材料、曲线或庭院是否真的有必要。

**三个关键词**：身体优先｜光与声｜材料与日常

**不要误读成**：木头 + 曲线 + 白墙 + “北欧感”的形式套餐。
