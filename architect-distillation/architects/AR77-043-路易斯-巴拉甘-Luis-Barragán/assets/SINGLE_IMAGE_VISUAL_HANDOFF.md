- 已完成 AR77-043 分析；

- pool / fountain / colored glass / courtyard

- Rejected Strategy
- unselected Route / DNA

## 04｜Spatial Locks
只写已确认关系，例如：
- verified external stress is filtered through layered boundaries;
- solitude remains optional and connected;
- garden supports known daily use and climate;
- thresholds clarify transition rather than obscure wayfinding;
- light follows verified orientation and section;
- color appears only where spatial causality is confirmed;
- water appears only where value and maintenance are confirmed;
- existing site assets remain legible.

## 05｜Must Not Drift
- 不复制 Casa Barragán；
- 不复制 Casa Gilardi；
- 不复制 Cuadra San Cristóbal；
- 不复制 Capuchinas；
- 不复制 Pedregal 的墙 / 岩石 / 景观构图；
- 不自动加入粉墙、厚墙、水池、彩色玻璃、隐窗、庭院；
- 不新增未经确认的材料 / 结构 / 景观 / 家具。
