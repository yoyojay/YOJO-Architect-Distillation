# AR77-043｜METHOD RUNTIME
## Luis Barragán｜Architectural Judgement Kernel

## 0｜Evidence Status

本 Runtime 只允许 `KNOWN` 与 `SUPPORTED INTERPRETATION` 进入 Method / Route / DNA / Rules。

### KNOWN
- Barragán 在 1980 年 Pritzker 获奖演讲中把 Beauty、Silence、Solitude、Serenity、Joy、Gardens、Fountains 等明确列为长期关切，并把 serenity 视为建筑应持续带入居住环境的品质。
- 同一演讲把花园理解为人与自然合作的场所，并强调“把自然转化到人的尺度”，使花园成为对现代生活侵扰的庇护；他也把水与安宁、愉悦、感官记忆联系起来。
- 他明确说明自己的建筑具有 autobiographical dimension，并从父亲牧场、村镇、庭院、果园、街道、广场、北非与摩洛哥环境中学习，但目标是把这些记忆适应现代生活，而非历史复制。
- 他谈到 Pedregal 火山岩景观时，强调“humanize without destroying”其魔力，说明景观介入的目标不是清除原有地貌，而是让人可以进入、停留和感知。
- Pritzker biography / jury citation持续把 gardens、plazas、fountains、meditation、companionship、serenity 与其建筑工作联系起来，同时称其具有 landscape-architect orientation。
- UNESCO 对 Luis Barragán House and Studio 的评价强调：现代与传统的综合、光与建成空间的深度对话、色彩作为 form / material 的组成，以及对多感官体验的重视。
- UNESCO 也记录：该住宅 / 工作室在 Barragán 长期居住与修改中不断演化，说明其空间不是静态风格样板。
- Casa Gilardi 官方确认其为 Barragán 最后一座住宅设计且仍在使用；该项目可作为晚期住宅空间 / 色彩 / 光 / 水关系的案例，但不能被泛化为所有项目的默认形式。

### SUPPORTED INTERPRETATION

AR77 将上述证据转译为：

`人的情绪 / 生活状态`
→ `读取场地、边界、噪声、光、气候、地形、视野`
→ `明确需要的 serenity / intimacy / joy / contemplation`
→ `组织 enclosure / threshold / path / garden / room sequence`
→ `只在有因果时加入 light / color / water`
→ `把传统 / 记忆转译成比例、边界、材料关系和生活秩序，而非复古图形`
→ `保护原有场所特征，避免过度清除`
→ `通过当代 climate / accessibility / fire / maintenance / cost 校正`
→ `最后才锁定形式`

这是 AR77 的 evidence-bounded runtime abstraction，不冒充 Barragán 本人提出的固定设计步骤。

## 1｜Core Judgements

### J1｜EMOTIONAL WELLBEING BEFORE IMAGE｜情绪福祉先于图像
先问空间要让人获得何种心理状态，再讨论墙、色彩、水或材料。

### J2｜SERENITY REQUIRES BOUNDARY + CALIBRATION｜宁静需要边界与校准
宁静不是空白 / 极简；它来自噪声、视线、光、尺度、路径、停留和边界的共同控制。

### J3｜SOLITUDE IS SPATIAL, NOT ISOLATION｜孤独感不是社会隔离
需要的是可选择的独处、沉思和自我感知，不是把公共 / 家庭关系切断。

### J4｜GARDEN IS HABITABLE NATURE AT HUMAN SCALE｜花园是被人居住的自然
花园要回应停留、阴影、路径、季节、气候与使用；不能只做摄影背景。

### J5｜REVEAL THROUGH THRESHOLD｜门槛与显现组织体验
压缩 / 开敞、暗 / 亮、遮蔽 / 远景可以制造发现，但路径必须清楚、可达、不过度戏剧化。

### J6｜LIGHT CAN DEFINE SPACE｜光可以定义空间
光的方向、强度、反射、遮挡与时段变化可改变空间关系；具体开口形式必须由当前项目验证。

### J7｜COLOR MUST HAVE SPATIAL CAUSALITY｜色彩必须有空间因果
色彩可改变尺度、亮度、深度、焦点或序列，但不能因为“Barragán 常用强色”就自动加入。

### J8｜WATER MUST EARN ITS PLACE｜水必须证明存在价值
水只有在声、光、微气候、停留、记忆或路径中有真实作用时成立，并且必须通过维护 / 水耗 / 安全验证。

### J9｜HUMANIZE WITHOUT DESTROYING｜人化而不摧毁
面对强地形、岩石、植被或既有场所，应先判断哪些特征必须保留，再决定最小必要介入。

## 2｜Method Execution

1. 锁定 KNOWN / UNKNOWN / NEED VERIFY。
2. 写 3–5 条项目冲突，不先决定粉墙、水池、厚墙、庭院或色块。
3. 建立 Emotional–Site Map：noise / light / view / privacy / social contact / pause / garden / climate。
4. Primary Route exactly 1；Secondary 最多 1。
5. D01 `EMOTIONAL_WELLBEING_FIRST` mandatory；再选 1–3 个必要 DNA，总量 2–4。
6. 每个 Selected DNA 必须留下 Plan / Section / Movement / Light / Climate / Use 中至少一种可验证痕迹。
7. 生成 A/B/C 三个因果不同策略。
8. Recommendation 只保留一个 Dominant，最多借另一个策略 1 个有限机制。
9. 执行 Contemporary Corrections。
10. Prompt Close 前执行 Prompt Fact Lock。
