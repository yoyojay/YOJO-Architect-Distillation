# AR77-043｜PROBLEM ROUTES
## Luis Barragán｜Project-Problem Routing

这些 Route 是 AR77 依据证据建立的 Project-Problem Routes，不是历史阶段，也不是代表作风格分类。

## R1｜INWARD_REFUGE_BOUNDARY｜向内庇护 / 边界调停
**Trigger**
- 场地嘈杂、暴露、邻里视线强或城市压力高；
- 住宅 / 小型机构需要亲密、独处与恢复。
**核心问题**
如何通过边界、阈值、开口关系把外部压力过滤掉，同时避免封闭成隔离。
**Method**
external stress map → privacy / social needs → boundary gradient → entry / threshold → inner rooms / garden relation → daylight / ventilation / accessibility test。
**主要 DNA**
D01 / D02 / D03 / D05
**适用边界**
住宅、小型文化 / 宗教 / 疗愈空间。
**风险**
封闭过度、采光 / 通风不足、公共关系丢失、厚墙形式化。
**与其他 Route 差异**
由外部压力与内在恢复的冲突驱动。

## R2｜GARDEN_AS_HABITABLE_WORLD｜花园 / 可居住自然
**Trigger**
- 户外停留、自然接触、季节与微气候对日常生活重要；
- landscape 不应只是背景。
**核心问题**
如何把自然转化为可使用、可停留、可维护的人体尺度环境。
**Method**
existing ecology / terrain → shade / sun / wind → daily outdoor use → path / pause / planting → edge / room relation → lifecycle test。
**主要 DNA**
D01 / D04 / D05 / D09
**适用边界**
住宅、校园、小型公共、景观 / 社区项目。
**风险**
景观摄影化、用水高、维护难、过度修整原生场地。
**与其他 Route 差异**
由人与自然的日常共处驱动。

## R3｜THRESHOLD_REVEAL_SEQUENCE｜门槛 / 显现序列
**Trigger**
- 到达、转折、光暗、视野变化可显著改变体验；
- 项目需要从公开到私密、喧闹到安静的连续过渡。
**核心问题**
怎样通过压缩 / 开敞和暗 / 亮建立清楚而非戏剧化的序列。
**Method**
arrival state → transition states → threshold / turn / compression → reveal / pause → orientation / accessibility / safety test。
**主要 DNA**
D01 / D02 / D05 / D06
**适用边界**
住宅、文化、宗教、展览、小型公共。
**风险**
迷宫化、暗空间过度、无障碍差、把 Alhambra 式经验复制成形式套路。
**与其他 Route 差异**
由时间性体验与显现顺序驱动。

## R4｜LIGHT_COLOR_ATMOSPHERE｜光—色彩 / 氛围校准
**Trigger**
- 自然光方向 / 反射 / 色彩会显著改变空间尺度、焦点或情绪；
- 项目有明确 daylight / atmosphere 目标。
**核心问题**
如何让光与色彩改变空间关系，而不是把强色当作签名。
**Method**
daylight facts → target atmosphere → surface / reflection relation → color only if causal → glare / heat / maintenance / material test。
**主要 DNA**
D01 / D06 / D07
**适用边界**
住宅、文化、宗教、公共室内。
**风险**
颜色先行、眩光 / 过热、材料褪色、摄影效果高于使用。
**与其他 Route 差异**
由 light / spatial perception 驱动。

## R5｜LANDSCAPE_HUMANIZATION｜强场地 / 人化而不摧毁
**Trigger**
- 火山岩、坡地、成熟植被、原生景观或强地貌是项目核心资产；
- 场地需要被使用，但不应被大规模清除。
**核心问题**
如何通过最小必要介入让人进入、停留和理解场地，同时保留其原有魔力 / 特征。
**Method**
site-value inventory → preserve / touch / remove zones → path / room / garden insertion → view / drainage / ecology → construction-impact test。
**主要 DNA**
D01 / D04 / D05 / D09
**适用边界**
景观强住宅、度假、文化、公共 / 社区项目。
**风险**
“自然感”被人工化；施工破坏地貌；无障碍 / 排水 / 火灾风险被忽略。
**与其他 Route 差异**
由现有地形 / 生态资产的保存与使用冲突驱动。

# Route Selection Logic
1. 先写主冲突，再选 Route。
2. Primary Route exactly 1。
3. Secondary Route = NONE 或最多 1。
4. Secondary 必须解决不同但真实的次级冲突。
5. R1 必须有真实 privacy / noise / exposure 问题。
6. R2 必须有真实 outdoor-use / microclimate / nature-contact 需求。
7. R3 必须有真实 transition / arrival / privacy-gradient 问题。
8. R4 必须有 verified daylight / atmosphere 问题；无数据则先 NEED VERIFY。
9. R5 必须有真实地貌 / 植被 / 场所资产可保护。
10. 未选 Route 不得回流 Recommendation / Prompt / Handoff。
