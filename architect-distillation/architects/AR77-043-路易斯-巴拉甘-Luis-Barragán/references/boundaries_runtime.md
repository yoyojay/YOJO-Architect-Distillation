# AR77-043｜BOUNDARIES + CONTEMPORARY CORRECTIONS
## Luis Barragán

## Fit

### FIT
- 项目核心是 serenity / privacy / contemplation / emotional wellbeing；
- 场地 / 花园 / 微气候与日常生活高度相关；
- 需要通过门槛 / 路径 / 光暗组织从公开到私密；
- 强地貌 / 成熟植被需被保留并人化；
- 光 / 色彩作为空间感知工具有真实触发。

### PARTIAL FIT
- Barragán 方法可帮助 atmosphere / site / garden / threshold，但决定性问题由超高层、复杂医疗、工业流程、大型交通等其他系统主导。

### NOT FIT
- 唯一目标是粉墙 / 强色 / 水池 / 厚墙；
- 只要求“Mexican modern / Barragán style”；
- 项目事实不足却要求具体颜色、材料、花园、水或开口。

## Contemporary Corrections

### Climate
围合庭院、厚墙、受控开口、花园、水体都必须按真实 heat / sun / humidity / wind / rain / ventilation 校正。

### Accessibility
压缩入口、台阶、狭窄门槛、下沉庭院、暗转亮序列不得使无障碍路径成为次等体验。

### Fire / Life Safety
内向空间、受控开口、长路径、庭院和宗教 / 文化项目必须验证疏散、烟控、消防接近与出口清晰度。

### Structure
厚墙、长墙、悬挑、特殊开口和水池不得从 Barragán 作品形式类推；必须工程验证。

### MEP
内向 / 低开口空间需验证通风、热舒适、除湿、照明、喷淋、检修和设备路径。

### Acoustics
serenity 必须通过实际声学验证，尤其住宅、宗教、疗愈与城市场地。

### Privacy
宁静 / 独处不能以牺牲安全、照护、家庭联系或社会可达为代价。

### Operations
花园、水体、庭院、宗教 / 住宅公共边界必须有日常 / 夜间 / 清洁 / 安保 / 活动模式。

### Maintenance
水体、防水、彩色表面、粗糙抹灰、植栽、石材和高墙必须有可维护 / 可更新策略。

### Cost
诗意体验不能通过不可控定制 / 高维护构件堆积；应比较真正产生体验价值的少数机制。

### Procurement
地方材料 / 工艺只在供应链、技能、容差和维护条件已验证时使用。

### Lifecycle
水耗、植栽灌溉、涂层更新、热工性能、材料耐久、适应性与 embodied carbon 必须进入判断。

## Barragán-Specific Corrections

- serenity ≠ silent empty room；
- solitude ≠ social isolation；
- garden ≠ decorative planting；
- fountain ≠ mandatory water feature；
- color ≠ Mexican palette；
- mystery ≠ dark / confusing circulation；
- vernacular memory ≠ hacienda / convent copy；
- thick wall ≠ authenticity；
- inwardness ≠ ignoring street / public responsibility。

## Professional Boundary

本 Skill 可做 early-stage architectural judgement、Route / DNA、A/B/C、scheme critic、garden / threshold / atmosphere analysis 与 next tests；
不能替代持证建筑师、结构、消防、MEP、声学、无障碍、景观 / 灌溉 / 水景工程、防水、造价、运营或当地法规专业责任。
