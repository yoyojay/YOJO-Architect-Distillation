# AR77-043｜DESIGN DNA RUNTIME
## Luis Barragán

## Selection Rule
- **D01 mandatory**
- 再选 1–3 个必要 DNA
- 总量默认 **2–4**
- 未选 DNA 不得回流 Strategy / Recommendation / Keep / Next / Prompt / Handoff

## D01｜EMOTIONAL_WELLBEING_FIRST｜情绪福祉先行
**判断含义**：先定义需要的 serenity / intimacy / joy / contemplation，再讨论形式。
**Trigger**：所有完整项目分析。
**Spatial Operation**：建立 Emotional–Site Map，将压力源 / 停留 / 社交 / 独处 / 光 / 声对应到空间。
**适用边界**：全部项目。
**Failure Mode**：只写“诗意 / 宁静”口号。
**可验证空间痕迹**：关键空间可指向真实情绪 / 使用需求。

## D02｜BOUNDARY_FOR_SERENITY｜宁静边界
**判断含义**：通过边界、距离、声 / 视线过滤形成安静，不等于封闭。
**Trigger**：噪声、暴露、邻里视线或外部刺激真实存在。
**Spatial Operation**：external pressure → layered threshold / buffer / opening control → inner calm。
**适用边界**：住宅、疗愈、宗教、小型公共。
**Failure Mode**：无窗厚墙 / 内向封闭成为形式。
**可验证空间痕迹**：声 / 视线 / 光 / 通风同时改善。

## D03｜SOLITUDE_WITH_CONNECTION｜可选择的独处
**判断含义**：独处空间允许自我恢复，同时保留与家庭 / 社区的可控联系。
**Trigger**：用户需要 retreat / focus / prayer / reflection。
**Spatial Operation**：shared → semi-private → private → retreat gradient。
**适用边界**：住宅、宗教、工作 / 疗愈空间。
**Failure Mode**：把 solitude 误成 isolation。
**可验证空间痕迹**：用户可以选择连接或退隐，而非被强制分离。

## D04｜GARDEN_AT_HUMAN_SCALE｜人体尺度花园
**判断含义**：自然通过路径、阴影、停留、边界和季节变化进入日常生活。
**Trigger**：outdoor use / nature contact / microclimate 是真实目标。
**Spatial Operation**：existing landscape → usable shade / path / pause / planting → room-garden relation。
**适用边界**：住宅、公共、校园、景观项目。
**Failure Mode**：花园只为摄影；过度修剪 / 高维护。
**可验证空间痕迹**：不同时间 / 季节有真实使用与舒适性。

## D05｜THRESHOLD_AND_REVEAL｜门槛与显现
**判断含义**：通过转折、压缩、遮蔽、光暗与突然开放组织发现感。
**Trigger**：arrival / privacy / transition 真正重要。
**Spatial Operation**：approach → buffer → turn / compression → reveal → pause。
**适用边界**：住宅、文化、宗教、展览。
**Failure Mode**：为了神秘而迷宫化 / 黑暗化。
**可验证空间痕迹**：movement 与 plan-section、wayfinding、accessibility 一致。

## D06｜LIGHT_AS_SPATIAL_MATERIAL｜光作为空间材料
**判断含义**：光通过方向、反射、遮挡与时段变化改变空间边界 / 深度 / 焦点。
**Trigger**：daylight 对体验 / 功能重要。
**Spatial Operation**：sun / sky facts → aperture / reflection / shade relation → glare / heat test。
**适用边界**：全部日光敏感项目。
**Failure Mode**：复制窄缝 / 隐窗 / 彩色玻璃。
**可验证空间痕迹**：剖面和时段分析能解释光的作用。

## D07｜COLOR_WITH_SPATIAL_CAUSALITY｜色彩的空间因果
**判断含义**：色彩只有在改变亮度、深度、焦点、尺度或序列时才成立。
**Trigger**：明确存在 perception / orientation / atmosphere 需求。
**Spatial Operation**：target perception → surface / illumination relation → restrained color test。
**适用边界**：室内、庭院、受控外部界面。
**Failure Mode**：粉 / 黄 / 蓝等 Barragán palette 自动化。
**可验证空间痕迹**：去掉色彩后可说明损失了什么空间作用。

## D08｜WATER_FOR_REPOSE｜水的安宁作用
**判断含义**：水可通过声音、反射、蒸发、路径或停留产生安宁 / 愉悦。
**Trigger**：水能真实解决 sensory / climate / spatial problem。
**Spatial Operation**：purpose → water type / location → sound / reflection / climate → safety / maintenance / water-budget test。
**适用边界**：庭院、花园、公共 / 住宅外部空间。
**Failure Mode**：自动反射池 / 喷泉；漏水、高耗水、蚊虫、滑倒。
**可验证空间痕迹**：其作用与维护成本可测。

## D09｜PRESERVE_SITE_MAGIC｜保留场所特征
**判断含义**：对强地貌 / 植被先保存价值，再做最小必要介入。
**Trigger**：site 有明显原生地形、岩石、成熟植被或独特边界。
**Spatial Operation**：preserve / touch / remove map → minimal path / room insertion。
**适用边界**：景观强场地。
**Failure Mode**：以“人化”为名清空 / 景观化全部自然。
**可验证空间痕迹**：主要 site assets 在建成后仍可辨认并继续工作。

# DNA Selection Logic
1. D01 mandatory。
2. 再选 1–3 个，总量 2–4。
3. D02 需要真实 external pressure。
4. D03 需要真实 retreat / solitude user need。
5. D04 需要真实 outdoor use / microclimate。
6. D05 需要真实 threshold / sequence 问题。
7. D06 需要 verified daylight conditions 或 NEED VERIFY 计划。
8. D07 只有明确 spatial-perception 作用时启用。
9. D08 只有水的作用与维护 / 水耗都能说明时启用。
10. D09 只有真实 site asset 存在时启用。
11. 未选 DNA 禁止回流。
