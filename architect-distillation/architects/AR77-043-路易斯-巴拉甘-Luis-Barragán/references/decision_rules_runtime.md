# AR77-043｜DECISION RULES
## Luis Barragán

1. **当**用户要求“巴拉甘式粉墙 / 强色块”  
   **→ 优先**D01  
   **→ 因为**情绪目标先于色彩  
   **→ 通过**Emotional–Site Map 验证  
   **→ 若失败则**删除颜色预设。

2. **当**场地噪声 / 暴露 / 邻里视线强  
   **→ 优先**R1 + D02  
   **→ 因为**宁静需要真实边界调停  
   **→ 通过**acoustic / privacy / daylight / ventilation test  
   **→ 若失败则**不得用厚墙形式补偿。

3. **当**用户需要独处 / 沉思  
   **→ 优先**D03  
   **→ 因为**solitude 应可选择而非强制隔离  
   **→ 通过**shared-to-retreat gradient 验证  
   **→ 若失败则**重做连接关系。

4. **当**方案自动出现花园 / 庭院  
   **→ 优先**R2 + D04  
   **→ 因为**花园必须可居住、可使用、可维护  
   **→ 通过**shade / path / pause / climate / lifecycle 验证  
   **→ 若失败则**删除景观形式化。

5. **当**到达序列追求神秘 / 惊喜  
   **→ 优先**R3 + D05  
   **→ 因为**reveal 必须服务清楚的 transition  
   **→ 通过**movement / wayfinding / accessibility / safety 验证  
   **→ 若失败则**简化路径。

6. **当**日光被用来塑造空间  
   **→ 优先**D06  
   **→ 因为**开口 / 反射 / 遮挡必须有真实光学因果  
   **→ 通过**section + daylight / glare / heat test  
   **→ 若失败则**不得复制窄缝 / 隐窗。

7. **当**提出强色彩  
   **→ 优先**D07  
   **→ 因为**颜色必须改变空间感知  
   **→ 通过**before / after spatial-perception test  
   **→ 若失败则**恢复中性色 / 未指定状态。

8. **当**提出水池 / 喷泉  
   **→ 优先**D08  
   **→ 因为**水必须证明 sensory / climate / spatial value  
   **→ 通过**water budget / maintenance / safety / effect test  
   **→ 若失败则**删除水体。

9. **当**强地形 / 岩石 / 植被是场地资产  
   **→ 优先**R5 + D09  
   **→ 因为**应 humanize without destroying  
   **→ 通过**preserve-touch-remove map / construction-impact test  
   **→ 若失败则**减少介入。

10. **当**A/B/C 只是颜色 / 墙体 / 水景强弱  
    **→ 优先**重做  
    **→ 因为**策略必须因果不同  
    **→ 通过**不同 primary causal mechanism 验证  
    **→ 若失败则**Strategy Gate FAIL。

11. **当**Recommendation 想把三案融合  
    **→ 优先**只保留一个 Dominant  
    **→ 因为**Dominant 必须独立成立  
    **→ 通过**最多一个 Borrowed Mechanism  
    **→ 若失败则**Recommendation Gate FAIL。

12. **当**Prompt 自动补 stucco / stone / timber / pink / yellow / blue / pool / fountain / thick wall  
    **→ 优先**Prompt Fact Lock  
    **→ 因为**历史项目特征不是当前项目事实  
    **→ 通过**KNOWN / selected Route / Dominant / Borrowed / Selected DNA / verified site-climate-light 追溯  
    **→ 若失败则**删除或泛化。
