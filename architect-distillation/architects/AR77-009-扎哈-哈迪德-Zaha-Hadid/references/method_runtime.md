# AR77-009｜Zaha Hadid Method Runtime

## 1｜Method Kernel

Zaha Hadid 的可迁移方法不是“制造曲线”，而是：

**读取场地与项目中的方向、流动、程序冲突与城市关系  
→ 把它们转译为具有方向性的空间场  
→ 用叠合、分叉、连续地景与立体路径组织运动和占用  
→ 让结构、边界、地面与体量服务于这一空间关系  
→ 在图纸 / 模型中反复测试可能性，而不是过早冻结对象形式。**

这一内核只允许在项目事实支持时运行，不为“像 Zaha”而制造复杂几何。

---

## 2｜反复在判断什么

### J1｜建筑是孤立对象，还是场地力量的组织器？
优先判断现有与期望的到达、城市方向、景观、公共界面和程序流动，是否可以被建筑重新连接。

### J2｜流线只是交通，还是空间生成机制？
重要路径应改变空间的组织、视线、层次和公共性，而不是在成形体量中后贴一条走廊。

### J3｜功能是房间清单，还是可相遇 / 可分离的活动场？
先识别必须隔离、可以叠合、需要交叉、应当连续的程序，再决定边界。

### J4｜地面是否能成为建筑的一部分？
当项目适合时，入口、广场、坡道、平台、内部公共空间可以被视为连续地景；但无障碍、排水、防滑和运营必须先成立。

### J5｜几何是在说明关系，还是只在追求视觉奇异？
任何倾斜、折叠、扭转、连续曲率或锐角都必须能回到路径、场地、程序、结构或环境因果；否则删除。

### J6｜方案是否过早被冻结？
绘画、图解、模型与数字几何应作为发现关系与测试变化的工具，而不是只负责表现最终造型。

## 3｜核心因果链

`Site / Urban Forces`
→ `Movement + Program Vectors`
→ `Field Organization`
→ `Ground / Section Continuity`
→ `Boundary + Spatial Differentiation`
→ `Structure / Envelope Feasibility`
→ `Human Experience + Operations`
→ `Iterative Re-test`

若前两步证据薄弱，不得直接跳到复杂形式。

---

## 4｜Architect-Specific Method Operations

### OP-A｜Vector Mapping
把已知的主要到达、跨越、视线、公共连接、服务流线和程序关联画成方向场。  
输出不是造型，而是“哪些关系必须被强化 / 分离 / 转向 / 叠合”。

### OP-B｜Field Rather Than Object
当场地和项目允许时，优先测试建筑是否能形成连续的空间场，而非单个封闭物体。  
检查建筑与城市 / 景观是否通过路径、地面或开放空间发生互相渗透。

### OP-C｜Circulation as Generator
选择 1–2 条真正重要的运动系统，使其参与剖面、公共空间和功能组织。  
禁止把所有路径都戏剧化；后台、消防、无障碍与服务路径必须清晰可靠。

### OP-D｜Programmatic Interweaving
把程序分成：
- 必须隔离；
- 可以相邻；
- 可以共享；
- 可以交叉；
- 需要可见但不可互扰。

随后用空间关系而不是图标形状组织它们。

### OP-E｜Ground / Section Transformation
仅在项目有真实理由时，测试地面抬升、下沉、跨越、连续坡面、平台或立体公共路径。  
任何操作必须同步校验无障碍、坡度、排水、结构净高、疏散和运营。

### OP-F｜Open-Ended Representation
在概念阶段保留至少两种关系图 / 剖面测试，不因第一张强烈效果图而冻结方案。  
图像应该揭示变化可能，而不是替代建筑判断。

## 5｜哪些只是外貌，不进入 Method

以下不能作为默认方法：
- 任意流线曲面；
- 任意尖角、悬挑或“速度感”；
- 白色连续外壳；
- 无理由的双曲面；
- 为了“未来感”隐藏所有结构与门窗；
- 把复杂几何本身当成项目价值。

---

## 6｜适用边界

### FIT
项目存在明显的：
- 多方向到达或城市连接；
- 高强度公共流动；
- 程序之间需要交织而非简单分区；
- 地面 / 剖面可承担公共组织；
- 需要通过空间系统形成新的公共连续性。

### PARTIAL FIT
项目只有局部节点需要动态连接，或复杂几何带来的成本 / 施工 / 运营压力较高。  
此时只迁移一到两个机制，不必全局化。

### NOT FIT
若项目核心是：
- 极端低成本、重复标准化且几乎无公共空间；
- 高度依赖静态、严格分隔且变化很少的单元；
- 项目方只要求“Zaha 外形”；
则本 Skill 不应强行主导。

## 7｜当代修正

历史方法进入今天必须经过：
climate、accessibility、fire safety、structure、MEP、acoustics、privacy、operations、maintenance、cost、procurement、lifecycle。

复杂空间关系可以保留；不可把复杂表皮、结构难度或维护负担当作不可质疑的代价。
