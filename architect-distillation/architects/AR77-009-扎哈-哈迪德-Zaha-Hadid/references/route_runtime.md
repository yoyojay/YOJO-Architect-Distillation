# AR77-009｜Problem Route Runtime

## 为什么是 Problem Routes
本 Skill 不把 Zaha Hadid 的职业生涯硬切成若干历史时期供项目套用。客户项目首先按“正在解决哪一种空间问题”路由；同一项目最多设一个 Primary Route，可有一个 Secondary Route。

## R1｜URBAN_FIELD｜城市场连接
**Trigger:** 多方向到达、城市断裂、公共开放空间需要重新连接。  
**Primary operations:** Directional Field + Urban Graft。  
**Watch:** 不要把城市连接简化成地标造型。

## R2｜MOVEMENT_INFRASTRUCTURE｜运动基础设施
**Trigger:** 交通、体育、展览、校园等项目中运动本身决定体验。  
**Primary operations:** Circulation Generator + Ground / Section Transformation。  
**Watch:** 后勤、疏散、无障碍必须形成独立可靠的性能层。

## R3｜PROGRAM_FIELD｜程序场编织
**Trigger:** 多功能公共建筑需要共享、交叉、分离并存。  
**Primary operations:** Program Interweave + Layered Field。  
**Watch:** 不能为了空间连续而损害声学、隐私和运营分区。

## R4｜LANDSCAPE_CONTINUITY｜地景连续
**Trigger:** 建筑需延续地形、广场、公园、河岸或公共地面。  
**Primary operations:** Ground Continuity + Boundary Continuity。  
**Watch:** 气候、排水、防滑、结构净高与维护为硬约束。

## R5｜EXPLORATORY_FIELD｜探索型空间场
**Trigger:** 早期概念问题尚未固定，需要用多版本图解 / 模型发现关系。  
**Primary operations:** Open-Ended Geometry + Vector Mapping。  
**Watch:** 最终必须回到使用、结构、环境和成本；不能停在实验图像。

## Route Lock
- Primary Route = 1。
- Secondary Route = 0 或 1。
- Route 是问题路由，不是风格分期。
- Prompt 只允许出现已确认 Route 所支持的空间关系，不写 Route 名称本身也可以。
