# AR77-009｜Boundaries + Contemporary Corrections

## Anti-Copy Lock
不得直接复制或移植任何著名 Zaha Hadid 项目的：
- 标志性外轮廓；
- 特定屋顶波形；
- 特定连续壳体；
- 具体尖角 / 折板构图；
- 项目专属坡道、桥体或大厅构图；
- 特定材料与表皮组合。

不得使用：
- `Zaha Hadid style`
- `Zaha style`
- `like MAXXI`
- `like Heydar Aliyev Center`
- `copy Vitra Fire Station`
- 任何著名项目名作为视觉目标。

只允许迁移已选择的 Method / Route / DNA 机制。

## Contemporary Corrections

### Climate
连续内外与大尺度公共空间必须校验热环境、遮阳、雨水、风、眩光与能耗。  
“开放 / 通透 / 连续”不是忽略气候边界的理由。

### Accessibility
地景化路径必须提供真实连续的无障碍等价路径。  
不得以“空间体验”为由制造无法通行的坡度、过长绕行或不可达节点。

### Fire Safety
动态平面和连续空间必须转译成可读的疏散距离、出口、分区与排烟策略。  
Skill 只指出风险，不声称完成消防合规。

### Structure
几何复杂度与受力逻辑要在早期对话。  
不得把结构体系当作 Prompt 装饰，也不得假定连续外形必然需要某种壳体或钢结构。

### MEP
连续空间与异形几何容易挤压设备路径和检修空间；概念阶段要预留技术带 / 服务核 / 机房的可行位置。

### Acoustics + Privacy
程序编织必须识别需要声音隔离、视觉隐私和人员控制的部分。

### Operations
公共流线、后台流线、收费边界、夜间关闭和活动切换必须可运营。  
空间连续性不能导致管理边界失效。

### Maintenance
高处、曲面、难达界面、复杂排水与非标准构件都需维护路径和生命周期判断。

### Cost + Procurement
任何非标准构件、复杂模板、定制幕墙或高精度几何都必须作为待验证成本 / 供应链风险，而不是默认事实。

## Professional Boundary
本 Skill 提供建筑判断、空间策略、风险与下一步验证，不替代注册建筑师、结构、消防、机电、无障碍、声学、造价、幕墙、施工和法规专业确认。
