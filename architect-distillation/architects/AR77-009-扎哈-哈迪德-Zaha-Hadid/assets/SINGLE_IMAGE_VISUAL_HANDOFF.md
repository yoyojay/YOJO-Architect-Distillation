# AR77-009｜SINGLE IMAGE VISUAL HANDOFF
## 单张概念视觉验证

### 定位
本模块只负责把**已经确认的空间判断**交给一张单张概念图测试。它不是完整效果图生产系统。

### 启动条件
必须已经确认：
- Dominant Strategy；
- Optional one Borrowed Mechanism；
- Primary Route；
- 2–4 Selected DNA；
- 与视觉直接相关的 KNOWN project facts。

## 01｜Confirmed Strategy
写出 Dominant Strategy。

## 02｜Borrowed Mechanism
`NONE` 或来自另一策略的一个有限机制。

## 03｜Primary Route
仅作为内部一致性检查，不把路线名称当视觉风格词。

## 04｜Selected DNA
只列已确认 DNA。

## 05｜Spatial Locks
只描述必须被看见的空间关系，例如：
- 一个真实城市方向如何进入公共空间；
- 关键流线怎样改变剖面或空间顺序；
- 程序如何交织又保持必要边界；
- 地面如何连续到入口或公共平台。

## 06｜Must Not Drift
- 不写 `Zaha Hadid style`；
- 不写著名项目名；
- 不复制标志性外轮廓、波形屋顶、连续白色外壳或特定尖角；
- 不自动补异形结构、玻璃幕墙、金属板、混凝土壳、无框玻璃等；
- 不引入 Rejected Strategy 或未选 DNA。

## 07｜Single Demonstration Image Prompt
Prompt 只使用：
KNOWN + Dominant Strategy + one Borrowed Mechanism + Selected DNA + verified site/climate/light + 已通过的空间关系。

## 08｜Prompt Fact Lock
输出前逐项扫描材料、结构、立面、开口、墙、屋顶、柱网、桁架、技术构件、表面、景观、家具、种植。  
无法追溯到允许证据的具体项，删除或改写成关系 / 性能语言。

## 09｜Handoff
> 这是一张概念验证图，用于检查当前设计判断进入视觉后是否成立；它不代表完整设计或施工结论。
