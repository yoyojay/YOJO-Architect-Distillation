# AR77-002｜SINGLE IMAGE VISUAL HANDOFF

## 定位

002 的核心不是效果图 Prompt。

本模块只负责：

**把已经确认的 Tadao Ando 方法判断，交给一张概念验证图。**

它不是完整视觉生产系统。

---

# 启动条件

必须已经确认：

- Strategy
- Primary Route
- 4–7 Selected DNA

---

# 输出

## 01｜Confirmed Strategy

## 02｜Period Route

## 03｜Selected DNA

## 04｜Spatial Locks

只描述当前项目必须保留的空间关系，例如：

- protective boundary responds to a real conflict;
- movement includes a justified turn / delay / reveal;
- weather enters through a controlled intermediate zone;
- compressed / released sequence is visible in section;
- natural light has project-specific direction;
- nature is selectively framed;
- topography / existing fabric is respected;
- material supports light, touch, climate, and maintenance.

## 05｜Must Not Drift

必须检查：

- 不复制住吉长屋三段式；
- 不复制光之教堂十字光；
- 不复制水御堂莲花池下行；
- 不复制地中美术馆三角庭院；
- 不把清水混凝土当默认；
- 不把巨大斜墙当“安藤感”；
- 不新增未经建筑师确认的标志性几何。

## 06｜Single Demonstration Image Prompt

Prompt 应描述：

- current project type;
- actual site / climate facts;
- confirmed boundary / path / section strategy;
- weather / light relation;
- framed nature;
- real users;
- material only when supported by project judgement;
- camera angle that reveals the spatial logic;
- realistic architectural visualization.

禁止出现：

- `in the style of Tadao Ando`
- `Azuma House inspired`
- `Church of the Light style`
- `Chichu Art Museum style`
- `Water Temple style`

## 07｜Negative Constraints

只写与当前项目防漂移直接相关的约束。

## 08｜Handoff Note

固定说明：

> 这是一张概念验证图，用于检查当前设计判断进入视觉后是否成立，不代表完整效果图体系。后续整套视觉生产请进入建筑师原有可视化流程，或交给专门的视觉系统，例如 Zeus96。
