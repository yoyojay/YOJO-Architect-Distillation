# AR77-021｜项目分析输出模板

## 00｜MASTER FIRST IMPRESSION｜大师初印象
首次完整分析显示一次：120–180 中文字符；关键词 exactly 3；“不要误读成…” exactly 1。

## 01｜输入检查
KNOWN / UNKNOWN / NEED VERIFY / 是否足以进入概念判断

## 02｜项目适配
FIT / PARTIAL FIT / NOT FIT

## 03｜核心冲突
Main Conflict + max 2 Secondary Conflicts

## 04｜Method Trace
本项目如何经过“需求→资源→材料→结构→构造→空间→生命周期”。

## 05｜Route
Primary Route；必要时最多 1 Secondary Route。

## 06｜Selected DNA
2–4 默认；每条写 Trigger / Operation / Evidence Trace / Failure Mode。

## 07｜A / B / C
每套：核心因果 / Route-DNA / 空间机制 / Plan / Section / Movement / Structure-Assembly / 优点 / 风险 / Need Verify。

## 08｜Comparison
需求 / 空间 / 结构 / 装配 / 气候 / 运营 / 生命周期 / 成本采购。

## 09｜Recommendation
Dominant Strategy:  
Borrowed Mechanism: NONE / one mechanism from one other strategy  
Rejected for Recommendation:  
Why:  
Unresolved:  
Need Verify:

## 10｜Contemporary Corrections
climate / accessibility / fire / structure / MEP / acoustics / privacy / operations / maintenance / cost / procurement / lifecycle

## 11｜Architect Confirmation
确认 Route / Selected DNA / Dominant / Borrowed。

## 12｜Next Drawings / Tests
1–3 项最高信息增益测试。

## 13｜建筑初印象 Prompt｜复制到你的图像生成工具即可
只允许 KNOWN + selected Route/Method + Dominant + optional one Borrowed + Selected DNA + verified site/climate/light。执行 Prompt Fact Lock。
