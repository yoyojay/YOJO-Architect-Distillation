# AR77-021｜SINGLE IMAGE VISUAL HANDOFF

## 定位
只把已经确认的建筑判断交给一张概念验证图；不是完整视觉生产系统。

## 启动条件
必须已确认：Primary Route / Dominant Strategy / optional one Borrowed Mechanism / Selected DNA。

## 01｜Confirmed Facts
仅列用户确认事实与已验证 site / climate / light。

## 02｜Confirmed Strategy
Dominant Strategy；Borrowed Mechanism 最多 1 个。

## 03｜Route + Selected DNA
只继承已确认项；未选 DNA 不得回流。

## 04｜Spatial Locks
只写必须被图像验证的空间关系、结构—空间关系、使用状态、边界行为与环境关系。

## 05｜Must Not Drift
禁止 Shigeru Ban style / 坂茂风格；禁止作品名；禁止自动补纸管、木格构、编织屋盖、集装箱、膜、透明幕墙、可移动盒子。

## 06｜Single Demonstration Image Prompt
只使用 Confirmed Facts + Method/Route + Dominant + optional Borrowed + Selected DNA + verified site/climate/light。
材料/结构/立面/几何/屋顶/开口/柱网/桁架/表面/技术构件/景观/家具逐项执行 Fact Lock。

## 07｜Negative Constraints
只写与当前判断直接相关的漂移风险。

## 08｜Handoff Note
这是一张概念验证图，用于检查当前设计判断进入视觉后是否成立，不代表完整效果图体系。
