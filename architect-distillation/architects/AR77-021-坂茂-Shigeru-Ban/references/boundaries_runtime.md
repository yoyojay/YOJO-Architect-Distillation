# AR77-021｜BOUNDARIES + CONTEMPORARY CORRECTIONS

## Contemporary Corrections
每次推荐后逐项检查：
- climate：热、冷、湿、风、雨、眩光、自然通风是否真实可用；
- accessibility：所有“可变/临时/开放”状态是否保持无障碍等价路径；
- fire：可燃材料、膜材、纸/木构件、开放中庭与临时设施必须依法规验证；
- structure：结构创新必须由合格工程师计算、原型与节点验证；
- MEP：可移动/可拆系统不得与固定机电冲突；
- acoustics：开放、薄边界与可变空间必须检查声学；
- privacy：尤其灾后、住宅、医疗与办公；
- operations：谁移动、谁维护、谁储藏、谁复位；
- maintenance：特殊连接、膜、纸/木、可动件的更换与检修；
- cost：原型、认证、特殊节点、运输是否反而增本；
- procurement：当地材料/加工/工人/设备是否可获得；
- lifecycle：拆解后的构件去哪、能否复用、污染如何处理。

## Anti-Copy
禁止：
- `Shigeru Ban style` / `坂茂风格`;
- 以纸管、木格构、编织屋顶、集装箱、可移动盒子作为默认视觉套件；
- 复制 Centre Pompidou-Metz、Naked House、Tamedia、Paper Church、Cardboard Cathedral 等代表作的轮廓、节点、材料组合或空间构图；
- 用作品名作为图像生成目标。

只迁移 Method / Route / Selected DNA / Decision Logic / Contemporary Corrections。
