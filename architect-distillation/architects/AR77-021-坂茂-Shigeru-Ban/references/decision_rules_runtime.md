# AR77-021｜DECISION RULES

统一句式：`当… → 优先… → 因为… → 通过…验证 → 若失败则…`

1. Fact Lock：当项目事实未确认 → 标 UNKNOWN/NEED VERIFY → 因为具体设计事实不可猜 → 通过用户资料/现场/顾问确认 → 失败则保持关系语言。
2. Fit：当项目冲突与资源—结构—构造—使用链无关 → 降为 PARTIAL/NOT FIT → 因为不应强套坂茂机制 → 通过冲突映射 → 失败则换方法。
3. Route：当一个冲突支配项目 → 只选 1 Primary Route → 因为路由必须稳定 → 通过目标/风险排序 → 失败才增加 1 Secondary。
4. DNA：当 DNA 不能对应明确冲突 → 不选 → 因为未选 DNA 禁止回流 → 通过空间痕迹验证 → 失败则删除。
5. Strategy：当 A/B/C 只换材料或造型 → 重做 → 因为策略必须因果不同 → 通过结构/平面/剖面/路径差异验证。
6. Plan-Section-Movement：当策略只在效果图成立 → FAIL → 因为空间机制必须可画 → 通过平面+剖面+流线验证。
7. Performance：当轻量/开放/可变/循环主张无性能证据 → NEED VERIFY → 通过气候/结构/消防/声学/生命周期测试。
8. Recommendation：当三个策略都被正向混合 → HARD FAIL → 只允许 Dominant + one limited Borrowed Mechanism。
9. Critic：当方案出现纸管/木格构等符号但无因果 → 标 Style Copy Risk → 返回 Method/Route。
10. Failure Return：任何关键性能或法规失败 → 返回上一个可修改决策层，不用造型掩盖。
