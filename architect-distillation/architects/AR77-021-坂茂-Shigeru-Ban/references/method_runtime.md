# AR77-021｜坂茂 Shigeru Ban｜METHOD RUNTIME

## Evidence status
本 Runtime 只把 KNOWN 与 SUPPORTED INTERPRETATION 纳入方法。主要公开证据包括：坂茂建筑设计官方项目档案、Voluntary Architects’ Network (VAN) 项目档案、2014 Pritzker Prize 官方资料。客户 Runtime 不包含内部 Source Ledger。

## Method Kernel
`真实需求与尊严 → 约束/资源盘点 → 材料可用性 → 结构原理 → 构造与装配 → 空间开放/变化 → 气候与感知 → 可拆/复用/维护 → 现实校正`

### M1｜从问题与人开始，而不是从“高级材料”开始
KNOWN：Pritzker 官方资料强调他持续“倾听为之工作的人”，并把灾后使用者、私人客户与公众置于同一专业责任中。VAN 的 PPS 直接以避难所隐私与生活条件为问题。
执行：先定义人的基本需要、运营时限、隐私、尊严、可达与安全，再讨论形式。

### M2｜把材料当作能力，不当作身份
KNOWN：纸管、木、集装箱、织物及其他常见材料被反复实验；Tamedia、Pompidou-Metz 等项目显示木结构也并非单一视觉套路。
执行：先问本项目材料的可获得性、重量、加工、运输、连接、法规、复用与生命周期，再决定是否适合成为结构/围护/构件。

### M3｜结构不是后置工程，而是空间生成器
KNOWN：Tamedia 的无钢节点木框架、Pompidou-Metz 的木格构大屋盖、纸管体系都把结构逻辑与空间组织直接绑定。
执行：至少用一张结构—空间剖面或轴测证明“力如何走、空间如何被释放、构造如何装配”。

### M4｜用构造简化换取可建造性
SUPPORTED INTERPRETATION：从纸管救灾、学生/志愿者参与建造、可拆临时工作室与反复迭代的 PPS，可归纳出“降低现场复杂度、让非专家参与、缩短搭建”的持续判断。
执行：优先减少特殊湿作业、不可逆连接与高依赖工种；但不得牺牲法规、耐久或安全。

### M5｜边界应响应使用变化
KNOWN：Naked House 的可移动个人房间、Tamedia 的室内外中间带、Pompidou-Metz 的可开启边界说明“固定墙体”并非默认答案。
执行：只有当运营确实需要变化时，才采用可移动/可开启/可重组机制，并验证声学、隐私、消防、气候与维护。

### M6｜轻量、可拆、复用必须是系统结果
SUPPORTED INTERPRETATION：救灾项目的运输、搭建、拆卸、复用及可回收性与临时建筑实践共同支持这一判断。
执行：若项目声称“轻量/循环”，必须画出构件层级、连接、拆装顺序与去向，不得只用“环保材料”口号。

## Anti-style note
纸管不是坂茂方法的必选材料；木格构、透明边界、大屋顶、可移动房间也都不是默认形式。方法迁移的是“需求—资源—材料—结构—构造—空间—复用”的判断链。
