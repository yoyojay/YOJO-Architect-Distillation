# AR77-038｜PROBLEM ROUTES
## Minoru Yamasaki｜Project-Problem Routing

这些 Route 是 AR77 依据 Yamasaki 的证据建立的 Project-Problem Routes，不是历史阶段，也不是代表作风格分类。

## R1｜SERENE_INSTITUTIONAL_SEQUENCE｜宁静机构 / 空间序列
**Trigger**
- 教育、会议、文化、宗教、医疗 / 办公等环境中，压力、单调或制度感过强；
- 人需要在连续空间中获得停留、转换与心理恢复。
**核心问题**
怎样用可读的空间变化创造宁静与愉悦，而不是靠装饰营造“优雅”。
**Method**
stress / routine map → arrival → threshold → varied rooms / courts → light / shade → pause points → acoustic / operation check。
**主要 DNA**
D01 / D02 / D03 / D05
**适用边界**
校园、会议、文化、宗教、办公机构。
**风险**
过度仪式化、低效率、难维护水景、形式装饰压过真实使用。
**与其他 Route 差异**
由心理恢复 + 空间变化驱动，而不是巨大尺度或工业重复本身驱动。

## R2｜COURTYARD_LANDSCAPE_REFUGE｜庭院 / 景观避难所
**Trigger**
- 城市 / 校园环境需要安静停留、绿荫、微气候或公共聚集；
- 建筑之间的空地比单体外观更重要。
**核心问题**
如何把 landscape / court / water / shade 组织成真实可使用的公共环境。
**Method**
public-use map → climate / shade / wind → sitting / walking → court / planting / water only where justified → building edges → maintenance / accessibility / water budget。
**主要 DNA**
D01 / D02 / D05 / D06
**适用边界**
校园、文化、公共机构、城市综合体。
**风险**
水耗、泄漏、维护、无障碍、安防、热舒适与“空旷广场化”。
**与其他 Route 差异**
由外部公共体验与微气候驱动。

## R3｜LARGE_SCALE_HUMANIZATION｜巨大尺度 / 人本调停
**Trigger**
- 高层、超大综合体、大型办公或展览项目可能产生恐高、压迫、尺度失真或地面层冷漠；
- 大系统不可避免，但需保持 human scale。
**核心问题**
如何让巨大结构 / 体量在人的接近、入口、窗口、地面层和停留距离上仍可被理解与使用。
**Method**
macro-scale constraints → human-scale risk points → ground interface / opening / rhythm / threshold → vertical experience → public realm → safety / performance test。
**主要 DNA**
D01 / D04 / D07 / D08
**适用边界**
高层、总部、混合用途、大型机构。
**风险**
把“human scale”简化成窄窗 / 细柱；高层的消防、结构、幕墙、风环境与运营必须专业验证。
**与其他 Route 差异**
由建筑整体尺度与人体感知之间的冲突驱动。

## R4｜INDUSTRIAL_REPETITION_HUMANIZED｜工业重复 / 体验丰富化
**Trigger**
- 预制、重复构件、标准化、快速建造或批量空间是重要现实条件；
- 项目有“机器单调”风险。
**核心问题**
怎样在保持经济 / 工业逻辑的同时，用节奏、阴影、开合、节点差异和空间序列避免无差别重复。
**Method**
repetition / prefab constraints → component family → structural validity → light / shadow / rhythm → selective variation → manufacturing / tolerance / maintenance test。
**主要 DNA**
D01 / D03 / D05 / D07
**适用边界**
预制公共建筑、学校、办公、展览、模块化 / 重复型项目。
**风险**
把“丰富”变成装饰成本；形式复杂性破坏预制经济。
**与其他 Route 差异**
由工业化与人本体验的冲突驱动。

## R5｜PUBLIC_EXHIBITION_DELIGHT｜公共展示 / 发现体验
**Trigger**
- 科学、博物馆、展览、公共教育或游客型项目需要激发探索；
- 到达、转折、庭院 / 展厅转换和标志性公共空间承担重要认知作用。
**核心问题**
如何让 surprise / delight 服务发现与公共学习，而不是制造视觉奇观。
**Method**
visitor journey → orientation anchors → reveal / pause / exhibit sequence → light / court / outdoor relation → crowd / accessibility / durability test。
**主要 DNA**
D01 / D03 / D04 / D05
**适用边界**
博物馆、科学中心、文化 / 教育展示项目。
**风险**
导向混乱、无障碍不足、标志构件维护成本高、展项更新困难。
**与其他 Route 差异**
由探索 / 学习 / visitor sequence 驱动。

# Route Selection Logic
1. 先写主冲突，再选 Route。
2. Primary Route exactly 1。
3. Secondary Route = NONE 或最多 1。
4. Secondary 必须解决不同但真实的次级冲突。
5. R2 只有 landscape / microclimate / public-stay 问题真实存在时启用；不自动加水。
6. R3 只有巨大尺度 / 高层 / 压迫风险真实存在时启用。
7. R4 只有 prefab / repetition / standardization / speed 真实重要时启用。
8. R5 只有 visitor discovery / exhibition journey 真实重要时启用。
9. 未选 Route 不得回流 Recommendation / Prompt / Handoff。
