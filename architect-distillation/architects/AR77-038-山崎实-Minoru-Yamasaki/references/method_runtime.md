# AR77-038｜METHOD RUNTIME
## Minoru Yamasaki｜Architectural Judgement Kernel

## 0｜Evidence Status

本 Runtime 只允许 `KNOWN` 与 `SUPPORTED INTERPRETATION` 进入 Method / Route / DNA / Rules。

### KNOWN
- 在 1959 年 Smithsonian Archives of American Art 访谈中，Yamasaki 明确提出建筑应建立在 **human experience** 上，而不是抽象形式、技巧、聪明装置或建筑师个人雕塑冲动。
- 同一访谈中，他反复强调建筑应提供 **serenity**、**surprise** 与 **delight**，并以一连串不同庭院、种植、光影和水面体验说明“空间变化”如何对抗机器社会的单调重复。
- 他明确反对为了“动感”而让建筑显得 restless，并主张机器时代的环境需要由宁静的建筑来获得平衡。
- 同一访谈也说明他并不拒绝技术与工业生产；相反，他认为现代机器可以生产丰富的形态，关键是 restraint、sensitivity 与人的体验。
- McGregor Memorial Conference Center 被 NPS 认定为其职业转折点；其平台、庭院、反射池、花园、遮阳构件与会议功能共同形成安静、停留、思考和变化的环境。
- Pacific Science Center 的官方历史记录其快速建造所使用的大量预制 / 预应力混凝土构件，以及工程师 John Christiansen 的协作；同时项目通过庭院、水、平台、光与地标构件建立公共体验。
- Pacific Science Center 当前修复工作显示原庭院在今天必须重新面对 accessibility、water use、maintenance 与 environmental sustainability，说明历史体验机制不能脱离当代性能。
- 9/11 Memorial Museum 记录：Yamasaki 担心原 World Trade Center 高层用户产生恐高，因而把窗洞控制得接近人体肩宽，试图在巨型塔楼中维持可感知的人体尺度。
- NPS 对 McGregor 的资料指出，Yamasaki 认为 World Trade Center 场地和建筑同样重要，并把高低建筑与 plaza / garden space 共同理解为都市中的安静空间。
- Wayne State Reuther Library 保存 Minoru Yamasaki Papers 和 Yamasaki Associates 的职业档案，可作为其工作与言论的一手 / 档案基础。

### SUPPORTED INTERPRETATION
`人的真实体验 / 情绪需求`
→ `识别环境中的混乱、单调、巨大尺度或制度压力`
→ `设定需要的宁静 / 惊喜 / 愉悦强度`
→ `用尺度、序列、停留、庭院 / 景观、光影、结构节奏与技术系统组织体验`
→ `用工业化 / 重复构件实现，但避免机械单调`
→ `在高层 / 大型项目中重新引入 human scale`
→ `通过气候、无障碍、维护、运营与社会后果校正`
→ `最后才锁定形式`

这是 AR77 的 evidence-bounded runtime abstraction，不冒充 Yamasaki 本人提出的固定步骤。

## 1｜Core Judgements

### J1｜HUMAN EXPERIENCE BEFORE ARCHITECTURAL OBJECT
人的体验先于建筑物体。每个关键决策必须能回答人在这里如何到达、停留、观看、工作、学习、休息或感受。

### J2｜SERENITY AS COUNTERBALANCE
宁静是对环境压力的调停，不是空白或极简外观。它可以来自尺度、声环境、遮蔽、庭院、光影、停留距离、边界清晰度与节奏。

### J3｜SURPRISE + DELIGHT THROUGH CHANGE
惊喜与愉悦来自有意义的空间变化、光影变化、开合、庭院序列、视线与停留节奏，而不是奇形怪状。

### J4｜HUMAN SCALE MUST SURVIVE LARGE SYSTEMS
高层、校园、交通 / 展览、办公综合体都要验证入口、窗口、柱距、庭院、地面层与行走距离是否可感知。

### J5｜TECHNOLOGY SHOULD ENABLE RICHNESS, NOT MONOTONY
预制、重复、标准化可以降低成本并加快建造，但必须避免让使用体验变成无差别重复。

### J6｜LANDSCAPE + WATER + COURTYARD ARE EXPERIENCE TOOLS, NOT SIGNATURES
庭院、水、花园只在真实微气候、停留、视线、声环境或公共空间问题存在时启用。

### J7｜STRUCTURAL / ENVELOPE RHYTHM CAN MEDIATE LIGHT + SCALE
重复构件、柱列、遮阳和开口比例可以调节光、阴影与尺度，但必须由结构、围护、气候和使用条件支持。

### J8｜SERENITY WITHOUT SOCIAL REALITY IS INSUFFICIENT
人本体验不能只靠美学承诺；住宅、校园、公共空间、高层和大型机构必须同时检查运营、维护、可达、安全、社会使用和长期成本。
