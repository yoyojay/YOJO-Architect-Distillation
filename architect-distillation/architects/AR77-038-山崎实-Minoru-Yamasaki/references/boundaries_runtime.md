# AR77-038｜BOUNDARIES + CONTEMPORARY CORRECTIONS
## Minoru Yamasaki

## Fit

### FIT
- 项目存在机器化 / 重复 / 巨大尺度与人的体验冲突；
- 教育、文化、机构、办公或公共环境需要心理恢复 / 清晰序列；
- outdoor court / public ground / visitor sequence 是关键；
- 高层 / 大型系统需要 human-scale mediation。

### PARTIAL FIT
- Yamasaki 方法能帮助 human experience / scale / sequence，但项目核心由医疗工艺、复杂基础设施、特殊工业流程、文保等其他专业逻辑主导。

### NOT FIT
- 唯一目标是复制 World Trade Center / McGregor / Pacific Science Center 的形式；
- 只要求 pointed arch / narrow window / thin column / white formalism；
- 项目事实不足却要求具体材料 / 水景 / 结构 / 窗形。

## Contemporary Corrections

### Climate
庭院、遮阳、玻璃 / 实体比例、水体、深立面都必须按真实 sun / heat / wind / rain / glare / energy 校正。

### Accessibility
平台、台阶、下沉庭院、桥式入口、窄开口与复杂序列必须提供平等、直观、非边缘化的无障碍路径。

### Fire / Life Safety
高层、展览、会议、校园和大型公共项目必须校验疏散、烟控、防火分区、出口宽度与高峰人流。

### Structure
细柱、深构件、预制立面、窄开口、高层外柱系统不得从历史项目推断；必须工程验证。

### MEP
深立面、无窗 / 受控开口空间、庭院、高层核心和展示空间必须验证通风、空调、喷淋、电力、检修与控制。

### Acoustics
serenity 不能只靠视觉；办公室、会议、宗教、展览、庭院都要校验背景噪声、混响与私密性。

### Privacy
高密办公、教育、住宅 / 机构与庭院共享空间必须校验视线、声学与行为边界。

### Operations
水景、花园、展览序列、地面公共空间、高层 plaza 必须有日常 / 高峰 / 夜间 / 安保 / 清洁模式。

### Maintenance
预制构件、复杂 screen、池水、防水、喷泉、石材 / 金属表皮与高层外墙必须有替换 / 检修路径。

### Cost
delight 不能靠昂贵装饰堆积；必须比较空间价值、维护与生命周期成本。

### Procurement
工业化构件只有在本地制造、运输、吊装、容差和供应链成立时才采用。

### Lifecycle
水耗、材料替换、表皮耐久、适应性、embodied carbon 与运营能耗必须进入判断。

### Social / Housing / Institutional Governance
若项目涉及公共住房、学校、校园或大型公共机构：
- 不得把“优美 / 宁静”视为社会成功的充分条件；
- 必须检查管理、维护资金、居民 / 使用者参与、安全、服务、交通、社会支持与长期运营；
- 建筑不能替代公共政策，但应避免制造隔离、死角、不可维护公共空间。

### High-Rise Human Experience
高层的 human scale 必须同时校验：
- wind at ground
- elevator waiting / travel
- refuge / evacuation
- facade safety
- window / view comfort
- public ground access
- security / operations

而不是只控制窗口比例。

## Professional Boundary

本 Skill 可做 early-stage judgement、Route / DNA、A/B/C、scheme critic 与 next tests；
不能替代持证建筑师、结构、消防、MEP、幕墙、声学、无障碍、景观 / 水景工程、造价、运营、社会住房政策或当地法规专业责任。
