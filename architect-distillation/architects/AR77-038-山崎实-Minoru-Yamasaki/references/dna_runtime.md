# AR77-038｜DESIGN DNA RUNTIME
## Minoru Yamasaki

## Selection Rule
- **D01 mandatory**
- 再选 1–3 个必要 DNA
- 总量默认 **2–4**
- 未选 DNA 不得回流 Strategy / Recommendation / Keep / Next / Prompt / Handoff

## D01｜HUMAN_EXPERIENCE_FIRST｜人的体验先行
**判断含义**：建筑从人在空间中的经历出发，而不是从抽象形式开始。
**Trigger**：所有完整项目分析。
**Spatial Operation**：建立 arrival / movement / pause / view / light / stress / social-use map。
**适用边界**：全部项目。
**Failure Mode**：只写“人本”口号，没有行为或空间证据。
**可验证空间痕迹**：每个关键决定可指向真实使用场景。

## D02｜SERENITY_AS_COUNTERBALANCE｜宁静作为调停
**判断含义**：通过尺度、边界、声环境、遮蔽、光与停留对抗混乱 / 压力。
**Trigger**：环境或程序有明显噪声、速度、密度、制度压力。
**Spatial Operation**：识别 overstimulation → 增加受控停留 / 缓冲 / 视觉安定点。
**适用边界**：校园、办公、医疗、文化、公共机构。
**Failure Mode**：把宁静误成空白极简或无人空间。
**可验证空间痕迹**：路径中存在可停、可坐、可恢复的真实位置与声 / 光改善。

## D03｜SURPRISE_THROUGH_SPATIAL_CHANGE｜变化中的惊喜
**判断含义**：惊喜来自连续体验中的差异，而非奇形怪状。
**Trigger**：长路径、重复空间、展览 / 教育体验容易单调。
**Spatial Operation**：改变尺度、光、视线、开合、庭院 / 室内关系或停留节点。
**适用边界**：文化、教育、办公、公共展示。
**Failure Mode**：戏剧化路径、无意义转折或视觉噱头。
**可验证空间痕迹**：至少两处体验变化与真实活动 / 导向有关。

## D04｜HUMAN_SCALE_MEDIATION｜人体尺度调停
**判断含义**：在高层 / 大体量 / 大跨度中保留可感知尺度。
**Trigger**：建筑整体尺度明显超过日常人体尺度。
**Spatial Operation**：重点校准 ground interface / entry / opening / column rhythm / threshold / seating / viewing distance。
**适用边界**：高层、大型机构、展览、交通。
**Failure Mode**：自动复制窄窗、细柱、拱券。
**可验证空间痕迹**：从人眼高度和步行距离看，入口与边界可读。

## D05｜LIGHT_SHADOW_RHYTHM｜光影 / 节奏
**判断含义**：结构 / 围护重复可以通过真实光影与节奏丰富体验。
**Trigger**：重复构件、深立面、遮阳或庭院边界影响空间。
**Spatial Operation**：结构 / 围护职责 → shade / light → rhythm → human perception。
**适用边界**：公共、办公、校园、展示。
**Failure Mode**：把装饰格栅 / 尖拱当作光影策略。
**可验证空间痕迹**：剖面与日照验证节奏的光热作用。

## D06｜COURTYARD_REFUGE｜庭院 / 外部停留
**判断含义**：外部空地可成为城市 / 校园中的恢复、交往与过渡空间。
**Trigger**：项目需要 outdoor pause / social space / microclimate relief。
**Spatial Operation**：shade / seating / planting / water only where justified / edges / paths。
**适用边界**：公共、校园、文化、办公。
**Failure Mode**：自动水景；高水耗、维护差、空场、无障碍不足。
**可验证空间痕迹**：日常使用、气候舒适、维护与可达同时成立。

## D07｜STRUCTURAL_REPETITION_WITH_RICHNESS｜结构重复中的丰富度
**判断含义**：重复与预制不是单调的同义词；构件可以在同一规则内产生阴影、深度和层次。
**Trigger**：prefab / repetitive bay / industrialized construction。
**Spatial Operation**：component family + structural validity + selective variation + tolerance control。
**适用边界**：重复型 / 预制项目。
**Failure Mode**：为了“丰富”增加无结构 / 无性能装饰。
**可验证空间痕迹**：构件图、节点、制造与空间效果可相互追溯。

## D08｜GROUND_LEVEL_RELIEF_IN_LARGE_COMPLEX｜大型项目的地面层缓冲
**判断含义**：巨大建筑必须在 ground level 重新提供可停留、可进入、可理解的公共尺度。
**Trigger**：高层 / 大型综合体 / 大校园。
**Spatial Operation**：macro mass → human approach → plaza / arcade / garden / lobby only as justified → entrances / services / public paths。
**适用边界**：高层、总部、城市综合体。
**Failure Mode**：空旷 corporate plaza；风环境、安防、运营失败。
**可验证空间痕迹**：人行路径、入口、停留、风 / 日照 / 夜间运营均可验证。

# DNA Selection Logic
1. D01 mandatory。
2. 再选 1–3 个，总量 2–4。
3. D02 只在真实 overstimulation / stress condition 存在时选。
4. D03 只在序列 / 重复单调是问题时选。
5. D04 只在 scale conflict 真实存在时选。
6. D05 必须有 light / shadow / envelope / structure 的实际条件。
7. D06 只有 outdoor refuge / microclimate / public-stay 需求存在时选；不自动加水。
8. D07 只有 industrial repetition / prefab 条件存在时选。
9. D08 只有 large complex / tower / campus 的 ground-level problem 存在时选。
10. 未选 DNA 禁止以“细节”回流。
