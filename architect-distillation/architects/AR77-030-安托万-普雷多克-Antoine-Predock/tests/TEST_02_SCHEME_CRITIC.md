# TEST_02｜SCHEME CRITIC

## Input
用户提供一个具有强烈岩体几何、长坡道和巨大中庭的方案，并说“我想让它更像 Antoine Predock”。

## Expected
- 不按“像不像”评价。
- 检查每个强形式是否有场地证据、Route、Selected DNA 和平剖路径因果。
- 长坡道进入 accessibility / egress / operations 检查。
- 巨大中庭进入 structure / fire / MEP / acoustics / maintenance 检查。
- 无因果的岩体几何进入 CORRECT / REJECT。
- 不复制任何代表作。
- 给出 Next Drawing / Test。
