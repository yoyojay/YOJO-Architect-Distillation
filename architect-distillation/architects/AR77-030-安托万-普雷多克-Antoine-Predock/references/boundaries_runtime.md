# AR77-030｜Boundaries + Contemporary Corrections Runtime

## 1｜Fit Boundary

### FIT
项目允许至少一个下列问题成为主要空间因果：
- 场所/气候/地形/生态关系；
- 身体移动与空间序列；
- 公共建筑与地景/城市公共领域的连接；
- 有真实证据的地质、历史或文化层积。

### PARTIAL FIT
Predock 方法可帮助其中一部分，但项目的主要约束由高度标准化流程、极窄预算、纯技术设备或固定既有壳体决定。

### NOT FIT
如果项目明确要求：
- 快速套用固定风格或代表作外形；
- 主要目标只是生成“Predock-like”视觉；
- 无场地信息且拒绝补充任何关键事实；
- 用任意象征替代真实历史/文化研究；
则不应强行使用该 Skill。

## 2｜Contemporary Corrections

### Climate
- 验证太阳、风、热、雨雪、排水和热舒适；
- 戏剧性明暗不能造成不可控眩光或过热；
- 地景动作不能破坏真实水文与生态。

### Accessibility
- 所有“旅程”必须提供连续、尊严一致的可达路径；
- 不把无障碍路线降级为后台替代路径；
- 长坡道、标高变化、休息距离与导向必须校核。

### Fire / Life Safety
- 复杂路径、巨大空间、长距离流线必须验证疏散距离、出口可见性、烟控和消防分区；
- 叙事路径不能与生命安全冲突。

### Structure
- 不把岩体感、悬挑、巨墙或长跨当作默认；
- 结构应与实际跨度、地震/风荷载、材料供应和施工能力共同发展。

### MEP
- 大空间、复杂剖面与强地景整合可能增加系统路由、维护和检修难度；
- 机电空间必须在概念阶段保留真实位置。

### Acoustics
- 高大公共空间、硬表面与连续流线可能产生混响；
- 反思/学习/展览/会议节点需要分别验证声环境。

### Privacy / Security
- 视点与公共连续性不能侵入私密、后台、安全或受控功能；
- 公共项目要明确收费、夜间和独立运营边界。

### Operations
- 每个停顿、公共节点和路径事件必须对应真实运营场景；
- 不以“空间体验”替代人员、排队、后勤、清洁和活动转换逻辑。

### Maintenance
- 复杂几何、难接近界面、特殊排水和高位空间必须验证检修；
- 不能为了形象制造不可维护细部。

### Cost / Procurement
- 概念阶段就识别非标准构件、复杂模板、定制结构和运输吊装风险；
- 若预算或供应链不支持，应保留空间因果、简化形式表达。

### Lifecycle / Carbon
- 地景化厚重构造若导致高材料量，需评估 embodied carbon；
- 优先保留场所、路径与公共关系，而不是把“重量感”当方法必需品。

### Cultural / Community Validation
- 涉及原住民、宗教、创伤、纪念或地方文化时，不由建筑师单向宣布意义；
- 将叙事、象征和场地解释送回相关社区与利益相关者验证。

## 3｜Professional Boundary

本 Skill 可做：
- 前期问题定义；
- Route / DNA 选择；
- 平面—剖面—movement 逻辑；
- 三案策略；
- 概念审查；
- 风险识别；
- 下一步图纸 / 测试。

本 Skill 不替代：
- 注册建筑师最终责任；
- 结构、消防、MEP、声学、无障碍、法规顾问；
- 成本、采购、施工与生命周期专业评估；
- 文化/历史/社区主体的授权与解释权。
