# AR77-030｜Problem Routes Runtime

## Route 01｜PLACE_FORCE｜场所力路由

**Trigger**  
场地的地形、气候、水文、生态、到达或城市边缘关系明显决定项目成败。

**核心问题**  
建筑应如何从真实环境力中获得组织，而不是把一个预设对象放进场地。

**Method**  
先做场所线索图谱，再把最强的 2–3 个力转成朝向、地面、阈值、遮蔽、开放、路径或剖面关系。

**主要 DNA**  
D01 场所线索图谱；D02 环境力校准；视项目可选 D05 视点累积或 D07 公共地景连续。

**适用边界**  
场地信息必须足够。气候或生态数据缺失时只能先提出验证，不得凭地区印象补写。

**风险**  
把“场所回应”误写成地方材料拼贴；为了地景意象牺牲可达性、结构、排水或运营。

**与其他 Route 的差异**  
主因是外部场地力，不是叙事旅程，也不是历史象征。

---

## Route 02｜CHOREOGRAPHIC_JOURNEY｜身体旅程路由

**Trigger**  
博物馆、文化、教育、公共或复杂混合项目中，使用者如何逐步经历空间是核心问题。

**核心问题**  
如何让移动、停顿、转向、聚集与视点变化构成有意义的空间序列，而不是普通走廊串房间。

**Method**  
先画路径事件而非形式：arrival → threshold → compression/release → pause → orientation → encounter → exit；再用平剖关系验证。

**主要 DNA**  
D03 编舞路径；D05 视点累积；D06 停顿—释放节奏；必要时 D08 意外发现。

**适用边界**  
路径不能为了戏剧性而过长、迷失或排斥行动不便者；必须同时满足清晰导航、疏散与运营。

**风险**  
把坡道、长路径或戏剧性剖面当作 Predock 符号；体验叙事压过功能效率。

**与其他 Route 的差异**  
主因是身体在时间中的经历，不是地质/文化记忆本身。

---

## Route 03｜CIVIC_LANDSCAPE｜公共地景路由

**Trigger**  
市政、校园、文化或社区项目需要把建筑内部公共性与广场、街道、校园、河岸或地景连接起来。

**核心问题**  
建筑如何成为公共生活的地形与接口，而不是一座孤立机构。

**Method**  
把到达、公共地面、共享大厅、外部停留、城市/校园边界和主要公共功能作为一个连续系统分析；再确定哪些界面必须开放、遮蔽、受控或分时运行。

**主要 DNA**  
D01 场所线索图谱；D07 公共地景连续；D03 编舞路径；必要时 D05 视点累积。

**适用边界**  
安全、夜间关闭、隐私、声学和独立运营必须明确；公共性不能只靠“开放感”。

**风险**  
用过度巨构或象征性姿态代表公共性；忽略日常管理与可维护性。

**与其他 Route 的差异**  
主因是机构与公共领域的关系，不是个人化的空间旅程。

---

## Route 04｜STRATA_MEMORY｜层积记忆路由

**Trigger**  
场地或项目确有可验证的地质、历史、文化、纪念或集体记忆层次，而且这些层次对项目意义关键。

**核心问题**  
怎样把“时间的厚度”转译为空间关系，而不是把历史做成表面图案或任意象征。

**Method**  
识别真实层次 → 判断哪些应该保留、显露、跨越、对照或留白 → 用剖面、阈值、路径和视点建立现在与过去的关系。

**主要 DNA**  
D04 深时间剖面；D03 编舞路径；D06 停顿—释放节奏；必要时 D05 视点累积。

**适用边界**  
没有可靠历史/文化证据时不可启用；涉及原住民、宗教、创伤或社区记忆时必须由相关群体参与验证。

**风险**  
象征过度、文化挪用、把复杂历史压缩成单一视觉隐喻。

**与其他 Route 的差异**  
主因是可验证的时间/记忆层次，而不是一般性的场所环境力。

---

# Route Selection Rule

1. 先选 **1 个 Primary Route**。
2. 只有当项目确有第二个不可回避的核心冲突时，才允许 **1 个 Secondary Route**。
3. Secondary Route 只能贡献一个明确机制，不能与 Primary Route 并列成双主导。
4. 若四个 Route 都没有可靠 Trigger，输出 `NOT FIT` 或 `PARTIAL FIT`，不要为了完整性强行路由。
5. 未选择 Route 不得在 Recommendation 或 Prompt 中回流。
