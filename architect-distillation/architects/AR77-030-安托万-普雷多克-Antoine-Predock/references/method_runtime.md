# AR77-030｜Antoine Predock Method Runtime

## 1｜Method Kernel

Antoine Predock 的可迁移判断不是一种沙漠造型，而是一条因果链：

`读取场所线索`
→ `区分环境力 / 文化痕迹 / 深时间`
→ `确定人与场地如何接触`
→ `把身体移动组织成可经历的路径`
→ `通过视点、停顿、明暗与地平关系逐步展开`
→ `让形式从这些关系中出现`
→ `用当代性能与运营条件校正`

核心原则：

1. **Place before object**  
   不先寻找一个“建筑物形象”。先研究场地如何工作、如何被记忆、如何被感知。

2. **Forces are evidence**  
   风、太阳、地形、水、生态、到达、文化与历史痕迹可以成为设计因果；它们不是装饰性故事。

3. **Architecture is experienced in motion**  
   空间判断必须进入身体路径：接近、转向、抬升、下降、停顿、远眺、聚集、退出。

4. **Deep time can thicken the present**  
   当场地确有地质、历史或文化层次时，可把这些层次转成剖面、阈值、路径或视点关系；没有证据时不得虚构“古老记忆”。

5. **Unexpected does not mean arbitrary**  
   意外性应来自真实路线、视点、地形或程序关系的转折，而不是为奇观而制造复杂几何。

6. **Form is a consequence, not a premise**  
   在场所、路径、性能和运营关系尚未成立前，不锁定岩体、峡谷、塔、折面、巨墙等名词化形式。

## 2｜Operational Sequence

每次完整分析按下列 architect-specific sequence 工作：

### Step A｜Read the Territory
至少识别：
- topography / ground;
- sun / wind / water / climate;
- ecological traces;
- arrival and horizon relationships;
- existing cultural / social / historical traces;
- what is KNOWN versus what is only a possible interpretation.

### Step B｜Find the Project's Primary Encounter
判断项目最需要哪一种“人与场所的相遇”：
- 以环境适应为主；
- 以身体旅程为主；
- 以公共生活与城市/地景连接为主；
- 以历史、记忆或深时间的空间化为主。

据此选择 Problem Route。

### Step C｜Select 2–4 DNA
默认只选必要 DNA。未选 DNA 不得在后文以“辅助机制”重新出现。

### Step D｜Build Plan–Section–Movement Causality
每个空间动作必须说明至少一条：
- 平面上改变了什么关系；
- 剖面上改变了什么关系；
- 人的移动与视点如何改变；
- 环境性能如何因此改变。

### Step E｜Generate A / B / C
三案必须由不同的主因驱动，而不是同一形体的三个版本。

### Step F｜Correct for Today
把象征、几何、路径与地景动作送入 climate / accessibility / fire / structure / MEP / acoustics / privacy / operations / maintenance / cost / procurement / lifecycle 检查。

## 3｜What Is Not Transferable by Default

下列内容不是 Predock Method 的默认设计指令：

- 沙漠色材料；
- 厚重混凝土；
- 岩体般体量；
- 峡谷式中庭；
- 折面屋顶；
- 地景化巨构；
- 塔或纪念性尖顶；
- 某种固定铜、石、玻璃组合；
- 任何代表作的轮廓、坡道、墙体、开口或材料组合。

它们只有在当前项目事实、选定 Route/DNA、Dominant Strategy 与工程条件共同支持时才可能出现。

## 4｜Evidence Discipline Inside Runtime

本客户 Runtime 不携带完整 Source Archive，但方法运行时必须保持证据分级：

- `KNOWN`：用户项目事实或本 Runtime 已蒸馏确认的建筑师方法；
- `SUPPORTED INTERPRETATION`：由 Method / Route / DNA 推导的可迁移判断；
- `NEED VERIFY`：合理但项目证据不足；
- `UNKNOWN`：没有依据。

只有前两类可以成为策略核心。`NEED VERIFY` 可以进入风险和下一步测试，不能伪装成事实。
