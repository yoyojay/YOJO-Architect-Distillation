# AR77-030｜Antoine Predock Design DNA Runtime

> DNA 是可迁移的判断机制，不是造型词汇。每个项目默认选择 **2–4 个**。

## D01｜场所线索图谱｜Territory Clue Map
**判断含义**：把场地理解为一组可被读取的物理、生态、社会与文化线索，而非空白基地。  
**Trigger**：场地关系明显影响概念方向。  
**Spatial Operation**：把地形、到达、日照、风、水、生态、主要视域、现存路径与文化痕迹叠加，找出需要响应的主力。  
**适用边界**：数据不足时只记录 UNKNOWN / NEED VERIFY。  
**Failure Mode**：把“地域性”缩成当地材料或视觉符号。  
**可验证空间痕迹**：总平与剖面能指出每个关键动作对应哪条场地证据。

## D02｜环境力校准｜Environmental Force Calibration
**判断含义**：把太阳、风、热、雨、水与生态约束变成空间与性能决策。  
**Trigger**：气候暴露、室外活动、地形排水或生态敏感性重要。  
**Spatial Operation**：以方向、遮蔽、开放深度、过渡空间、地面和路径位置回应已验证环境条件。  
**适用边界**：不替代专业气候模拟、排水或生态评估。  
**Failure Mode**：把气候叙述变成造型借口。  
**可验证空间痕迹**：日照/风/雨图与平剖决策可以一一对照。

## D03｜编舞路径｜Choreographic Path
**判断含义**：建筑不是静态物体，而是在时间中被身体经历的一连串事件。  
**Trigger**：到达、游览、学习、展览或公共体验的顺序重要。  
**Spatial Operation**：组织接近、阈值、转向、抬升/下降、停顿、相遇和离开，并让路径与空间事件互相解释。  
**适用边界**：必须满足可达、导航、疏散和运营效率。  
**Failure Mode**：为了“旅程感”制造冗长坡道或迷宫。  
**可验证空间痕迹**：平面与剖面可画出连续路径事件，不靠效果图说明。

## D04｜深时间剖面｜Deep-Time Section
**判断含义**：当场地确有地质、历史或文化层积时，用剖面让不同时间层发生关系。  
**Trigger**：遗址、纪念、旧城、地质地貌或长期场地记忆是真实项目条件。  
**Spatial Operation**：通过埋入、显露、跨越、切开、保留、对照或留白组织不同层次。  
**适用边界**：文化/历史意义必须被验证。  
**Failure Mode**：凭空制造“古老感”或沉重材料。  
**可验证空间痕迹**：剖面可以标出真实层次、介入位置及其因果。

## D05｜视点累积｜Accumulated Vantage Points
**判断含义**：意义来自移动中连续变化的观察位置，而不是一个唯一正面。  
**Trigger**：场地有地平、城市天际、公共活动、景观或内部事件值得逐步揭示。  
**Spatial Operation**：校准开合、转角、标高和停留点，使不同视点承担不同信息。  
**适用边界**：视线不能牺牲隐私、眩光控制或功能布置。  
**Failure Mode**：为“景观框景”堆砌任意开口。  
**可验证空间痕迹**：路径图上能标注关键视点与所揭示关系。

## D06｜停顿—释放节奏｜Pause / Release Rhythm
**判断含义**：旅程需要压缩、停顿、聚集、释放与再定位，而非持续戏剧化。  
**Trigger**：项目存在学习、反思、等候、社交或仪式性节奏。  
**Spatial Operation**：在关键路径中设置尺度、声学、光线或视域不同的停顿节点，并与下一段路径形成清晰关系。  
**适用边界**：节点必须服务真实使用，不做纯舞台布景。  
**Failure Mode**：空间过度纪念化，日常功能被叙事压制。  
**可验证空间痕迹**：程序表、路径图和剖面同时能解释停顿发生的原因。

## D07｜公共地景连续｜Civic Landscape Continuum
**判断含义**：公共建筑可把室内公共空间与街道、广场、校园或地景组织成连续公共领域。  
**Trigger**：公共可达性、机构开放性和城市/校园关系是核心目标。  
**Spatial Operation**：把入口、外部停留、共享空间、公共服务和主要地景连接为可读的公共序列。  
**适用边界**：夜间、安全、收费、管理、噪声和独立运营必须校正。  
**Failure Mode**：把“开放”当无边界，导致管理冲突。  
**可验证空间痕迹**：开放时段图、公共/受控边界图与路径图一致。

## D08｜意外发现｜Calibrated Discovery
**判断含义**：建筑旅程可以包含出乎意料的空间发现，但意外必须从真实关系中产生。  
**Trigger**：项目需要探索、好奇或层层发现，而不是一眼看完。  
**Spatial Operation**：通过路径偏转、视点延迟、局部遮蔽、标高变化或程序邻接制造被校准的发现。  
**适用边界**：不能损害导航、无障碍或安全。  
**Failure Mode**：把复杂几何本身当“意外”。  
**可验证空间痕迹**：每个发现点都能追溯到路径、视点、程序或场地逻辑。

# DNA Selection Logic

- 默认选择 **2–4 个 DNA**，只选必要项。
- Primary Route 的主要 DNA 优先。
- 对 `FIT` 项目，通常至少包含：
  - 1 个场所/环境/时间证据 DNA：D01 / D02 / D04；
  - 1 个体验/移动 DNA：D03 / D05 / D06 / D08。
- 若项目不需要上述两类同时出现，不强行选择；应重新判断 Fit 或 Route。
- D04 仅在真实层积证据存在时可选。
- D07 仅在公共领域关系确实是项目核心时可选。
- 未选 DNA 不得在 Strategy、Recommendation、Critic、Prompt 或 Handoff 中回流。
