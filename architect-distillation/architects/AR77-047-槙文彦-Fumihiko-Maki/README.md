# AR77-047｜Fumihiko Maki（槙文彦）Agent Skill
## Callable Runtime v1.0

### 开始使用
直接描述真实建筑项目，或打开并填写 `AR77_PROJECT_INPUT_FORM_v1.0.md` 后发到对话中。
首次完整分析会展示 `MASTER FIRST IMPRESSION｜大师初印象`，随后依次执行：
`KNOWN/UNKNOWN/NEED VERIFY → Fit → 3–5 Conflicts → Method → Route → DNA → A/B/C → Comparison → Recommendation → Contemporary Corrections → Architect Confirmation → 1–2 Next Tests → 建筑初印象 Prompt`。

资料不足，每轮只问 1–3 个关键问题。

### 迁移的判断，不是风格
- 如何判断整体与多个建筑 / 功能之间的 Linkage；
- 多期开发能否维持可用公共空间与运营；
- 街道到内部的阈值和城市纵深；
- 研究协作中的可见性与隐私；
- 文化设施的公共共享、功能自治与采光；
- 高层建筑的步行街道责任。

特别防止从 Hillside Terrace、Spiral、MIT Media Lab、Aga Khan Museum 或 4 WTC 复制外观。

### Method Authorship
1960 `Group-Form` 与 Masato Ohtaka 合作；1964 `Linkage` 研究与 Jerry Goldberg 合作。Maki and Associates / 项目工程、执行建筑师的协作必须保留。

### 路由与 DNA
6 条 **Project-Problem Routes**，不是历史分期；10 项候选 DNA 中 D01 强制，再选 2–3 项必要机制，总数 3–4。A/B/C 是因果不同的项目替代方案。Recommendation 只能有单一 Dominant，最多借用另一个方案的一个有限机制。

### 单图交接
只有策略明确确认后才启用 `assets/SINGLE_IMAGE_VISUAL_HANDOFF.md`，不得在视觉化时补充项目事实。

### 交付边界
仅包含可调用 Runtime，不含生产工厂研究、内部 Source Ledger、Benchmark、内部 QA、Carousel / Publishing Factory。
