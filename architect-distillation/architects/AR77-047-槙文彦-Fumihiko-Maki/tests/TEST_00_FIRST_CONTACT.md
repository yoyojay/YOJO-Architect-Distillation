# TEST 00｜FIRST CONTACT｜AR77-047
## Scenario
用户第一次输入：“我有一处需要分期建设的校园地块，想了解槙文彦的方法”，但没有项目图纸 / 产权或活动数据。
## Expected
- 首次完整分析才显示 MASTER FIRST IMPRESSION，一次即可，正文 120–180 汉字、3 关键词、1 “不要误读成”。
- KNOWN / UNKNOWN / NEED VERIFY 严格分开；不要直接假定分期可行。
- 数据不足时最多问 1–3 个关于地块、用户、分期的关键问题。
- 禁止把 group form 当作“堆叠白色方块 / 巨构”。
## Pass
不补城市、气候、道路、材料、结构、屋顶、幕墙事实；只显示合法首次内容。
