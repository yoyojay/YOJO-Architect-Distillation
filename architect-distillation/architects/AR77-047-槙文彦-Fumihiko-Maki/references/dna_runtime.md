# AR77-047｜DESIGN DNA RUNTIME
## Fumihiko Maki｜可选机制而非固定形态菜单

**Selection**：D01 mandatory；额外 2–3 个必要 DNA；合计 **3–4**。DNA 数量是 AR77 源证据驱动的操作建模，不是槙文彦本人出版的“十个 DNA”。
每项至少需要 **判断含义 / Trigger / Spatial Operation / 适用边界 / Failure Mode / 可验证空间痕迹**。
未选 DNA 不得流入 Strategy / Recommendation / Keep / Next / Prompt / Handoff。

## D01｜COLLECTIVE_RELATION_BEFORE_OBJECT｜关系先于单体
**判断含义**：建筑既是对象，更是城市中其他对象、人和路径之间的关系。
**Trigger**：所有完整分析。
**Spatial Operation**：绘制 buildings / program / city / people / existing urban fabric 的节点与关系、断点、可连接机会。
**适用边界**：全部类型；单体项目则检查建筑与周边的实际关系，不虚构“群体”。
**Failure Mode**：只有“整体感”口号，实际是孤立地标。
**可验证空间痕迹**：site-linkage map 和 plan-section 中至少有一个可追溯的真实连接结果。

## D02｜LINKAGE_WITH_A_JOB｜有职责的连接
**判断含义**：link 必须促进公共路径、服务组织、协作或社区连续性。
**Trigger**：多个建筑 / 单元 / 程序间存在真实断裂。
**Spatial Operation**：link type (pedestrian/service/visual/sectional) → endpoint → user → capacity → fallback route。
**适用边界**：校园、多单元文化、研究、高层城市界面。
**Failure Mode**：画很多桥 / 走廊 / 连廊但对真实使用没有价值。
**可验证空间痕迹**：流线图明确谁在何时使用连接、断开后如何到达。

## D03｜PHASED_FORM_WITH_PUBLIC_CONTINUITY｜分期持续公共性
**判断含义**：各期可不同，但每一期都应拥有可工作的关系 / 公共空间。
**Trigger**：有真实时序、业主承诺、预算或实施分期。
**Spatial Operation**：phase map → phase-1 completeness → interim edges → future adapt / infill → stewardship.
**适用边界**：街区 / 校园 / 多期地块。
**Failure Mode**：假设未来一定建成；把一期做成半成品。
**可验证空间痕迹**：每期独立的 site plan、使用路径、治理和临时界面测试。

## D04｜THRESHOLD_LAYERING_SPATIAL_DEPTH｜层次门槛形成纵深
**判断含义**：连续但有差别的 public/shared/private edge 可产生深度与发现。
**Trigger**：密集场地需从街道到内侧形成层次。
**Spatial Operation**：public edge → semi-public transition → pause/look-aside → protected inner space with clear wayfinding。
**适用边界**：密集混合、住宅、校园、城市文化。
**Failure Mode**：人为造迷宫 / 日式美学符号 / 无障碍弱化。
**可验证空间痕迹**：plan + section 能读出层次；关键入口显著可达。

## D05｜SHARED_SCENES_FOR_SOCIAL_LIFE｜支持社会生活的场景
**判断含义**：“unforgettable scenes”是对多种人与人互动的容纳，不是巨大景观照片。
**Trigger**：真实共享生活、交流、展览、文化活动已知。
**Spatial Operation**：map daily use + event states → shared pause/encounter locations → privacy/operations boundary.
**适用边界**：社区、研究、文化、校园、城市街道。
**Failure Mode**：造一块空广场就声称产生公共生活。
**可验证空间痕迹**：时间-人群-活动矩阵与空间节点吻合。

## D06｜CIRCULATION_AS_RECIPROCAL_OBSERVATION｜路径与相互观看
**判断含义**：必要路径可以产生对其他活动的认知、偶遇或参观，但不能强迫所有活动暴露。
**Trigger**：visitor / research / culture 各类人的运动和活动可互动。
**Spatial Operation**：program node → connecting path → selected views / pauses → alternative private/service routes。
**适用边界**：文化设施、教育、研究、高密机构。
**Failure Mode**：为了“互动”制造拥堵、旁观压力或无意义循环。
**可验证空间痕迹**：sequence drawing 显示可见与不可见区域、目的地和路径效率。

## D07｜VISIBILITY_WITH_PROTECTION｜可见性与保护共存
**判断含义**：视觉连通必须与研究保密、声学、气候、隐私及安保同时校准。
**Trigger**：共享 / 研究活动需要 selective visibility。
**Spatial Operation**：visual interface matrix → where reveal/obscure → glare/acoustics/energy → access control。
**适用边界**：研究机构、教育、展示、文化建筑。
**Failure Mode**：全部透明化；展品 / 实验 / 用户被无条件展示。
**可验证空间痕迹**：plan-section 与 privacy / glare / acoustics 图上可见边界逻辑。

## D08｜LIGHT_MEDIATES_PROGRAM｜光协调功能
**判断含义**：自然光、反射和层次需服务不同功能，并产生有节制的共享体验。
**Trigger**：功能间对光需求差异大，或昼夜与季节变化具有可验证价值。
**Spatial Operation**：program daylight requirements → orientation → buffer/shared space → seasonal test → shielding / conservation。
**适用边界**：文化、教育、研究、公共。
**Failure Mode**：把光当白色玻璃建筑的通行证；损伤展品 / 过热。
**可验证空间痕迹**：时段光照图 + section + program requirements。

## D09｜CITY_INTERFACE_ACTIVATION｜城市界面激活
**判断含义**：大型建筑在地面层对城市步行、换乘与公共可达负有实际责任。
**Trigger**：高层 / 大综合体的 street edge、交通和公共活动是项目冲突。
**Spatial Operation**：pedestrian desire line → access / edge programs → security-service split → ground wind/shade。
**适用边界**：高层、交通连接、公共复合建筑。
**Failure Mode**：空白 podium、不可停留的私有公共空间。
**可验证空间痕迹**：城市地面层的实测 walkability / activity / wind / access 方案。

## D10｜CONTEXT_TIME_AND_TERRAIN｜时间与微地形作为城市底稿
**判断含义**：场地既有小尺度地形、历史关系与未来变化，不是设计前清零的白纸。
**Trigger**：地形 / 历史 / 多期场地资料影响关系组织。
**Spatial Operation**：existing assets + slope + inherited paths → preserve/adjust → overlay future phases / activity。
**适用边界**：城市更新、校园、复杂地块。
**Failure Mode**：浪漫化旧城或随意宣称地域精神；真实微地形被抹平。
**可验证空间痕迹**：survey overlay / cut-fill / preserved relation diagram。

## DNA SELECTOR（必须实际运行）
1. D01 强制。
2. 从 D02–D10 只增加 **2–3 个**，总量 3–4；若不足两条有证据触发，应返回关键提问，不能硬凑。
3. D03 只有 verified phasing / expansion conditions 才选。
4. D04 只有 verified urban edge + depth / privacy gradient 才选。
5. D05 只对 KNOWN users and activities 建立“场景”，不得虚构文化活动。
6. D06 只有两种活动间相互观看 / 移动有明确目的时选。
7. D07 需有 privacy / security / acoustic 等边界问题，不等于默认玻璃。
8. D08 需照度 / 眩光 / 展品保护的验证方案。
9. D09 只对真正有 city ground responsibility 的项目。
10. D10 只对确有既存街道 / 地形 / 时间资料的项目。
11. 输出 Selected / Rejected DNA、每项触发事实和 verifiable trace。
12. 未选 DNA 不能作为“细节 / 借用 / 补充”回流；如变更必须重新过 DNA Selector 并重算后文。
