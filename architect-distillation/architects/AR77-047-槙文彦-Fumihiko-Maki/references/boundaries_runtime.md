# AR77-047｜BOUNDARIES + CONTEMPORARY CORRECTIONS
## Fumihiko Maki

## PROJECT FIT
**FIT**：真实问题是建筑之间连接、随时间分期、街道与内部层次、机构跨团队协作、文化功能独立与共享、高层的街道责任。
**PARTIAL FIT**：关系机制可启发，但决定性问题由特殊医疗流程、绝密设施、特殊工业 / 交通技术或既有法定条件主导。
**NOT FIT**：只想复制 Hillside Terrace、Spiral、MIT E14、Aga Khan Museum、4 WTC 外观；只要“日式轻盈 / 金属 / 玻璃 / 白色”；没有实际场地、活动或连接问题却要指定桥梁 / 廊道 / 庭院 / 浮屋顶。

## CONTEMPORARY CORRECTIONS｜全部必须检查，适用与否显式写明
- **Climate**：门槛、外廊、庭院、露台、玻璃与共享地面按真实热、雨、风、日照、湿度、遮阳、能耗校正。
- **Accessibility**：多级阈值、坡地、桥梁、跨楼连接、参观回游不能构成只对部分人的特殊路线；明确等效无障碍与导向。
- **Fire**：连通桥 / 中庭 / 共享地面 / 多期建设 / 多单元系统必须复核疏散、防火分区、烟控、消防通道与分期合规。
- **Structure**：跨层空间、连桥、特殊屋顶、钢 / 混凝土 / 玻璃不能从历史工程直推；由结构工程验证。
- **MEP**：中庭、科研设备、分期接口、不同室内条件、竖向通道必须有设备、检修、控区 / 洁净与扩展策略。
- **Acoustics**：开放研究、连通中庭、文化展厅需验证言语私密、机械噪声与混响。
- **Privacy**：透明 / 可见性按科研保密、使用者同意、居民生活和数据隐私做差异化处理。
- **Operations**：公共路径的开放时段、地块管理、跨物业责任、安保、活动安排、分期运营要有治理主体。
- **Maintenance**：层叠界面、室外平台、幕墙、天窗、露台排水、室外连廊、可变使用要可检修 / 清洁 / 替换。
- **Cost**：连廊 / 构件增量、跨期基础设施、分期临时界面、精密外皮需证明公共收益超过全生命周期成本。
- **Procurement**：若采用预制 / 金属 / 特种玻璃，必须核实当地加工、容差、供应链、替代件。
- **Lifecycle**：分期增长、空间改造、公共地面使用权、碳排、水耗、更新与拆除后果要比较。

## ARCHITECT-SPECIFIC CORRECTIONS
- `Group Form` ≠ 把一组体块随意拼接；必须有 urban linkage + phasing 或 collective relation 的实际证据。
- `Megastructure` 是 1964 研究的分析范式，不能默认设计必须有巨构或可无限扩展。
- `Oku / depth` ≠ 玄学 / 不透明 / 迷宫；必须带来清楚可用的过渡层次。
- `unforgettable scenes` ≠ 建筑摄影点；必须有真实活动与公共参与。
- `linkage` ≠ corridor / skybridge 图形；交通组织、人流和消防要成立。
- `transparency` ≠ full-height glass；实验室保密、声学、热工优先。
- `light as catalyst` ≠ 全采光中庭；艺术品、仪器、眩光、能耗需边界。
- `quiet tower + active ground` ≠ 自动采用 4 WTC 的 podium 或玻璃幕墙。
- `cultural continuity` ≠ 把亚洲 / 日本传统元素加到外立面。
- `phased urbanism` 必须通过多期土地与日常管理机制核查，不等于“形式可增加”。

## CRITIC HARD-FAIL TRIGGERS
- 没有已知地块 / 参与者，却宣布 six-phase growth；没有治理，却预设共有公共地面。
- 用户活动不明就宣称“自发相遇”；跨楼连接跨越消防 / 安全边界。
- 项目已确定需要隐私却强行全透明；没有太阳数据就输出特定开口 / 屋顶采光。
- 渲染样貌代替 Plan–Section–Movement 证据；Copy precedent / Rejected DNA 重新进入 Prompt。
