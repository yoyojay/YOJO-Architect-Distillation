# AR77-047｜PROJECT-PROBLEM ROUTES
## Fumihiko Maki｜独立于历史阶段的可执行路由

这些是 AR77 的证据约束问题路由，不是槙文彦自行命名的时期，也不是六种外观类型。
每一轮先审查真实冲突；选择 `Primary exactly 1` 与 `Secondary NONE / max 1`。
未选 Route 不得流入 Strategy / Recommendation / Prompt / Handoff。

## R1｜PHASED_COLLECTIVE_GROWTH｜分期群体形态
**Trigger**：多个建筑 / 地块会随年月分期发展；公私活动需跨阶段持续；确有产权 / 建设期条件。
**核心问题**：如何让各期具有差异，却共享可持续的公共骨架，而不依赖一次建完的总图。
**Method**：verify phases → existing/target urban fabric → common public ground + link network → unit differences → phase-1 usable state → intermediate states → final scenario → stewardship test。
**主要 DNA**：D01 / D02 / D03 / D05 / D10。
**适用边界**：城市更新、校园、邻里、复合街区，多主体渐进开发。
**风险**：未来工程并不发生；每期切断公共空间；物业 / 管理权无法延续；巨构式总体控制。
**与其他 Route 差异**：时间和分期是主驱动，而不仅是“多体量”。
**证据**：1964 Collective Form / Hillside Terrace 官方六期与公共活动记录。

## R2｜LINKED_MULTI_UNIT_INFRASTRUCTURE｜多单元系统连接
**Trigger**：会展、教育、公共机构等有清楚多个功能单元、流量峰值、不同用户 / 服务路径。
**核心问题**：连接系统如何使大型整体清楚可达，而不抹掉单元差异。
**Method**：program nodes + audience → matrix of flows → choose meaningful public linkage → service separations → sectional interfaces → peak/safety test。
**主要 DNA**：D01 / D02 / D06 / D07。
**适用边界**：会展 / 大校园 / 集合式公共设施。
**风险**：一条长走廊 / 主脊柱反而造成拥堵；后勤交叉；集体形式僵化。
**与其他 Route 差异**：主因果是跨单元的清晰连接与服务组织，不是分期。
**证据**：1964 Linkage；Pritzker Makuhari Messe 主轴连接单元记录。

## R3｜URBAN_THRESHOLD_LAYERING｜城市边界与纵深层叠
**Trigger**：街道到安静内侧距离有限、场地边界复杂，需同时处理公共性、隐私、侧向发现与多尺度到达。
**核心问题**：如何在有限长度中建立“可读而丰富”的空间深度。
**Method**：street edge → public/private gradient → pause + side view opportunities → terrain section → protected shared exterior only if justified → wayfinding/climate test。
**主要 DNA**：D01 / D04 / D05 / D10。
**适用边界**：密集城市住宅、文化 / 商业混合、街道插入、校园边界。
**风险**：把 `oku` 变成玄学或人造迷宫；难找入口；深处无采光；边界安防冲突。
**与其他 Route 差异**：主因果是街道—内部层次，不是项目漫长分期。
**证据**：Pritzker Hillside Terrace 深度 / 阈值；事务所地形、层叠和受保护公共空间说明。

## R4｜RESEARCH_VISIBILITY_INTERACTION｜研究协作与可见性
**Trigger**：实验室 / 工作室 / 学术平台有跨团队协作需求，同时又有保密、噪声、洁净、设备风险。
**核心问题**：怎样用可控的可见性和交会节点促进交流，而不以全透明替代专业分区。
**Method**：research work modes → secure/quiet/support rooms → encounter network → controlled visual links → section/atrium only if justified → fire/MEP/privacy test。
**主要 DNA**：D01 / D02 / D06 / D07 / D08。
**适用边界**：研发、教育、跨学科机构。
**风险**：研究隐私失效、声学污染、全天眩光、实验安全、空调能耗。
**与其他 Route 差异**：由知识协作 / 受控观察驱动，不是参观仪式。
**证据**：MIT Media Lab / official MIT collaboration design intent；联建旧馆。
**作者边界**：MIT 项目 Maki and Associates + Leers Weinzapfel Associates + 顾问团队。

## R5｜CULTURAL_PROGRAM_LIGHT_INTEGRATION｜文化功能与采光共存
**Trigger**：展览 / 教育 / 演出 / 接待各自要求不同的光、安静、独立性，但要形成一个公共文化整体。
**核心问题**：如何让独立功能经共享中介组织成整体，光发挥可验证的场所作用。
**Method**：program autonomy matrix → shared encounter threshold → light/daylight control per activity → independent circulation/egress → public gathering → conservation/acoustic test。
**主要 DNA**：D01 / D05 / D06 / D08。
**适用边界**：博物馆、文化中心、演艺与多功能教育。
**风险**：庭院 / 全玻璃带来展品损伤、眩光、能耗、泄漏、维护成本；把中庭当万能方案。
**与其他 Route 差异**：由不同活动的自治与共享，及光的性能矛盾驱动。
**证据**：Aga Khan Museum 官方四功能 / courtyard / light；Spiral 的混合文化路线。
**作者边界**：Aga Khan 场地 Prayer Hall = Charles Correa；garden = Vladimir Djurovic；Museum = Maki and Associates。

## R6｜TOWER_PUBLIC_GROUND_MEDIATION｜高层与街道公共界面
**Trigger**：高层 / 大综合体的城市存在感，与街道活力、公共入口、交通换乘之间存在真实冲突。
**核心问题**：怎样使高层克制而地面层积极承担城市角色。
**Method**：tower impact + street assets → ground-level permeability → transit + pedestrian nodes → security/service separation → wind/shade/urban activity test。
**主要 DNA**：D01 / D02 / D05 / D09。
**适用边界**：高层、总部、交通复合街区。
**风险**：无人的空旷 podium、风峡谷、私有化公共地面、高安保封锁、人流割裂。
**与其他 Route 差异**：塔楼—街道的双尺度责任是主因果。
**证据**：4 WTC 官方 “quiet ... tower” + activating podium 的设计陈述。
**边界**：不得复制 4 WTC 幕墙、外形或交通枢纽模式。

## ROUTE SELECTOR
1. 主矛盾涉及多年分期 / 多主体发展 → 优先审查 R1；无真实分期则禁用。
2. 主要问题是大型多功能单元间的组织、峰值流线 → R2；不得自动加中央长轴。
3. 主要问题是街道到内部的公共/私密纵深 → R3；不得自动加迂回与庭院。
4. 研发协作 + 保密冲突已证实 → R4；透明围护绝非默认。
5. 文化功能自治 + 共享 + 展品采光冲突 → R5；庭院必须另过气候 / 保护测试。
6. 高层影响与街道公共性冲突 → R6；塔楼 / podium 不是形态默认。
7. 输出 Primary / Secondary / Rejected Routes 与选择原因；Secondary ≤1 且不能掩盖 Primary。
8. 如果所有触发都不成立，给 PARTIAL/NOT FIT 与资料缺口，不伪选。
9. 未选 Route 不得在后文复活；确需调整必须回到 Route Selector 重选。
