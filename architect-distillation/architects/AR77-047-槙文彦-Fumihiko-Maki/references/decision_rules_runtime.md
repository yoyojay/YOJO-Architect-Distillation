# AR77-047｜DECISION RULES
## Fumihiko Maki｜If–Then–Because–Verify–Fallback

每条规则的操作范式：
`当（真实可证条件） → 优先（Route / DNA / 空间操作） → 因为（因果） → 通过（测试）验证 → 若失败则（明确退回路径）`

1. **Fact Lock**：当场地、程序、分期只有假设 → 先标 NEED VERIFY → 因为城市关系不能凭空绘制 → 通过 survey / brief / stakeholder 验证 → 失败则只提供不依赖假设的关系草图 / 问题。
2. **Fit**：当用户只要求白色玻璃或浮动银屋顶 → 优先做 FIT 复核 → 因为外观与方法无关 → 通过真实 linkage/conflict 检查 → 无冲突则 NOT FIT。
3. **Route R1**：当且仅当真实分期存在 → 选 R1 + D03 → 因为群体形式必须支持不同时点公共使用 → 通过各期 site/use diagrams → 失败则取消分期驱动设计。
4. **Route R2**：当多功能单元高峰流量冲突 → 优先 R2 + D02 → 因为要清楚连接 / 服务分离 → 通过 flows & evacuation test → 失败则减少/重置连接，不强加 spine。
5. **Route R3**：当街道—内部层级是真问题 → 优先 R3 + D04 → 因为层次可使有限场地更深 → 通过 plan-section accessibility / orientation → 失败则缩短路径而非加迷宫。
6. **Route R4**：当研究可见性与保密冲突 → 优先 R4 + D07 → 因为受控可见性不同于全透明 → 通过 research access/acoustic/MEP → 失败则关闭相关视觉接口。
7. **Route R5**：当多种文化功能相互独立又需共享 → 优先 R5 + D08（仅有可核对 daylight data 时） → 因为光必须满足使用 / 展品保护 → 通过 daylight + conservation study → 失败则独立功能优先，移除装饰性采光。
8. **Route R6**：当塔楼地面层不活跃 → 优先 R6 + D09 → 因为塔楼公共责任先于材料造型 → 通过 pedestrian/wind/shade/operation → 失败则改写街道界面。
9. **Linkage**：当新走廊 / 桥仅有形象目的 → 先删去 → 因为 linkage 必须有明确 end points 和 users → 通过 origin-destination test → 失败则删除构件。
10. **Program scenes**：当宣称会有自发公共生活 → 优先 D05 进行活动核实 → 因为物理广场不等于公共生活 → 通过 user calendar + management → 失败则标 NEED VERIFY。
11. **Light / Glass**：当选玻璃、金属、透明幕墙来“像槙文彦” → 优先 D07/D08 资格验证 → 因为材料不是机制 → 通过 climate/privacy/cost tests → 失败则删去具体材料。
12. **A/B/C**：当三策略仅在体块、颜色或材料上不同 → 重写成分期、连接、程序中介等不同因果 → 通过 Plan/Section/Movement/System 差异验证 → 失败则 Strategy FAIL。
13. **Recommendation**：当选择两个以上积极策略来源 → 保留 1 Dominant + 借另一策略 1 个有限机制 → 因为主体必须独立成立 → 通过 strategy genealogy → 若第三者回流则 Recommendation FAIL。
14. **Critic**：当渲染冻结设计但连通 / 阈值 / 活动不成立 → 退回 site-network + plan-section → 因为外观不可弥补功能失败 → 通过 trace 与用户/运营复核 → 失败则重新路由。
15. **Prompt Fact Lock**：当 Prompt 出现金属板、玻璃、混凝土、长轴、天桥、院落、漂浮屋顶、斜坡、柱网、家具或景观 → 逐项追溯 KNOWN / selected Route / Dominant / optional Borrowed / Selected DNA / verified site-climate-light → 不能追溯则删除或改写为关系 / 性能语言。
16. **Attribution**：当 Group-Form 被写成槙文彦单独研究、或把独立场地建筑 / 工程师贡献划归他一人 → 复核 Ohtaka / Goldberg / 团队的源资料 → 若不能修正则 Authorship FAIL。
17. **Failure Return**：任何 required gate 不成立 → STOP → route/DNA/strategy/prompt 定位错误 → FIX → RE-AUDIT；不以“概念灵感”掩盖失效。
