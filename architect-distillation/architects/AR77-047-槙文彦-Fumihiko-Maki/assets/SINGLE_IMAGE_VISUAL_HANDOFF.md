# SINGLE IMAGE VISUAL HANDOFF
## AR77-047｜Fumihiko Maki｜单张概念验证

### 定位
只把**已经确认的建筑判断**交接给一张图，验证 Relation / Linkage / Threshold / Social Scene 进入视觉后是否仍成立。
不是图纸识别器、第二套概念 Prompt、全套效果图生产系统或“槙文彦风格”图像生成器。

### 启动条件（必须全部成立）
- 已完成 AR77-047 的当前项目完整判断；
- 建筑师 / 用户已确认 exactly one Dominant Strategy；
- optional Borrowed Mechanism 最多来自另一个策略之一；
- Selected Route / DNA 已确认；
- 用户明确要求**单张**概念视觉验证。

### 继承允许清单
- confirmed KNOWN project facts
- confirmed Method / Primary Route + optional one Secondary
- confirmed Dominant Strategy
- optional one limited Borrowed Mechanism
- Selected DNA only
- verified site / climate / light
- confirmed `Spatial Locks` and `Must Not Drift`

### 禁止新加事实
- 未验证地形、日照、街道与城市环境；
- 材料如 white glass / stainless steel / concrete / metal mesh；
- 浮动银屋顶、透明玻璃幕墙、支柱、屋顶花园、中庭、天桥、螺旋坡道、修长 podium；
- 新节点 / 新房间 / 新家具 / 新植物 / 新结构系统；
- Rejected Strategy / unselected DNA / unselected Route；
- 代表作视觉外观、抽象 Japan / Metabolist style。

## 04｜Spatial Locks
单图必须清楚看见已经确认的空间关系，如：
- distinct built/program parts remain linked by a verified route;
- a known public path changes from city edge to inner shared space;
- known users use a verified place for encounter;
- programmed light conditions maintain privacy and conservation;
- existing terrain remains legible if site survey confirms it。

只包含项目实际已确认的条目。

## 05｜Must Not Drift
- 不复制 Hillside Terrace 的多块体组合、Spiral 的螺旋路径、MIT E14 透明皮肤 / 彩色梯、Aga Khan Museum 的庭院、Makuhari Messe 的长廊 / 屋顶、4 WTC 的塔楼外形。
- 不自动引入 glass、steel、white metal、floating roofs、skybridges、atriums、courtyards。
- 不使用建筑师姓名作为 style 提示。
- 不改变已经确认的用户、分期、活动、入口、城市边界和 DNA。

## 06｜Single Demonstration Image Prompt
以自然语言描述：
- confirmed project type / site facts；
- confirmed user and program relationships；
- confirmed Route / Method / Dominant / optional Borrowed / Selected DNA；
- observable plan-section-movement causality；
- verified time of day and climate only where known；
- credible architectural observation view rather than dramatic icon rendering。

具体构造 / 材料 / 灯光 / 家具 / 景观均受 Prompt Fact Lock 限制。

## 07｜Negative Constraints
根据具体项目列出最多 3–6 条相关偏移风险，禁止添加无关风格长列表。

## 08｜Handoff Note
> 这只是一张概念验证图，用来检查已确认的建筑判断是否在视觉化时仍成立。图像不能反向成为新增的项目事实，也不是完整效果图工作流。
