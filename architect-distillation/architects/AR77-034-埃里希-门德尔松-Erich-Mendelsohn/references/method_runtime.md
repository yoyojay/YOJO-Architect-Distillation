# AR77-034｜METHOD RUNTIME
## Erich Mendelsohn｜Architectural Judgement Kernel

## 1｜Evidence Status

本 Runtime 只允许 `KNOWN` 与 `SUPPORTED INTERPRETATION` 进入 Method / Route / DNA / Rules。

### KNOWN

- Mendelsohn 在 1923 年关于“Dynamics and Function”的理论文本中明确区分机械功能与建筑功能：建筑中的功能是用途、材料与结构要求之间的空间与形式依存关系。
- 他同时明确指出：材料与结构关系只是建筑组织的前提；技术组织本身并不会自动产生建筑，还需要把这些条件转译成建筑表达。
- 同一文本把物质与光、理性与感受、功能与动态的统一视为空间创造的重要组成。
- Einstein Tower 的深化与 Zeiss / Siemens 等技术方的仪器要求发生直接互动；技术协商改变了塔体尺寸、内部独立基础与开窗等设计。
- Schocken 百货的空间和外部形象与顾客移动、商品展示、日光、人工照明以及城市可见性有关；其销售层强调清晰与连续的购物环境。
- De La Warr Pavilion 为 Mendelsohn 与 Serge Chermayeff 合作项目，公共文化、娱乐与社交程序以及显著流线共同构成建筑组织；该项目不能作为 Mendelsohn 单独作者证据使用，但可作为其公共运动空间方法的协作证据。
- Weizmann House 明确回应场地、亚热带 / 地中海气候与环境：庭院、朝向、海风、光与空气被纳入空间组织。
- Mendelsohn 在美国的部分犹太社区项目包含可扩展 / 可变的集会空间，用于不同规模的礼拜与社区活动。

### SUPPORTED INTERPRETATION

从上述证据可蒸馏以下 AR77 执行链：

`用途 / 技术 / 运营 / 场所条件`
→ `建立目的—材料—结构的依存关系`
→ `组织流线、体量、光与技术系统`
→ `通过动态关系把组织条件转成空间表达`
→ `按城市界面 / 气候 / 集会变化进一步校正`
→ `最后才锁定形式`

这是 AR77 对 Mendelsohn 反复判断机制的证据约束翻译，不冒充其本人提出的固定流程。

## 2｜Core Judgements

### J1｜Dependency Before Image｜依存关系先于形象
任何形式必须先能解释它与用途、材料、结构、设备或场地条件的依存关系。

### J2｜Function Is Necessary but Not Sufficient｜功能必要但不充分
程序、结构与技术成立只是前提；还必须形成可感知的空间秩序、光的关系与整体张力。

### J3｜Dynamics Means Relational Tension｜动态不是曲线
“动态”优先解释为体量、路径、光、方向、速度、城市视线或使用变化之间的张力，不等于流线型曲面。

### J4｜Technical Demands Can Generate Spatial Order｜技术条件可生成空间秩序
仪器、生产、展示或设备要求可成为平面 / 剖面 /结构的生成因，但必须保持维护、安全与操作可行。

### J5｜Urban Presence Is Operational｜城市形象必须有运营依据
商业 /公共建筑的街角、到达、夜间识别与展示应服务真实的人流、可见性与运营，而非制造“速度感”。

### J6｜Context Changes the Method's Output｜场所改变输出
气候、文化、地形与材料供应改变建筑组织；不得把德国 1920s 项目的表皮语言搬到其他场所。

### J7｜Assembly Must Scale With Community Use｜集会空间服从使用规模
需要不同容量、仪式与社区活动时，可变边界 / 扩展空间是工具，但必须经过声学、消防、MEP 与运营验证。

## 3｜Method Execution

每次完整项目分析必须：

1. 锁定 KNOWN / UNKNOWN / NEED VERIFY。
2. 写出 3–5 条项目冲突，不先画圆角、横窗或流线体。
3. 把主冲突转换为“哪些条件互相依存”的问题。
4. 选择 exactly 1 个 Primary Route；必要时选择最多 1 个 Secondary Route。
5. D01 为基础 DNA；再选 1–3 个必要 DNA，总量 2–4。
6. 每个 Selected DNA 必须留下 Plan / Section / Movement / Light / System / Operation 中至少一种可验证痕迹。
7. 生成 A/B/C 三个因果不同策略。
8. Recommendation 只保留一个 Dominant Strategy，最多从另一个策略借 1 个有限机制。
9. 做当代校正。
10. Prompt Close 前执行 Prompt Fact Lock。

## 4｜Form Discipline

禁止把以下历史表象当默认答案：

- Einstein Tower 式雕塑曲面；
- Schocken 式连续水平窗带；
- 圆角街角；
- 强调速度感的水平线；
- 白色 / 浅色抹灰；
- reinforced concrete / steel / glass 作为“门德尔松材料包”；
- 夜间发光立面；
- De La Warr Pavilion 的曲面楼梯塔；
- Weizmann House 的庭院 / 水池 /石材组合；
- 美国会堂项目的穹顶或具体礼拜构图。

形式只有在 KNOWN + selected Route + Dominant Strategy + Selected DNA 能共同追溯时才可进入。
