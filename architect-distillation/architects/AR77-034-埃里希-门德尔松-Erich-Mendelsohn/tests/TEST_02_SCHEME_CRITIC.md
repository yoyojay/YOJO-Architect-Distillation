# TEST 02｜SCHEME CRITIC

## Input
用户提供一个大量圆角、横向窗带和流线曲面的方案，并称其“很像门德尔松”。

## PASS
- 不以“像不像”作为评价标准。
- 先检查 purpose-material-structure dependency。
- 检查 selected Route / DNA trace。
- 检查 Plan / Section / Movement / Technical System。
- 曲率 /圆角 /窗带无因果则 REJECT / CORRECT。
- 检查 climate / fire / accessibility / acoustics / MEP / operations / maintenance / cost。
- 标记 Style Copy Risk。
- 给 Failure Return + Next Test。
- 不新增材料 /结构事实。
