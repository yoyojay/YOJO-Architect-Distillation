# SINGLE IMAGE VISUAL HANDOFF
## AR77-034｜Erich Mendelsohn

### 定位
本模块只把 **已确认的建筑判断** 交给一张概念验证图。
不是风格生成器，不是完整视觉生产系统。

### 启动条件
- 项目已完成 AR77-034 分析；
- 用户已确认 Dominant Strategy；
- Route / Selected DNA 已确认；
- 用户明确要求单张概念视觉验证。

### 只允许继承
- confirmed KNOWN facts
- confirmed Method / Route
- confirmed Dominant Strategy
- optional one Borrowed Mechanism
- Selected DNA
- verified site / climate / light

### 禁止新增
- unsupported material / structure
- curve / rounded corner / ribbon window
- roof / opening / column / grid / truss
- luminous facade
- courtyard / pool / landscape
- furniture / technical components
- Rejected Strategy
- unselected Route / DNA

## 04｜Spatial Locks
只写已确认关系，例如：
- technical system and occupied space relationship;
- movement sequence and event nodes;
- day/night urban interface when verified;
- mass-light relation in section;
- climate-adjusted boundary;
- verified assembly capacity states.

## 05｜Must Not Drift
- 不复制 Einstein Tower；
- 不复制 Schocken Department Store；
- 不复制 De La Warr Pavilion；
- 不复制 Weizmann House；
- 不自动加入曲面、圆角、横向窗带、夜间发光、白色抹灰；
- 不把“dynamic”翻译成流线造型；
- 不新增未经确认的材料、结构、家具、景观或技术构件。

## 06｜Single Demonstration Image Prompt
描述：
- current project type;
- confirmed users / activities;
- confirmed dependency and spatial mechanism;
- confirmed movement / technical / climate relation;
- verified light;
- a viewpoint revealing plan-section causality;
- realistic architectural observation.

禁止：
`Erich Mendelsohn style`
`expressionist architecture style`
`like Einstein Tower`
`like Schocken Department Store`
任何代表作名作为视觉目标。

## 07｜Negative Constraints
只保留与当前判断直接相关的负向约束。

## 08｜Handoff Note
> 这是一张概念验证图，只用于检查已确认的空间判断是否在视觉中仍然成立；它不代表完整效果图体系，也不得新增设计事实。
