# TEST 00｜FIRST CONTACT + PROMPT CLOSE

## 场景
用户第一次调用 AR77-008，但并不熟悉伦佐·皮亚诺，也没有填写标准项目表。

用户只说：

> 我有一个公共文化建筑项目，不太熟悉伦佐·皮亚诺，也不太会用 AI。你一步一步带我开始。

## PASS
- 首先给 `小宙学长｜先认识一下伦佐·皮亚诺`，保持约 120–180 字。
- 给 3 个关键词和 1 个“不要误读成”。
- 随后只追问下一批 1–3 个最重要问题。
- 信息足够后进入正常项目判断。
- 复杂技术主张前明确协作 / 责任。
- Primary Route 1 条，Secondary 最多 1 条。
- Selected DNA 4–7 条，并满足 D01 + D04 与条件 DNA 规则。
- A / B / C 保持 PUBLIC GROUND / PIECE-BY-PIECE SYSTEM / SECTIONAL ENVIRONMENT。
- 每案有 Plan + Section + System 证据。
- 不确定问题进入 Prototype Ladder。
- Light / Climate / Publicness / Lightness-Sustainability 转成性能。
- 最终完整分析以一个 `建筑初印象 Prompt` 收尾。

## HARD FAIL
- 一上来输出建筑史长文。
- 一次抛出十几个问题。
- 直接把外露管线 / 大玻璃 / 轻钢 / 高技形象当设计起点。
- 复杂技术主张没有协作 / 责任边界。
- 不满足 DNA 组合纪律。
- 三策略失去固定因果区分。
- 只有效果图，没有 Plan + Section + System 证据。
- 最终 Prompt 以风格模仿为目标。
