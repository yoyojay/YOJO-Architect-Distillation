# AR77-008｜SINGLE IMAGE VISUAL HANDOFF

## 定位

008 的核心不是效果图 Prompt。

本模块只负责：

**把已经确认的 Renzo Piano 方法判断，交给一张概念验证图。**

---

# 启动条件

必须已经确认：

- Strategy
- Primary Route
- 4–7 Selected DNA
- Plan / Section / System evidence
- key collaboration / technical boundaries

---

# 输出

## 01｜Confirmed Strategy

## 02｜Primary Route

## 03｜Selected DNA

## 04｜Spatial / Technical Locks

例如：

- public ground works under real opening / security / weather conditions;
- the key piece has a manufacturing and replacement logic;
- section coordinates structure, circulation, light, air, systems, and maintenance;
- daylight is task-specific;
- technical visibility is justified;
- local climate and operations are credible;
- maintenance access remains visible in the concept;
- lifecycle ambition is not reduced to appearance.

## 05｜Must Not Drift

必须检查：

- 不复制 Pompidou 彩色管线 / 外置扶梯 / gerberette；
- 不复制 Menil roof leaves；
- 不复制 Kansai wave roof；
- 不复制 Tjibaou shell / timber-rib silhouette；
- 不复制 California Academy undulating green roof / domes；
- 不默认薄白屋顶；
- 不默认所有技术外露；
- 不把“轻盈”做成纯视觉标签。

## 06｜Single Demonstration Image Prompt

Prompt 应描述：

- current project type;
- actual site / climate facts;
- confirmed strategy;
- public-ground / key-piece / sectional logic being tested;
- real users and operations;
- structure / envelope / daylight / climate relationship;
- material and fabrication logic only where confirmed;
- maintenance / replacement visibility where relevant;
- realistic architectural visualization;
- camera angle that reveals the actual spatial-system judgement.

禁止出现：

- `in the style of Renzo Piano`
- `Pompidou inspired`
- `Menil roof style`
- `Kansai Airport style`
- `Tjibaou style`
- `California Academy style`
- `generic high-tech architecture`

## 07｜Negative Constraints

只写与当前项目防漂移直接相关的约束。

## 08｜Handoff Note

> 这是一张概念验证图，用于检查当前设计判断进入视觉后是否成立，不代表完整效果图体系。后续整套视觉生产请进入建筑师原有可视化流程，或交给专门的视觉系统，例如 Zeus96。
