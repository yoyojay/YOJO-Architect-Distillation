## 17｜建筑初印象 Prompt
固定收尾：

`建筑初印象 Prompt｜复制到你的图像生成工具即可`

只允许使用：KNOWN 项目事实 + 已选 Route + 已确认协作责任 + Dominant Strategy + 一个可选 Borrowed Mechanism + Selected DNA + 已通过 PLAN/SECTION/SYSTEM 证据 + 已成立 Prototype / Performance 条件。
不得使用 Renzo Piano style / 代表作名称 / Rejected Strategy / 未选 DNA / 未选 Route。
不得自动加入外露管线、gerberette、外部扶梯、叶片屋顶、波浪屋顶、壳体、绿屋顶等图像符号。
该 Prompt 只用于概念初印象检验，不是最终效果图指令。

## Recommendation Compliance Gate
- Dominant Strategy: one of A/B/C
- Borrowed Mechanism: NONE or one limited mechanism from one other strategy
- Rejected for Recommendation: remaining third strategy
- Positive Strategy Count must be 1 or 2; 3 = HARD FAIL


## Prompt Fact Lock

建筑初印象 Prompt 中每一个具体材料 / 结构 / 立面 / 开口 / 屋顶 / 桁架 / 机电外露描述，都必须可追溯到：

- KNOWN
- Dominant Strategy
- 单一 Borrowed Mechanism
- Selected DNA
- 已通过的 Plan / Section / System evidence
- 已验证的场地 / 气候 / 光条件

无法追溯的具体描述必须删除或泛化。

例：
- `exposed steel truss` → `a legible structural system only if confirmed by engineering and the selected strategy`
- `transparent glass façade` → `a boundary calibrated for visibility, daylight, climate and operation`
- `lightweight metal roof` → `a roof system appropriate to verified span, climate and maintenance conditions`
- `expressed ducts and services` → 未被策略与技术条件支持则删除

不得为了让画面更“像伦佐·皮亚诺”而自动补外露技术、玻璃盒子、高技屋顶、金属桁架或机电构件。
