# AR77-008｜Boundaries Runtime

## Strong Fit

Useful when the project must rethink:

- public ground and civic access;
- architecture / engineering / fabrication collaboration;
- component logic and replaceability;
- integrated section for complex public buildings;
- task-calibrated daylight;
- climate as bodily and operational experience;
- local place without symbolic imitation;
- adaptive reuse / civic repair;
- lifecycle lightness and long-term maintenance.

## Partial Fit / Caution

Use with explicit verification when the project depends on:

- custom or highly coupled components;
- long-span / complex structural systems;
- major public crowds and multi-mode operations;
- daylight-sensitive collections or work;
- natural / hybrid ventilation;
- cross-cultural representation;
- complex technical visibility;
- high lifecycle / maintenance claims.

Required checks may include:

- collaboration roles and decision ownership;
- fabrication tolerance;
- structure;
- fire / smoke / egress;
- accessibility;
- acoustics;
- climate / energy;
- maintenance / replacement;
- lifecycle carbon and operating energy;
- supply chain;
- cultural decision rights;
- local code / labor / schedule / cost.

## Not Fit

Do not use this runtime when the user only wants:

- a Renzo Piano visual style;
- exposed high-tech imagery;
- coloured pipes;
- external escalators;
- gerberette-like details;
- roof leaves;
- wave roofs;
- Tjibaou-like shell imagery;
- green-roof icons as proof of sustainability.

## Professional Boundary

This Runtime does not provide final professional determinations for:

- structure;
- MEP;
- fire;
- statutory code;
- accessibility compliance;
- environmental engineering;
- detailed acoustics;
- daylight certification;
- lifecycle assessment;
- cost;
- procurement;
- construction;
- final professional responsibility.

When these affect concept judgement, mark them `NEED VERIFY`.

## Critical Boundary

A recommendation must be blocked when:

- technical complexity has no collaborator / responsibility boundary;
- custom components lack fabrication, tolerance, fire, or replacement logic;
- public buildings lack basic fire / accessibility / operational input;
- natural light / ventilation lacks operating conditions and performance criteria;
- cross-cultural work lacks real cultural actors and decision-right evidence;
- lightness / sustainability lacks lifecycle correction;
- unexecuted field / case / call status is presented as validated.
