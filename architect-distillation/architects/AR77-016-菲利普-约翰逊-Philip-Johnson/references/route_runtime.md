# AR77-016｜PROBLEM ROUTE RUNTIME

## R1｜PRECEDENT_REFRAME
**Trigger:** heritage, typology, institutional memory or architectural precedent is central.
**Core Question:** what relationship to precedent serves the present project without literal quotation?
**Method:** identify relevant precedent → extract principle/position → transform it against present facts → test recognition, difference and performance.
**Primary DNA:** D1 / D2 / D7 / D8.
**Boundary:** heritage significance, cultural accuracy, no pastiche.
**Risk:** historical motif selected before project need.
**Difference:** precedent argument leads.

## R2｜ORDERED_PAVILION
**Trigger:** compact domestic, exhibition, cultural or landscape program benefits from a strong primary order.
**Core Question:** what minimal geometric/boundary order can clarify use and relation to site?
**Method:** establish primary geometry → locate enclosed/service/threshold conditions → calibrate boundary/view/privacy → test occupation.
**Primary DNA:** D3 / D4 / D5 / D6.
**Boundary:** climate, privacy, acoustics, servicing.
**Risk:** abstract object suppressing ordinary life.
**Difference:** primary spatial order leads.

## R3｜SEQUENCE_THRESHOLD
**Trigger:** arrival, procession, framed view or transition between distinct conditions is central.
**Core Question:** how can thresholds make the project's relationships legible?
**Method:** map approach → identify transitions → frame views/pauses → test accessibility and directness.
**Primary DNA:** D4 / D6 / D3 / D5.
**Boundary:** accessibility, egress, crowding, weather.
**Risk:** theatrical procession without user value.
**Difference:** experience through transition leads.

## R4｜CONTEXTUAL_CONTRAST
**Trigger:** a new object/intervention must coexist with a strong landscape, campus, urban or historical setting.
**Core Question:** should the project align, counterpoint or recede—and why?
**Method:** map dominant contextual orders → define deliberate relation → test scale/edge/view/ground → verify that contrast clarifies rather than erases.
**Primary DNA:** D1 / D5 / D7 / D2.
**Boundary:** heritage, public realm, neighborhood impact.
**Risk:** contrast used as permission for arbitrary object-making.
**Difference:** relation to context leads.

## R5｜INSTITUTIONAL_IDENTITY
**Trigger:** corporate/civic/cultural project needs a legible public identity.
**Core Question:** what architectural position expresses the institution without reducing it to a logo-building?
**Method:** define institutional values/contradictions → select spatial/public mechanism → establish order and threshold → test everyday user experience.
**Primary DNA:** D1 / D3 / D4 / D8.
**Boundary:** inclusivity, public meaning, adaptability, branding drift.
**Risk:** representational gesture overwhelming use.
**Difference:** institutional position leads.
