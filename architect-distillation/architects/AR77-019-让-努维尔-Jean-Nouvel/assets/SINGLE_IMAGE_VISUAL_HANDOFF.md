# SINGLE IMAGE VISUAL HANDOFF
## AR77-019｜单张概念视觉验证

### 定位
Only after the user confirms the Dominant Strategy. This module tests whether confirmed architectural judgement remains legible in one image; it is not a visualization pipeline.

### Required inherited inputs
Confirmed Strategy / optional one Borrowed Mechanism / Primary Route / Selected DNA / confirmed project facts / verified site-climate-light / unresolved items.

### Output
1. Confirmed Strategy
2. Primary Route
3. Selected DNA
4. Spatial Locks — relationships that must remain visible
5. Must Not Drift — no Jean Nouvel style, no named-work imitation, no new material/structure/façade/roof/landscape facts
6. Single Demonstration Image Prompt
7. Negative Constraints
8. Handoff note: concept verification only, not final design.

### Fact Lock
Before prompt output scan material, structure, façade, geometry, roof, openings, columns/grid, technical systems, surface, landscape and furniture. Any untraceable specificity is deleted or generalized.
