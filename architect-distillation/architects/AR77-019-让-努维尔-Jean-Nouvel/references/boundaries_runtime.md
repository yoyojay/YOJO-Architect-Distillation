# AR77-019｜Boundaries + Contemporary Corrections Runtime
Audit every recommendation against climate, accessibility, fire, structure, MEP, acoustics, privacy/security, operations, maintenance, cost, procurement and lifecycle.

## Architect-specific correction priorities
1. **Transparency / reflection:** glare, heat gain, privacy, night reversal, bird safety where applicable, cleaning and replacement.
2. **Responsive/kinetic systems:** fail-safe state, manual override, controls, commissioning, maintenance access, spare parts and lifecycle cost.
3. **Darkness / selective light:** safe egress, accessible wayfinding, exhibition conservation, task lighting and surveillance.
4. **Large public/event spaces:** crowd movement, acoustic separation, servicing, back-of-house, queueing and emergency operation.
5. **Cultural reference:** verify with relevant communities/clients; avoid motif pastiche or claims not supported by evidence.
6. **Strong site inclusion:** flood/waterproofing, drainage, microclimate, universal access and maintenance where relevant.
7. **Formal/technical exception:** complexity must earn measurable spatial, environmental, civic or operational value.

## Failure Return
If a correction invalidates the strategy, do not cosmetically patch it. Return to the Main Conflict, reselect Route/DNA if necessary, regenerate A/B/C, and re-run Recommendation Gate.
