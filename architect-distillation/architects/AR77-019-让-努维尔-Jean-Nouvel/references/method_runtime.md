# AR77-019｜Method + Problem Routes Runtime

## Method Kernel
Jean Nouvel’s official biography states that his work is not derived from style or ideology but from a singular combination of people, place and time. The Pritzker jury similarly describes context—culture, location, program and client—as provoking a different strategy for each project. This runtime therefore treats **specificity → concept → perceptual/spatial relation → technical instrument → reality test** as the transferable kernel.

## Route 1｜CONTEXTUAL_HINGE
**Trigger:** two or more urban, cultural, historical or landscape conditions must be negotiated.
**Core question:** how can the project become a hinge without literal pastiche?
**Method:** identify each condition → define a relation/difference → encode it in orientation, access, view, boundary or program.
**Primary DNA:** SPECIFICITY_BEFORE_TYPE, CONSTRAINT_TO_CONCEPT, SITE_INCLUSION.
**Boundary:** not a license to quote cultural motifs.
**Risk:** symbolic storytelling without spatial consequence.
**Trace:** plan/section shows different but connected responses to the conditions.

## Route 2｜PERCEPTUAL_DEPTH
**Trigger:** the project’s key conflict concerns seeing, being seen, depth, boundary or presence/absence.
**Core question:** what should be revealed, withheld, layered or framed?
**Method:** map viewpoints and thresholds → choreograph reveal/conceal → test day/night and occupation.
**Primary DNA:** REVEAL_CONCEAL, LAYERED_PERCEPTION, PRODUCTIVE_CONTRADICTION.
**Boundary:** transparency is not a default material instruction.
**Risk:** visual spectacle, privacy failure, glare.
**Trace:** measurable/viewable changes in depth, sightline and threshold sequence.

## Route 3｜ENVIRONMENTAL_FILTER
**Trigger:** light, shade, heat, glare or weather is central.
**Core question:** can environmental control become a legible spatial relation?
**Method:** verify climate/light → define target performance → position filter → test maintenance/failure.
**Primary DNA:** LIGHT_AS_RELATION, TECHNOLOGY_AS_INSTRUMENT, CONSTRAINT_TO_CONCEPT.
**Boundary:** responsive technology is optional, never default.
**Risk:** gadgetry and maintenance burden.
**Trace:** section/environmental study shows differentiated conditions.

## Route 4｜INCLUSIVE_GROUND
**Trigger:** landscape, waterfront, public realm or exterior condition should participate in the building.
**Core question:** how does the outside enter the organization without becoming decoration?
**Method:** identify external generator → translate into ground/path/view/threshold relation → protect operation and climate.
**Primary DNA:** SITE_INCLUSION, SPECIFICITY_BEFORE_TYPE, LAYERED_PERCEPTION.
**Boundary:** do not copy KKL water strips or Quai Branly garden devices.
**Risk:** metaphor without use.
**Trace:** public route/ground/section materially changes because of the site relation.

## Route 5｜PROGRAMMATIC_EVENT
**Trigger:** complex cultural/public program resists generic typology.
**Core question:** how can distinct program identities coexist in one project-specific whole?
**Method:** identify program differences → assign spatial identities → establish a unifying relation → test circulation/acoustics/operations.
**Primary DNA:** CONSTRAINT_TO_CONCEPT, PRODUCTIVE_CONTRADICTION, TECHNOLOGY_AS_INSTRUMENT.
**Boundary:** not permission for arbitrary formal fragmentation.
**Risk:** event architecture that fails daily operation.
**Trace:** plan/section shows distinct program conditions and a clear common order.

## Evidence Basis (customer-safe)
- Ateliers Jean Nouvel biography: project uniqueness from people/place/time; distrust of style.
- Pritzker Prize 2008 jury citation/biography: context, program, site, light, transparency/opacity, project-specific strategy.
- AJN project texts: Arab World Institute (cultural hinge + light), Fondation Cartier (real/virtual + layered depth), KKL Lucerne (principle of inclusion), Quai Branly (selective dematerialization), recent Fondation Cartier Palais Royal (freedom and transformability).
These precedents justify mechanisms only; their forms are prohibited as templates.
