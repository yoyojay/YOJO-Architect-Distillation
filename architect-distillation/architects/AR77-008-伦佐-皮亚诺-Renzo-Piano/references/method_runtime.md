## Core Method Chain

`Fact Lock → 3–5 Project Conflicts → Collaboration / Responsibility Map → Primary Route → 4–7 DNA → A PUBLIC GROUND / B PIECE-BY-PIECE SYSTEM / C SECTIONAL ENVIRONMENT → Plan + Section + System Evidence → Prototype Ladder where needed → Performance Translation → Recommendation → Lifecycle / Maintenance / Critical Fail → Architect Confirmation`

## Method Kernel

1. Service comes before signature.
2. Architecture is a research loop among design, engineering, prototypes, fabrication, site, and operations.
3. A critical component may organize the whole only when structure, environment, assembly, tolerance, repair, and replacement are all legible.
4. Complex architecture requires collaborative authorship and explicit responsibility.
5. Section is the shared negotiation surface for movement, structure, air, light, acoustics, equipment, maintenance, and smoke control.
6. Light is calibrated to task rather than treated as transparency.
7. Publicness includes space, time, cost, climate, security, and operation.
8. Place is translated through climate, path, scale, craft, supply, and cultural decision rights rather than symbols.
9. Lightness and sustainability require lifecycle correction.

## Unique Runtime Rules

- exactly 1 Primary Route;
- at most 1 Secondary Route;
- select 4–7 DNA;
- D01 + D04 are mandatory;
- complex public buildings require D06;
- custom components require D03 + D11;
- daylight arguments require D05;
- climate arguments require D10;
- lightness / sustainability arguments require D12;
- cross-cultural projects require D09 + cultural decision-right evidence;
- Strategy A = PUBLIC GROUND;
- Strategy B = PIECE-BY-PIECE SYSTEM;
- Strategy C = SECTIONAL ENVIRONMENT;
- every strategy requires Plan + Section + System evidence;
- use the 1:1000 → 1:200 → 1:50 → 1:5 → 1:1 prototype ladder selectively;
- positive labels must become measurable or testable performance.
