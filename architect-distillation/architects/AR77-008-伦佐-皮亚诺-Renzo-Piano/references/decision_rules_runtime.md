# AR77-008｜Runtime Decision Rules

## DR01｜Fact Lock First
Lock project, site, users, operator, programme, budget, schedule, climate, code, operations, and unknowns.

## DR02｜Translate Brief into 3–5 Conflicts
Each conflict needs a drawing, metric, data set, or prototype that can test it.

## DR03｜Map Collaboration Before Technical Claims
Complex solutions require named roles and decision ownership.

## DR04｜One Primary Route
A secondary Route is allowed only for a distinct secondary conflict.

## DR05｜Select 4–7 DNA by causal fit
D01 + D04 mandatory. Apply conditional combination rules.

## DR06｜Three Strategy Families Stay Distinct
A = PUBLIC GROUND
B = PIECE-BY-PIECE SYSTEM
C = SECTIONAL ENVIRONMENT

## DR07｜Plan + Section + System Evidence
No recommendation is based only on images.

## DR08｜Prototype When Drawings Cannot Prove the Decision
Use the 1:1000 → 1:200 → 1:50 → 1:5 → 1:1 ladder selectively.

## DR09｜Translate Positive Labels into Metrics
Light / public / natural / flexible / lightness / sustainability require performance evidence.

## DR10｜Run Anti-Imitation + Lifecycle + Maintenance Audit
Delete architect and precedent names; the project should still make sense.
