# AR77-008｜Runtime Core Judgements

## J01｜The stable method is building research, not visual “lightness”
Appearance changes. What remains useful is the feedback loop among design, engineering, models, mockups, fabrication, and site.

## J02｜Architecture first serves, but service requires trade-offs
Public responsibility, users, operators, future change, and conflict priorities must become testable decisions.

## J03｜A component can contain the logic of the whole
A critical piece should answer structure, environment, fabrication, assembly, tolerance, repair, and replacement.

## J04｜Complex architecture is collaborative authorship
Engineering, fabrication, consultants, local teams, operators, and users are part of reliable judgement.

## J05｜Technology is visible only when the task benefits
Exposed technology is not a default language.

## J06｜Section is the primary drawing for system negotiation
When movement, structure, air, light, equipment, acoustics, and smoke control conflict, draw the integrated section first.

## J07｜Light is task-calibrated, not transparency
Different uses require different light performance.

## J08｜Publicness includes space, time, cost, climate, and operation
A plaza or transparent ground floor alone does not create publicness.

## J09｜Place comes from relationships, not symbols
Scale, path, climate, supply, craft, and cultural decision rights matter more than traditional silhouette.

## J10｜Lightness requires lifecycle correction
Thin, white, or transparent architecture may still be materially and operationally heavy.

# Runtime acceptance

A valid 008 proposal must:

1. begin from project service and conflicts;
2. map collaboration where technical complexity exists;
3. use a Route chosen by task;
4. select 4–7 DNA with source-derived combination rules;
5. generate PUBLIC GROUND / PIECE-BY-PIECE / SECTIONAL ENVIRONMENT as causally different strategies;
6. produce plan / section / system evidence;
7. define prototype steps where uncertainty remains;
8. verify lifecycle and maintenance;
9. avoid iconic Renzo Piano imagery.
