# AR77-008｜Runtime Limits & Corrections

## L01｜Custom-component worship
**Misuse:** more special details = better architecture.  
**Correction:** compare standard / semi-custom / custom; verify supply, tolerance, spare parts, replacement cycle.

## L02｜Visual lightness
**Misuse:** thin / white / transparent = light.  
**Correction:** verify structure, embodied carbon, energy, repair, lifespan, and adaptability.

## L03｜High-tech imagery
**Misuse:** expose every system.  
**Correction:** state visibility reason and maintenance access for each system.

## L04｜Empty space = flexibility
**Misuse:** a large platform can host everything.  
**Correction:** verify acoustics, fire, exhibition, equipment, management, day/night zoning.

## L05｜Natural-light romanticism
**Misuse:** more skylight / glass = better light.  
**Correction:** verify orientation, illuminance, UV, glare, heat, cleaning, and replacement.

## L06｜Passive-ventilation romanticism
**Misuse:** airflow arrows = performance.  
**Correction:** verify temperature, humidity, pollution, noise, extreme weather, and active backup.

## L07｜Certification = sustainability
**Misuse:** green roof or certificate proves performance.  
**Correction:** verify operational energy, maintenance, POE, and lifecycle data.

## L08｜Local-symbol imitation
**Misuse:** copy hut, timber ribs, traditional silhouette.  
**Correction:** verify cultural decision rights, scale, path, climate, craft, supply, and benefit.

## L09｜Star-author narrative
**Misuse:** all innovation attributed to Piano.  
**Correction:** record engineering, consultant, local architect, manufacturer, operator, and user contributions.

## L10｜Prototype theater
**Misuse:** mockup made only for presentation.  
**Correction:** define test question, pass criterion, modification, freeze / reject record.

## L11｜Over-coupled systems
**Misuse:** one system does everything.  
**Correction:** provide redundancy, isolation, maintenance, replacement, and failure-mode logic.

## L12｜Local implementation distortion
**Misuse:** import museum / European technical assumptions unchanged.  
**Correction:** verify local code, cost, supply chain, climate, operations, schedule, and labor.

---

# Critical Fail

Block recommendation if any occur:

- project facts are missing but precedent-like form is already generated;
- complex technical systems have no collaborators or responsibility boundary;
- custom components lack fabrication, tolerance, fire, or replacement path;
- cross-cultural project lacks real cultural actor and decision-right evidence;
- public building lacks basic fire, accessibility, and operational input;
- natural light / ventilation lacks operating conditions and performance criteria;
- lightness / sustainability lacks lifecycle correction;
- AR77 inference is presented as Renzo Piano's own words;
- unexecuted call / field / case status is presented as validated.
