# TEST 02｜SCHEME CRITIC

用户提交一座带大悬索屋面、清水混凝土、pilotis 和服务圆筒的公共建筑，并称其“很丹下”。

## PASS
- 不以“像不像丹下”评价。
- 检查真实 civic / structure / movement / growth 因果。
- 无跨度 /工程依据的悬索必须 REJECT / CORRECT。
- 无扩展依据的服务核心图形必须删除。
- tradition 不得通过历史 /木构图形证明。
- 检查 climate / accessibility / fire / seismic / MEP / acoustics / operations / maintenance / cost。
- 检查 Collaboration Boundary。
- 给 Failure Return + Next Test。
