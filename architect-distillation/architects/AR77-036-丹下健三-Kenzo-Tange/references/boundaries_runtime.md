# AR77-036｜BOUNDARIES + CONTEMPORARY CORRECTIONS
## Kenzo Tange

## Fit

### FIT
- 公共使命 /纪念 /机构身份需要空间化；
- 大跨结构与集体空间关系关键；
- 城市增长 /交通 /基础设施需要重组；
- 项目有真实扩展 /分期；
- 文化传统需要当代转译而非复古。

### PARTIAL FIT
- 丹下方法能处理公共秩序 /结构 /城市关系，但项目核心由特殊工艺、医疗流程、文保、住宅私密性等其他系统主导。

### NOT FIT
- 唯一目标是复制 Yoyogi / Hiroshima / Kagawa / Tokyo Plan / Tokyo Cathedral / Tokyo City Hall 的外观；
- 只想要“Metabolism style / Brutalist Tange style”；
- 缺少事实却要求具体混凝土、悬索、巨构或轴线答案。

## Contemporary Corrections

### Climate
大跨屋面、开放地面、玻璃 /混凝土围护、城市平台必须按真实热、雨、风、日照、热岛与能耗重新判断。

### Accessibility
纪念轴线、平台、高差、体育 /文化集会必须提供同等清晰的无障碍体验，不得以仪式序列排除人群。

### Fire / Life Safety
大跨、巨型公共空间、可增长系统、服务核心和分期必须验证疏散、烟控、防火分区与消防设备。

### Structure / Seismic
任何悬索、壳、核心、桥接、巨构、长跨都必须由当代结构 /抗震 /风工程验证；不得从历史先例推出。

### MEP
大跨空间、可扩展楼层、服务核心和复杂公共建筑必须验证设备容量、分区、检修和未来更新。

### Acoustics
体育、宗教、文化、纪念与集会空间必须独立校验混响、语言清晰度与设备噪声。

### Privacy / Security
公共开放不等于无限开放；政府 /机构 /纪念场所必须区分 public / controlled / secure zones。

### Operations
仪式高峰、普通日常、夜间关闭、赛事 /活动状态必须分别运行。

### Maintenance
悬挂结构、高位屋面、混凝土修复、复杂核心与城市基础设施必须有长期维护路径。

### Cost / Procurement
非标准结构、超大尺度基础设施和预留扩展不得因“未来性”自动合理化。

### Lifecycle
优先可维修、可分期、可适应；必须比较 embodied carbon、结构寿命、更新周期与拆除风险。

### Urban Governance + Social Equity
Tokyo Plan 1960 一类增长逻辑进入今天必须额外检查：
- public transit vs automobile dependency
- displacement / land rights
- ecological / waterfront impact
- phasing / financing
- governance
- public access
- demographic uncertainty

### Memory Ethics
纪念空间不得用单一宏大轴线抹平多元历史叙事；必须验证谁被记忆、谁被排除、日常使用如何共存。

### Tradition Correction
“tradition as catalyst”绝不许可复制日式屋顶、木构纹样、神社 /寺院空间符号。

### Metabolism Boundary
丹下与 1960s Metabolist discourse 存在重要关联 /影响，但不得在无来源时称其为《Metabolism 1960》作者或把所有代谢派方法归入本 Skill。

## Professional Boundary

本 Skill 可做前期建筑 /城市判断、Route / DNA、A/B/C、Critic 与下一步测试；
不能替代持证建筑师、城市规划审批、结构 /抗震 /风工程、MEP、消防、声学、交通、文保、景观、造价、治理与社会影响评估。
