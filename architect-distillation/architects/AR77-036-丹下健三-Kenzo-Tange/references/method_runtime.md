# AR77-036｜METHOD RUNTIME
## Kenzo Tange｜Architectural Judgement Kernel

## 0｜Evidence + Collaboration Boundary

本 Runtime 只允许 `KNOWN` 与 `SUPPORTED INTERPRETATION` 进入 Method / Route / DNA / Rules。

丹下健三拥有明确的个人理论与设计主导，但大量重要项目由 Tange Laboratory、URTEC、结构工程师、设备工程师与其他专业共同完成。
因此：
- 不把团队工程成果全部归为丹下个人技术发明；
- 不把 Fazlur-Khan 式“作者英雄化”逻辑带入本 Skill；
- 对代代木等结构密集项目，结构系统必须保留工程协作边界；
- 对 Metabolism 1960，不得把该出版物的作者身份错误归给丹下。

## 1｜KNOWN

- Pritzker 资料将丹下的反复主题概括为：形式 / 空间 / 外观必须逻辑清楚，同时建筑要触动人的情感；创造应体现 technology 与 humanity 的结合。
- 丹下本人把 tradition 描述为“catalyst”：传统可以参与创造，但不应作为直接可复制的创造形式。
- 广岛和平纪念公园的竞赛方案通过清楚的轴线，把 Peace Boulevard、博物馆、纪念设施与 A-Bomb Dome 建立城市尺度的视线与记忆关系。
- 丹下长期研究城市结构；其 1959 年博士论文研究大城市空间结构与通勤运动，Tokyo Plan 1960 则用线性城市 / 基础设施框架回应增长与变化。
- Tokyo Plan 1960 是 Tange Team 的提案，Harvard 档案保留其 Tokyo Bay 模型与《A Plan for Tokyo, 1960; Toward a Structural Reorganization》。
- 代代木国立竞技场把大跨悬索结构与集体公共空间结合；相关结构研究具有明确的工程协作背景，不应被简化成丹下个人的“屋顶造型”。
- 香川县厅舍由 Kenzo Tange Laboratory 设计，核心与结构秩序清楚；官方资料把其理解为现代技术、战后公共性、日本传统与现实社会的结合。
- 山梨文化会馆 / Yamanashi Broadcasting and Press Center 通过服务筒与水平工作空间构成可增长的开放系统；Pritzker 资料明确提到其 expansion potential。
- 丹下与 1960 世界设计会议、Metabolist 世代关系密切，但 Harvard 档案显示《Metabolism 1960》的主要文章由菊竹清训、槙文彦 / 大高正人、黑川纪章等人撰写；不得把该宣言作者身份归给丹下。

## 2｜SUPPORTED INTERPRETATION

AR77 将上述证据转译为：

`公共使命 / 使用 / 场地 / 城市或技术问题`
→ `建立逻辑清楚的空间与结构秩序`
→ `把人的感受 / 集体意义纳入判断`
→ `让传统只作为关系、比例、秩序或文化记忆的催化剂`
→ `通过轴线 / 结构 / 核心 / 交通 / 增长框架组织尺度`
→ `在建筑—城市之间验证变化能力`
→ `通过当代气候 / 社会 / 工程边界校正`
→ `最后才锁定形式`

这是 AR77 的 evidence-bounded runtime abstraction，不冒充丹下本人提出的固定七步法。

## 3｜Core Judgements

### J1｜LOGIC + HUMAN HEART｜逻辑与人心同时成立
建筑不能只有功能 / 技术逻辑，也不能只有情绪 / 象征；两者必须在空间中同时可验证。

### J2｜TRADITION AS CATALYST｜传统是催化剂
传统进入设计应改变比例、秩序、空间关系、公共意义或构造思考，而不是复制木构轮廓、屋顶或历史符号。

### J3｜CIVIC ORDER CAN BE SPATIAL｜公共使命可以被空间化
纪念、政府、文化与公共项目需要把集体意义转成到达、轴线、视线、开放地面与空间等级，而非只做纪念性表皮。

### J4｜STRUCTURE CAN CREATE COLLECTIVE SPACE｜结构可生成集体空间
大跨 / 公共建筑的结构系统应同时组织跨度、视线、人群、剖面与空间情绪；结构必须由工程验证。

### J5｜CITY IS A MOVEMENT + GROWTH SYSTEM｜城市是运动与增长系统
城市结构要回应流动、基础设施、增长与变化，而不是只拼建筑物体。

### J6｜FIXED INFRASTRUCTURE + CHANGEABLE INFILL｜固定基础设施与可变内容分层
核心、服务、交通可作为稳定骨架，工作 / 使用空间可按需求变化；这只在真实扩展需求存在时成立。

### J7｜SCALE MUST TRANSLATE, NOT SIMPLY ENLARGE
建筑尺度的秩序不能直接放大为巨构；每次跨尺度都要重新验证社会、交通、生态、治理与维护。

## 4｜Method Execution

1. 锁定 KNOWN / UNKNOWN / NEED VERIFY。
2. 写 3–5 条项目冲突，不先决定混凝土、悬索、轴线、巨构。
3. 判断问题发生在 ROOM / BUILDING / CIVIC / URBAN 哪个尺度，以及哪些尺度必须联动。
4. 选择 exactly 1 Primary Route；Secondary 最多 1。
5. D01 `LOGIC_HUMANITY_SYNTHESIS` mandatory；再选 1–3 个必要 DNA，总量 2–4。
6. 每个 DNA 指定 Plan / Section / Movement / Structure / Public Realm / Growth / Performance 的可验证痕迹。
7. 生成三个因果不同策略。
8. 比较后只推荐一个 Dominant，最多借一个有限机制。
9. 做 Contemporary Corrections。
10. Prompt Close 前执行 Prompt Fact Lock。
