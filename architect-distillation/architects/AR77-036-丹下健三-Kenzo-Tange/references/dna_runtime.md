# AR77-036｜DESIGN DNA RUNTIME
## Kenzo Tange

## Selection Rule

- **D01 mandatory**
- 再选 1–3 个真正必要 DNA
- 总量默认 **2–4**
- 未选 DNA 不得回流 Strategy / Recommendation / Keep / Next / Prompt / Handoff

---

## D01｜LOGIC_HUMANITY_SYNTHESIS｜逻辑—人性综合

**判断含义**
空间、形式与技术必须逻辑成立，同时回应人的情感 / 集体体验。

**Trigger**
所有完整项目分析。

**Spatial Operation**
同时建立 functional / technical logic 与 human / collective experience 两张证据图，并寻找共同空间决策。

**适用边界**
全部项目。

**Failure Mode**
只讲“感动人”无空间机制，或只讲效率无人的体验。

**可验证空间痕迹**
同一关键决策既能解释系统逻辑，也能解释人的到达、观看、使用或感知。

---

## D02｜TRADITION_AS_CATALYST｜传统作为催化剂

**判断含义**
传统改变设计思考，但不以直接复制的形式出现。

**Trigger**
场地 /机构 /文化任务与传统存在真实关系。

**Spatial Operation**
把传统拆成比例、秩序、层级、阈值、集体行为、构造原则等，再用当代条件重新生成。

**适用边界**
公共、文化、机构、场所敏感项目。

**Failure Mode**
复制屋顶、斗拱、木构格子、庭院或材料纹样。

**可验证空间痕迹**
即使去掉历史图形，空间秩序仍能说明文化连续性。

---

## D03｜CIVIC_AXIS + MEMORY ALIGNMENT｜公共轴线 / 记忆对位

**判断含义**
重要视线、遗址、仪式与公共建筑可通过空间对位形成集体认知。

**Trigger**
纪念 /历史 /城市公共项目中存在必须被看见、经过或关联的真实对象。

**Spatial Operation**
组织 approach / sightline / axis / open ground / event sequence。

**适用边界**
纪念、文化、城市公共空间。

**Failure Mode**
轴线变成权威主义构图；日常路径被仪式性压制。

**可验证空间痕迹**
总平、视线与人行路径同时证明关系。

---

## D04｜STRUCTURE_AS_SPATIAL_ORDER｜结构作为空间秩序

**判断含义**
结构通过跨度、剖面、视线和空间层级组织公共体验。

**Trigger**
跨度 /荷载 /抗震显著影响空间。

**Spatial Operation**
比较多个工程可行结构概念对 section / circulation / sightline / services 的影响。

**适用边界**
大型公共、体育、礼堂、机构。

**Failure Mode**
直接复制悬索、壳、混凝土框架或结构表情。

**可验证空间痕迹**
结构路径与空间 /视线 /设备关系在剖面一致。

---

## D05｜MOVEMENT_BASED_URBAN_STRUCTURE｜运动驱动城市结构

**判断含义**
城市秩序应从真实流动与基础设施关系出发。

**Trigger**
通勤、交通、区域连接、增长压力影响城市组织。

**Spatial Operation**
用 movement / access / transit data 重新定义 network / spine / centers。

**适用边界**
城市设计、TOD、区域 /新城规划。

**Failure Mode**
把 Tokyo Plan 的线性巨构或海湾跨越当模板。

**可验证空间痕迹**
交通 /步行 /公共领域 / program 分布存在因果图。

---

## D06｜GROWTH_CHANGE_FRAMEWORK｜增长 / 变化框架

**判断含义**
设计要区分长期稳定骨架与可能变化内容。

**Trigger**
项目存在真实的扩展、分期、人口 / program 变化。

**Spatial Operation**
建立 phase 0 / phase 1 / future state，定义哪些固定、哪些可替换 /扩展。

**适用边界**
建筑与城市尺度。

**Failure Mode**
为“未来感”制造大量未使用空间或巨型基础设施。

**可验证空间痕迹**
不同阶段都有独立运营能力和清楚接口。

---

## D07｜SERVICE_CORE_AS_INFRASTRUCTURE｜服务核心作为基础设施

**判断含义**
交通 /设备 /服务可以形成稳定骨架，让使用空间更自由或可变。

**Trigger**
服务系统、垂直交通、MEP 与未来变化是关键矛盾。

**Spatial Operation**
先定义真实 core / service dependency，再测试 adaptable occupied zones。

**适用边界**
办公、机构、研究、分期建筑。

**Failure Mode**
复制山梨文化会馆的圆筒核心或“插接”视觉。

**可验证空间痕迹**
core / services / fire / maintenance / adaptable zone 在平剖可验证。

---

## D08｜PUBLIC_OPENNESS + COLLECTIVE_GROUND｜公共开放 / 集体地面

**判断含义**
公共建筑应通过到达、地面层、平台 /广场或共享空间建立真实社会关系。

**Trigger**
政府、纪念、文化、体育等具有明确公共责任。

**Spatial Operation**
校准 public approach / threshold / gathering / everyday use / after-hours control。

**适用边界**
公共机构与大型集会项目。

**Failure Mode**
开放空间只是一张空旷纪念性效果图；缺少遮荫、可达、安全、日常活动。

**可验证空间痕迹**
日常 /仪式 /夜间三种状态都能运行。

---

# DNA Selection Logic

1. D01 mandatory。
2. 再选 1–3 个，总量 2–4。
3. D02 必须有真实文化 /传统条件。
4. D03 必须有真实 memory object / sightline / civic event。
5. D04 必须有真实结构 /跨度问题，且结构类型保持 NEED VERIFY 直到工程验证。
6. D05 必须有 movement / infrastructure 证据。
7. D06 必须有真实 growth / phasing scenario。
8. D07 必须有 service/core 约束。
9. D08 必须有明确 public responsibility / operation。
10. 未选 DNA 禁止以“次要优点”回流。
