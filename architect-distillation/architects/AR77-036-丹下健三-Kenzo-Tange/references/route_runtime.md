# AR77-036｜PROBLEM ROUTES
## Kenzo Tange｜Project-Problem Routing

这些 Route 是 AR77 从丹下健三证据中建立的项目问题路由，不是历史 Period，也不是“作品类型风格”。

---

## R1｜CIVIC_MEMORY_FRAME｜公共记忆 / 城市纪念框架

**Trigger**
- 纪念、灾后重建、公共历史、国家 / 城市记忆是核心任务；
- 需要把一个既有遗址、事件、城市视线或公共仪式纳入空间。

**核心问题**
怎样让公共记忆通过到达、轴线、视线、开放空间和设施关系被体验，而不是依赖纪念性造型。

**Method**
memory / existing trace → public approach → axis / view relationship → collective ground → building placement → ritual / everyday use → contemporary accessibility.

**主要 DNA**
D01 / D03 / D08 / D02

**适用边界**
纪念馆、公共文化、灾后重建、历史城市公共空间。

**风险**
单一轴线压过多元记忆；仪式空间牺牲日常可达；象征性压过真实使用。

**与其他 Route 差异**
由 collective memory / civic meaning 驱动，不由大跨结构或增长本身驱动。

---

## R2｜COLLECTIVE_SPAN_STRUCTURE｜集体空间 / 大跨结构

**Trigger**
- 体育、文化、集会等空间需要大跨度、清楚视线与强集体体验；
- 结构会显著改变剖面和空间。

**核心问题**
怎样让结构成为空间秩序，而不是成为视觉结构主义符号。

**Method**
crowd / sightline / span → structural options → section / circulation → acoustic / services → roof / enclosure relation → human experience.

**主要 DNA**
D01 / D04 / D08

**适用边界**
体育馆、礼堂、大型文化 /公共集会空间。

**风险**
结构形式先行；声学、消防、抗震、维护、吊挂 /设备失配。

**与其他 Route 差异**
由跨度、视线和集体空间共同驱动。

---

## R3｜URBAN_GROWTH_INFRASTRUCTURE｜城市增长 / 基础设施框架

**Trigger**
- 城市增长、交通拥堵、基础设施、区域扩张或长期变化是主问题；
- 单体建筑无法解决问题。

**核心问题**
怎样用运动、基础设施与增长结构重组城市，而不是制造静态总图。

**Method**
movement / commuting evidence → growth scenario → infrastructure spine / network → program distribution → phasing → public realm / ecology / governance test.

**主要 DNA**
D01 / D05 / D06

**适用边界**
总体规划、新城、区域 /交通导向开发、大型城市更新。

**风险**
汽车依赖、生态破坏、超级尺度、拆迁、治理不可行、投资 /分期失真。

**与其他 Route 差异**
由 urban movement + future change 驱动。

---

## R4｜OPEN_ENDED_CORE_FRAME｜核心骨架 / 可增长系统

**Trigger**
- 项目存在真实扩展、分期、未来 program 变化；
- 垂直交通、设备、服务与可变空间关系是主要矛盾。

**核心问题**
怎样把稳定基础设施与可变使用分层，使建筑在时间上可调整。

**Method**
future scenarios → fixed service / circulation infrastructure → adaptable occupied zones → connection rules → expansion boundaries → structure / fire / MEP validation.

**主要 DNA**
D01 / D06 / D07 / D04

**适用边界**
媒体 /办公 /机构、科研、校园、分期公共建筑。

**风险**
“可增长”从未发生；过度预留造成成本浪费；服务核心变成图形符号。

**与其他 Route 差异**
由 building-scale future change 驱动，而不是 city-scale megastructure。

---

## R5｜CIVIC_INSTITUTION_TRANSLATION｜公共机构 / 传统转译

**Trigger**
- 政府、教育、文化机构需要公共开放与身份；
- 场所文化 / 传统具有意义，但不应直接复古。

**核心问题**
怎样让公共制度、开放性与文化连续性通过现代结构 /空间秩序成立。

**Method**
civic use → public interface → structural / spatial order → tradition as catalyst → local social / climate test → contemporary institution.

**主要 DNA**
D01 / D02 / D08 / D04

**适用边界**
政府、大学、文化机构、市民建筑。

**风险**
把传统简化为木构仿形 / 格栅；把纪念性当权威；公共开放只停留在视觉。

**与其他 Route 差异**
由 civic institution + cultural continuity 驱动，而不是 memorial event 或 urban growth 驱动。

---

# Route Selection Logic

1. 先写主冲突，再选 Route。
2. Primary Route exactly 1。
3. Secondary = NONE 或最多 1。
4. Secondary 必须解决不同但真实的次级冲突。
5. R1 只有 collective memory / historical trace 为真实核心时启用。
6. R2 必须有真实 span / sightline / collective-space 需求。
7. R3 必须有 movement / growth / infrastructure 数据或清楚 NEED VERIFY。
8. R4 必须有真实的未来扩展 / change scenario。
9. R5 不得通过历史造型证明“传统”。
10. 未选 Route 禁止回流 Recommendation / Prompt / Handoff。
