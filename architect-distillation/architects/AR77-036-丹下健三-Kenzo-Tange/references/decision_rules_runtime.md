# AR77-036｜DECISION RULES
## Kenzo Tange

1. **当**用户要求“丹下式纪念性”  
   **→ 优先**D01 + 项目真实公共使命  
   **→ 因为**纪念性必须来自人 / 城市 / 事件的关系  
   **→ 通过**approach / use / civic meaning 验证  
   **→ 若失败则**删除纪念性造型。

2. **当**项目涉及传统  
   **→ 优先**D02  
   **→ 因为**传统在丹下方法中是 catalyst，不是复制对象  
   **→ 通过**去掉历史图形后空间逻辑是否仍成立验证  
   **→ 若失败则**删除仿古形式。

3. **当**纪念对象 / 遗址 / 城市视线真实重要  
   **→ 优先**R1 + D03  
   **→ 因为**公共记忆可以通过空间对位建立  
   **→ 通过**site plan + sightline + pedestrian sequence 验证  
   **→ 若失败则**轴线不成立。

4. **当**大跨结构可能塑造公共空间  
   **→ 优先**R2 + D04  
   **→ 因为**结构要服务跨度、视线、剖面与集体体验  
   **→ 通过**structure / section / sightline / services 联动验证  
   **→ 若失败则**不得指定悬索 / 壳 / 桁架等形式。

5. **当**城市问题主要来自增长 /通勤 /基础设施  
   **→ 优先**R3 + D05 / D06  
   **→ 因为**城市结构应回应 movement + change  
   **→ 通过**transport / public realm / phasing / ecology 验证  
   **→ 若失败则**禁止巨构化。

6. **当**项目希望“可扩展”  
   **→ 优先**D06 + D07  
   **→ 因为**变化必须有固定 /可变层级  
   **→ 通过**future scenarios + MEP / fire / structure / operation 验证  
   **→ 若失败则**取消预留增长系统。

7. **当**政府 /公共机构想表达“传统 + 现代”  
   **→ 优先**R5  
   **→ 因为**公共开放、现代结构与文化连续性必须同时成立  
   **→ 通过**public-ground + spatial-order + contemporary performance 验证  
   **→ 若失败则**不得用混凝土木构仿形补偿。

8. **当**A/B/C 只是混凝土 /玻璃 /屋顶形式差异  
   **→ 优先**重做  
   **→ 因为**策略必须因果不同  
   **→ 通过**不同 primary causal mechanism 验证  
   **→ 若失败则**Strategy Gate FAIL。

9. **当**Recommendation 想合并三案  
   **→ 优先**只保留一个 Dominant  
   **→ 因为**Dominant 必须独立成立  
   **→ 通过**最多一个 Borrowed Mechanism 验证  
   **→ 若失败则**Recommendation Gate FAIL。

10. **当**城市巨构方案忽略治理 /社会 /生态  
    **→ 优先**Contemporary Correction  
    **→ 因为**1960s growth optimism 不能直接移植到今天  
    **→ 通过**governance / displacement / transit / ecology / lifecycle 验证  
    **→ 若失败则**缩小尺度或改用可分期网络。

11. **当**Prompt 自动补 concrete / pilotis / suspension roof / brise-soleil / megastructure / service cylinder  
    **→ 优先**Prompt Fact Lock  
    **→ 因为**历史项目特征不是当前项目事实  
    **→ 通过**KNOWN / selected Route / Dominant / Borrowed / Selected DNA / verified site-climate-light 追溯  
    **→ 若失败则**删除或泛化。

12. **当**把 Metabolism 1960 或结构工程成果全部归给丹下本人  
    **→ 优先**Collaboration / Authorship Boundary  
    **→ 因为**史实存在明确团队与作者分工  
    **→ 通过**来源归属验证  
    **→ 若失败则**改写为团队 /关联 /影响关系。
