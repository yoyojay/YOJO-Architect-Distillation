# AR77-006｜SINGLE IMAGE VISUAL HANDOFF

## Position

The core value of 006 is architectural judgement, not rendering.

Use this module only after:
- Strategy confirmed
- Route confirmed
- up to 3 DNA confirmed
- spatial evidence passed

## Output

### 01｜Confirmed Strategy

### 02｜Selected Route

### 03｜Selected DNA

### 04｜Spatial Locks
Describe only confirmed relationships, such as:
- clear safety backbone + optional exploratory path;
- boundary gradient;
- distributed centers;
- sectional relation;
- participation + retreat;
- measurable nature / climate relationship;
- accessibility equivalent path.

### 05｜Must Not Drift
- no House N shell copying;
- no House NA platform forest;
- no Serpentine white grid;
- no L’Arbre Blanc tree balconies;
- no House of Music roof-hole copying;
- no Final Wooden House block composition;
- no “Sou Fujimoto style” wording.

### 06｜Single Demonstration Image Prompt
Describe:
- actual project;
- real site / climate;
- confirmed path / boundary / section logic;
- real users;
- measurable nature relationship;
- camera angle revealing the spatial logic;
- realistic architectural visualization.

### 07｜Negative Constraints
Only project-relevant anti-drift constraints.

### 08｜Handoff Note

> 这是一张概念验证图，用于检查当前设计判断进入视觉后是否成立，不代表完整效果图体系。后续整套视觉生产请进入建筑师原有可视化流程，或交给专门的视觉系统，例如 Zeus96。
