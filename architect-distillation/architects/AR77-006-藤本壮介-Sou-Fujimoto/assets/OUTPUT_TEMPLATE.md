## 14｜建筑初印象 Prompt
固定收尾：

`建筑初印象 Prompt｜复制到你的图像生成工具即可`

只允许使用：KNOWN 项目事实 + 锁定冲突 + 已选 Route + Dominant Strategy + 一个可选 Borrowed Mechanism + 最多 3 条 Selected DNA + 已通过的 Spatial Evidence。
不得使用 Sou Fujimoto style / 代表作名称 / Rejected Strategy / 未选 DNA / 未选 Route。
不得自动加入白色网格、透明盒子、平台森林、树形阳台等图像符号。
该 Prompt 只用于概念初印象检验，不是最终效果图指令。

## Recommendation Compliance Gate
- Dominant Strategy: one of A/B/C
- Borrowed Mechanism: NONE or one limited mechanism from one other strategy
- Rejected for Recommendation: remaining third strategy
- Positive Strategy Count must be 1 or 2; 3 = HARD FAIL


## Prompt Fact Lock

建筑初印象 Prompt 中每一个具体材料 / 结构 / 立面 / 开口 / 屋顶 / 平台 / 种植描述，都必须可追溯到：

- KNOWN
- Dominant Strategy
- 单一 Borrowed Mechanism
- Selected DNA
- 已通过的 Spatial Evidence
- 已验证的场地 / 气候 / 光条件

无法追溯的具体描述必须删除或泛化。

例：
- `white steel grid` → `a lightweight relational framework only if supported by the confirmed structural strategy`
- `transparent glass box` → `a visually permeable boundary calibrated for climate, privacy and operation`
- `stacked platforms` → 只有在 Selected DNA + 剖面 / 无障碍证据支持时才能出现
- `tree-covered balconies` → 未确认种植 / 维护 / 结构 / 气候条件则删除

不得为了让画面更“像藤本壮介”而自动补白网格、透明盒子、平台森林、树形阳台。
