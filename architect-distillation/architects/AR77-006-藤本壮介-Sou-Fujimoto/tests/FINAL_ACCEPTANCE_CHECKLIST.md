# AR77-006｜FINAL 外部验收

## First Contact PASS
- [ ] 首次完整项目分析先出现约 150 字大师初印象
- [ ] 有 3 个关键词 + 1 条“不要误读成”
- [ ] 不要求用户预先熟悉藤本壮介或 AI 命令
- [ ] 信息不足时每轮最多追问 1–3 个关键问题
- [ ] Critic / Handoff 不重复大师初印象

## Project Analysis PASS
- [ ] 使用标准项目表或等价自然语言项目资料
- [ ] 先做输入检查，UNKNOWN 不补写
- [ ] Fit Check 正确
- [ ] 1 条主矛盾 + 最多 2 条次矛盾
- [ ] Primary Route 1 条，Secondary 最多 1 条
- [ ] Selected DNA 最多 3 条
- [ ] 未选 DNA 不得后门回流
- [ ] A = 稳健型 / B = 平衡型 / C = 实验型
- [ ] A/B/C 因果不同
- [ ] 每案有 Site / Plan / Section / Path / Boundary / Environment / Structure / Safety / Operations 证据
- [ ] 推荐最多正向使用 2 个策略
- [ ] 推荐使用 Dominant / Borrowed / Rejected 固定结构
- [ ] 推荐保持 Route / DNA / Spatial Evidence 一致
- [ ] 清晰安全骨架优先于探索路径
- [ ] 有气候 / 消防 / 结构 / 隐私 / 无障碍 / 运营 / 生态校正
- [ ] 有建筑师确认点
- [ ] 有下一步 1–2 张图 / 测试
- [ ] 不复制藤本壮介作品
- [ ] 不做工程专业最终结论

## Visual Handoff PASS
- [ ] 只有一个单图 Handoff
- [ ] Strategy / Route / ≤3 DNA 已确认
- [ ] Spatial Evidence 已通过
- [ ] 有 Spatial Locks
- [ ] 有 Must Not Drift
- [ ] Prompt 不出现 Sou Fujimoto style
- [ ] 不扩展成整套效果图

## Prompt Close PASS
- [ ] 每次完整项目分析最后只有 1 个建筑初印象 Prompt
- [ ] Prompt 只使用 KNOWN + 锁定冲突 + Route + Dominant + 单一 Borrowed + ≤3 DNA + 已通过证据
- [ ] 不使用 Rejected Strategy
- [ ] 不使用未选 DNA / Route
- [ ] 不出现 Sou Fujimoto style / 代表作名称
- [ ] 不新增白网格 / 透明盒子 / 平台森林 / 树形阳台等默认图像
- [ ] 定位为概念初印象检验，不冒充最终效果图

## HARD FAIL
- 直接生成 Sou Fujimoto 风格建筑
- 复制 House N / House NA / Serpentine / L’Arbre Blanc / House of Music / Final Wooden House
- 白色网格 / 透明盒子 / 平台森林 / 树形阳台成为默认形式
- Selected DNA 超过 3 条
- 三案只是换造型
- A+B+C 三个一起进入推荐
- UNKNOWN 当事实
- Spatial Evidence 缺失
- 探索路径牺牲清晰安全主路径
- 把单图出口做成完整视觉生产系统


## Prompt Fact Lock PASS
- [ ] Prompt 中每一个具体材料 / 结构 / 立面 / 开口 / 屋顶 / 平台 / 种植描述都有可追溯依据
- [ ] 不把 UNKNOWN 写成具体物质事实
- [ ] 未确认材料使用中性表达
- [ ] 未确认平台 / 网格 / 玻璃 / 种植构造使用关系或性能表达，而不是图像符号
- [ ] 不为了“更像藤本壮介”自动补 white grid / glass box / platform forest / tree balconies
