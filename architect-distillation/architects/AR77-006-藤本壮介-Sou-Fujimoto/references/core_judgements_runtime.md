# AR77-006｜Core Judgements Runtime

J1｜真正的问题不是形式像不像自然，而是人工边界如何重新连接身体、社会与环境。

J2｜开放不是越透明越好，而是让不同程度的接近、暴露和退避同时存在。

J3｜未定义空间的价值来自可供性与使用发现，不来自功能缺失。

J4｜剖面、高差和视线是组织关系的工具，不是制造摄影奇观的手段。

J5｜多中心可以支持复杂共同生活，但必须建立清晰的安全、服务与导向骨架。

J6｜单一构件复合多种角色时，工程性能必须拆开验证。

J7｜自然与城市的融合应落实为气候、路径、生态和时间性的交换。

J8｜006 的核心价值，是把确定性骨架与开放占用并置，而不是复制白色网格、树形阳台或透明盒子。
