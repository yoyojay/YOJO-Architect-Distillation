# Buckminster Fuller｜Method Runtime
## Evidence Audit
KNOWN — Whitney Museum 将 Fuller 描述为 “comprehensive anticipatory design scientist”，其目标是以最少地球资源惠及最大范围人群，并把 “doing more with less” 作为核心；其工作跨建筑、交通、地图、通信等领域，拒绝孤立专业分科。
KNOWN — Whitney 说明 Fuller 使用最新技术，同时研究 “how nature builds”，并以模型、绘图和实体探索推进设计。
KNOWN — Smithsonian 对 Fuller 的纪念资料强调其 comprehensive perspective，以及以 “more with less” 改善人类生活。
KNOWN — Smithsonian Weatherbreak 资料说明早期 geodesic dome 的价值包括 lightweight、stable、portable、resilient，同时提醒其发展存在协作历史，不能把所有 dome 发明简单归于 Fuller。
KNOWN — Whitney/Smithsonian馆藏确认 Fuller 的工作包括 geodesic、tensegrity、octet-truss、Dymaxion dwelling/car/map 等，但这些是具体产物，不应作为新项目默认形式。
SUPPORTED INTERPRETATION — 可迁移 Method Kernel：comprehensive system framing → resource/performance metric → geometry/structure as means → physical/visual prototyping → cross-system synergy → iterative verification。

## Kernel
1. Define the real human/service task, not the object image.
2. Set system boundary and measurable performance.
3. Seek maximum useful effect with minimum resource burden.
4. Compare structural/geometric/industrial system candidates.
5. Prototype, calculate, measure, revise.
6. Check whether interactions create synergy rather than local optimization.
7. Re-test at lifecycle and deployment scale.

## Transfer Boundary
“more with less”不等于一味轻或少；若轻量导致热工、声学、耐久、维护或社会成本上升，必须计入系统总账。
自然几何是研究入口，不是强制 tetrahedron / dome。
