# Problem Routes
## R1｜RESOURCE_PERFORMANCE
Trigger: 材料、重量、跨度、能源或碳是主约束。
核心问题: 单位资源能提供多少有效性能。
Method: baseline → resource metric → alternatives → prototype/calculation → lifecycle correction.
主要 DNA: D1 D2 D4.
边界: 不能只优化结构重量。
风险: 局部减重转移到围护/设备。
差异: 从资源绩效起步。

## R2｜LIGHTWEIGHT_SPAN
Trigger: 大覆盖、大跨、可移动或低自重是主问题。
核心问题: 如何用稳定几何/结构系统降低自重并维持空间性能。
Method: load/span definition → structural families → geometry → engineering comparison.
主要 DNA: D2 D3 D5.
边界: 不预设 geodesic。
风险: 结构效率牺牲防火、声学、热工。
差异: 从结构覆盖起步。

## R3｜INDUSTRIAL_DEPLOYMENT
Trigger: 重复生产、运输、快速装配、拆卸或远程部署关键。
核心问题: 建筑能否成为可制造、可运输、可替换的部件系统。
Method: module logic → part count → packing → assembly → replacement.
主要 DNA: D4 D6 D7.
边界: 不默认预制优于现场建造。
风险: 标准化压过地方需求。
差异: 从生产物流起步。

## R4｜SYSTEMS_SYNERGY
Trigger: 结构、围护、能源、空间、服务相互牵制。
核心问题: 能否通过系统耦合同时减少多个负担。
Method: system map → dependencies → leverage point → prototype → whole-system metric.
主要 DNA: D1 D5 D8.
边界: 复杂耦合必须可维护。
风险: “综合”变成不可验证宏大叙事。
差异: 从跨系统反馈起步。
