# Boundaries + Contemporary Corrections
- climate: 热、湿、风、雨、日照与极端天气按当地数据。
- accessibility/fire: 轻量/模块系统不得削弱无障碍、疏散、防火与烟控。
- structure: geodesic/tensegrity 等任何系统都必须当代工程计算；协作发明史不得简化为个人神话。
- MEP/acoustics/privacy: 薄轻系统常带来设备、隔声、隐私负担，必须计入。
- operations/maintenance: 接头、膜/板、密封、排水、替换和高处维护可达。
- cost/procurement: 专用构件、模具、运输、认证和供应链风险计入。
- lifecycle: embodied carbon、运行能耗、维修、拆解、回收统一核算。
- social/local fit: comprehensive design 不能以全球统一技术方案覆盖地方生活、劳工、文化与法规。
- technology optimism: 预测性方案必须区分 KNOWN / NEED VERIFY，不以未来技术自动解决当前问题。
