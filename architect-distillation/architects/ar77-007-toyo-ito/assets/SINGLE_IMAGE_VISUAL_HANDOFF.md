# AR77-007｜SINGLE IMAGE VISUAL HANDOFF

## 定位

007 的核心不是效果图 Prompt。

本模块只负责：

**把已经确认的 Toyo Ito 方法判断，交给一张概念验证图。**

---

# 启动条件

必须已经确认：

- Strategy
- Primary Route
- 4–7 Selected DNA
- Plan / Section / System evidence

---

# 输出

## 01｜Confirmed Strategy

## 02｜Primary Route

## 03｜Selected DNA

## 04｜Spatial / System Locks

例如：

- the modified rule is explicit;
- structure / circulation / services have a real spatial role;
- public and restricted areas remain legible;
- topological links are readable;
- environmental claims are tied to real daylight / air / thermal logic;
- accessibility and fire paths remain clear;
- the image shows actual use, not only iconic form.

## 05｜Must Not Drift

必须检查：

- 不复制 Sendai 13 tubes；
- 不复制 TOD'S branch façade；
- 不复制 Tama repeated arches；
- 不复制 Taichung cave-like walls；
- 不复制 Tower of Winds illuminated cylinder；
- 不复制 Home-for-All hut aesthetics；
- 不把曲线、网格、透明当作默认“伊东感”。

## 06｜Single Demonstration Image Prompt

Prompt 应描述：

- current project type;
- actual site / climate facts;
- confirmed strategy;
- exact rule / infrastructure / network being tested;
- real users and public activity;
- verified boundary / structure / environment relationship;
- realistic architectural visualization;
- a camera angle that makes the spatial-system logic visible.

禁止出现：

- `in the style of Toyo Ito`
- `Sendai Mediatheque inspired`
- `TOD'S style`
- `Tama Library style`
- `Taichung Theater style`

## 07｜Negative Constraints

只写与当前项目防漂移直接相关的约束。

## 08｜Handoff Note

> 这是一张概念验证图，用于检查当前设计判断进入视觉后是否成立，不代表完整效果图体系。后续整套视觉生产请进入建筑师原有可视化流程，或交给专门的视觉系统，例如 Zeus96。
