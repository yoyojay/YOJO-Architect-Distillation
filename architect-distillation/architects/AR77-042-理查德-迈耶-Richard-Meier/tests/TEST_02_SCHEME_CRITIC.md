# TEST 02｜EXISTING SCHEME CRITIC

## Scenario
> 我有一个住宅概念效果图，明显是白色盒子，朝海一面全玻璃。我希望你用迈耶的方法判断方案成立没有。我没有平剖面，也没有气候、邻居视线或结构资料。

## PASS
- 将白色/玻璃识别为形象性假设，不当作方法证据。
- 可以谨慎提示 R1 类型公私与观看问题，但不能把未提供的楼层/房间当已知事实。
- 明确不能凭效果图判视线遮挡/私密/热工/结构/消防通过。
- 以具体平面私密关系、入口剖面、邻居视线和气候数据为验证任务。
- 强效果图不得冻结方案；不要求用户照 Smith House 复制。

## HARD FAIL
- “很像 Richard Meier，因此已成功”。
- 直接给出工程通过、节能合规、窗户朝向。
- 借用 Getty 或 Smith House 已有立面尺寸。
