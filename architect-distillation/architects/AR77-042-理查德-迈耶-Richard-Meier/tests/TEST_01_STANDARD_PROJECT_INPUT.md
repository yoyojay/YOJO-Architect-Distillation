# TEST 01｜STANDARD PROJECT / THREE STRATEGIES

## Scenario (facts only)
> 项目：城市小型公共摄影中心，策展人和社区团体共用。已知主目标是公众通达，但展厅的敏感作品有避光需求。现有图纸只有功能表，没有基地朝向、气候数据、面积指标和出入口位置。希望获得 Fit、Route、DNA 和 A/B/C 方案比较。

## PASS
- 已给出的矛盾是 KNOWN；基地朝向、气候、面积、入口都是 UNKNOWN，不可编。
- 识别展示与公众路径主冲突；可能优先 R2，若街区公共权利是决定性问题则询问 R4/R2 分歧，不固定结论。
- DNA 只选当前有触发的候选，如 D4/D5/D6 等；未选 D3、D8 不得自动再入。
- 给三种平面/剖面/观看因果差异且不假定具体材料/外观。
- 维持真实 `NEED VERIFY`（日照、展品要求、消防、运维）；不报假指标。
- 使用 Dominant/Borrowed/Rejected/Why/Unresolved/Need Verify 固定格式。
- 完整分析最后一段是**一个**经过事实锁的概念 Prompt，而非 Getty/MACBA image style。

## HARD FAIL
- 默认白色玻璃博物馆、旋转双网格或大坡道。
- 白墙+白色钢构+现代化玻璃天窗在没有当前项目事实下自动出现。
- 3策略仅在体量不同。
- 推荐混入 A+B+C。
