# AR77-042｜Customer Runtime Acceptance Checklist

> This checklist is **for executing tests** in the target Agent. File presence and static scan never alone prove actual behavioral PASS.

## 00｜First contact
- [ ] New full-project analysis shows exactly one Master First Impression, Chinese-character body 120–180, 3 keywords, 1 “不要误读成” warning.
- [ ] In incomplete input, asks only 1–3 blocking questions rather than issuing a long questionnaire.
- [ ] Does not show first impression again in Critic/follow-up/Handoff.

## 01｜Project input / fit / conflict
- [ ] Accepts natural language and standard full input form.
- [ ] Known/Supported Interpretation/Unknown/Need Verify separated; conflicting facts surfaced.
- [ ] Fit rationale based on actual spatial conflict, not architect names or museum/home type alone.
- [ ] Exactly 1 main conflict, <=2 secondary, with drawing/testable consequence.

## 02｜Method / Route / DNA
- [ ] Moves Program → Site → Order → Movement/Stasis → Light/Scale → Test/Revise with actual project evidence.
- [ ] Selects exactly one Primary Route R1/R2/R3/R4 (or returns ROUTE_UNRESOLVED).
- [ ] For selected Route shows Trigger/Main Question/Method/DNA candidate/Limit/Failure/Other Route difference.
- [ ] Each selected DNA has judgement/trigger/operation/boundary/failure/plan-section-movement trace.
- [ ] Defaults to 2–4 meaningful DNA only when supported; unselected DNA cannot return.
- [ ] Doesn't assume whiteness, curve, ramp, dual axis, all-glass façade.

## 03｜Three strategies + Recommendation
- [ ] A/B/C three causally different project spatial mechanisms with different plan/section/path consequences.
- [ ] Comparison shows main conflict, environment, operation, engineering, risks and tests.
- [ ] Dominant is single and independently operable.
- [ ] Borrowed is NONE or exactly one bounded mechanism from one other strategy; never a third contributor.
- [ ] Rejected strategies do not return in Why/Next/Prompt, and no unselected DNA resurfaces.
- [ ] Absent data leads to Need Verify, not fake compliance numbers.

## 04｜Corrections / critic / boundary
- [ ] Climate, accessibility, fire, structure, MEP, acoustics, privacy, operations, maintenance, cost, procurement, lifecycle checked or N/A justified.
- [ ] On diagram contradiction or strong rendered image, requires real plan/section/path evidence.
- [ ] No claims of licensed engineering/law final approval.

## 05｜Confirmation / prompt / visual
- [ ] Architect Confirmation Point explicitly asks for Dominant / Borrow / facts before Handoff.
- [ ] Full analysis ends with one “建筑初印象 Prompt｜复制到你的图像生成工具即可”.
- [ ] Fact Lock checks material/structure/façade/geometry/roof/openings/column/truss/surface/tech/landscape/furniture/program.
- [ ] No `Richard Meier style`, named copied buildings, new construction facts, rejected or unselected mechanism.
- [ ] Single Image Handoff only **after** actual customer confirmation and user request, contains one image prompt + spatial locks/negative drift.
- [ ] Next drawings/tests are specific to dominant spatial hypothesis.

## Mandatory hard failures
- Missing Universal Runtime execution logic in main SKILL.md.
- Copied Getty fixed axes, Atheneum ramps, Jubilee geometry or white envelope unprompted.
- A/B/C differentiated only by shape/materials.
- `UNKNOWN` silently becomes verified.
- Rejected strategy/third contributor or unselected DNA returns.
- Prompt invents material/structural/façade/roof facts.
- Handoff without confirmed strategy.
- Any no-real-run claim `Smoke Test: PASS`.
