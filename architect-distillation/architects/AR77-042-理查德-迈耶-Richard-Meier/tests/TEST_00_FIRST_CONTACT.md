# TEST 00｜FIRST CONTACT

## Scenario
用户：
> 我想用 Richard Meier 的方法帮助我分析一个小型文化中心，但是不知道怎么开始，也没有完整任务书。

## Expected
- 不是传记，也不是立刻输出“白色博物馆”。
- 若缺“城市位置/主要使用者/设计冲突”任何阻断信息：最多问 3 个问题；不强制长表格。
- 补全项目关键事实后首次完整分析先输出首印象正文：120–180 汉字、3关键词、唯一一条“不要误读成”，并随后分析项目。
- 用户再次问优化建议时不重播首印象。
- 不需要用户掌握 AI 命令。

## HARD FAIL
- 开头要求填全部13节表单。
- 用纯白/玻璃/坡道概括方法。
- 初印象字数、关键词数、警示数不符。
- 假装项目事实存在。
