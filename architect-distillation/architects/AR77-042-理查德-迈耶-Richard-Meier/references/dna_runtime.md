# AR77-042｜Meier Design DNA — Evidence-Bound Working Index

> 8 个条目是 **AR77 蒸馏出的工作索引**，非迈耶自述的 DNA 分类。选择原则是「只选必要而可验证者」，**默认 2–4 个**，这是工作负荷控制而非历史事实。未选 DNA 不得在策略、推荐、图像 Prompt 或 Handoff 中回流。

## D1｜SITE ORDER DIALOGUE｜场地秩序对话
- **判断含义**：以可核查的地形/城市参照组织建筑，而不是把建筑图案投射到土地。
- **Trigger**：场地轴线/坡度/临街格局对路径和组团有决定性影响。
- **Spatial Operation**：画场地参考轴与功能轴叠置图，注明哪一条服务何种使用。
- **边界**：绝不默认双轴偏转，数值与方向来自项目证据。
- **Failure Mode**：抽象网格凌驾高差、土地权利和入口。
- **可验证空间痕迹**：总平主轴、剖面抵达点、交通转接矩阵。
- **证据**：Getty 官方与迈耶文稿（S5/S6/S7）。

## D2｜PRIVACY/COMMON GRADIENT｜私密—共同生活梯度
- **判断含义**：使用者角色和活动强度决定边界，而非「越透明越好」。
- **Trigger**：居住或日常公共/私密转换明确。
- **Spatial Operation**：功能分区结合进入顺序、视线遮蔽、楼层关系。
- **边界**：应兼顾无障碍/安全/昼夜与邻里距离。
- **Failure Mode**：为景观暴露居住隐私。
- **可验证空间痕迹**：平面隐私图+入口横剖+视线遮挡测试。
- **证据**：Smith House、Saltzman House（S3/S12）。

## D3｜ORDER/COUNTERPOINT｜秩序与有效偏移
- **判断含义**：秩序用于提供可读性，偏移仅用于化解场地与项目需求冲突。
- **Trigger**：一套明确组织系统无法同时处理环境和功能。
- **Spatial Operation**：先建立单系统，再用局部第二参考系解决被指明的冲突。
- **边界**：不自动添加旋转网格/曲面。
- **Failure Mode**：几何过度导致无效面积、结构造价和导向负担。
- **可验证空间痕迹**：两套轴对应的问题、走道面积比、节点可读性对比。
- **证据**：Getty 文稿与 MoMA Atheneum 方案材料（S7/S10）。

## D4｜PATH/PAUSE/VIEW｜路径—停驻—观看
- **判断含义**：移动改变对场地/空间的认识；每个转折要有使用意义。
- **Trigger**：公共访问、分层参观、景观感知与导向冲突。
- **Spatial Operation**：定义到达、转折、停驻、关键视线、垂直变换；测试等效无障碍路由。
- **边界**：不默认坡道、屋顶观景台或延长参观路径。
- **Failure Mode**：过度曲折、迷失、疲劳或紧急疏散不达标。
- **可验证空间痕迹**：路径长度/高差、动线叠图、视线序列、停留面积。
- **证据**：Atheneum（S4/S10）、MACBA（S8）。

## D5｜CONTROLLED DAYLIGHT｜可控制的自然光
- **判断含义**：自然光是活动条件，不是无条件透明的图像效果。
- **Trigger**：展品保护、工作视环境、昼光体验、热工/眩光条件影响空间决定。
- **Spatial Operation**：依据需要分区设受光目标、遮阳和可控程度；先画剖面光路径。
- **边界**：气候、朝向、藏品限制必须验证；不假设具体幕墙构造。
- **Failure Mode**：眩光、展品损伤、过热、过高维护/能耗。
- **可验证空间痕迹**：不同功能光量要求、采光/眩光模拟、季节性遮阳策略。
- **证据**：Getty 官方受控天光与 MACBA 的受光空间（S5/S8）、本人演说（S1）。

## D6｜HUMAN SCALE SECTION｜尺度与剖面清晰性
- **判断含义**：由活动、视线和停驻需求判断高度层次、压缩与释放，不靠巨构造型。
- **Trigger**：上下功能的联系、进深、体量与人的尺度发生矛盾。
- **Spatial Operation**：在平面邻接基础上画入口/公共/安静区的关键剖面。
- **边界**：不自动引入通高空间或特殊悬挑。
- **Failure Mode**：只追求戏剧性而使环境/声学/疏散/成本失控。
- **可验证空间痕迹**：剖面高度关系、使用者视线、实际活动尺度。
- **证据**：1984年本人演说（S1）、Smith House（S3）、Atheneum（S4）。

## D7｜PUBLIC EDGE CONTRIBUTION｜公共边界贡献
- **判断含义**：建筑与城市公共空间之间必须有可达、可用、可管理的真实关系。
- **Trigger**：场地缺少公共路径/停留空间，建筑社会责任明确。
- **Spatial Operation**：识别日常来往路线、非收费空间、门厅阈值和夜间闭合方式。
- **边界**：不能把私人地面默认为公众可进入；须与城市/社区/业主核实。
- **Failure Mode**：视觉上开放但社会/运营上封闭。
- **可验证空间痕迹**：全天/分时开放图、公共通行图、非馆内访客使用场景。
- **证据**：MACBA 官方历史档案（S8/S9）。

## D8｜PERCEPTUAL CONTRAST｜通过表面与光增强感知
- **判断含义**：表面明度与光影对比是观察周围变化的**可选**空间工具，而非「白色强制」。
- **Trigger**：项目已有明确的自然光、材质和观看目标，且对比有绩效/养护依据。
- **Spatial Operation**：用光反射/阴影对比样本验证可读性、眼部舒适和维护；具体饰面用户或工程确认前不提。
- **边界**：D8 非默认必选、不得构成图像风格命令；不由它自动派生白墙/白色陶板。
- **Failure Mode**：反射眩光、污损维护、过热、艺术品/文化语境冲突。
- **可验证空间痕迹**：亮度对比模型、现场材料反射测试、维护与生命周期评估。
- **证据**：1984年本人演说关于白色作为多种可能手段之一（S1）。

## DNA Selection Logic

1. 只有 Primary Route 确定后才选 DNA；每项必须对应一个当前项目问题和一种可验证的空间痕迹。
2. 逐一填写 `Selected? / Related primary conflict / Trigger evidence / Route / Plan-Section-Path Trace / Verification / Exclusion reason`。
3. 默认 2–4 项；若仅 1 项有证据可选 1 项并注明理由；绝不为了数量凑数。超过 4 项须解释为什么减不了，先考虑合并验证任务而不是增加术语。
4. D8 是条件型，未经亮度/环境目标和维护依据不能选；D3 必须证明两套秩序的必要性。
5. 未选 DNA 在 A/B/C、Dominant、Borrowed、Why、Next、Prompt、Handoff 不得作为「视觉建议」或「子机制」回流。
6. 路线发生改变、项目事实纠正时重新运行选择，而不是悄悄添加。
