# AR77-042｜Richard Meier Method Runtime

> **性质**：AR77 从 Richard Meier 本人论述和可核实项目事实形成的**操作性归纳**；不称为迈耶本人创设的「六步法」。每一机制是可迁移的建筑决策关系，而不是形式清单。

## M0｜核心判断问题

设计不是先把项目「变白」，而是：**如何使用平面秩序、相对位移、光线、尺度与路径，使使用活动、场地环境和空间知觉相互清晰？**

迈耶在1984年普利兹克获奖演说中主动指出其关注点是光与空间、人的尺度、视线变化、运动和停驻；亦明确把白色称为提高感知的一种手段，而非所有建筑必需材料（证据 S1，KNOWN）。
- Smith House：入口侧私密功能与面海侧共用生活空间形成清楚的平剖面关系，且决定观看方位（S3，KNOWN）。
- Atheneum：参观流线、坡道、转折和对周边历史镇景的观看共同构成建筑经验（S4、S10，KNOWN）。
- Getty：不同地形脊线、洛杉矶城市格局和园区程序决定秩序轴，馆内自然光有遮阳/保护机制（S5–S7，KNOWN）。
- MACBA：展厅、纵向公共厅、坡道、自然光及周边城市需求互相关联（S8、S9，KNOWN）。

## 可执行六次判断（AR77 转译）

1. **PROGRAM GRADIENT｜明确谁的空间**：从用户活动列出公共/私密、观众/后勤、静/动关系；对应可操作的平面边界，未得到用户输入不得默认「公共」。
2. **SITE ORDER｜建立场地事实**：把已验证的到达、地形、视线、边界、既有纹理、城市权利标注成事实图；未核准日照角度不能写「南向采光」。
3. **ORDER & COUNTERPOINT｜选择可解释的秩序**：用功能轴/场地轴组织邻接和模块关系；仅当交通、地形、使用冲突真实存在，才允许第二秩序形成相对位移；反对为了视觉刺激强行旋转网格。
4. **MOVEMENT & STASIS｜编排体验而非复制坡道**：选关键到达、视线、停留点、向上/向下关系；必须有等效无障碍通达、疏散与运营证据。
5. **LIGHT & HUMAN SCALE｜让光可控制**：为使用需求定义日光获得、眩光、展示保护、热负荷和尺度；把对比/表面反射当可选的感知工具，**不得自动推荐白色/玻璃/曲面/陶瓷板**。
6. **BUILD/TEST/REVISE｜证明具体可用**：在平面—剖面—路径—日光/眩光—环境—运维中留下可验证痕迹；失败时回退 Program/Site/Route，不能以外形修补因果失效。

## 因果 vs 外观

- **因果且可迁移**：公共与私密的空间界限 → 平剖面组织；地形与城市网格 → 园区坐标；展厅与环流关系 → 光、坡道、视线的次序；服务设施与保护需求 → 不同受光与访问权。
- **需项目验证的迁移**：第二轴偏转、连续坡道、室内中庭、通透边界、光影对比、可见层次。
- **仅历史视觉证据、不得默认迁移**：纯白色表皮、特定陶瓷幕墙、特定坡道和栏杆组合、Getty 的石材与网格数字、Jubilee Church 的三曲壳与宗教符号、具体作品轮廓。

## 停止/复位

若项目对使用者需求、场地实际数据或消防/无障碍边界未知：先列明 `UNKNOWN / NEED VERIFY`，问最多 3 个决定路线的问题，不生成确定形式。
若第二秩序增加面积和成本而无改善：删除第二秩序，回到主要功能轴。
若自然光损伤展品/隐私/热舒适：改以控制日光性能为目标，重新做平剖面，而非坚持通透形式。
