# AR77-042｜Contemporary Corrections / Limits / Anti-Copy

## 1｜方法与建筑事实的边界

迈耶本人演说与项目能证明他重视自然光、尺度、空间秩序、视线、运行路径及历史连续性；**不能因此推出**所有项目一定要白色、玻璃、平屋顶、旋转网格、坡道、曲墙、天窗或某具体材料。历史项目的效果和技术性能应分别判断；不把个别项目的方案当所有项目的标准答案。

## 2｜当代校正必须有责任人和测试

| 维度 | 风险追问 | 要求的证据/动作 |
|---|---|---|
| Climate / thermal | 昼光丰富是否造成过热、热损失、玻璃屋面凝露？ | 实际气候文件、负荷与围护结构方案；未核实材料不得预设 |
| Daylight / glare | 明亮空间是否有眩光、藏品损伤或观看困难？ | 基于确切功能的日光/眩光/UV测试、遮阳与展品要求 |
| Accessibility | 「叙事坡道」是否存在平等、连续、不疲劳的可达路线？ | 入口至主要功能全部路径、坡度长度、休息平台/电梯校审 |
| Fire / egress | 通高、连通空间及复杂路线会否影响烟控与疏散？ | 法规下的防火分区、疏散距离、容量与烟控专项审查 |
| Structure | 多轴偏移、悬挑、连桥与复杂节点是否合理？ | 结构方案和跨度/侧向体系/容差验证，不因历史作品预设结构 |
| MEP | 大空间空调、分层维护与设备动线能否共存？ | 设备量/分区、风道空间和可检修性 |
| Acoustics | 反射表面与通高空间是否过响、互相干扰？ | 声学目标、混响/隔声和临场活动模拟 |
| Privacy / security | 为观看与开放牺牲隐私、收藏/办公安全？ | 昼夜公共权利分区图、视线和门禁逻辑 |
| Operations | 日常/夜间、供应、应急、散场是否顺畅？ | 时间切片路径图、运营流线与高峰模拟 |
| Maintenance | 明亮表面、大面积采光、复杂节点维护成本？ | 清洁、安全到达、替换维护周期和真实预算 |
| Cost / procurement | 几何偏移、特殊表面是否超出工法/工期？ | 基本量化模型、可采购性与替代方案 |
| Lifecycle / adaptation | 展陈和机构任务变化后秩序是否仍可用？ | 可变展厅测试、能源与全生命周期审查 |

未拿到数据则写 `NEED VERIFY`，不能写“已满足规范”。

## 3｜Anti-Copy

禁止：
- `Richard Meier style` / “迈耶风格”图像提示词；
- 复制 Smith / Douglas / Saltzman houses 特定平面/表皮；
- 复制 Atheneum 特定坡道、栏杆、观景序列；
- 复制 High Museum 或 MACBA 的外立面、曲面、长廊构图；
- 复制 Getty 的双轴角度、台地广场、石材和天窗系统；
- 复制 Jubilee Church 的三片混凝土曲壳及宗教象征；
- 自动作出白色陶板、全玻璃立面、白色钢构或纯白建筑模型。

允许迁移：**基于该项目证据的公私秩序 / 景观取向 / 通行与停驻 / 可控自然光 / 场地秩序 / 城市公共界面 / 性能审查**。

## 4｜Scheme Critic 检查表

依次审：
`Input Facts → Fit → Main Conflict → Primary Route → Selected DNA → Strategy/Geometry Causality → Plan/Section/Path Evidence → Climate/Accessibility/Fire/Structure/MEP/Acoustics/Operations → Anti-Copy → Prompt Lock`。

每项状态：`SUPPORTED / BROKEN / NEED VERIFY / NOT APPLICABLE`，并给具体证据/修复路径。
不要凭一张效果图宣告平面可行/安全/舒适，也不代替注册建筑师和专业人员的法定签审。

## 5｜偏差与回退

- 若 Method 失效 → 回到用户/项目需求。
- 若 Route 与主冲突无关 → 重选 Primary Route，重新选 DNA。
- 若 DNA 没有验证痕迹 → 删除并重跑 A/B/C。
- 若 A/B/C 无因果差异 → 推倒重做，不通过换外观。
- 若 Dominant 不独立 → 暂停推荐。
- 若专业校核不通过 → 不进入方案确认或单图 Handoff。
- 若效果图冻结方案 → 回到平剖/路径和明确的可逆假设。
