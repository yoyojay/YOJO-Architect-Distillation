# Antoni Gaudí｜Method Runtime
## Evidence Basis
- KNOWN: Sagrada Família 官方资料明确说明 Gaudí 的方法依赖 trial-and-error，模型对他极其重要，且模型可优先于平面图；他在现场工作室用比例模型试验形态与结构。
- KNOWN: 官方资料把自然与光列为长期来源，并说明几何被用于形成新形态、平衡且逻辑的结构与连续表面。
- KNOWN: UNESCO 将其贡献同时归于建筑与建造技术，并强调艺术与技术在其作品中不可分割。
- SUPPORTED INTERPRETATION: 对当代项目最可迁移的不是历史形象，而是“性能问题 → 模型试验 → 几何校正 → 结构/空间/构造整合”的判断链。

## Kernel
Problem reframing → model experiment → geometric/structural calibration → spatial consequence → construction/detail feedback → repeat.

## Transfer Boundary
自然观察不是“画成植物”；几何不是自由造型；模型不是展示模型。三者都必须承担验证功能。
宗教象征、特定历史工艺和具体材料不作为通用默认。
