# Problem Routes
## R1｜STRUCTURAL_EQUILIBRIUM
Trigger: 主冲突来自跨度、支撑、力流、空间连续与结构厚重之间的矛盾。
核心问题: 如何让力的传递本身参与空间生成。
Method: 建立可验证的荷载路径假设 → 模型/计算校正 → 剖面与空间同步调整。
主要 DNA: D1, D2, D4.
边界: 必须由结构工程验证；不得把悬链线/斜柱当图像符号。
风险: 形式复杂化早于工程证据。
差异: 从“力”起步，而非从边界/装配起步。

## R2｜GEOMETRIC_MEDIATION
Trigger: 程序、采光、边界、连续曲面或复杂空间关系需要一个可控制的几何系统协调。
核心问题: 几何能否同时减少冲突而非制造奇观。
Method: 将约束参数化/制模 → 比较几何变体 → 以性能和可建造性筛选。
主要 DNA: D2, D3, D5.
边界: 复杂度必须可测量、可放样、可施工。
风险: 数字工具制造无因果复杂度。
差异: 从“关系协调”起步。

## R3｜INTEGRATED_ASSEMBLY
Trigger: 项目价值集中在结构、围护、节点、细部、工艺与整体体验如何成为同一系统。
核心问题: 局部部件如何既完成技术任务又加强整体空间秩序。
Method: 部件—节点—表皮—空间往返验证。
主要 DNA: D4, D6, D7.
边界: 不默认历史工艺或手工材料。
风险: 细部过度定制导致维护/采购失控。
差异: 从“建造反馈”起步。

## R4｜LIGHT_SPATIAL_CALIBRATION
Trigger: 光、深度、方向与使用仪式/公共体验是核心空间冲突。
核心问题: 光如何通过几何和空间层级被组织，而非作为装饰效果。
Method: 真实朝向/使用时段 → 剖面与开口关系 → 光测试 → 结构/围护回校。
主要 DNA: D3, D5, D8.
边界: 未验证朝向、气候、眩光和热负荷前不指定具体开口形态。
风险: 追求戏剧性光效牺牲舒适与能耗。
差异: 从“环境与体验”起步。
