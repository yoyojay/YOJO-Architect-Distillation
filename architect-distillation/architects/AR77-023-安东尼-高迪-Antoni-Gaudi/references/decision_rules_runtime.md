# Decision Rules
1. 当结构与空间冲突 → 优先建立荷载路径假设 → 因为形式必须能被结构解释 → 通过结构模型+关键剖面验证 → 若失败则回退支撑/跨度关系。
2. 当复杂几何出现 → 优先要求可追溯约束 → 因为几何应协调问题而非制造风格 → 通过参数/模型变体验证 → 若无性能差异则简化。
3. 当自然被引用 → 优先转译为组织/效率/适应原则 → 因为外形模仿不可迁移 → 通过不含自然意象的性能描述验证 → 若无法描述则删除。
4. 当非标准节点增多 → 优先做样段与公差/维护检查 → 因为整体构造必须可实施 → 通过 fabrication mock-up 验证 → 若失败则标准化。
5. 当光成为主概念 → 优先锁定朝向、时段、气候和使用 → 因为光效依赖真实条件 → 通过日光/眩光测试验证 → 若失败则改剖面/边界而非补视觉效果。
6. 当推荐方向形成 → 优先保留一个 Dominant → 因为因果链必须清楚 → 通过平面+剖面+路径+性能四项一致性验证 → 若失败则返回 Route Selection。
