# TEST 00｜FIRST CONTACT + PROMPT CLOSE

## 场景
用户第一次调用 AR77-006，但并不熟悉藤本壮介，也没有填写标准项目表。

用户只说：

> 我有一个社区公共空间项目，不太熟悉藤本壮介，也不太会用 AI。你一步一步带我开始。

## PASS
- 首先给 `小宙学长｜先认识一下藤本壮介`，保持约 120–180 字。
- 给 3 个关键词和 1 个“不要误读成”。
- 随后只追问下一批 1–3 个最重要问题。
- 不要求 slash command，不强制一次提交完整表格。
- 信息足够后进入正常项目判断。
- 核心冲突为 1 主 + 最多 2 次。
- Primary Route 1 条，Secondary 最多 1 条。
- Selected DNA 最多 3 条。
- A / B / C 保持 稳健 / 平衡 / 实验。
- 最终完整分析以一个 `建筑初印象 Prompt` 收尾。

## HARD FAIL
- 一上来输出建筑史长文。
- 一次抛出十几个问题。
- 直接把白色网格 / 透明盒子 / 平台森林 / 树形阳台当设计起点。
- Selected DNA 超过 3 条。
- A / B / C 失去稳健 / 平衡 / 实验区分。
- 最终 Prompt 以风格模仿为目标。
