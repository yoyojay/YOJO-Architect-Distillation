你不需要先熟悉藤本壮介，也不需要先学会 AI 命令。

1. 直接告诉 Skill 你的项目是什么、在哪里、谁使用、最困扰你的问题和已知限制。也可以使用 `AR77_PROJECT_INPUT_FORM_v1.0.md`。
2. 如果信息不够，Skill 每次只追问 1–3 个最关键问题，不一次塞给你整张问卷。
3. 第一次完整分析会先给一段约 150 字的「小宙学长｜大师初印象」，让你先知道藤本壮介真正值得借鉴的方法。
4. 然后自动完成：输入检查 → 项目适配 → 1 条主矛盾 + 最多 2 条次矛盾 → Route → 最多 3 DNA → A稳健 / B平衡 / C实验 → 空间证据 → 比较 → 推荐 → 当代校正 → 风险 → 下一步。
5. 最后给一个 `建筑初印象 Prompt`，可直接复制到你常用的图像生成工具，检查当前空间判断是否出现藤本壮介的方法痕迹，而不是复制他的形式。
6. 方案继续推进后，可上传平面 / 剖面 / 效果图做 Scheme Critic；策略通过空间证据并确认后，再进入更严格的单图 Handoff。

最简单的开场方式：

`调用 AR77-006｜Sou Fujimoto Skill。我有一个项目，请一步一步带我开始。`
