# AR77-006｜Decision Rules Runtime

## DR-01｜事实锁
Key project facts missing → complete / label unknowns before concept generation.

## DR-02｜核心矛盾
Style word / room list → rewrite as a real value conflict.

## DR-03｜Route 选择
Multiple Routes available → choose the one most directly answering the main conflict, plus up to one secondary Route.

## DR-04｜DNA 限量
Never use all DNA → max 3.

## DR-05｜多策略
Main conflict locked → generate A稳健 / B平衡 / C实验.

## DR-06｜边界梯度
Public/private or inside/outside conflict → draw relation levels before transparent façade.

## DR-07｜剖面先行
Limited area + complex relationships → use section to test height, sightline, bodily position.

## DR-08｜主秩序与探索
Exploration required → clear primary path first, then shortcuts / branches / pauses.

## DR-09｜构件复合
One component has many roles → separate performance verification.

## DR-10｜自然运行
Forest / tree / cloud idea → translate into measurable light, wind, rain, planting, path, season.

## DR-11｜共同生活
Distributed centers / openness → check vulnerable users, supervision, privacy, night operation.

## DR-12｜反风格 Critic
White grid / transparent box / tree balconies / platform forest appear → demand project problem + performance evidence. If no causal evidence exists, redesign.
