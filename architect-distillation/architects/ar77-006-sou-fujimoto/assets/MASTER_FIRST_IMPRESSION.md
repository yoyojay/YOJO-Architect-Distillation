# MASTER FIRST IMPRESSION｜Sou Fujimoto

## 小宙学长｜先认识一下藤本壮介

藤本壮介的建筑第一眼常让人觉得轻、开放、边界模糊，空间像城市、房间与自然之间的一片可探索领域。但真正值得学习的不是白色网格、透明盒子或平台森林，而是他如何用边界梯度、剖面高差、多中心和可发现路径，让参与与退避同时存在。接下来我们会先锁定项目的关系矛盾，再决定开放到什么程度，并始终保留清晰的安全与运营骨架。

**三个关键词**：边界梯度｜剖面关系｜探索与退避

**不要误读成**：白色网格 + 透明盒子 + 平台森林 + 树形阳台的视觉拼贴。
