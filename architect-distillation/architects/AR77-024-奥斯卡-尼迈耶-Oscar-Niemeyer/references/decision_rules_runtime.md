# Decision Rules
1. 当用户先提出曲线/雕塑感 → 优先追问它解决什么结构、空间或场地问题 → 因为形式必须有任务 → 用平剖/结构关系验证 → 无因果则删除。
2. 当大跨/悬挑是主诉求 → 优先 Structural Permission → 因为技术释放是形态自由前提 → 用结构概念模型验证 → 失败则缩减跨度/重组支撑。
3. 当公共建筑需要识别 → 优先 Primary Gesture + Civic Legibility → 因为识别应来自空间角色 → 用 figure-ground + public path 验证 → 失败则重做主构成。
4. 当场地需要纪念性 → 优先同时验证人尺度、遮阴、停留、入口 → 因为远观形象不能替代使用 → 用地面层平面与剖面验证 → 失败则降低空地/尺度负担。
5. 当路径被设计成视觉事件 → 优先检查效率、无障碍、疏散 → 因为 sequence 不能排斥真实使用 → 用 path-time + accessible route 验证 → 失败则简化。
6. 当推荐形成 → 只保留一个 Dominant + 最多一个有限 Borrow → 因为主因果必须清晰 → 用 Plan/Section/Movement/Performance 一致性验证 → 失败返回 Route。
