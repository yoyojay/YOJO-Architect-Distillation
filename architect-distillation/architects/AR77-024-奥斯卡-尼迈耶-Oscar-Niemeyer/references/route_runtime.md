# Problem Routes
## R1｜STRUCTURAL_RELEASE
Trigger: 跨度、支撑、悬挑、架空或空间连续是主冲突。
核心问题: 结构能否以更少/更明确的动作释放空间。
Method: structural permission → primary support logic → section → spatial consequence.
主要 DNA: D1 D2 D4.
边界: 必须工程验证；材料不默认。
风险: 先画夸张悬挑再找工程理由。
差异: 从结构技术起步。

## R2｜CIVIC_FIGURE_GROUND
Trigger: 公共/文化/制度项目需要明确集体空间与建筑—空地关系。
核心问题: 建筑主形与可使用公共地面如何互相定义。
Method: public role → figure/ground → approach → threshold → gathering.
主要 DNA: D2 D3 D6.
边界: 纪念性不得牺牲人尺度、遮阴、运营与可达性。
风险: 空旷平台变成不可用背景。
差异: 从公共场所与代表性起步。

## R3｜SEQUENCE_AND_VIEW
Trigger: 场地坡度、到达、连续观看、室内外转换是主冲突。
核心问题: 移动如何逐步揭示空间而非只服务造型。
Method: arrival → path → changing viewpoints → entry → return view.
主要 DNA: D4 D5 D7.
边界: 坡道不是默认形式；必须满足无障碍与疏散。
风险: 路径被戏剧化到效率失衡。
差异: 从身体移动与观看起步。

## R4｜LANDSCAPE_ART_SYNTHESIS
Trigger: 建筑必须与景观/艺术/开放空间形成整体，而非孤立对象。
核心问题: 不同媒介如何共享空间秩序又保持各自作用。
Method: site field → building placement → landscape/art interfaces → public circuit.
主要 DNA: D3 D6 D8.
边界: 不默认壁画、陶瓷、特定植物或水体。
风险: “综合艺术”退化为装饰堆叠。
差异: 从跨媒介场地整体起步。
