# AR77-013｜PROBLEM ROUTE RUNTIME

## R1｜RELATIONAL_INTERIOR
**Trigger:** the success of a cultural, workplace, educational, civic or social project depends on how groups see, meet, listen to or move around one another.
**Core Question:** what spatial relationships make the desired social/performative exchange possible before an exterior object is composed?
**Method:** map key relationships → establish shared/adjacent/differentiated zones → test movement, visibility and encounter → only then develop enclosure/volume.
**Primary DNA:** D1 / D2 / D4 / D5.
**Boundary:** privacy, security, acoustics, crowding and operational separation.
**Risk:** theatrical social space that ignores real work or refuge.
**Difference:** human/program relationship leads rather than context image or technical system.

## R2｜SITE_DIALOGUE
**Trigger:** the project sits in a strong urban, historic, infrastructural or landscape context and cannot be treated as an isolated object.
**Core Question:** how can a new building be distinct while entering a deliberate dialogue with its neighbors, routes and public realm?
**Method:** map context forces → identify what should align, contrast or connect → test differentiated masses and ground relationships → verify public route and scale.
**Primary DNA:** D2 / D3 / D4 / D8.
**Boundary:** heritage, planning, public realm, daylight/wind, neighbor impact.
**Risk:** using “contrast” as permission for arbitrary icon-making.
**Difference:** context relationship leads.

## R3｜MODEL_LED_VOLUME
**Trigger:** the project has real three-dimensional uncertainty—complex section, circulation, adjacencies, large volumes or multiple interacting masses.
**Core Question:** what must be learned in three dimensions that plan/elevation alone cannot resolve?
**Method:** make quick alternative models → test site/interior/volume/scale/movement → compare → eliminate unproductive complexity → translate only the surviving logic.
**Primary DNA:** D2 / D3 / D4 / D5.
**Boundary:** model must answer architectural questions, not merely produce novelty.
**Risk:** model formalism; sculptural complexity detached from use.
**Difference:** iterative three-dimensional learning leads.

## R4｜PERFORMANCE_COLLABORATION
**Trigger:** acoustics, structure, façade, fabrication or another specialist performance system is central to architectural quality.
**Core Question:** how can specialist requirements and architectural experience be developed together rather than sequentially?
**Method:** define performance criteria → co-develop spatial/technical options with specialists → test → revise geometry and systems together → coordinate digitally where complexity warrants.
**Primary DNA:** D1 / D2 / D7 / D5.
**Boundary:** responsibility, code, verification, maintainability and commissioning.
**Risk:** treating digital precision as proof of performance.
**Difference:** specialist performance leads.

## R5｜ADAPTABLE_ASSEMBLAGE
**Trigger:** a large institution contains multiple groups, neighborhoods or functions that need identity, connection and future change.
**Core Question:** how can differentiated communities coexist inside one legible, adaptable whole?
**Method:** define group identities + shared connectors → organize neighborhoods/parts → create encounter nodes and clear movement → protect change zones → test future scenarios.
**Primary DNA:** D1 / D3 / D4 / D7.
**Boundary:** operational change, MEP, fire compartmentation, acoustics, loose fit.
**Risk:** over-integrated bespoke parts becoming hard to change.
**Difference:** organizational adaptability leads.
