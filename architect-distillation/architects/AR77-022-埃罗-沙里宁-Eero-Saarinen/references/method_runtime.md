# Eero Saarinen｜Method Runtime

## Evidence status
以下 Method 只纳入 KNOWN 或 SUPPORTED INTERPRETATION。NPS 记录 Saarinen 强调更大环境与“same form-world”；NYC LPC 将其方法描述为分析每个问题、借助现代技术寻找独特形式/结构，并追求“whole organism”与反流水线式表达；Yale 档案与《Shaping the Future》显示其项目跨度巨大且以结构表达、技术创新和多样解法著称。

## Kernel
### M1｜Specific Job Before Signature
判断含义：每个项目先建立自己的问题定义与身份，不从固定形式语言出发。
执行：写出“这个项目若成功，必须让何种活动/机构/公共意义变得可读？”再开始空间组织。
边界：不等于任意造型；独特性必须由任务证据支撑。

### M2｜Next-Largest Context
对象必须在更大的房间/建筑/环境/城市关系中判断。执行时至少写出一个外部关系和一个内部关系。

### M3｜Organizing Idea
将复杂任务压缩为一个能同时影响 plan / section / path / system 的组织命题。若只能影响立面或形象，则不合格。

### M4｜Form-World Coherence
总体、结构、路径、构件与细部应属于同一因果世界。不是“都长得一样”，而是都服务同一组织命题。

### M5｜Technology as Expressive Means
结构/技术可以成为空间秩序与身份表达的手段，但技术类型必须由跨度、功能、施工、性能和成本共同验证。

### M6｜Experience + Whole
以到达、移动、停留、聚集、识别、离开等身体经验回测整体；表达不能牺牲使用与安全。

## Failure return
若组织命题无法在 plan-section-path 三者留下可验证痕迹，返回 M1/M3；若表达只剩造型，返回 M4；若结构/性能不可行，返回 M5 并重构而非装饰性修补。
