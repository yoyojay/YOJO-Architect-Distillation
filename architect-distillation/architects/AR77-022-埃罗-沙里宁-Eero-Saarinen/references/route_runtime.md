# Problem Routes Runtime

## R1｜INSTITUTIONAL_IDENTITY_SYSTEM
Trigger：企业、研究、办公或机构项目需要把组织方式与身份同时空间化。
核心问题：如何让工作系统、场地秩序与机构识别互相强化。
Method：M1→M2→M3→M4→M5。
主要 DNA：JOB-SPECIFIC CHARACTER / FORM-WORLD COHERENCE / STRUCTURE-AS-ORGANIZER / SYSTEM + DETAIL UNITY。
边界：身份不能压过运营弹性。
风险：把品牌表达降格为表皮。
差异：以系统秩序而非戏剧化移动为首因。

## R2｜MOVEMENT_AS_EXPERIENCE
Trigger：交通、到达、转换、候乘、展览等项目的路径本身是主要体验。
核心问题：如何让移动序列成为空间组织，而非导视补丁。
Method：M1→M3→M6→M4→M5。
主要 DNA：MOVEMENT DRAMATURGY / HUMAN EXPERIENCE CALIBRATION / FORM-WORLD COHERENCE。
边界：无障碍、疏散、容量优先。
风险：戏剧路径降低效率。
差异：以身体序列为首因。

## R3｜CIVIC_SYMBOLIC_WHOLE
Trigger：纪念、公共文化或城市节点需要长期公共识别。
核心问题：如何由场地与公共意义形成清晰整体，而非任意图标。
Method：M2→M1→M3→M4→M6。
主要 DNA：SYMBOLIC LEGIBILITY / NEXT-LARGEST CONTEXT / FORM-WORLD COHERENCE。
边界：象征解释不得冒充事实；公共可达性与日常使用必须成立。
风险：符号压倒人尺度。
差异：以公共意义和城市整体为首因。

## R4｜CAMPUS_COLLECTIVE_ORDER
Trigger：校园、多建筑群、学习/居住共同体。
核心问题：如何让建筑之间的关系、共同空间与个体单元形成可读秩序。
Method：M2→M3→M6→M4。
主要 DNA：NEXT-LARGEST CONTEXT / HUMAN EXPERIENCE CALIBRATION / SYSTEM + DETAIL UNITY。
边界：不预设封闭庭院或特定几何。
风险：总体秩序压平局部差异。
差异：以多体关系和共同体为首因。

## R5｜CONCENTRATED_ASSEMBLY
Trigger：礼堂、竞技、宗教/集会等高度集中空间。
核心问题：结构、声学/视线、聚集与空间身份如何形成一个整体。
Method：M1→M3→M5→M6→M4。
主要 DNA：STRUCTURE-AS-ORGANIZER / HUMAN EXPERIENCE CALIBRATION / FORM-WORLD COHERENCE。
边界：声学、结构、消防必须专业验证。
风险：结构姿态先于性能。
差异：以集中共同体验与大空间系统为首因。
