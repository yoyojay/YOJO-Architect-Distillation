# Design DNA Runtime
选择 3–5 个必要 DNA。未选项不得回流。

## D1｜JOB-SPECIFIC CHARACTER
判断含义：建筑身份来自特定任务，而非固定签名。
Trigger：通用方案无法表达机构/活动差异。
Spatial Operation：把关键任务转成一个组织命题并贯穿总体。
边界：不等于追求奇形。
Failure Mode：独特=造型猎奇。
可验证痕迹：平面、剖面、路径至少两处由同一任务命题改变。

## D2｜NEXT-LARGEST CONTEXT
含义：每个对象在更大关系中设计。
Trigger：单体与场地/城市/群体脱节。
Operation：建立外部到达、地景/邻接、群体关系，再定单体。
边界：不得凭空补景观。
Failure：只做孤立物体。
痕迹：总图关系能解释主要体量/入口/公共界面。

## D3｜FORM-WORLD COHERENCE
含义：各部分属于同一因果系统。
Trigger：结构、空间、细部各说各话。
Operation：用同一组织原则校准总体—构件—细部。
边界：不是形式重复。
Failure：视觉统一替代功能一致。
痕迹：至少三尺度可追溯到同一设计判断。

## D4｜MOVEMENT DRAMATURGY
含义：移动序列承担空间理解与体验。
Trigger：到达/转换是核心活动。
Operation：组织压缩—释放、方向变化、视线与停留节点；具体几何由项目决定。
边界：不得损害最短疏散/无障碍等效路径。
Failure：绕路只为戏剧效果。
痕迹：path storyboard 与平剖一致。

## D5｜STRUCTURE-AS-ORGANIZER
含义：结构逻辑参与空间组织与表达。
Trigger：跨度/聚集/整体身份需要结构成为秩序。
Operation：先定义受力/跨度与空间目标的关系，再由工程验证系统。
边界：不预设薄壳、拱或混凝土。
Failure：结构形象与真实受力脱节。
痕迹：结构示意能解释剖面与空间边界。

## D6｜SYSTEM + DETAIL UNITY
含义：技术系统与细部服从整体命题。
Trigger：项目易被设备、幕墙、节点切碎。
Operation：建立模块、接口、设备与细部的共同规则。
边界：维护/替换性优先。
Failure：为了纯净隐藏不可维护系统。
痕迹：典型节点与总体规则一致。

## D7｜SYMBOLIC LEGIBILITY
含义：公共意义通过整体关系被读出。
Trigger：纪念/公共身份是明确任务。
Operation：把象征目标转成尺度、位置、序列与整体关系，而非图像模仿。
边界：象征解释需标注 SUPPORTED/PROJECT INTENT。
Failure：图标化。
痕迹：无需作品类比也能解释公共意义的空间来源。

## D8｜HUMAN EXPERIENCE CALIBRATION
含义：强整体必须经身体、停留、使用和感知校准。
Trigger：大尺度/强表达可能压过日常体验。
Operation：用视线、步行时间、停留、声光、触达与可达性回测。
边界：具体性能需专业数据。
Failure：宏观形象成立、使用失败。
痕迹：关键人尺度剖面与路径测试。
