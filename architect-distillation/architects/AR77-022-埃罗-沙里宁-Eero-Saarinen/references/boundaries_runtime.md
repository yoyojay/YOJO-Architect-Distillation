# Boundaries + Contemporary Corrections Runtime
逐项输出 `PASS / RISK / NEED VERIFY`：
1. Climate：热湿、太阳、风、雨雪、冷桥、能耗；不得把历史玻璃/薄壳做法默认复制。
2. Accessibility：连续无障碍路径、坡度、电梯、座席与等效体验。
3. Fire：疏散距离/宽度、分区、烟控、耐火与消防救援。
4. Structure：跨度、侧向、振动、渐进倒塌、抗震/风；表达结构须由工程验证。
5. MEP：机房、竖井、维护、设备替换、冷凝与控制。
6. Acoustics：集会/交通/开放空间的混响、隔声与噪声。
7. Privacy：办公、教育、居住及安保边界。
8. Operations：峰值流量、排队、分时、后勤、清洁与安保。
9. Maintenance：特殊几何、屋面排水、幕墙、可达检修。
10. Cost：非标构件、模具、结构复杂度、全寿命成本。
11. Procurement：当地供应链、施工能力、样板/测试与工期。
12. Lifecycle：碳、耐久、适应性、拆换、未来用途变化。

校正规则：优先保存“任务→组织→整体→体验”的机制；历史材料、构造和技术答案均可改变。
