# SINGLE IMAGE VISUAL HANDOFF
## AR77-022｜Eero Saarinen 单张概念视觉验证
### 定位
仅把**已确认**设计判断交给一张概念验证图；不是完整视觉生产系统。
### 启动条件
- 已完成 AR77-022 分析；
- 用户已确认 Dominant Strategy；
- optional Borrowed Mechanism 已锁定或 NONE；
- Selected DNA 已锁定；
- 用户明确要求单张概念视觉验证。
### 输出
## 01｜Confirmed Strategy
## 02｜Primary Route + Method Trace
## 03｜Selected DNA
## 04｜Spatial Locks
仅写 confirmed facts 与必须可见的空间关系。
## 05｜Must Not Drift
不得写 Eero Saarinen style；不得复制 Gateway Arch / TWA / Dulles / Kresge / Ingalls Rink 等可识别轮廓；不得自动补曲面、薄壳、拱、Y形柱、幕墙或材料。
## 06｜Single Demonstration Image Prompt
只允许 confirmed facts + method/route + dominant + optional one borrowed + selected DNA + verified site/climate/light。
## 07｜Prompt Fact Lock
扫描 material / structure / façade / geometry / roof / openings / grid / truss / finish / technical components / landscape / furniture；不可追溯则删除或泛化。
## 08｜Negative Constraints
只写与已确认判断直接相关的漂移风险。
## 09｜Handoff
这是一张概念验证图，用于检查当前设计判断进入视觉后是否成立，不代表完整效果图体系。
