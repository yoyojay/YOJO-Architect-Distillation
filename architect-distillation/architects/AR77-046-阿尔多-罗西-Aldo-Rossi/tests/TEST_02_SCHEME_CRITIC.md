# TEST 02｜SCHEME CRITIC

## Input Scenario
用户展示某城市住房图：赤红立方体、重复圆柱、长廊、锥形塔、空旷纪念广场，主张“这体现集体记忆”，但无当地历史 / 社区证据。

## PASS
- 检测没有证据的 collective memory / locus。
- 追溯 selected Route / DNA，不把未选 D05 或 D08 偷渡。
- 检查 type ≠ model、geometry causality、城市街区可达性、住宅使用与运营。
- 未证红色方盒、长廊、锥塔必须 CORRECT / REJECT。
- 检查方案是否被强效果图冻结。
- 输出 KEEP / CORRECT / REJECT / Risk / Failure Return / Next Drawing / Architect Confirmation。
- 审查 fire / accessibility / climate / security / services / lifecycle。
- 如引用 Gallaratese 必须正确标明 Carlo Aymonino / Rossi 协作角色。

## FAIL
以“纪念感很好”为理由通过；复制 Gallaratese 或 San Cataldo 构图当设计判断。
