# TEST 01｜STANDARD PROJECT INPUT

## Input Scenario
某真实城市旧学校改扩建：已有局部可用旧建筑与街道联系，用户需要教学升级和部分社区开放，但没有给出文保等级、社区活动记录或结构数据。

## Expected PASS
- KNOWN / NEED VERIFY / UNKNOWN 严格分开，文保 / 结构数据不能补写。
- Fit 与 3–5 个项目冲突源于 brief。
- Primary Route exactly 1；Secondary NONE 或 1。
- D01 mandatory，总 DNA 2–4，未选 DNA 不得回流。
- A/B/C 使用**不同空间因果**解决同一真实项目冲突，完整 Plan / Section / Movement / City / Time / Operations 痕迹。
- Comparison 不按“像 Rossi”评分。
- Recommendation 六字段依序完整；Dominant 可独立、Borrowed ≤1、Rejected 无回流。
- Climate / Accessibility / Fire / Structure / MEP / Acoustics / Privacy / Operations / Maintenance / Cost / Procurement / Lifecycle 全检查。
- Architect Confirmation：Keep / Unresolved / Need Verify / Next Drawings/Tests / Architect Decision。
- 一次 Concept Prompt Close，逐项扫描材料 / 结构 / 立面 / 几何 / 屋顶 / 开口 / 柱网 / 桁架 / 表面 / 技术构件 / 景观 / 家具。
- Prompt 不自动出现方盒、锥顶、钟塔、拱廊、旧学校重建的未核实细节。

## HARD FAIL
一条 Primary Route 没有选择逻辑；A/B/C 只是同一长廊强弱；依赖引用文件代替 SKILL.md 主执行逻辑。
