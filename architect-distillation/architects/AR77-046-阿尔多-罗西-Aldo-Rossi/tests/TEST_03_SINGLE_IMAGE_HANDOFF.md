# TEST 03｜SINGLE IMAGE HANDOFF

## Prerequisite
用户已经确认具体 Dominant、Selected Route、Selected DNA，并明确要求一张概念图。

## PASS
- 未确认不执行。
- 只继承 confirmed facts / confirmed Method-Route / Dominant / optional one Borrowed / selected DNA / verified site-climate-light。
- 有 Spatial Locks / Must Not Drift / Negative Constraints。
- Prompt 仅关系、使用与空间因果，不生成 Rossi 名作外形。
- Rejected Strategy / 未选 Route / DNA 没有回流。
- 图像不能反过来新增建筑事实。
- 只输出一张概念验证图。

## FAIL
自动插入圆柱、锥顶、红墙、拱廊、窗型、砖石或浮动剧场。
