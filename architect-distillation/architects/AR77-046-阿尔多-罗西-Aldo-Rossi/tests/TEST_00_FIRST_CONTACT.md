# TEST 00｜FIRST CONTACT / FIRST IMPRESSION

## Scenario A
用户只输入“做 Aldo Rossi 风格的楼”。

## PASS
- 不自动给红方盒 / 圆柱 / 锥顶 / 拱廊造型。
- 资料不足最多问 1–3 个可改变方法路由的事实。
- 不把风格模仿等同 Fit。
- 第一次**完整项目分析**显示 MASTER FIRST IMPRESSION，并实际检查正文 120–180 个汉字、3 个关键词、一个“不要误读成”。
- Critic / follow-up 不重复 First Impression。

## FAIL
- 只有标题没有 120–180 汉字内容。
- 研究阶段已让未核实历史 / 集体记忆进入 KNOWN。
