# AR77-046｜BOUNDARIES & CONTEMPORARY CORRECTIONS
## Aldo Rossi

## Project Fit
**FIT**：真实城市结构 / 历史片段 / 类型与 program 变化 / 公共记忆 / 集体设施与街区 / 居住群体与城市 / 临时事件与场所的矛盾可由 Rossi 方法解决。

**PARTIAL FIT**：可补充 locus / type / civic 场所思考，但主要控制力在医疗工艺、高危工业、交通工程、偏自然生态的特殊任务等其他逻辑。

**NOT FIT**：唯一诉求是复制 San Cataldo 方盒空窗、Gallaratese 白色廊道、Teatro del Mondo 浮动木塔、Fagnano Olona 圆柱图书馆或红色锥顶；没有任何真实城市 / 类型 / 时间问题。

## Contemporary Corrections — Every Full Analysis

### 01｜Climate & Energy
保留 / 重建历史类型不能豁免能效、热舒适、雨洪、被动遮阳、日照、风、城市热岛。传统拱廊 / 厚墙 / 砖石绝不自动有效。

### 02｜Accessibility
延续历史路径、廊道、纪念地面或台阶须提供连续平等到达；“纪念性”不能牺牲残障者、老年人或照护者。

### 03｜Fire / Life Safety
旧城改造、高密居住、学校、墓园、剧场、临时设施须校验疏散、人员容量、消防通道、防火区划与烟控。

### 04｜Structure / Geotechnical
新旧连接、空窗方盒、大跨度长廊、临时构筑物不能由 Rossi 作品外形证明合理性；必须结构、基础、地震、风 / 水工验证。

### 05｜MEP / Building Systems
保留 type 时确认通风、空调、排水、给排水、电气、维护与未来改造接口；技术不能因“历史持续性”被隐藏。

### 06｜Acoustics
学校、剧场、住房公共路径、墓园静思空间需单独校验声学与私密需求。

### 07｜Privacy / Security / Safeguarding
住房与学校的“公共城市性”须明确公共 / 半公共 / 私有界面、日常安防、儿童保护与数据 / 视觉隐私。

### 08｜Operations
区分日常 / 活动 / 夜间、假日 / 节日和未来 program 转换状态；谁维护、谁管理、谁被排除必须问清。

### 09｜Maintenance / Durability
所谓“永久的城市建筑”应通过长期维修、可替换构件、渗水、材料风化和采购计划验证，而非使用传统材料作为暗示。

### 10｜Cost / Phasing
既有结构保护与再利用须计入调研、加固、停业、产权、文保审批；类型学方案不能掩盖成本。

### 11｜Procurement
历史材料、色彩、工法或城市符号都须由本地供应链和实施能力核实，不得根据 Rossi 的作品配置默认砖、石、混凝土或色彩。

### 12｜Lifecycle / Carbon
比较继续使用 / 修复 / 新建的 embodied carbon 与运行周期；持久性须能适应变化，不是拒绝技术更新。

## Architect-Specific Contemporary Corrections

### Heritage / Authenticity
分清真实保存、解释性重建、新增插入和伪历史；涉及保护名录必须由文保 / 政府审批。

### Plural Collective Memory
“集体记忆”可能相互冲突。核查不同年龄、文化、族群、信仰、非主流叙事，不能用单一纪念几何代替参与。

### Urban Governance
城市更新必须审查搬迁、租赁、产权、社区服务、步行 / 交通、公共资金、长期维护、公平与可进入性。

### Housing & Social Life
Gallaratese 不能被当成“住房成功模板”；需检查真实家庭结构、服务供给、社会基础设施与居民反馈。

### Temporal / Event Impact
临时空间须检查拆装、重复使用、废弃、噪声、活动许可、消防、聚集风险，不以历史浪漫化豁免。

### Type / Model Separation
如果 type 的全部说明只是圆柱、锥屋顶、长廊或某一平面复制，即 `TYPE FAIL`。

### Locus / Invention Separation
必须把 verified site trace 与设计类比清楚区分。没有现场证据不能虚构“城市记忆”。
