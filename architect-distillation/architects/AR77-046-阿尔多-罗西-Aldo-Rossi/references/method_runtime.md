## 1｜KNOWN — Source-Grounded Findings

### 1.1 城市而不只是单体
Rossi 的《城市建筑学》（1966）是其理论与城市研究的核心文本。城市不是可随时清零的对象，它由长期积累的街区、路径、公共建筑、地形、活动与记忆构成。`urban artifact` 是理解城市历史形成、特异性和持续变化的研究入口。学术研究指出 Rossi 区分 **type / model** 并探讨 **locus / permanence / collective memory**。

### 1.2 类型不等于外形模板
Rossi 的类型学研究关注从特定地方的历史中抽取空间组织与城市关系；MoMA 把其城市绘画解读为 types 与记忆的关联。不能从一个圆筒或三角屋顶倒推“类型”具有建筑普适性。

### 1.3 记忆与时间
Rossi 关注建筑跨越原有功能后仍可能持续作为城市构成与公共记忆载体。1990 年普利兹克资料强调其“从过去学习而不复制”，并将场所、建筑与时间视作相互影响。永久性（permanence）是研究问题，不是每栋新建筑都要呈现纪念性。

### 1.4 公共建筑的城市角色
Rossi 在 1990 年演讲中主张能够重新组织城市并使公共生活更可见的 civic architecture，同时表示拒绝 styles and fashions。Fagnano Olona 小学项目的基金会描述明确强调“学校作为小城市”：中心广场 / 公共活动、校内使用与街区共享，说明 program 与 civic sequence 的联结。

### 1.5 住宅作为城市组成
意大利文化部建筑档案确认 Rossi 参与 Gallaratese / Monte Amiata 合作项目，设计一栋与 Aymonino 其他建筑相区别的居住单元；其总体意图是 **building urban community, not isolated objects**。重复性居住与有公共生活的城市界面应一起研究，不得复制白色长廊、柱列比例或长条轮廓。

### 1.6 墓园的空间与记忆
Fondazione Aldo Rossi 对 San Cataldo 项目记载：在既有墓园围护连续性中扩建，使用有城市街道特征的廊道及路径组织；与 Gianni Braghieri 合作。可迁移的是“新旧联系 / 集体记忆 / 路径 / 时间层级”，不是空窗方盒与几何墓园形象。

### 1.7 剧场与临时城市
Fondazione 的 Teatro del Mondo 项目页收录 Rossi 本人的论述：剧场具有实际使用空间、回应威尼斯城市地标的尺度 / 位置、浮于水上；城市的剧场性和临时性可结合特定场所、公共事件与建筑构造。**木材和浮筏是该项目具体事实，不是新项目的默认材料或结构。**

### 1.8 历史碎片的重新组合
Fondazione 对 Carlo Felice 剧院的文献中，Rossi 谈到战损后的旧入口、城市关系、剧场内外与新整体形成；是有具体残留与使用前提的“重新组合”，并由多人合作。不能自动把任何旧房子变成戏剧化遗址。

## 2｜SUPPORTED INTERPRETATION — AR77 Transfer Kernel

此为 AR77 的可调用推断，不声称 Rossi 历史上发布此七步法。

`观察可证的城市—场地现状`
→ `辨认 urban artifacts / 原有活动 / 可能持久的关系`
→ `比较地方历史中的空间 type 而不是照搬模型`
→ `确定一个 locus 的特殊条件与时间层次`
→ `建立建筑与街区 / 公共空间 / 集体生活的因果连接`
→ `使当下 program 能工作，并检验长期适应与公共可达`
→ `把记忆关系落实到平面、剖面、路径、运营和城市界面`
→ `最后才允许出现可由事实推导的几何或材料`

## 3｜Architectural Judgements

### J1｜CITY BEFORE ISOLATED OBJECT
新项目首先判断自己加入了怎样的城市过程：历史结构、路径、公共场所、服务、界面与时间。

### J2｜TYPE AS RELATION, NOT MODEL
Type 是反复出现的组织原则（例如共享路径与房间关系），不是可照抄的某个圆柱、方盒、拱廊或屋顶。

### J3｜LOCUS IS SPECIFIC
只有真实场地的自然 / 历史 / 文化 / 社会特征才能构成 locus；“意大利小城气氛”不是未验证地段的事实。

### J4｜PERMANENCE WITH CHANGE
保留有集体价值的关系，同时允许实际用途、气候技术与社会需求演化；古老几何不保证持续性。

### J5｜MEMORY REQUIRES A COLLECTIVE TRACE
集体记忆必须指向真实社区 / 地点 / 事件 / 建筑使用的证据；Rossi 的私人记忆不能冒充所有使用者的记忆。

### J6｜CIVIC SPACE STRUCTURES PROGRAM
学校、剧场、墓园和公共机构可通过共享地面、路径、阈值和空间等级承担城市角色；不能把 monumentality 当成唯一策略。

### J7｜ANALOGY IS CRITICAL TRANSLATION
类比 / analogical city 是探索现实关系与记忆的研究手段，不是随意拼贴或从画作中抄建筑图形。

### J8｜ORDINARY REPETITION MUST REMAIN LIVEABLE
住宅或机构的重复秩序要和真实的住房需求、日常通达、社会性、维护与邻里联系一起成立。

### J9｜THEATRE AS EVENT AND CITY CONDITION
当项目存在真实公众演出 / 事件 / 迁移 / 临时性时，可研究事件与城市空间的相互作用；禁止默认建造浮动木塔。

## 4｜Execution — Required on Each Full Project Call

1. 记录 `KNOWN / UNKNOWN / NEED VERIFY`；未知的既有街区历史不得补写。
2. 建立 **Urban Artifact + Locus Map**：有哪些可验证的街道 / 体块 / 历史遗存 / 公共活动 / 交通 / 集体使用。
3. 抽出 3–5 项真实矛盾，例如旧城持续性与新用途、学校安全与社区开放、住宅重复与邻里生活。
4. 检验 Fit；选择 **Primary Route exactly 1**，Secondary = NONE / max 1。
5. **D01 URBAN_ARTIFACT_READING mandatory**，再选 1–3 个真正必要的 DNA；默认总数 2–4。
6. 每个 DNA 在 Plan / Section / Movement / City Interface / Phasing / Operations 中留下可检测空间痕迹。
7. 建立 A/B/C 因果不同策略；先空间因果，后几何或材料。
8. 按 Comparison 推荐独立成立的一个 Dominant；最多从另一方案借一个有限机制。
9. 运行 Contemporary Corrections / Scheme Critic / Authorship Audit。
10. 最后生成一次 Concept Impression Prompt 并逐项执行 Prompt Fact Lock。
