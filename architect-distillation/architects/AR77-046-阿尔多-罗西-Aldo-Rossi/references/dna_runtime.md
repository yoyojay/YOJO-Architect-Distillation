# AR77-046｜DNA RUNTIME
## Aldo Rossi｜Spatial Decision Mechanisms

本条目均为 **AR77 基于证据的可迁移决策机制**，不是“Rossi 官方 DNA”。每项须包含 Trigger、空间操作、边界、失败形态及可检验空间痕迹。

## D01｜URBAN_ARTIFACT_READING｜读取城市构成

- **判断含义**：把城市看作具有历史、使用与空间关系的具体构成，不把基地视为可任意置入雕塑的空地。
- **Trigger**：任何完整项目初审；若为与城市关系弱的孤立工地，也要记录这一事实和 Fit 限度。
- **Spatial Operation**：标出既有 street / block / edge / node / public life / traces，形成 **Urban Artifact + Locus Map**。
- **适用边界**：所有项目的初步城市关系判断；不假定每个项目都有历史遗迹。
- **Failure Mode**：城市分析流于空话或由 Rossi 画作替代实地证据。
- **可验证空间痕迹**：Site plan 上能指明本方案所保留、强化或修正的真实现有关系。

## D02｜TYPE_NOT_MODEL｜类型而非固定模型

- **判断含义**：type 是历时性的空间组织关系，不是建筑形状模板。
- **Trigger**：住房、学校、机构、改造中可证明存在的地方空间类型 / 组织反复。
- **Spatial Operation**：抽取 core relations（共享路径、房间 / 公共领域、服务 / 活动）并根据现有功能进行可检验变体。
- **适用边界**：有类型学研究依据的项目；没有资料时只能列候选研究对象。
- **Failure Mode**：把长廊、方盒、圆柱、塔或锥屋顶当“类型”直接复制。
- **可验证空间痕迹**：类型关系图与新平剖能显示何者连续、何者调整，且新 program 能运营。

## D03｜LOCUS_SPECIFICITY｜场所特异性

- **判断含义**：空间必须对特定地段的时间、地理、文化与公众生活作出回应。
- **Trigger**：项目的地段 / 社会 / 历史特性会改变布置、入口、界面或公共活动。
- **Spatial Operation**：将已证 locational traces 与 program 对照，确定真实视线、路径、门槛和地面关系。
- **适用边界**：具有明确场所事实的城市 / 乡村项目。
- **Failure Mode**：凭空创造“古城气质”、纪念性遗产或某地方传统材料。
- **可验证空间痕迹**：一条选定空间决策能够被至少一项真实现场记录解释。

## D04｜PERMANENCE_WITH_CHANGE｜持续性与变化

- **判断含义**：某些空间关系 / 城市机构长期持续，而用途与技术可以变化。
- **Trigger**：更新、扩建、长期 civic / institutional 项目涉及存续价值与新需求。
- **Spatial Operation**：建立 `Preserve / Adapt / Replace` 表 + `present / future-use` 状态，确定接口与更新边界。
- **适用边界**：历史城区、更新、可变机构、长生命周期建筑。
- **Failure Mode**：保存空壳却失去使用；用“永恒”拒绝无障碍、节能和运营调整。
- **可验证空间痕迹**：平剖中保留 / 改造边界及两个运营阶段均可工作。

## D05｜COLLECTIVE_MEMORY_TRACE｜集体记忆的空间痕迹

- **判断含义**：记忆必须基于真实集体叙事、场所对象或公共事件，而非建筑师主观怀旧。
- **Trigger**：纪念、墓园、战后修复、社区记忆是已知 brief / 资料的一部分。
- **Spatial Operation**：`source / community / trace → arrival / route / threshold / ritual + everyday use`。
- **适用边界**：经核实的 public memory 项目。
- **Failure Mode**：单一叙事压制其他群体；用空窗方盒 / 纪念轴线制造“沉默”效果。
- **可验证空间痕迹**：记忆地图与真实使用 / 纪念路径叠合，参与方可说明关系。

## D06｜CIVIC_GROUND_AS_STRUCTURE｜公共地面作为组织者

- **判断含义**：公共空间不只是留白，可通过广场、共享阈值、通行与活动组织建筑 / 城市。
- **Trigger**：学校、居住、剧院、机构或公共设施存在真实 civic / shared-use 需求。
- **Spatial Operation**：`public life → access / shared room / ground edge → program distribution / daily operations`。
- **适用边界**：具有明确公众或社区使用责任的项目。
- **Failure Mode**：空旷纪念广场、缺少服务与安全、公共性只在鸟瞰图成立。
- **可验证空间痕迹**：日常、活动、夜间三个使用状态的平面 / 路径一致。

## D07｜ANALOGICAL_RELATION_CONTROL｜类比关系 / 克制转译

- **判断含义**：以城市、记忆、类型等之间可说明的关系展开设计，而不照搬 Rossi 的图像拼贴。
- **Trigger**：存在真实的文化 / 空间类比研究，能说明源与当前任务的连接。
- **Spatial Operation**：写出 `source relationship → abstract shared mechanism → new constraints → changed spatial decision`。
- **适用边界**：研究型公共文化、城市更新、特殊场所。
- **Failure Mode**：没有证据的历史拼贴、怀旧的几何物、标志性形式自我引用。
- **可验证空间痕迹**：类比推导图和新项目平剖能显示可迁移关系，去掉原始形象后机制仍成立。

## D08｜REPETITION_LIVEABILITY｜重复秩序中的日常可居住性

- **判断含义**：住宅 / 机构重复布局要和城市界面、共享生活、光和实际社会服务同时成立。
- **Trigger**：大量重复户型、长廊、标准房间或高密生活是现实 brief。
- **Spatial Operation**：优化 `repeatable unit + access + shared/public gradient + neighborhood connections`。
- **适用边界**：住房、宿舍、学校、日常机构。
- **Failure Mode**：复制 Gallaratese 长廊比例；社区服务不足、动线冷漠、隐私 / 声学 / 安全失败。
- **可验证空间痕迹**：单位—共享—公共路径、日照、维护及可达分布有图纸和运营依据。

## D09｜THEATRE_TIME_CITY｜事件 / 临时性与城市舞台

- **判断含义**：特定限期活动能把建筑、城市和时间组织成公众事件；剧场性不是外形。
- **Trigger**：真实临时剧场、节庆、展览、仪式或阶段性公共事件。
- **Spatial Operation**：`event time + spectators → arrival / gathering / staging → support / disassembly / reuse`。
- **适用边界**：有活动证据、周期和管理责任的项目。
- **Failure Mode**：未经核实水上浮筏 / 木塔 / 戏剧性轮廓；活动结束后浪费。
- **可验证空间痕迹**：活动 / 非活动、搭建 / 拆除与安全疏散状态均有明确模型。

## DNA Selection Algorithm — Hard Lock

1. D01 **mandatory**。其他 8 项只作为候选，根据项目冲突再选 1–3 项；**total 2–4**。
2. 每项需明确 `Trigger` 的 KNOWN 证据；若只有 NEED VERIFY，不能把它作为已成立的形式依据，可先提验证任务。
3. D02 需要 local type / spatial relationship 证据；D03 需要真实 locus 事实；D04 需要长期存续 / 变化问题。
4. D05 需要集体记忆主体 / 资料；D06 需要公共空间真实使用；D07 需要可信的类比链；D08 需要重复居住 / 机构事实；D09 需要临时事件事实。
5. **未选 DNA** 不得进入任何策略、Recommended Keep、Next、Prompt、Single Image Handoff。
6. 若方案需要新增 DNA，先重做 Selection，再重算 A/B/C 与 Recommendation，禁止隐蔽回流。
7. 不设“官方 9 DNA”之类历史声明；9 是本次 evidence-bounded runtime 的候选机制数。
