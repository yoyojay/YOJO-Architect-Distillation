# AR77-046｜DECISION RULES
## Aldo Rossi

每条须被执行而非引用。标准语义：**当… → 优先… → 因为… → 通过…验证 → 若失败则…**

1. **Fact Lock**｜当历史、纪念对象、地形或街区类型尚未有资料 → 优先列 `UNKNOWN / NEED VERIFY` → 因为城市判断必须来自真实现状 → 通过现场/档案/使用访谈检验 → 若失败则不得说该场地“承载集体记忆”。

2. **Fit**｜当用户只要求红色方盒、锥顶或罗西风格 → 优先 `NOT FIT / Anti-Copy` → 因为 Rossi 自己反对 styles and fashions → 通过是否有真实城市 / 类型 / 时间冲突验证 → 若失败则不产出风格化生成指令。

3. **Urban Artifact / D01**｜当新体量可能割裂街道、公共路径或遗存 → 优先读取 D01 的 urban artifact map → 因为城市由时间积累的联系构成 → 通过既有 / 未来城市界面叠图验证 → 若失败则退回场地诊断。

4. **Route Selection**｜当主问题是现状修复 → 优先 R1；若主问题是 type 适应新程序 → 优先 R2；有真实公共记忆才 R3；重复住房与社区才 R4；临时文化事件才 R5 → 因为问题路由不是作品外形 → 通过一主冲突对应一 Primary Route 验证 → 若失败则重选，不得混用五路由。

5. **Type / D02**｜当用户指着圆柱、拱廊、方盒说“这是类型” → 优先提取空间关系及历史比较 → 因为 type ≠ model → 通过类型图与新 plan-section 验证 → 若失败则删掉几何原型。

6. **Locus / D03**｜当设计强调“场所感” → 优先核实真实地理、历史、城市行为 → 因为 locus 是特定位置与时间 → 通过可标注来源的 site map 验证 → 若失败则不使用地方符号。

7. **Permanence / D04**｜当建筑被要求“永恒” → 优先确定何种城市联系要持续而非保留旧外观 → 因为持久性不等于静止 → 通过 preserve / adapt / replace 与未来运营验证 → 若失败则不要冻结用途。

8. **Memory / D05**｜当用户要求纪念性 → 优先核实 community / event / historic trace → 因为 collective memory 需要公共主体 → 通过参与式记忆地图、路径和日常使用验证 → 若失败则删除纪念形象。

9. **Civic / D06**｜当学校、墓园、剧场或居住方案提出公共广场 → 优先检验谁使用、何时、如何维护 → 因为 civic ground 是真实社会空间 → 通过日常/活动/夜间三模式验证 → 若失败则改用更有效的共享空间，而非空广场。

10. **Analogy / D07**｜当建筑师想按 Rossi 城市画作拼贴 → 优先提取类比中的因果关系 → 因为 analogical city 不是图像菜单 → 通过 source-relationship-transfer 因果图验证 → 若失败则放弃该类比。

11. **Housing / D08**｜当采用重复长廊、标准房间 → 优先连接公共服务、日照、隐私、维护与城市路径 → 因为重复秩序必须为生活服务 → 通过 occupancy、plan、section、operation 验证 → 若失败则调整类型秩序。

12. **Temporary / D09**｜当提出浮动剧场、木构钟塔或节日设施 → 优先核实真实临时事件和地点 → 因为 Teatro del Mondo 的形式是特定威尼斯 / 水上 / 活动条件的产物 → 通过 logistics / fire / stability / after-use 验证 → 若失败则不引入该形式。

13. **Strategy A/B/C**｜当三案只换红色 / 圆柱 / 拱廊比例 → 优先重做三条不同因果链 → 因为 Strategy 必须空间机制不同 → 通过平面、剖面、城市路径三方面比较验证 → 若失败则 `Strategy FAIL`。

14. **Recommendation**｜当准备 A+B+C 全混 → 优先一个可独立成立的 Dominant → 因为正向机制不可失去清晰主体 → 通过最多从另一个策略借 1 项有限机制的检查验证 → 若失败则 `Recommendation FAIL`。

15. **Contemporary Boundary**｜当既有街区或记忆价值被用作反对无障碍、气候、消防或公众参与的理由 → 优先现行专业核查和社会参与 → 因为历史延续不能豁免安全和包容 → 通过 accessibility / fire / maintenance / community review 验证 → 若失败则返回修改。

16. **Critic / Failure Return**｜当方案只在鸟瞰 / 效果图呈现“永恒气质”，而平剖和使用不支持 → 优先否定未经证明的几何 → 因为 form 不能替代 urban artifact / type / memory → 通过 Plan / Section / Movement / Program 检验 → 若失败则退回 Method / Route / DNA Selection。

17. **Authorship**｜当 Gallaratese 变成 Rossi 独创完整 masterplan、San Cataldo 忽略 Gianni Braghieri 或 Carlo Felice 忽略 Gardella 团队 → 优先修正署名 → 因为协作归属是 Source Audit 硬约束 → 通过基金会 / 官方文化档案对照 → 若失败则停止案例结论。

18. **Prompt / Handoff Fact Lock**｜当 prompt 自动补圆柱、塔楼、红墙、长廊、空窗、锥顶、钟、木结构、水上设施 → 优先逐项追溯到 KNOWN / selected Route / Dominant / selected DNA → 因为建筑史案例不能提供当前项目事实 → 通过 prompt noun scan → 无来源即删除 / 改为关系与性能语言。
