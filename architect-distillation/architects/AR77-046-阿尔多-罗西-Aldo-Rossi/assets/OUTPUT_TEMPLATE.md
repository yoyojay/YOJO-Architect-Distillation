## 00｜MASTER FIRST IMPRESSION｜大师初印象
首次完整项目分析才显示 `assets/MASTER_FIRST_IMPRESSION.md`：正文 120–180 中文汉字、exactly 3 关键词、exactly 1 `不要误读成…`。后续 / Critic / Handoff 不重复。

## 01｜Input Validation
### KNOWN
### NEED VERIFY
### UNKNOWN
### 是否足以路由（否则本轮最多问 1–3 个关键问题）

## 02｜Project Fit
**FIT / PARTIAL FIT / NOT FIT**  
Why: 项目主问题是否真实关联城市构成、类型变化、locus、记忆、住宅社区或城市事件。

## 03｜Project Conflicts
3–5 项：`条件 A ↔ 条件 B → 需验证 X`。不得把未知历史变成条件。

## 04｜Method Trace
`Urban Artifact / Locus Evidence → Type (not Model) / Permanence / Memory (only where selected) → Spatial Decisions → Plan/Section/City/Time`

## 05｜Route Selection
Primary Route: exactly one  
Secondary Route: NONE / one  
Trigger / 核心问题 / Method / 主要 DNA / 适用边界 / 风险 / 与其他 Route 差异 / Evidence Status

## 06｜DNA Selection
D01 mandatory；另外选 1–3；总数 2–4。  
每条：`Name → 判断含义 → Trigger → Spatial Operation → 适用边界 → Failure Mode → 可验证空间痕迹`。

## 07｜Strategy A

同样完整；主要因果与 A 不同。

## 09｜Strategy C
同样完整；主要因果与 A、B 不同。

## 10｜Comparison

## 15｜建筑初印象 Prompt｜复制到你的图像生成工具即可
最后且仅一次。内容只由 KNOWN + selected Route/Method + Dominant + optional one Borrowed + Selected DNA + verified site/climate/light 组成。
不得出现 architect name style、历史名作视觉目标、Rejected Strategy、未选 DNA / Route，或无依据的材料、几何、立面、结构、开口、屋顶、柱网、桁架、表面、技术构件、景观、家具。
