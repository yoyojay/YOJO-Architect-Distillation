# SINGLE IMAGE VISUAL HANDOFF
## AR77-046｜Aldo Rossi

### 定位
用于 **已经由项目建筑师确认** 的唯一方案的**单张概念关系验证**。不是 Rossi style generator、纪念形象生产器或城市拼贴机器。

### 启动条件
1. 完整分析、Recommendation 与 Corrections 已完成；
2. 用户明确确认 Dominant Strategy；
3. 已确认 Route / Selected DNA 与关键 KNOWN facts；
4. 用户明确要求一张概念验证图。

若条件不齐，拒绝跳入 Handoff，返回 Architect Confirmation 或追问 1–3 个必要事实。

### 只允许继承
- confirmed KNOWN site / program / user / urban artifacts
- confirmed Method / selected Route
- confirmed Dominant Strategy
- optional **one** confirmed Borrowed Mechanism from one other strategy
- Selected DNA only
- verified site / climate / light
- Prompt Fact Lock

### 禁止新增
- 材料、结构、立面、几何、屋顶、开口、柱网、桁架、表面、技术构件、景观、家具；
- 历史街区 / 纪念对象 / 群体记忆，若未核实；
- Rejected Strategy / unselected Routes / unselected DNA；
- 任意 Rossi 原作形状或作品名称视觉目标。

## 01｜Confirmed Strategy
仅写用户确认的 Dominant 与最多一个有限 Borrowed。不要改名换案。

## 02｜Route / Method Trace
写出 Primary / optional Secondary Route 和实际触发的城市 / 类型 / 时间问题，禁止借其他 Route 的图形。

## 03｜Selected DNA
仅列确认的 2–4 项；标出空间验证对象。

## 04｜Spatial Locks
只陈述可追溯关系，例如：
- 已核实街道关系在新建筑公共动线中仍可读；
- 程序变换后地方空间类型的共享关系仍成立；
- 已核实记忆对象通过公众路径与日常活动发生联系；
- 更新的保留 / 新增边界在平剖中可读；
- 真实活动与城市到达关系可以用同一画面验证。

## 05｜Must Not Drift
- 不是 San Cataldo 的空窗方盒 / 三角墓园；
- 不是 Gallaratese 的白色长廊；
- 不是 Fagnano Olona 的圆筒学校；
- 不是 Teatro del Mondo 的浮动木塔、锥顶；
- 不是 Carlo Felice 的特定剧院 / 灯塔；
- 不是 Rossi 绘画中的红黄几何。
- 不补没有项目来源的材料、结构、立面、景观或使用者。

## 06｜Single Demonstration Image Prompt
在无 style token 的条件下描述：
`current confirmed project type + verified urban/site facts + confirmed Dominant spatial relationship + selected Route/DNA trace + verified people/activities + verified light/climate + viewpoint revealing plan-section-city causality`。

不出现代表作名。只生成**一张**验证关系的图像描述，不以图像推断新的设计事实。

## 07｜Negative Constraints
只列当前方案的已知边界、Rejected / unselected 不得回流、禁止虚构资料与避免图像造型冻结的要求。

## 08｜Handoff Note
> 概念图仅验证已确认的空间判断是否在视觉中成立，不得把图片中的新几何、材料或历史暗示反向变成设计事实。
