# Problem Routes
## R1｜FUNCTIONAL_HIERARCHY
Trigger: 不同使用角色/公共性/层级需要被组织并表达。
核心问题: 如何让真实功能差异获得空间身份，同时保持整体。
Method: program roles → hierarchy → plan/section → external expression.
主要 DNA: D1 D2 D4.
边界: 功能不决定唯一形式。
风险: diagram 机械变成立面。
差异: 从使用角色起步。

## R2｜TALL_TYPE_EXPRESSION
Trigger: 高层、垂直重复、多层办公/混合使用产生整体尺度与重复问题。
核心问题: 如何让大量重复单元形成“一个高建筑”，而非堆楼层。
Method: repeated unit → vertical continuity → base/interface → termination → whole.
主要 DNA: D2 D3 D5.
边界: 不预设三段式、竖墩或檐口。
风险: 历史 skyscraper composition 复刻。
差异: 从类型与重复起步。

## R3｜COMMERCIAL_PUBLIC_INTERFACE
Trigger: 首层商业/公共界面、入口、展示与街道关系关键。
核心问题: 建筑如何在地面层对人和城市清晰开放，同时与上部整体相连。
Method: street activity → threshold → entry/display → structural/envelope rhythm → upper relation.
主要 DNA: D1 D4 D6.
边界: 不默认拱、金属 ornament 或大玻璃。
风险: 首层成为独立“装饰底座”。
差异: 从街道与人的接触起步。

## R4｜INTEGRAL_ORNAMENT
Trigger: 项目明确需要表面、细部、标识或工艺表达。
核心问题: 局部表达如何从整体观念和构造生长，而非贴图。
Method: governing idea → location/scale → material/process → generative motif/rule → prototype.
主要 DNA: D5 D7 D8.
边界: ornament 不是必选；不默认植物纹。
风险: 复制 Sullivan 图案。
差异: 从 whole-to-detail expression 起步。
