# AR77-015｜PROBLEM ROUTE RUNTIME

## R1｜STRUCTURE_AS_SPACE
**Trigger:** bridge, station, hall, long span or building where structural forces materially shape inhabitable space.
**Core Question:** how can the load-bearing system organize space and remain legible without becoming structural theater?
**Method:** define span/load/support constraints → compare load paths → integrate supports with movement/use → test section, deflection, robustness and fabrication.
**Primary DNA:** D1 / D4 / D7 / D6.
**Boundary:** fire, vibration, redundancy, erection, cost, maintenance.
**Risk:** skeletal expression with inefficient or hidden secondary structure.
**Difference:** real force and support lead.

## R2｜MOVEMENT_TRANSFORMATION
**Trigger:** a building element genuinely needs to open, fold, track, shade, reveal, protect or change.
**Core Question:** what useful change of state improves function, climate or collective experience?
**Method:** define states + trigger → design kinematic sequence → check forces/clearances/control/fail-safe → test maintenance and static fallback.
**Primary DNA:** D2 / D7 / D1 / D8.
**Boundary:** reliability, sensors, wind/weather, safety, inspection, replacement.
**Risk:** kinetic spectacle with no operational value.
**Difference:** real transformation leads.

## R3｜BODY_NATURE_ABSTRACTION
**Trigger:** proportion, movement or structural organization can benefit from analogy to body/nature.
**Core Question:** what underlying relation—not literal shape—can be abstracted?
**Method:** draw observed relation → identify principle of balance/joint/repetition/opening/rotation → translate to architecture → test against program/structure.
**Primary DNA:** D3 / D7 / D4 / D5.
**Boundary:** no literal biomorphic copying; function and structure still rule.
**Risk:** wing/bone/eye mimicry.
**Difference:** analogy becomes abstract ordering principle.

## R4｜CIVIC_MOVEMENT
**Trigger:** station, museum, transport/civic building where arrival, passage and collective identity are central.
**Core Question:** how can movement through the building create orientation, civic presence and emotional sequence?
**Method:** map flows/arrival → establish sectional sequence → align structure/light with movement → test accessibility, crowd flow and operations.
**Primary DNA:** D5 / D6 / D8 / D4.
**Boundary:** egress, crowding, security, acoustics, climate.
**Risk:** monumental procession that obstructs efficient movement.
**Difference:** public movement/sequence leads.

## R5｜LIGHTWEIGHT_CIVIC_SPAN
**Trigger:** a large public enclosure needs both generous span and daylight while retaining legible support.
**Core Question:** how can section, support and light form one inhabitable order?
**Method:** set span/daylight/comfort criteria → compare section/support systems → locate light relative to structure → test thermal, glare, smoke and maintenance.
**Primary DNA:** D1 / D4 / D6 / D7.
**Boundary:** heat gain, glare, acoustics, fire/smoke, cleaning, replacement.
**Risk:** luminous skeletal hall as image rather than performance.
**Difference:** span + light + support jointly lead.
