# AR77-015｜BOUNDARIES + CONTEMPORARY CORRECTIONS

## Climate
Check verified sun, heat, cold, humidity, rain, snow/ice, wind and future climate. Large glazed/kinetic structures require weather-specific proof.

## Accessibility
Expressive movement sequences must retain dignified step-free equivalents, clear gradients, resting, handrails, wayfinding and equivalent civic experience.

## Fire
Large halls, transport spaces, atria and unusual structures require egress, smoke control, compartmentation, structural fire performance and fire-service review.

## Structure
Any expressive support, mast, cable, rib, cantilever or long-span element requires load path, buckling, vibration, deflection, fatigue, robustness, erection and connection checks.

## MEP
Coordinate plant, ducts, drainage, smoke systems, controls and access with expressive structure before geometry freezes.

## Acoustics
Large hard public volumes require reverberation, speech intelligibility, isolation and services-noise checks.

## Privacy / Security
Civic openness stops where safeguarding, operational control, screening or confidential functions require separation.

## Operations
Test peak flow, queues, event mode, after-hours zoning, loading, cleaning and staff routes.

## Maintenance
Kinetic and expressive systems require inspection routes, cleaning, lubrication, access, replacement parts and safe maintenance states.

## Cost
Compare expressive mechanisms against simpler systems delivering the same spatial/performance effect. Symbolic value does not exempt whole-life cost.

## Procurement
Verify specialist fabrication, tolerances, temporary works, sequencing, contractor capability, testing and commissioning.

## Lifecycle
Check fatigue, coatings/finishes, moving parts, seals, bearings, controls, embodied carbon, adaptability and replacement cycles.

## Kinetic Safety
For every moving element: operating envelope / wind-weather limit / sensors / interlocks / emergency stop / manual override / fail-safe state / inspection regime / responsibility.

## Historical Correction Rule
When a documented Calatrava mechanism conflicts with contemporary requirements, preserve the underlying judgement only if useful; redesign the means. Historical precedent is never a waiver.
