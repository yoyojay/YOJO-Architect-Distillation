# AR77-015｜DESIGN DNA RUNTIME

> DNA = distilled decision mechanism, never a motif list.

## D1｜FORCE MADE LEGIBLE
**Judgement Meaning:** structural force can contribute to architectural understanding when the load path is real.
**Trigger:** span/support/stability materially affects space.
**Spatial Operation:** align supports, depth, curvature or tension/compression zones with actual forces and inhabitation.
**Boundary:** engineering verification, fire, redundancy, vibration, erection.
**Failure Mode:** fake structural expression or unnecessary mass.
**Verifiable Spatial Trace:** load-path diagram and section correspond to visible support logic.

## D2｜MOVEMENT AS REAL CHANGE
**Judgement Meaning:** dynamic architecture should physically change state for a verified reason.
**Trigger:** shading, access, ceremony, protection or program genuinely requires transformation.
**Spatial Operation:** define states, hinges/tracks/clearances and user/environmental triggers before styling moving parts.
**Boundary:** safety, fail-safe, weather, controls, maintenance, manual override.
**Failure Mode:** costly kinetic spectacle.
**Verifiable Spatial Trace:** state sequence + mechanism + operational scenario.

## D3｜BODY / NATURE ABSTRACTION
**Judgement Meaning:** anatomy/nature can seed relations of balance, joint, growth or motion without literal copying.
**Trigger:** a human-scale or movement problem benefits from analogy.
**Spatial Operation:** extract relational principle from sketch and translate it into proportion, sequence or structure.
**Boundary:** analogy must improve project logic.
**Failure Mode:** bone, bird, wing or eye mimicry.
**Verifiable Spatial Trace:** diagram shows source relation → abstract rule → project consequence.

## D4｜STRUCTURE + SPACE UNITY
**Judgement Meaning:** structural order and spatial order should reinforce one another.
**Trigger:** supports/span materially condition program or public space.
**Spatial Operation:** coordinate bays, supports, voids, circulation and enclosure as one system.
**Boundary:** MEP, acoustics, fire, future change.
**Failure Mode:** expressive primary frame plus unrelated functional box.
**Verifiable Spatial Trace:** plan/section show structure organizing occupancy and movement.

## D5｜SEQUENCE THROUGH SECTION
**Judgement Meaning:** movement becomes architectural when section changes how bodies arrive, climb, cross, pause and see.
**Trigger:** civic/public circulation or topography is important.
**Spatial Operation:** compose vertical transitions, bridges, ramps, stairs, landings and views around destinations.
**Boundary:** accessibility, fatigue, egress, crowd flow.
**Failure Mode:** theatrical route that reduces usability.
**Verifiable Spatial Trace:** sectional storyboard explains each transition.

## D6｜LIGHT THROUGH STRUCTURAL ORDER
**Judgement Meaning:** structure and daylight can jointly organize large public space.
**Trigger:** deep/large-span public interiors need daylight and orientation.
**Spatial Operation:** position structure, openings and sectional depth so light supports path and occupancy.
**Boundary:** glare, heat, smoke, acoustics, maintenance.
**Failure Mode:** glassy ribbed hall without climate logic.
**Verifiable Spatial Trace:** daylight test maps to structural section and program.

## D7｜SKETCH → MODEL → TRANSLATION
**Judgement Meaning:** expressive intent must move through deliberate representational stages toward technical reality.
**Trigger:** structural, geometric or kinetic complexity is consequential.
**Spatial Operation:** sketch core relation → model/schematic → compare → coordinate engineering/digital information → revise.
**Boundary:** each stage must test a question rather than preserve an image.
**Failure Mode:** first sketch treated as untouchable icon.
**Verifiable Spatial Trace:** design iterations show evidence-based change.

## D8｜CIVIC SYMBOL FROM FUNCTION
**Judgement Meaning:** public symbolism is strongest when amplified from real movement, structure, climate or collective use.
**Trigger:** civic/transport/cultural programs require shared identity.
**Spatial Operation:** identify the actual public act—arrival, crossing, gathering, opening—then intensify it spatially.
**Boundary:** cost, operations, inclusivity, context.
**Failure Mode:** independent symbolic object.
**Verifiable Spatial Trace:** symbolic reading disappears if functional/public mechanism is removed.

## Selection Lock

Select 3–5 only. Every selected DNA must materially affect a drawing, model, structural diagram or test. Unselected DNA cannot re-enter Recommendation, Prompt or Handoff.
