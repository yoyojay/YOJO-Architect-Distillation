# AR77-015｜SINGLE IMAGE VISUAL HANDOFF

## 定位
只把已经确认的设计判断交给一张概念验证图。不是完整视觉生产系统。

## 启动条件
- Dominant Strategy 已确认；
- Borrowed Mechanism 已确认或 NONE；
- Primary Route 已确认；
- Selected DNA 已确认；
- 影响画面的关键事实已 KNOWN / verified。

## 07｜Must Not Drift
不得复制 Milwaukee Art Museum / Oculus / Turning Torso / Alamillo Bridge / City of Arts and Sciences / Liège-Guillemins。
不得自动补：白色钢肋、鸟翼、眼形、骨架式天棚、斜桅杆、标志性拉索轮廓、扭转塔楼、可动翼形遮阳或其他已识别的 Calatrava 构图。

## 08｜Prompt Fact Lock
逐项扫描 material / structure / façade / geometry / roof / opening / grid / mast / cable / truss / rib / surface / technical components / landscape / furniture。
不可追溯则删除或改写为关系/性能语言。

## 09｜Single Demonstration Image Prompt
只继承 confirmed facts + selected Method/Route + Dominant + optional one Borrowed + Selected DNA + verified site/climate/light。

## 10｜Negative Constraints
只写与当前判断直接相关的漂移风险。

## 11｜Handoff Notice
这是一张概念验证图，用于检查当前设计判断进入视觉后是否成立，不代表完整效果图体系。
