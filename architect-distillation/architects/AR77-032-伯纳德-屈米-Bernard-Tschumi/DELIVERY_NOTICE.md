# AR77 Runtime Delivery Notice

这是 `AR77-032 Bernard Tschumi Architect Skill` 的客户运行版。

建议正式销售协议至少覆盖：
- 指定购买人 / 组织使用；
- 禁止转售、再分发；
- 禁止重新包装为竞争性 Skill；
- 禁止公开销售提取出的运行指令。

本 Notice 不是针对特定司法辖区的法律意见。

## Delivery Protection
客户包只交付可调用 Runtime。以下内容不随包交付：
私人研究档案 / 来源档案 / 生产规范 / 私有 QA 历史 / 批量生产与发布系统。

任何必须在客户本地读取的 Skill 文件，都不能保证文件持有人绝对无法查看；保护策略依赖授权、合同、版本管理与 Runtime Fingerprint 的组合。
