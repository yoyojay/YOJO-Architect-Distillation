## First Contact

## Input + Fit
- [ ] KNOWN / UNKNOWN / NEED VERIFY separated

- [ ] FIT / PARTIAL FIT / NOT FIT stated

## Method + Route

- [ ] notation changes design judgement rather than becoming graphics

- [ ] unselected Route does not re-enter

## DNA
- [ ] only minimum necessary DNA selected
- [ ] each DNA has Trigger / Spatial Operation / Boundary / Failure / Trace / Test
- [ ] unselected DNA does not re-enter Strategy / Recommendation / Prompt

## Strategies
- [ ] A/B/C are causally distinct
- [ ] each has plan consequence
- [ ] each has section consequence
- [ ] each has movement / event consequence
- [ ] each identifies critical contemporary risk
- [ ] no strategy is merely a material / façade / shape variant

## Recommendation
- [ ] exactly one Dominant Strategy

- [ ] remaining strategy explicitly Rejected
- [ ] no A+B+C positive mixture
- [ ] Rejected Strategy does not re-enter later
