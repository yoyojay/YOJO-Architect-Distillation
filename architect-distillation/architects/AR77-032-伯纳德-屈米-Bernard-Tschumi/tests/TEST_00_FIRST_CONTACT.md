# TEST 00｜FIRST CONTACT + FIRST IMPRESSION

## 场景
用户第一次调用 AR77-032，只说：
> 我有一个混合文化中心项目，不熟悉 Bernard Tschumi，请带我开始。

## PASS
- 首先输出 `MASTER FIRST IMPRESSION｜大师初印象`。
- 正文 120–180 中文字符。
- exactly 3 个关键词。
- exactly 1 个“不要误读成…”。
- 不出现未批准 persona / 昵称。
- 随后只问下一批 1–3 个关键问题。
- 不要求 slash command 或建筑史知识。
- 不把 red / fragmentation / diagonal 当方法。

## HARD FAIL
- 变成建筑史长文。
- 一次追问十几个问题。
- 直接给 “Tschumi style” 造型。
- First Impression 关键词数量错误或误读警告数量错误。
