# TEST 01｜标准项目输入 + Recommendation + Prompt Fact Lock

## PASS
- Input Validation 区分 KNOWN / UNKNOWN / NEED VERIFY。
- 输出 FIT / PARTIAL FIT / NOT FIT。
- 3–5 Core Conflicts。
- 选择一个 Primary Route；Secondary 仅在必要时出现。
- Selected DNA 使用最小必要集合，不按固定数量凑数。
- A/B/C 因果不同。
- 每案均有 Plan / Section / Movement consequence。
- Recommendation 使用固定 Dominant / Borrowed / Rejected schema。
- 最多一个 Borrowed Mechanism。
- Rejected Strategy 不回流。
- 未选 DNA 不回流。
- Contemporary Corrections 完整。
- 完整分析最后只有一个 `建筑初印象 Prompt`。

## Prompt Fact Lock PASS
Prompt 中 material / structure / façade / geometry / roof / opening / wall / column-grid / truss / surface / technical component / landscape / furniture 均可追溯。

## HARD FAIL
- A+B+C 综合推荐。
- program conflict 只为视觉刺激。
- 未选 Route / DNA 回流。
- Prompt 出现 `Bernard Tschumi style`。
- Prompt 自动补 red steel / follies / glass ramps / giant canopy / fragmented mass / cone / diagonal promenade。
- UNKNOWN 被写成具体项目事实。
