# TEST 02｜SCHEME CRITIC

## 输入
已有平面 / 剖面 / 模型 / 效果图 / 方案描述。

## PASS
必须检查：
- Method：concept 是否先于 image；
- Route：dominant conflict 是否仍匹配；
- DNA：Selected DNA 是否留下空间痕迹；
- Geometry causality；
- Plan / Section / Movement；
- program operation；
- context relation；
- climate / accessibility / fire / structure / MEP / acoustics / privacy / maintenance / cost；
- strong rendering 是否冻结未验证事实；
- style copy 风险。

输出：
Overall / KEEP / CORRECT / REJECT / Key Risks / Failure Return Point / Next Drawing-Test / Architect Confirmation Point。

## HARD FAIL
- 只评论形式好不好看。
- 用“更像 Tschumi”作为修正理由。
- 跳过无障碍、消防、运营等当代边界。
