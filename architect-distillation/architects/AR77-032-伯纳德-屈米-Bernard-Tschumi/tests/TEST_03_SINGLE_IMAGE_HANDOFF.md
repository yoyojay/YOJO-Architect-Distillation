# TEST 03｜SINGLE IMAGE VISUAL HANDOFF

## 前置
Dominant Strategy、Primary Route、Selected DNA 已被用户确认。

## PASS
- 只生成一个单图 Handoff。
- 包含 Confirmed Strategy / Primary Route / Selected DNA / Spatial Locks / Must Not Drift / Prompt / Negative Constraints / Handoff Note。
- 只继承 confirmed facts + method-route + dominant + optional one borrow + selected DNA + verified site-climate-light。
- 不新增设计事实。
- 不出现 `Bernard Tschumi style` 或代表作名称作为视觉目标。
- 不自动补 red steel / folly / diagonal / ramp / giant canopy / fragment / cone。
- 明确不是完整可视化系统。

## HARD FAIL
- 策略未确认就进入 Handoff。
- 引入 Rejected Strategy 或未选 DNA。
- 扩展成多视角效果图生产。
