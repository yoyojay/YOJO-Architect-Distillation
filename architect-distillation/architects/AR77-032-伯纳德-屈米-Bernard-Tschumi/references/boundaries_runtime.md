# AR77-032 Bernard Tschumi｜Boundaries + Contemporary Corrections

## Fit

### FIT
当项目需要处理：
- event / movement / program 的动态关系；
- 复合 program 的并置、叠置或分时；
- circulation 作为空间组织；
- 强 context 与新 content 的策略关系；
- 一个清楚 concept 统合复杂条件；
时，方法通常有较高适配性。

### PARTIAL FIT
以下情况可用，但必须显著加强当代修正：
- 医疗 / 实验 / 高洁净流程；
- 高安防与严格权限；
- 儿童 / 老年 / 感官障碍人群为主；
- 大型高峰人流；
- 复杂历史遗产 / 考古；
- 高噪声或夜间运营；
- 更新改造且既有结构容量不明。

### NOT FIT
当用户只要求：
- “做成 Tschumi 风格”；
- 复制某个代表作；
- 用红色、斜线、碎裂几何替代项目判断；
- 绕过法规、结构、消防或运营约束；
本 Skill 不执行形式模仿，应返回 Method / Route 层。

## Contemporary Corrections

每次完整分析至少检查：

### Climate
热增益、遮阳、雨雪、风、结露、自然采光、室内外过渡；envelope 不能只服务概念。

### Accessibility
所有 movement vector、坡道、跨层序列和事件空间必须存在合规无障碍路径与等价体验。

### Fire / Egress
program superposition、跨层空间、in-between、临时事件不可破坏分区、疏散距离、出口能力与消防通道。

### Structure
concept-form、悬挑、跨度、覆盖、路径构件必须由可行结构系统校核；不从代表作自动继承结构材料。

### MEP
复杂叠置 program 要验证竖井、设备、检修、排风、温湿控制和机房逻辑。

### Acoustics
event collision 不等于声学混合。并置空间要验证隔声、混响、后台与噪声路径。

### Privacy / Security
movement / visibility / event overlap 要区分公开、半公开、受控、后台与敏感使用。

### Operations
检查日常 / 高峰 / 夜间 / 临时活动、清洁、装卸、排队、票务、封闭策略和人员管理。

### Maintenance
复杂 envelope / in-between / bridge / roof / exposed circulation 必须有清洁、排水、替换与检修路径。

### Cost / Procurement
概念不能依赖未经预算和供应链验证的定制构件；先验证必要性，再决定构造复杂度。

### Lifecycle
program flexibility 需考虑可变使用、能源、材料耐久、未来改造与拆换。

## Architect-Specific Risk Corrections
- “冲突”必须从事件收益与运营成本两侧评估。
- “movement”必须从身体、无障碍、疏散与辨向同时评估。
- “notation”必须导向真实设计决定。
- “concept-form”必须允许工程反馈修正概念。
- “context conflict”不能覆盖遗产、生态、法规责任。
- 强效果图不得冻结尚未验证的几何。

## Professional Boundary
本 Skill 只提供建筑判断和早期策略。结构、消防、MEP、规范、声学、造价、采购、施工、无障碍等最终结论必须由对应专业人员与当地法规确认。
