# AR77-032 Bernard Tschumi｜Method Runtime

## 1｜Method Kernel

本 Runtime 蒸馏的是 Bernard Tschumi 反复出现的建筑判断机制，不是视觉语言。

核心链：

`EVENT / ACTION`
→ `MOVEMENT`
→ `SPACE`
→ `NOTATION`
→ `PROGRAM RELATION`
→ `CONCEPT`
→ `MATERIALIZATION`
→ `PLAN / SECTION / SEQUENCE TEST`
→ `CONTEMPORARY CORRECTION`

### M1｜Architecture starts from relations, not image
先判断会发生什么、谁如何移动、程序怎样相遇，再讨论形式。形式没有独立特权。

### M2｜Space / Movement / Event can be separated before being recombined
不要一开始把功能、路径和空间揉成一个漂亮平面。先分别记录，再判断它们应当：
- 对齐；
- 叠置；
- 错位；
- 冲突；
- 或保持必要的独立。

关键不是“制造冲突”，而是让关系成为明确设计决定。

### M3｜Notation is a design instrument
传统平、立、剖不足以描述时间、身体、事件和变化时，增加：
- sequence；
- movement trace；
- event timeline；
- occupancy scenario；
- program overlap diagram。

Notation 不是图形装饰；它必须改变后续空间决策。

### M4｜Program is more than area schedule
功能表只是静态输入。必须追问：
- 什么时候发生？
- 谁与谁相遇？
- 哪些活动可互相强化？
- 哪些冲突必须被保留、缓冲或禁止？
- 同一空间能否在时间上承担不同事件？

### M5｜Concept precedes formal signature
Concept 是一个能组织多维项目条件的明确命题。它可以来自 program、movement、technology、social relation、context 等，但必须能够落到平面、剖面、路径和运营。

### M6｜Context / Content / Concept relation is strategic
Context 不是必须模仿的背景，Content 也不是自动决定形式的程序。项目必须明确三者是：
- reciprocity；
- conflict；
- strategic independence；
中的哪一种关系，以及为什么。

当代项目中，“conflict / independence”仍必须受法规、遗产、生态、气候与公共安全约束。

### M7｜Materialization must remain testable
概念一旦进入建筑，就必须接受：
- structure；
- fire / egress；
- accessibility；
- climate；
- MEP；
- acoustics；
- privacy；
- operations；
- maintenance；
- cost / procurement；
的修正。

概念不因强烈而获得专业豁免。

## 2｜What is transferable
可以迁移：
- event / movement / space 的关系判断；
- notation 作为设计推理；
- program juxtaposition / superposition；
- movement vector；
- envelope 作为 shelter + movement relation，而非“立面图像”；
- active in-between；
- concept / context / content 的策略关系；
- concept-form 的组织逻辑。

不可直接迁移：
- 代表作几何；
- 红色钢构筑物；
- 固定点阵；
- 特定斜线 promenade；
- 玻璃坡道；
- 巨型覆盖屋顶；
- 圆锥 / 折线 / 碎裂等既有形式；
- “解构主义外观”。

## 3｜Method Test
任何设计主张都要能回答：

1. 它回应了什么事件 / 行动？
2. 它改变了什么 movement relation？
3. 它如何进入 plan / section / sequence？
4. 它与 program / context 的关系是什么？
5. 它由什么 concept 组织？
6. 它经过哪些 contemporary corrections？
7. 去掉视觉效果后，这个机制是否仍成立？

若无法回答，视为形式先行，退回前一阶段。
