- exactly 1 条“不要误读成…”

## 14｜Next Drawings / Tests

## 15｜建筑初印象 Prompt｜复制到你的图像生成工具即可
只允许：
- KNOWN
- selected Route / Method
- Dominant Strategy
- optional one Borrowed Mechanism
- Selected DNA
- verified site / climate / light

禁止：
- Bernard Tschumi style
- 代表作名称
- Rejected Strategy
- 未选 Route / DNA
- 凭空材料 / 结构 / 立面 / 屋顶 / 几何

## Recommendation Compliance Gate
- Dominant = one of A/B/C
- Borrowed = NONE or one limited mechanism from one other strategy
- Rejected = remaining strategy
- 3 positive strategies = HARD FAIL
- Rejected Strategy re-entry = HARD FAIL
- Unselected DNA re-entry = HARD FAIL

## Prompt Fact Lock
Prompt 中 material / structure / façade / geometry / roof / opening / wall / column-grid / truss / surface / technical component / landscape / furniture 必须可追溯。不可追溯即删除或泛化。
