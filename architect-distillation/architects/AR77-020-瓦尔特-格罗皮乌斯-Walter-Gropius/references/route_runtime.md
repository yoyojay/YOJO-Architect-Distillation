# Problem Routes｜Walter Gropius

Route 是项目问题路由，不是历史时期标签。默认选 1 条 Primary Route；只有当两个冲突真正同级时才允许 1 条 Secondary Route。

## R1｜FUNCTIONAL_PROCESS｜流程组织
- Trigger：复杂公众/生产/服务流线，交叉导致效率、安全或理解问题。
- 核心问题：不同活动如何分解并重新形成清楚整体？
- Method：绘制流程 → 识别交叉 → 功能分区/相邻关系 → 平剖验证。
- 主要 DNA：D1 功能分解与重组、D2 流线去冲突、D8 整体回收。
- 边界：不能用“效率”压倒无障碍、尊严、偶遇与公共性。
- 风险：机械功能主义。
- 差异：优先处理 movement/process，不以生产复制为主。

## R2｜COLLABORATIVE_TOTALITY｜跨专业综合
- Trigger：结构、MEP、声学、展陈/工艺、室内或运营相互牵制。
- 核心问题：如何让不同专业不是后置修补，而是共同生成空间？
- Method：建立共同约束图 → 冲突矩阵 → 共同接口 → 综合验证。
- 主要 DNA：D3 协作接口、D7 多系统协调、D8 整体回收。
- 边界：建筑师仍须承担明确决策责任。
- 风险：共识过度导致判断稀释。
- 差异：优先处理协作机制，而非单纯功能流线。

## R3｜INDUSTRIAL_REPRODUCIBILITY｜原型与系列
- Trigger：重复单元、规模化建造、工期/成本/采购压力。
- 核心问题：哪些差异必须保留，哪些可以标准化？
- Method：识别重复 → 定义原型 → 接口标准化 → 样板/成本/装配测试。
- 主要 DNA：D4 原型化、D5 标准化接口、D6 可变重复。
- 边界：标准化必须服从气候、法规、人体差异与场地。
- 风险：把使用者压成抽象平均值。
- 差异：关注生产与复制，不等于“工业美学”。

## R4｜DIFFERENTIATED_WHOLE｜差异化整体
- Trigger：多功能综合体，单一体量/同质空间掩盖真实差异。
- 核心问题：如何让不同功能各得其所，同时仍读成一个系统？
- Method：功能差异 → 体量/剖面/边界职责 → 连接节点 → 整体回收。
- 主要 DNA：D1、D7、D8。
- 边界：不得为了“可读性”制造无必要造型。
- 风险：形式化地把功能画成拼图。
- 差异：关注 parts-to-whole，而非流线或批量生产本身。

## R5｜SOCIAL_REPRODUCTION｜集体生活与可负担系统
- Trigger：住宅、教育、公共服务等需要在社会目标与生产约束间平衡。
- 核心问题：如何把可负担、日常生活质量与规模化交付同时纳入？
- Method：使用者需求 → 最小不可牺牲质量 → 重复/共享系统 → 运营与生命周期验证。
- 主要 DNA：D4、D6、D8，按需加入 D2。
- 边界：历史上的“普遍标准人”必须由当代多样性、无障碍与气候校正。
- 风险：标准化替代真实生活。
- 差异：以社会交付为目标，生产只是手段。
