# Walter Gropius｜Method Runtime

## Evidence status
本模块只使用 KNOWN 与 SUPPORTED INTERPRETATION。项目中的材料、结构和形式仍受 Fact Lock 约束。

## Method Kernel
**任务关系 → 功能分解 → 协作综合 → 技术/生产逻辑 → 空间与构造协调 → 使用与可变性验证 → 重新汇成整体**

1. **任务关系**：先识别真实使用、生产/服务流程、群体关系与社会目标，不从标志性形式开始。
2. **功能分解**：把不同功能、流线、环境需求拆成可判断的部分；差异允许在体量、剖面或边界上被表达。
3. **协作综合**：建筑不是孤立作者物；结构、工艺、室内、设备、艺术与制造条件应进入同一决策桌。
4. **技术/生产逻辑**：当重复、成本、工期或规模要求成立时，测试标准化、原型化、预制/系列生产，而非把“工业感”当视觉目标。
5. **空间与构造协调**：结构、围护、采光、交通各自承担明确职责，并在整体中协调。
6. **使用与可变性验证**：用真实流线、工作条件、转换能力、维护和生命周期检验方案。
7. **整体回收**：局部优化不能破坏整体；最后检查各部分是否形成可理解、可运行、可建造的统一系统。

## Historical evidence anchors
- Fagus Factory：工业流程、采光/轻质围护、功能与社会/工作环境的整体关系。
- Bauhaus Dessau：不同功能翼的差异化组织、跨工坊协作、技术与艺术的综合。
- Dessau Employment Office：无交叉公众流线、可变使用、技术通信与功能组织。
- Dessau-Törten：标准化单元与系列住宅生产的历史实验。

## Transfer rule
迁移的是“如何组织问题并验证系统”，不是某一历史项目的窗、幕墙、屋顶、材料组合或构图。
