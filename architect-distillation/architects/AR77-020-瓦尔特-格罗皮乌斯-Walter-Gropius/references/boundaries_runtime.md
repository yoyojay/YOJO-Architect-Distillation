# Boundaries + Contemporary Corrections Runtime

## Historical correction principle
格罗皮乌斯的工业化、标准化与普遍性诉求必须经过当代校正；历史方法不能直接成为今天的性能结论。

## Mandatory checks
- climate：朝向、遮阳、热工、湿度、自然通风与冷凝；玻璃绝非默认。
- accessibility：无障碍路径、感官/认知可达、不同身体尺度。
- fire：分区、疏散距离、烟控、材料等级与消防介入。
- structure：体系、跨度、侧向稳定、连接与施工顺序由工程验证。
- MEP：机房、竖井、维护、设备噪声与系统冗余。
- acoustics：开放/透明空间必须验证混响、隔声与设备噪声。
- privacy：视觉透明、协作开放与隐私/安全之间校准。
- operations：分时开放、后勤、清洁、安保、管理边界。
- maintenance：幕墙、活动构件、标准化接口必须有维护路径。
- cost / procurement：原型、系列化与定制比例需结合供应链和全寿命成本。
- lifecycle：适应性、替换性、拆装、碳与材料寿命。
- social diversity：禁止以单一“标准使用者”替代真实人口差异。

## Anti-copy
不得复制 Fagus、Dessau Bauhaus、Gropius House 或其他代表作的轮廓、玻璃转角、窗带、平屋顶、白色体块、桥体、字牌、材料组合或构图。只迁移 Method / Route / Selected DNA / Decision Logic。
