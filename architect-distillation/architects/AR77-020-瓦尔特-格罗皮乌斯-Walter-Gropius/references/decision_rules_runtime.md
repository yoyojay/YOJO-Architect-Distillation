# Decision Rules Runtime

- 当流线冲突是主问题 → 优先 R1 + D2 → 因为交通必须先作为组织关系解决 → 用路径冲突图验证 → 若冲突未减少，返回功能相邻关系。
- 当多专业互相后置修补 → 优先 R2 + D3/D7 → 因为综合必须前置 → 用综合剖面/接口矩阵验证 → 若只剩折中，重新定义共同约束。
- 当规模化交付是真约束 → 优先 R3 + D4/D5/D6 → 因为标准化应由生产与维护收益证明 → 用原型、变体、成本与装配测试验证 → 若收益不成立，取消系列化。
- 当复合功能被同质空间压平 → 优先 R4 + D1/D8 → 因为差异应由任务而非造型表达 → 用平剖职责图验证 → 若只是体块拼贴，返回 Main Conflict。
- 当社会交付与生活质量冲突 → 优先 R5 → 因为规模只是手段 → 用用户情景、无障碍、气候、运营和生命周期验证 → 若标准化损害核心质量，缩小标准化范围。
- Fact Lock：任何未确认材料/结构/立面/几何不得进入 Prompt。
- Failure Return：任何策略若无法在 Plan + Section + Movement + Performance 四层形成证据，返回 Route/DNA，不允许用效果图补理由。
