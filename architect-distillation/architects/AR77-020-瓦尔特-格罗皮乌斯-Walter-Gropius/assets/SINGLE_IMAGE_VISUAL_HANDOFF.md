# SINGLE IMAGE VISUAL HANDOFF｜AR77-020
## 定位
只把已经确认的 Walter Gropius 方法判断交给一张概念验证图；不是完整效果图系统。

## 启动条件
- 已完成分析；
- 用户已确认 Dominant Strategy；
- optional Borrowed Mechanism 已确认或 NONE；
- Selected DNA 已锁定；
- 用户明确要求单张视觉验证。

## 输出
### 01｜Confirmed Strategy
### 02｜Selected Route / Method
### 03｜Selected DNA
### 04｜Spatial Locks
只写必须看见的空间关系。
### 05｜Must Not Drift
不得复制 Fagus / Bauhaus Dessau / Gropius House 等代表作；不得自动加入玻璃幕墙、白色体块、平屋顶、钢框架、窗带、桥体或 Bauhaus 字牌。
### 06｜Single Demonstration Image Prompt
只使用 confirmed facts + Method/Route + Dominant + optional one Borrowed + Selected DNA + verified site/climate/light。
### 07｜Negative Constraints
仅列与当前判断直接相关的漂移风险。
### 08｜Fact Lock
逐项扫描材料、结构、立面、几何、屋顶、开口、柱网、桁架、表面、技术构件、景观、家具；无来源即删除/泛化。
### 09｜Handoff
这是一张概念验证图，用于检查已确认空间判断进入视觉后是否成立，不代表完整效果图体系。
