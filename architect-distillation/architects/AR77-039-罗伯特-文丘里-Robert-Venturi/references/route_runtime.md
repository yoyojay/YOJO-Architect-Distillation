# AR77-039｜PROBLEM ROUTES
## Robert Venturi｜Project-Problem Routing

这些 Route 是 AR77 依据证据建立的项目问题路由，不是历史 Period，也不是作品风格分类。

---

## R1｜BOTH_AND_PROGRAM_CONFLICT｜程序矛盾 / Both-And

**Trigger**
- 两个或多个真实要求彼此冲突，但不能简单删除；
- 例如开放 ↔ 私密、对称 ↔ 具体房间需求、统一 ↔ 不同使用尺度。

**核心问题**
如何在一个总体秩序中容纳矛盾，而不是把复杂 brief 简化成单一图式。

**Method**
conflict matrix → overall hierarchy → local exceptions → plan / section reconciliation → performance check。

**主要 DNA**
D01 / D02 / D03 / D08

**适用边界**
住宅、机构、教育、文化、办公、复杂改造。

**风险**
把“矛盾”变成故意奇怪；主次丢失；局部例外过多导致整体不可读。

**与其他 Route 差异**
由 program / spatial contradiction 驱动，而不是 context 或 communication 驱动。

---

## R2｜ORDINARY_ENVIRONMENT_LEARNING｜普通环境观察 / 用户认知

**Trigger**
- 商业街、郊区、交通走廊、校园、城市边缘等环境被传统专业判断视为“普通 / 杂乱”；
- 用户实际通过速度、标识、习惯、停车、视线等使用环境。

**核心问题**
如何先理解现实中的 communication / behavior / convention，再决定设计应保留、修正还是替换什么。

**Method**
field observation → user / speed / sign / access mapping → ordinary patterns → value / problem distinction → design response。

**主要 DNA**
D01 / D04 / D05 / D06

**适用边界**
商业、交通相关、校园、城市更新、公共空间、规划前期。

**风险**
把“学习”误解为照抄广告 / 商业俗套；忽略行人、无障碍、气候与公共利益。

**与其他 Route 差异**
由 empirical observation of existing everyday environment 驱动。

**作者边界**
此 Route 大量依据 `Learning from Las Vegas`，必须标注 Venturi + Denise Scott Brown + Steven Izenour 的共同作者关系。

---

## R3｜COMMUNICATION_LAYER｜符号 / 信息沟通层

**Trigger**
- 建筑需要帮助公众识别用途、入口、机构身份、方向或文化含义；
- program / structure 本身难以清楚表达这些信息。

**核心问题**
如何让 sign / iconography / familiar convention 承担沟通，而不强迫结构 / 体量变成巨大符号。

**Method**
communication need → audience / viewing distance → spatial role vs symbolic role → sign / surface / text options → accessibility / code / maintenance test。

**主要 DNA**
D01 / D04 / D06 / D07

**适用边界**
商业、文化、教育、公共机构、展览、复杂入口。

**风险**
符号过度、广告污染、品牌替代建筑、夜间能耗、法规 / 版权 / 可达性问题。

**与其他 Route 差异**
由 communication problem 驱动。

**作者边界**
其理论依据与 `Learning from Las Vegas` 共同研究直接相关，禁止写成 Venturi 独有发明。

---

## R4｜CONTEXTUAL_ADDITION_WITH_DIFFERENCE｜语境扩建 / 相似与差异

**Trigger**
- 新建筑紧邻历史 / 重要既有建筑；
- 扩建必须同时尊重 context 与形成独立当代身份。

**核心问题**
如何在 scale / alignment / rhythm / access / material relationship 上建立联系，同时避免复制历史外观。

**Method**
existing-context reading → hierarchy of continuities → deliberate differences → entrance / circulation / gallery or program sequence → public-access / performance test。

**主要 DNA**
D01 / D02 / D04 / D07 / D08

**适用边界**
博物馆、校园、历史街区、机构扩建、既有建筑增建。

**风险**
复古复制、拼贴、fake history；或反过来过度对比破坏整体。

**与其他 Route 差异**
由 existing-context relationship 驱动。

**作者边界**
Sainsbury Wing 等证据属于 Venturi Scott Brown / VSBA 团队实践。

---

## R5｜ORDER_WITH_LOCAL_EXCEPTION｜整体秩序 / 局部例外

**Trigger**
- 一个清楚总体几何 / 对称 / 轴线 / 单体秩序受到若干具体功能干扰；
- 小项目或紧凑项目中局部冲突特别明显。

**核心问题**
如何允许局部变形而不让整体失去清晰度。

**Method**
base order → identify necessary exceptions → distort only where causal → preserve dominant reading → plan-section check。

**主要 DNA**
D01 / D02 / D03 / D08

**适用边界**
住宅、小型机构、紧凑公共建筑、复杂内部改造。

**风险**
人为制造“矛盾感”；每个房间都例外导致失序。

**与其他 Route 差异**
由 clear overall order vs specific local needs 驱动。

---

# Route Selection Logic

1. 先写主冲突，再选 Route。
2. Primary Route exactly 1。
3. Secondary Route = NONE 或最多 1。
4. Secondary 必须解决不同但真实的次级冲突。
5. R2 只有 field observation / ordinary-environment learning 真正必要时启用。
6. R3 只有 communication / wayfinding / symbolic-reading 问题真实存在时启用。
7. R4 只有 existing context / addition / adjacency 真实存在时启用。
8. R5 只有整体秩序与局部需求冲突真实存在时启用。
9. 未选 Route 不得回流 Recommendation / Prompt / Handoff。
