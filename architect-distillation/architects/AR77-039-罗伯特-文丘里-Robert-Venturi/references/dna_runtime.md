# AR77-039｜DESIGN DNA RUNTIME
## Robert Venturi

## Selection Rule
- **D01 mandatory**
- 再选 1–3 个必要 DNA
- 总量默认 **2–4**
- 未选 DNA 不得回流 Strategy / Recommendation / Keep / Next / Prompt / Handoff

## D01｜BOTH_AND_CONTRADICTION｜Both-And 矛盾容纳
**判断含义**：当两个真实要求冲突时，优先寻找分层并存而非非此即彼。
**Trigger**：所有完整项目分析。
**Spatial Operation**：建立 conflict matrix，标出可并置 / 必须主次 / 必须分离的关系。
**适用边界**：全部项目。
**Failure Mode**：为了“复杂”故意制造冲突。
**可验证空间痕迹**：至少一组真实矛盾在 plan / section 中被同时处理。

## D02｜HIERARCHY_IN_COMPLEXITY｜复杂性中的层级
**判断含义**：复杂建筑仍需要主次、整体与局部关系。
**Trigger**：program / context / symbol 变量较多。
**Spatial Operation**：定义 dominant order + secondary relations + local exceptions。
**适用边界**：复杂住宅、机构、扩建、公共建筑。
**Failure Mode**：所有元素同等强调，变成视觉噪声。
**可验证空间痕迹**：主要路径、中心、边界、例外在图纸中可区分。

## D03｜LOCAL_EXCEPTION_WITHIN_ORDER｜整体中的局部例外
**判断含义**：局部空间 / 结构需求可以扭曲理想秩序，但必须保护整体可读性。
**Trigger**：局部 program 与基本几何 / 对称 / 轴线冲突。
**Spatial Operation**：只在必要节点偏移、收窄、错位或改变路径。
**适用边界**：住宅、紧凑建筑、改造、机构。
**Failure Mode**：人为制造不规则；例外过多。
**可验证空间痕迹**：每个偏差都能指向具体需求，整体秩序仍可识别。

## D04｜CONVENTION_AS_COMMUNICATION｜常规元素作为沟通
**判断含义**：熟悉的门、窗、屋顶、文字、符号、街道尺度可以帮助公众识别用途和入口。
**Trigger**：项目存在 public recognition / identity / orientation 问题。
**Spatial Operation**：识别 audience familiar conventions → 选择可读元素 → 改变其比例 / 位置 / 组合以适应当前条件。
**适用边界**：公共、商业、文化、校园、住宅。
**Failure Mode**：历史元素直接复制；符号替代真实功能。
**可验证空间痕迹**：用户可更快识别入口 / 用途 / 方向，且无复制代表作。

## D05｜OBSERVE_ORDINARY_ENVIRONMENT｜观察普通环境
**判断含义**：设计前先研究真实用户已经如何读懂和使用 ordinary / commercial / vernacular environment。
**Trigger**：现状常被专业审美快速否定，但其使用机制尚未研究。
**Spatial Operation**：field observation / speed / sign / behavior / parking / pedestrian / desire-line mapping。
**适用边界**：城市、商业、校园、规划、公共空间。
**Failure Mode**：把“普通”浪漫化，或照抄商业俗套。
**可验证空间痕迹**：设计决策能回溯到观察数据而非偏好。
**作者边界**：与 Denise Scott Brown / Steven Izenour 的共同研究密切相关。

## D06｜SYMBOL_SPACE_ROLE_SPLIT｜符号—空间职责分层
**判断含义**：program / structure / enclosure 与 communication layer 可以承担不同工作。
**Trigger**：建筑需要清楚的身份 / 信息，但不必让结构形体本身成为巨大图像。
**Spatial Operation**：分开 program logic / structural logic / communication logic，再检查接口。
**适用边界**：商业、文化、教育、公共机构。
**Failure Mode**：把“decorated shed”理解为廉价盒子 + 任意招牌。
**可验证空间痕迹**：信息层可替换 / 更新而不破坏核心空间与结构。
**作者边界**：来自 `Learning from Las Vegas` 共同研究的 AR77 转译。

## D07｜CONTEXTUAL_INFLECTION｜语境中的相似与差异
**判断含义**：新介入既可回应既有 scale / alignment / rhythm / material relation，也应保持当代差异。
**Trigger**：历史 / 重要既有建筑邻接、扩建、校园插入。
**Spatial Operation**：选择少数真实 continuity points，再定义 deliberate difference。
**适用边界**：扩建、历史街区、校园、机构。
**Failure Mode**：复古复制；或故意反差。
**可验证空间痕迹**：context diagram 能显示哪些关系延续、哪些明确不同。

## D08｜SCALE_SHIFT_AS_HIERARCHY｜尺度变化建立层级
**判断含义**：放大 / 缩小 familiar element 可以建立主次或缓解局部复杂，但不能成为视觉噱头。
**Trigger**：入口、房屋意象、开口、城市界面需要层级辨识。
**Spatial Operation**：先定义人 / 建筑 / 城市阅读距离，再调节 element scale。
**适用边界**：住宅、机构、公共界面。
**Failure Mode**：巨大山墙 / 大柱 / oversized sign 被当作 Venturi 标签。
**可验证空间痕迹**：尺度变化与阅读距离 / program importance 相关。

# DNA Selection Logic

1. D01 mandatory。
2. 再选 1–3 个，总量 2–4。
3. D03 只有真实 local exception 存在时启用。
4. D04 只有公众识别 / 入口 / identity 问题存在时启用。
5. D05 需要真实观察或明确 NEED VERIFY，不能凭印象谈“普通环境”。
6. D06 只有 communication layer 与空间 / 结构责任确实可分时启用。
7. D07 只有 existing context / addition / adjacency 真实存在时启用。
8. D08 必须通过 viewing distance / hierarchy 证明，不得自动放大历史元素。
9. 未选 DNA 禁止回流。
