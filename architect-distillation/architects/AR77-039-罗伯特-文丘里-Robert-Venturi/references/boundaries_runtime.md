# AR77-039｜BOUNDARIES + CONTEMPORARY CORRECTIONS
## Robert Venturi

## Fit

### FIT
- brief 中存在无法简单消除的真实矛盾；
- ordinary / commercial / campus / urban environment 需要被重新观察；
- building identity / communication / wayfinding 是真实问题；
- historical / existing context 的扩建需要同时处理连续与差异；
- overall order 与 local exception 冲突明显。

### PARTIAL FIT
- Venturi 方法可帮助组织复杂性 / context / communication，但项目决定性问题主要由特殊结构、医疗工艺、基础设施或高危工业系统控制。

### NOT FIT
- 唯一目标是“后现代风格”；
- 要求断山墙、尖拱、柱式、装饰棚、复古拼贴；
- 想复制 Vanna Venturi House / Guild House / Sainsbury Wing；
- 项目事实不足却要求具体历史引用 / 材料 / 装饰。

## Contemporary Corrections

### Climate
historical-looking facade / deep opening / sign / screen / material references 都必须重新校验 heat / glare / rain / energy / durability。

### Accessibility
象征性入口、阶梯、复杂门廊、历史型构件、视觉层级不能削弱清晰可达 / wayfinding / inclusive access。

### Fire / Life Safety
复杂 plan、局部例外、展览 / 商业 communication layer 不得破坏疏散、出口辨识与防火分区。

### Structure
象征性 façade / oversized element / irregular opening 不得假装具有结构合理性；必须由工程验证。

### MEP
“ordinary box + sign”或历史型室内空间仍需真实设备 / 检修 / 空气 / lighting infrastructure。

### Acoustics
复杂空间 / 高度变化 / 公共大厅 / 展览必须独立检查声学，不得用视觉层级替代。

### Privacy
符号可读性 / 开放性不能牺牲住宅、教育、办公与公共机构的视觉 / 声音 / 数据隐私。

### Operations
signage、可变 communication layer、入口、展陈与 visitor route 必须支持日常更新、夜间模式和管理。

### Maintenance
applied ornament、sign、surface graphics、特殊 stone / cladding / oversized elements 必须可维修 / 替换。

### Cost
复杂性必须来自真实要求；不得用昂贵定制制造“矛盾感”。

### Procurement
历史引用 / custom component / sign system 必须匹配当地法规、制造、安装与维护资源。

### Lifecycle
communication layer 应尽量可更新；建筑核心空间 / 结构不应因短期品牌或 iconography 频繁拆改。

## Venturi-Specific Corrections

- both-and ≠ everything-at-once；
- complexity ≠ visual clutter；
- contradiction ≠ arbitrary distortion；
- convention ≠ historical copying；
- ordinary ≠ uncritical acceptance of car dependence / advertising / exclusion；
- decorated shed ≠ generic box + random ornament；
- symbolism ≠ accessibility / performance exemption；
- contextualism ≠ fake history；
- irony / wit ≠ user confusion。

## Mobility / Public Realm Correction
`Learning from Las Vegas` 研究了汽车速度与 Strip 的信息环境；今天若迁移其观察方法，必须额外检查：
- pedestrian safety
- transit
- accessibility
- heat / shade
- emissions
- public-space quality
- visual pollution
- sign regulation
- digital / electronic media energy

不得把 1960s automobile landscape 当作今天默认价值。
