# AR77-039｜METHOD RUNTIME
## Robert Venturi｜Architectural Judgement Kernel

## 0｜Evidence + Authorship Boundary

本 Runtime 只允许 `KNOWN` 与 `SUPPORTED INTERPRETATION` 进入 Method / Route / DNA / Rules。

必须区分：
- `Complexity and Contradiction in Architecture`：Robert Venturi 本人著作。
- `Learning from Las Vegas`：Robert Venturi + Denise Scott Brown + Steven Izenour 共同研究 / 著作。
- 后期 VSBA 建筑 / 规划：Venturi Scott Brown 及团队共同实践，不得全部改写成 Venturi 单一作者方法。

## 1｜KNOWN

- MoMA 与 VSBA 资料确认：`Complexity and Contradiction in Architecture` 反对正统现代主义的过度简化，倡导能容纳多重意义、矛盾、暧昧与张力的建筑。
- Vanna Venturi House 的官方项目说明明确以“complex and simple / open and closed / big and little”等并置关系说明其方法；平面对称秩序会因具体空间需求而被局部扭曲，而整体秩序仍可读。
- Venturi 的理论重点不是随机复杂，而是复杂要求在一个整体内形成层级、张力和相互依赖。
- MoMA 与 VSBA 资料显示，Venturi 重视 conventional / familiar elements，但会改变比例、位置、组合和语境，使熟悉元素产生新的意义。
- `Learning from Las Vegas` 的官方资料显示：Venturi、Scott Brown、Izenour 通过对 Las Vegas Strip 的实地观察研究用户感知、汽车速度、商业符号、环境与“ordinary / commercial vernacular”，强调先观察实际环境再建立判断。
- 同一共同研究提出建筑的 symbolic / communicative dimension：sign、iconography 和 conventional imagery 可以承担沟通，不必把所有意义都压进结构 / 形体本身。
- “duck / decorated shed”来自共同研究，是分析建筑如何承载意义的诊断框架，不是要求所有新建筑选择一种历史造型。
- Guild House 官方资料显示 conventional urban elements、普通材料、尺度变化、标识与廉价建造可以在真实预算 / 邻里条件下被重新组织，不依赖英雄式形式。
- Sainsbury Wing 官方资料显示：Venturi Scott Brown 在既有 National Gallery 旁通过 cornice / scale / material / facade reference 与差异化开口、入口、室内层级建立“联系又保持当代身份”的扩建；其设计归属 VSBA / Venturi Scott Brown，不得变成 Venturi 单独作者神话。
- Penn Architectural Archives 将 Venturi, Scott Brown Collection 作为两人职业实践、写作与教学的主要档案库。
- AIA 2016 Gold Medal 授予 Robert Venturi 与 Denise Scott Brown 两人，确认其长期共同影响与共同实践的重要性。

## 2｜SUPPORTED INTERPRETATION

AR77 将上述证据转译为：

`真实程序 / 场地 / 语境 / 用户认知`
→ `识别彼此冲突但都不能删除的要求`
→ `建立总体层级，而不是追求纯化`
→ `允许局部例外 / 歪曲 / 尺度变化处理具体条件`
→ `从普通环境和使用者认知中学习可读的 convention / sign / pattern`
→ `区分空间 / 结构 / program 与 communication layer 的责任`
→ `在既有语境中通过相似 + 差异建立关联`
→ `通过当代性能与社会边界校正`
→ `最后才锁定形式`

这是 AR77 的 evidence-bounded runtime abstraction，不冒充 Venturi 本人提出的固定流程。

## 3｜Core Judgements

### J1｜BOTH-AND BEFORE EITHER-OR｜兼容矛盾先于非此即彼
当两个真实要求冲突时，先尝试让两者在不同层级共同成立，而不是为了纯粹形式删除其中一个。

### J2｜COMPLEXITY NEEDS HIERARCHY｜复杂性需要层级
复杂不等于混乱。整体主次、中心 / 边缘、连续 / 分离、对称 / 例外必须可读。

### J3｜LOCAL EXCEPTION MAY PROTECT THE WHOLE｜局部例外可以保护整体
楼梯、壁炉、入口、开口或结构等具体需求可以局部扭曲理想秩序，但必须能说明它为什么必要。

### J4｜CONVENTION IS A COMMUNICATION RESOURCE｜常规元素是沟通资源
熟悉的门、窗、屋顶、标识、城市尺度或历史语汇只有在帮助用户识别 / 沟通时才有价值；不得直接复古。

### J5｜OBSERVE THE ORDINARY BEFORE JUDGING IT｜先观察普通环境
商业街、郊区、广告、停车、交通速度、用户习惯等可以是研究对象；“普通 / 俗”不应因审美偏见被先行排除。

### J6｜SYMBOL + SPACE CAN HAVE DIFFERENT JOBS｜符号与空间可分担不同职责
建筑意义不必全部由结构 / 形体承担；communication layer 可通过 sign / image / surface / text 实现，但必须符合当代法规、可达性、耐久、能耗与城市边界。

### J7｜CONTEXT CAN BE SIMILAR AND DIFFERENT｜语境可同时相似与不同
扩建 / 邻接项目可以在尺度、檐口、节奏、材料关系或空间次序上建立连续，同时保留新介入的独立身份。

### J8｜RHETORIC MUST NOT OVERRIDE USE｜建筑修辞不能压过使用
象征、引用、比例夸张、尺度错位等只有在 program / wayfinding / accessibility / climate / construction 不受损时才成立。

## 4｜Method Execution

1. 锁定 KNOWN / UNKNOWN / NEED VERIFY。
2. 写 3–5 条项目冲突，不先决定断山墙、拱券、柱式、招牌或装饰表皮。
3. 建立 Conflict Matrix：哪些要求可以并置，哪些必须有主次。
4. 选择 exactly 1 Primary Route；Secondary 最多 1。
5. D01 `BOTH_AND_CONTRADICTION` mandatory；再选 1–3 个必要 DNA，总量 2–4。
6. 每个 Selected DNA 必须留下 Plan / Section / Movement / Context / Communication / Performance 中至少一种可验证痕迹。
7. 生成 A/B/C 三个因果不同策略。
8. Recommendation 只保留一个 Dominant，最多从另一策略借 1 个有限机制。
9. 执行 Contemporary Corrections。
10. Prompt Close 前执行 Prompt Fact Lock。

## 5｜Form Discipline

不得默认：
- Vanna Venturi House 断山墙 / 巨型壁炉 / 特定窗型；
- Guild House 的拱券 / 大柱 / 招牌；
- “duck / decorated shed”作为形式二选一；
- historical quotation / classical column / pediment；
- Sainsbury Wing 的石材 / 古典构件 / gallery sequence；
- bright sign / billboard / ornament；
- “Postmodern / New Classical / Mannerist”作为 style token。

若形式不能追溯到当前项目的 KNOWN + selected Route + Dominant + Selected DNA，必须删除。
