# AR77-039｜DECISION RULES
## Robert Venturi

1. **当**两个真实要求发生冲突  
   **→ 优先**D01  
   **→ 因为**Venturi 的核心不是纯化，而是允许矛盾在整体中共存  
   **→ 通过**conflict matrix + plan-section 验证  
   **→ 若失败则**明确主次或分离，不制造假复杂。

2. **当**变量很多、方案显得杂乱  
   **→ 优先**D02  
   **→ 因为**复杂性必须被层级化  
   **→ 通过**dominant / secondary / exception reading 验证  
   **→ 若失败则**删除非必要机制。

3. **当**某局部需求破坏对称 / 网格 / 基本几何  
   **→ 优先**D03  
   **→ 因为**局部例外可以保护整体功能与秩序  
   **→ 通过**local-cause trace 验证  
   **→ 若失败则**恢复基本秩序。

4. **当**用户说“需要更有身份 / 更容易识别”  
   **→ 优先**D04 或 R3  
   **→ 因为**建筑可借助 convention / communication，而非让整体变成巨大符号  
   **→ 通过**user recognition / wayfinding test 验证  
   **→ 若失败则**删除符号层。

5. **当**现状被评价为“丑 / 俗 / 杂乱”  
   **→ 优先**R2 + D05  
   **→ 因为**先观察真实使用再判断价值  
   **→ 通过**field evidence / behavior / speed / sign mapping  
   **→ 若失败则**把结论标为 NEED VERIFY。

6. **当**出现 duck / decorated shed 讨论  
   **→ 优先**D06 作为诊断工具  
   **→ 因为**这是共同研究中的 communication analysis，不是造型模板  
   **→ 通过**program / structure / sign-role separation 验证  
   **→ 若失败则**不用该框架。

7. **当**新建筑邻接历史建筑  
   **→ 优先**R4 + D07  
   **→ 因为**context 可同时相似与不同  
   **→ 通过**scale / alignment / rhythm / access diagram 验证  
   **→ 若失败则**禁止历史复制或无理由强烈反差。

8. **当**放大门、窗、山墙、柱或文字  
   **→ 优先**D08  
   **→ 因为**scale shift 必须服务层级和阅读距离  
   **→ 通过**human / street / distant-view test 验证  
   **→ 若失败则**恢复常规尺度。

9. **当**A/B/C 只是三种装饰 / 历史引用 / 标牌  
   **→ 优先**重做  
   **→ 因为**策略必须因果不同  
   **→ 通过**不同 primary causal mechanism 验证  
   **→ 若失败则**Strategy Gate FAIL。

10. **当**Recommendation 想混合三案  
    **→ 优先**保留一个 Dominant  
    **→ 因为**Dominant 必须独立成立  
    **→ 通过**最多一个 Borrowed Mechanism 验证  
    **→ 若失败则**Recommendation Gate FAIL。

11. **当**Prompt 自动补 pediment / arch / column / ornament / billboard / historical stone  
    **→ 优先**Prompt Fact Lock  
    **→ 因为**历史引用不是当前项目事实  
    **→ 通过**KNOWN / selected Route / Dominant / Borrowed / Selected DNA / verified site-climate-light 追溯  
    **→ 若失败则**删除或泛化。

12. **当**`Learning from Las Vegas` 的机制被写成 Venturi 单独发明  
    **→ 优先**Authorship Boundary  
    **→ 因为**该研究 / 著作为 Venturi + Denise Scott Brown + Steven Izenour 共同成果  
    **→ 通过**来源归属验证  
    **→ 若失败则**改写为共同作者机制。
