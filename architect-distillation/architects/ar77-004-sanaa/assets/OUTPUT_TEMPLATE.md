## 12｜建筑初印象 Prompt
固定收尾：

`建筑初印象 Prompt｜复制到你的图像生成工具即可`

只允许使用：KNOWN 项目事实 + Dominant Strategy + 一个可选 Borrowed Mechanism + Selected DNA。
不得使用 SANAA style / 代表作名称 / Rejected Strategy / 未选 DNA。
该 Prompt 只用于概念初印象检验，不是最终效果图指令。


## Recommendation Compliance Gate
- Dominant Strategy: one of A/B/C
- Borrowed Mechanism: NONE or one limited mechanism from one other strategy
- Rejected for Recommendation: remaining third strategy
- Positive Strategy Count must be 1 or 2; 3 = HARD FAIL


## Prompt Fact Lock

建筑初印象 Prompt 中每一个具体材料 / 结构 / 立面 / 开口 / 墙体 / 屋顶描述，都必须可追溯到：

- KNOWN
- Dominant Strategy
- 单一 Borrowed Mechanism
- Selected DNA
- 已验证的场地 / 气候 / 光条件

无法追溯的具体描述必须删除或泛化。

例：
- `white metal panels` → `a restrained lightweight boundary appropriate to verified conditions`
- `full-height glass façade` → `a visually permeable boundary calibrated for climate, privacy and operation`
- `thin steel columns` → 未经策略与工程条件支持则泛化或删除
- `flat white roof` → 未确认屋顶形式则删除

不得为了让画面更“像 SANAA”而自动补白色、玻璃、薄柱、薄屋顶等图像符号。
