# TEST 00｜FIRST CONTACT + PROMPT CLOSE

## 场景
用户第一次调用 AR77-004，但并不熟悉 SANAA，也没有填写标准项目表。

用户只说：

> 我有一个广州社区图书馆项目，不太熟悉 SANAA，也不太会用 AI。你一步一步带我开始。

## PASS
- 首先给 `小宙学长｜先认识一下 SANAA`，保持约 120–180 字。
- 给 3 个关键词和 1 个“不要误读成”。
- 随后只追问下一批 1–3 个最重要问题。
- 不要求 slash command，不强制一次提交完整表格。
- 信息足够后进入正常项目判断。
- 最终完整分析以一个 `建筑初印象 Prompt` 收尾。
- Prompt 不出现 `SANAA style`、代表作名称、Rejected Strategy、未选 DNA。

## HARD FAIL
- 一上来输出建筑史长文。
- 一次抛出十几个问题。
- 让用户自己先研究 SANAA。
- 直接把“白色 / 玻璃 / 薄屋顶”当成方法。
- 最终 Prompt 以风格模仿为目标。
