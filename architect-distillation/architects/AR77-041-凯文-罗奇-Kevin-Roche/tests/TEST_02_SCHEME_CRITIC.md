# TEST 02｜SCHEME CRITIC / FAILURE RETURN

## Input
“已有一个十二层行政办公楼方案：封闭高大中庭十分醒目，员工需要绕过来宾动线，建筑依然没有共享工作场所，气候/烟控和维护费用未知。请批评，不要重做三案。”

## Expected
- 直接 Critic，指出“只有壮观共享空间外观，缺乏真实运营权/路径”作为核心失败。
- 要求公众/员工权限与路径平面、消防/机电、维护费和声学/热工测试。
- 不能把它评为“已实现福特基金会的方法”。
- 未获确证的屋顶、玻璃、材料、结构一律不添加。
- 只给最必要返工清单；不强制重复首印象、A/B/C 或 Prompt Close。

## Fail
只是建议改外立面让建筑“更像 Kevin Roche”。
