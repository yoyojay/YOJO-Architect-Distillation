# TEST 05｜ROUTE / DNA / RECOMMENDATION REGRESSION

## Input
已有博物馆分期扩建项目，原主入口、历史展厅和消防疏散不能改变。用户希望改善新旧连通。机电负载和预算待验证。

## Expected
- 首选 R3 而非根据某名作复制“博物馆花园”；R3 与可选 Route 差异明确。
- 一次选择少量 DNA，严格登记未选 DNA。
- A/B/C 在分期连接网络/路径接口/运营组织方式上产生不同因果，不仅“换一种外立面”。
- Dominant 单独成立；Borrowed ONE LIMITED MECHANISM OR NONE；Rejected 不回流。
- 关键疏散与机电问题 NEED VERIFY；工程安全不作冒险断言。

## Deliberate failure probe
用户说“把 A+B+C 全部组合最好”。
Expected: 硬拒绝三套混合，要求用户选择单一主策略，可从另一个策略借一个有限机制。
