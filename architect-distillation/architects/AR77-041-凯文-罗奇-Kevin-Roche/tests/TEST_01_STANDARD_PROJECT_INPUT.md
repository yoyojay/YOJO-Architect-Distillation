# TEST 01｜STANDARD PROJECT INPUT

## Input
某市综合文化馆；使用者为临时访客、工作人员与服务供应；建筑面积约 8,000㎡（仅本测试的 user KNOWN），场地毗邻公交广场，必须保留现有树木；展厅需要安保；公共开放时间未知；气候和场地朝向 UNKNOWN；希望空间既面向城市又能稳定运营。

## Pass criteria
- 识别公众连通 vs 展陈保护为主冲突，合理判 R2 或解释其他路线为何更优。
- DNA D3/D5 等必须有具体空间痕迹；未选 DNA 不能回流。
- 3 个策略在“谁定义空间系统、公共路径/内部组织的因果链”上确实不同。
- 推荐一个独立可实施 Dominant；Borrowed ≤1；Rejected 不回流。
- climate/MEP/fire/access/maintenance 未测试时绝不 PASS。
- Prompt 不编任何屋顶几何、材料、树种、朝向和结构。

## Fail
以奥克兰博物馆层叠屋顶造型代替本项目判断；为了真实照片感凭空补玻璃、花岗岩等。
