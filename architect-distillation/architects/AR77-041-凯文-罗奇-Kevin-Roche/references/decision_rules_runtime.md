# AR77-041 | Decision Rules
规则格式为：`WHEN → PRIORITIZE → BECAUSE → VERIFY BY → IF FAIL RETURN TO`。这是 AR77 可执行机制，不是 Roche 本人语录。

1. FACT LOCK — WHEN 项目材料/结构/几何/立面仍 UNKNOWN → PRIORITIZE 关系/性能描述而非具体构件 → BECAUSE 建筑事实未成立 → VERIFY Prompt 每项溯源 → IF FAIL 删除或改写、回输入审查。
2. FIT — WHEN 客户问题仅为复刻历史标志形式 → PRIORITIZE 从使用者/机构诉求重建问题 → BECAUSE 本方法不是造型包 → VERIFY 有明确待解决空间冲突 → IF FAIL NOT FIT。
3. ROUTE — WHEN 城市开放义务主导 → PRIORITIZE R2 而非仅供内部观赏的 R1 → BECAUSE 公共路径权限才是主要矛盾 → VERIFY 免费使用时段及连接 → IF FAIL 退回 Route 选择。
4. ROUTE — WHEN 遗产改造与分期约束主导 → PRIORITIZE R3 → BECAUSE 长期系统连续性高于单次新外观 → VERIFY 分期与保护界面 → IF FAIL 重构策略。
5. DNA — WHEN 某 DNA 无可见平面/剖面/动线/运营痕迹 → PRIORITIZE 删除该 DNA → BECAUSE 不能用标签替代设计 → VERIFY 设计证据图 → IF FAIL 回选择。
6. STRATEGY — WHEN A/B/C 只差材料、形状、尺寸或开放程度 → PRIORITIZE 修改“空间组织的因果机制” → BECAUSE 策略须可比较的取舍 → VERIFY 三条不同的空间形成链 → IF FAIL 重做三案。
7. PLAN–SECTION–MOVEMENT — WHEN 共享/景观公共空间被提出 → PRIORITIZE 可达、竖向路径、门禁、维护与疏散 → BECAUSE 公共价值不能只由渲染显示 → VERIFY 平剖加流线运营图 → IF FAIL 修改路线与机制。
8. PERFORMANCE — WHEN 大中庭、屋顶景观或多层共享体积拟采用 → PRIORITIZE 气候/消防/结构/MEP/生命周期验证 → BECAUSE 历史原型不证明当前适用 → VERIFY 专业测试 → IF FAIL 撤回未经支持的形态承诺。
9. RECOMMENDATION — WHEN 多个策略均有好处 → PRIORITIZE 一个独立成立的 Dominant，最多借另一策略一个子机制 → BECAUSE 混合丧失检验清晰度 → VERIFY 推荐字段与 DNA 清单 → IF FAIL 拒绝推荐。
10. CRITIC — WHEN 用户提交方案 → PRIORITIZE 检查空间判断、可操作性、当代边界而非外貌 → BECAUSE 审查需要可行动缺陷 → VERIFY 失效证据与返工图 → IF FAIL 请求缺失资料。
11. FAILURE RETURN — WHEN 关键安全/运营测试 FAIL → PRIORITIZE 回冲突定义与 Route，而非换外墙 → BECAUSE 失败动摇空间机制 → VERIFY 下一轮条件被满足 → IF FAIL 停止锁定设计。
12. CONFIRMATION — WHEN 用户没有确认 Dominant/选中 DNA → PRIORITIZE 保持概念讨论，禁止 Single Image Handoff → BECAUSE 不应被早期强图像冻结 → VERIFY 确认记录 → IF FAIL 不生成交接图。
13. PROMPT — WHEN Prompt 含“罗奇风格”或某著名项目名 → PRIORITIZE 删除并以对应实际空间逻辑重写 → BECAUSE Anti-Copy → VERIFY 逐词扫描 → IF FAIL Prompt Close FAIL。
