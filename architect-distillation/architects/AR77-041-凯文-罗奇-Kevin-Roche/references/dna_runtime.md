# AR77-041 | Evidence-Grounded Design DNA
八项 DNA 是 AR77 项目判断用的**蒸馏索引**，不是 Roche 本人曾列的八条原则。证据限定为公开来源事实与有依据解释；每项都具 Trigger → Operation → Boundary → Failure → Trace。

## D1 | 需求先于标签 — Problem Before Style
- **Meaning**：将机构具体需求/人员使用转换为空间问题，而不是风格造型决定使用。
- **Trigger**：项目形式语言先于业务冲突、使用者和使命。
- **Spatial Operation**：制作功能与人群关系图；把核心矛盾转换为可画的空间邻接/边界；选择最能回应需求的组织。
- **Boundary**：不能凭此替代法规、经济和伦理决策。
- **Failure Mode**：声称“功能主义”但忽略社会权利与实际体验。
- **Verifiable Trace**：邻接关系表与关键节点尺寸/通行校验。
- **Source**：[E1/E2 KNOWN]

## D2 | 共享生活的空间载体 — Collective Meeting Ground
- **Meaning**：共同生活/交流可通过有管理能力的共享空间来组织，并非默认大中庭。
- **Trigger**：机构不同人群欠缺可信的接触场景。
- **Spatial Operation**：设定谁何时可进入、停留、会面；在平剖面组织可达交汇点与清晰的权限界线。
- **Boundary**：保密、高度受控、热工/声学不合时不得强行连通。
- **Failure Mode**：精美但空置；访客只见空间不能使用。
- **Verifiable Trace**：访问日历、许可区图、可坐可停与运营成本清单。
- **Source**：[E2/E4 KNOWN; mechanism SUPPORTED INTERPRETATION]

## D3 | 建筑与公共地表融合 — Building–Landscape Commons
- **Meaning**：文化建筑与城市公园/户外活动可在场地层面合成有公共意义的整体。
- **Trigger**：项目承担公共开放、步行连接与景观责任。
- **Spatial Operation**：先画可穿行公共地面及进入制度，协调室内外界面、维护与无障碍连续。
- **Boundary**：不得把奥克兰阶梯屋顶复制为通用模板；极端气候/安全有否决权。
- **Failure Mode**：公众无法进入；屋顶种植导致渗漏/维护过度。
- **Verifiable Trace**：免费访问范围、绿地/户外使用时段、路径纵坡排水校验。
- **Source**：[E1/E5/E6 KNOWN; portable transfer SUPPORTED INTERPRETATION]

## D4 | 机构体系的连续更新 — Long-Horizon Institutional Coherence
- **Meaning**：以整体机构视角审查扩建、增容、原有建筑与未来变化的联系。
- **Trigger**：既有馆舍多期扩张、错综连接、保护限制。
- **Spatial Operation**：现状连接诊断 → 新旧路径接口 → 分期运营/后勤兼容 → 核实每期独立可运转。
- **Boundary**：无可靠既有资料时不能假定拆改可行。
- **Failure Mode**：过度拆改、无法通行的连接、扩建迫使服务中断。
- **Verifiable Trace**：分期接口图、保留/可改/禁改清单、各期疏散/运营测试。
- **Source**：[E3/E7 KNOWN; transfer SUPPORTED INTERPRETATION]

## D5 | 通行就是社会协议 — Access as Social Contract
- **Meaning**：不同群体是否真正共享一处机构，必须通过可执行路径、权限及到达公平证明。
- **Trigger**：公共、内部、物流、服务流线相互冲突。
- **Spatial Operation**：绘出四类流线与交叉点；基于运营与包容性确定安全且可理解的相遇/分离。
- **Boundary**：不承诺所有人可以进入所有空间；不牺牲火警/安保。
- **Failure Mode**：无障碍用户只能绕远或走员工区；门禁否定原设计意图。
- **Verifiable Trace**：各类用户路径图、坡度、电梯/门禁节点，开闭时间验证。
- **Source**：[E2/E5/E7 KNOWN; social-path interpretation SUPPORTED INTERPRETATION]

## D6 | 室内外层级的剖面协同 — Sectional Program–Ground Link
- **Meaning**：层次、展厅、公共地面、工作与维护应在剖面形成实用关系而非单靠体量造型。
- **Trigger**：多高度、多层次功能及室外公共路径需要组合。
- **Spatial Operation**：逐层审查公共性、服务功能、视线及环境界线，验证竖向流动与自然条件。
- **Boundary**：不默认阶梯式馆舍、可步行屋顶或全玻璃封闭中庭。
- **Failure Mode**：形式性剖面无法支撑竖向运输、防火、热湿或检修。
- **Verifiable Trace**：带入口/消防/机电/排水标注的剖面草图。
- **Source**：[E4/E5/E6 KNOWN; cross-case synthesis SUPPORTED INTERPRETATION]

## D7 | 人性化工作环境的可运营性 — Workplace Human Ecology
- **Meaning**：办公/机构工作空间评价要落到工作者体验、协作及实际运行。
- **Trigger**：协作低效、公共区域形同展示、后勤噪声影响集中工作。
- **Spatial Operation**：团队—邻接—共用支持系统—私密梯度组织，再验证实际任务与福利/成本。
- **Boundary**：不可把企业建筑当唯一适配对象；不能以心理叙事代替证据。
- **Failure Mode**：过量展示性公共面积挤占有效空间。
- **Verifiable Trace**：空间利用目标、噪声、邻接和运营场景。
- **Source**：[E1/E2/E8 KNOWN; operational synthesis SUPPORTED INTERPRETATION]

## D8 | 设计与建造的实证对话 — Buildable Design Inquiry
- **Meaning**：深入研究后形成的空间主张必须经建造/设备与寿命验证，不能停在视觉印象。
- **Trigger**：方案依赖复杂空间组织、围护、植物系统或分期施工。
- **Spatial Operation**：用结构/机电/防水/运营团队评估关键截面，备选方案以实测性能取舍。
- **Boundary**：不伪称某种具体结构或技术是 Roche 个人固定选择。
- **Failure Mode**：技术复杂性抹掉公共收益或后续财务不可承受。
- **Verifiable Trace**：关键节点可建造风险单、技术专家参与记录、维护成本。
- **Source**：[E2/E3/E8 KNOWN; runtime synthesis SUPPORTED INTERPRETATION]

## DNA selection logic — AR77 operational rule, NOT a historical count
- 默认挑选对 **Primary Route 核心冲突**真正有贡献的 **2–4 项**，而非把 8 项全装进去。
- 若需求尚不明，D1 必须先执行作为 Method 步骤，但 **不得自动宣布 D1 被选择**；D1 作为设计 DNA 必须有项目级空间痕迹。
- DNA 仅可在明确的 Plan / Section / Movement / Operation 证据中发生作用；无法画出/检验痕迹的移除。
- 每项选中 DNA 记录：选中理由 / 具体动作 / 不得触犯的边界 / 验证图。
- 未选 DNA = `UNSELECTED / DO NOT RE-ENTER`；不得在 A/B/C、Borrowed、Prompt、Next Steps 中悄悄回流。
- 用户条件不允许其中至少两项成立时，不强凑配额：输出 `DNA_INSUFFICIENT` 并回到项目输入判断。
