# AR77-041 | Boundaries, Contemporary Corrections & Scheme Critic

## 1. Non-negotiable correction matrix
逐项给状态：PASS（已有证据） / NEED VERIFY（尚待专业验证） / FAIL（已知冲突） / N/A（说明原因）。不可拿“当年有先例”替代当前规范。

| Domain | Check in current project | Failure/Return |
|---|---|---|
| CLIMATE | 天气边界、热湿负荷、炫光、光照与屋顶/室内植物条件有无气候资料 | 过热/不可维持则缩减或替换公共空间组织机制，不强保中庭 |
| ACCESSIBILITY | 全等参与的公众/员工路径、门禁和不同楼层到达 | 有障碍用户只能走后勤或明显不等价的动线，须重画 |
| FIRE/LIFE SAFETY | 防火分区、烟控、疏散容量、多层联系、公众开放时段 | 大共享空间难以排烟疏散，取消错误空间假定 |
| STRUCTURE | 大空间跨度、叠层/屋顶可达荷载、既有介入 | 无专业验证不得固定构造形式 |
| MEP | 多层共享体积的冷热湿分区、设备可达性、光热与通风 | 初期无法论证能效即 NEED VERIFY |
| ACOUSTICS | 人员交汇/办公/展陈声环境 | 公共性损害日常工作与保藏则重新分界 |
| PRIVACY/SECURITY | 员工、访客、儿童、敏感档案、安保边界 | “开放”不等于无门禁；冲突时优先实际安全 |
| OPERATIONS | 实际公共使用权、开放时间、人力管理、收费/免费 | 仅视觉共享无运营承诺，D2/D3 退回 |
| MAINTENANCE | 植物、屋面、幕墙、玻璃、滴水、排水、保洁 | 维护成本与能力不匹配则拒绝相关机制 |
| COST/PROCUREMENT | 资本支出、寿命周期、合约与施工分期 | 项目预算承受不了公共承诺则重算 |
| LIFECYCLE | 设备更新、未来改造、气候适应性、材料与碳 | 历史外观不能压倒长期性能 |

## 2. Historical reference is NOT contemporary prescription
- **Ford Foundation**：办公围绕室内花园有机构与公共空间示范价值 [E4]；绝不推论大温室天然节能、任意公共开放、无需烟控。2018更新强调了包容、环保和公共开放机制 [E9]。
- **Oakland Museum**：馆舍+公共花园可作为城市—馆舍关系证据 [E5/E6]；不抄台阶屋顶；与当代屋面、排水、展品保护、无障碍一并验证。
- **Met Museum**：1971 master plan 提供长期生长参考 [E7]；机构的历史、遗产审批、访问公平可能否决曾被采用的路线，2024/2026 后续改造不是 Roche 的新设计。
- **People-centred claims**：不能将“社区/人性化”当免检词，必须有实际可达性、停留权利与运维资料。

## 3. Scheme critic — operational examination
输入既有方案说明、平面/剖面/文字及 UNKNOWN。输出：
1. `Intent Fidelity`：是否真实回应用户业务、人群与机构诉求？
2. `Route Fidelity`：Primary Route Trigger 是否仍成立？是否把未选 Route 误作为主方案？
3. `Selected DNA Trace`：对每项已选 DNA 提供真实平、剖、路径或运营证据；无图时标 NEED VERIFY。
4. `Spatial Mechanism`：是否仅靠空中照片、玻璃庭院、屋顶种植来假装方法成立？
5. `Plan–Section–Movement`：出入口/竖向到达、公共与后勤分离、活动冲突、无障碍路径是否有效？
6. `Contemporary Corrections`：按矩阵逐项评估；关键安全问题 FAIL 必须先修。
7. `Anti-Copy`：是否对福特基金会的中庭、奥克兰博物馆的台地景观、梅特建筑片段进行形状复制？
8. `Rendering Freeze`：单张效果图是否冒充已批准图纸/材料与系统？
9. `Recommendation Gate`：Dominant 是否独立；是否混入两个以上策略；Rejected 与未选 DNA 是否回流？
10. 输出优先级 P0/P1/P2、返工目标、最小下一张图/下一项测试。

## 4. Style-Copy and attribution lock
不得输出 `Kevin Roche style`、`in the style of Kevin Roche` 或 `like Ford Foundation` 等形式任务；不得复制某一代表作轮廓、玻璃中庭、通高空间、层叠屋顶公园、材料/构件搭配；从机构需求、城市联系、人员路径与真实性能出发重新证明。

## 5. Professional boundary
代理分析不是结构、机电、消防、规划许可、景观运维或造价签字文件；所有法规、可建造性、设备策略与材料均需本地具资质团队核验。没有用户材料事实时，不得补做确定性技术细节。
