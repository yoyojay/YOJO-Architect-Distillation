# SINGLE IMAGE VISUAL HANDOFF
## AR77-004｜单张概念视觉验证

### 定位
本模块只负责：

**把已经确认的设计判断，交给一张单张概念效果图测试。**

它不是整套效果图生产、多视角系统、完整 3D 控制器，也不是 Zeus96 的替代品。

### 启动条件
- 项目已经完成 AR77-004 分析；
- 建筑师已经确认某个 Strategy；
- 3–5 条 DNA 已确定；
- 用户明确要求单张概念视觉验证。

### 输出

## 01｜Confirmed Strategy
## 02｜Selected DNA
## 03｜Spatial Locks
必须在图中看见的空间关系。

## 04｜Must Not Drift
禁止复制 SANAA 代表作，禁止白色玻璃符号化，禁止新增未经建筑师确认的造型主张。

## 05｜Single Demonstration Image Prompt
基于当前项目和确认策略。

禁止：
`SANAA style`
`like Kanazawa 21st Century Museum`
`copy SANAA`
`Rolex Learning Center style`

Prompt 应描述：
项目类型、确认的空间组织、真实使用活动、边界行为、经确认的气候/光环境、能够揭示空间关系的视角、现实建筑摄影感。

## 06｜Negative Constraints
只写与当前设计判断直接相关的负向约束。

## 07｜Handoff
固定说明：

> 这是一张概念验证图，用于检查当前设计判断进入视觉后是否成立。它不代表完整效果图体系。后续整套视觉生产请进入建筑师原有可视化流程，或交给专门的视觉系统，例如 Zeus96。
