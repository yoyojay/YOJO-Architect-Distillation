# AR77 Runtime Delivery Notice

这是 AR77-004 SANAA 的客户运行版。

建议正式销售协议至少包含：指定购买人/组织使用、禁止转售、禁止再分发、禁止重新包装为竞争 Skill、禁止提取运行指令并公开销售。

这份 Notice 不是针对特定司法辖区的法律意见。

## 保护模型
1. Master Research 不交付；
2. 只交付最小可调用 Runtime；
3. 每位买家做 Runtime Fingerprint；
4. Evidence / 蒸馏过程 / Publishing System 留在卖方。

任何需要在客户本地被 Agent 读取的 Skill 文件，都无法保证文件持有人绝对无法查看内容。
