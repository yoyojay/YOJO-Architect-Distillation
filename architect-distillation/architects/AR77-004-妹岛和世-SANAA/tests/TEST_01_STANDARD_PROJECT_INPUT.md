## v1.4 Regression Gate｜松庭案例已发现错误

以下推荐形式必须判定 HARD FAIL：

```text
以 B 为主
+ 借用 C 的一个机制
+ 再借用 A 的一个机制
```

即使 A 只作为“连接带 / 主轴 / 补充流动感”，仍属于第三策略正向回流。

正确示例：

```text
Dominant Strategy: B
Borrowed Mechanism: C 的“东侧边界差异化 + 夜间关闭”作为一个整体有限机制
Rejected for Recommendation: A
```

被 Reject 的 A 不得再进入 Why / Keep / Next / Summary。
