# AR77-040｜Contemporary Boundaries & Corrections

设计推导 ≠ 建成安全。所有“候选空间机制”必须进入当代专项验证；未验证清楚标注 NEED VERIFY，不得断言性能合格。

| 校正 | 检查的问题 | 必要图纸或测试 | 不通过时 |
|---|---|---|---|
| climate | 体量/天窗/贯通街道是否过热、受风雨影响？ | 气象、热工、日照/风/雨水 | 改剖面或取消外向承诺 |
| accessibility | 每条公开路径是否有连续无障碍等效路线？ | 连续坡度、净宽、转折、升降与标识 | 改动线，不能仅靠照片声明 |
| fire | 多部分装配后的疏散、防火分隔可否合规？ | 消防顾问审查与疏散策略 | 重做界面/分区 |
| structure | 不同体量接口及复杂屋顶能否可靠建造？ | 结构概念与连接节点 | 减少无目的构造复杂度 |
| MEP | 实验/展陈/公共等系统是否干扰或失衡？ | 机电分区、热负荷、设备检修 | 调整块体/服务策略 |
| acoustics | 对外公共路线是否伤害学习、住宿、研究？ | 声学评估、噪声分区 | 调整隔离与界面 |
| privacy/security | 公共穿行与受控机构能否共存？ | 门禁/视线/运营场景 | 减少或改道公共穿行 |
| operations | 跨夜间/节假日开放如何管理？ | 时段平面、管理和后勤模型 | 路线降级为受控通行 |
| maintenance | 大面积玻璃、复杂贴面或高处接缝能否维护？ | 排水、清洁、替换、寿命成本 | 去除高风险细部 |
| cost/procurement | 异形部分、非标准接口是否超预算或供应链能力？ | 造价比较与采购咨询 | 重新组织并简化接口 |
| lifecycle | 表现性屋顶/空间节点的长期能耗和适应性如何？ | 生命周期与空间弹性评估 | 优先更稳健空间机制 |

**历史经验的实际警告**：Historic England 记录 Cambridge History Faculty 因外围护/屋面等进行整改，Florey Building 存在热工、声学、贴面等争议。这不是对其建筑价值的整体否定，而是对“高表现力构造”的有证据的风险提醒。

## Critic 限制
- 不可给出“结构安全/消防合规/净零”保证；只有顾问与法定专业可确认。
- 不可在无业主和实际使用者反馈时断定运营可行。
- 不可仅为还原 Stirling 作品而引入屋顶、柱、色彩或古典部件。
