# 040｜DNA Runtime

> 八项为基于斯特林可核查文本与项目的**当代判断抽象**，不是他本人公布的 8 条法则。选择数量按项目实际必要性：通常 2–4，不满足触发时允许更少；**不得为凑数量选 DNA**。
> 每项：Meaning / Trigger / Spatial Operation / Boundary / Failure Mode / Verifiable Trace。

## D01｜功能差异可读
- Meaning：活动区别应在空间组织中被理解，而非任意显形。
- Trigger：两类以上不同使用/环境/权限。
- Spatial Operation：定义独立活动块与最少必要交界；比较合并与分部布置。
- Boundary：单位效率、结构/机电合理性；不要求体量外部分裂。
- Failure Mode：为了可读而过度分割、行走距离膨胀。
- Trace：功能矩阵、带连接编号的平面、交界清单。
- Evidence：Pritzker 1979 Stirling 自述。

## D02｜功能—象征双重可辨
- Meaning：机构活动的社会角色借真实使用空间被识别，而不是靠贴图。
- Trigger：公共机构需要易识别的入口、集会、身份与工作秩序。
- Spatial Operation：标记“谁从哪来→什么门槛→到哪一功能→如何退出”并将空间焦点放在实用节点。
- Boundary：无仪式或公众诉求时不用制造纪念性。
- Failure Mode：象征大于功能，成了空置雕塑。
- Trace：使用者路径标注、入口动线、公共节点日程。
- Evidence：Pritzker 1979 Stirling 自述。

## D03｜历史类型再解释
- Meaning：借用院、廊、集会等类型*组织关系*，不是某建筑复刻。
- Trigger：文化/学术机构存在真实的识别与交往程序。
- Spatial Operation：提取原型的公共私密层级和交通逻辑，再对照当前法规与计划图改造。
- Boundary：不得在缺乏意义时强行引用；地区历史需当地研究。
- Failure Mode：古典装饰拼贴、空泛“致敬”。
- Trace：抽象类型图、功能映射、三处剖面转译差异说明。
- Evidence：Pritzker Florey 描述；CCA WZB 类型研究。

## D04｜差异部件的明确装配
- Meaning：多元活动和类型通过可解释的临接关系形成整体。
- Trigger：单一空间秩序无法满足多部分的不同使用。
- Spatial Operation：不同块体/房间的邻接与连接节点研究；保留冲突界面可调。
- Boundary：不能把复杂性当价值本身。
- Failure Mode：拼贴体量、冗余循环。
- Trace：邻接图、平剖拼合接口、功能分区对照。
- Evidence：Pritzker 1979 自述；CCA WZB 方案分析。

## D05｜真实公共穿行
- Meaning：公共流线可以是城市关系的具体空间机制，不是视觉手势。
- Trigger：有已核实的公共连通需求和合法开放许可。
- Spatial Operation：验证两个城市端点、路径连续性与独立管理的馆内通行。
- Boundary：气候、无障碍、安保、开放时段必须通过。
- Failure Mode：只在效果图中可通过的“公共坡道”。
- Trace：总图实测城市端点、全路径坡度/净宽/门禁、开闭时段图。
- Evidence：Pritzker Stuttgart 城市上下文；迁移机制属 SUPPORTED INTERPRETATION。

## D06｜制度边界作为空间门槛
- Meaning：开放、半开放与受控使用的界限应能被使用者识别。
- Trigger：公共与安静、后台、研究/储藏共存。
- Spatial Operation：入口、前厅、次入口、后勤与管理分区形成易解释的层级。
- Boundary：当有隐私、噪声、安保要求，先满足法规与运营。
- Failure Mode：公共与后勤冲突，边界逻辑模糊。
- Trace：三色权限分区平面、门禁逻辑、工作日/夜间模式。
- Evidence：Pritzker 1979 使用生活方式论述＋机构项目，可迁移解释。

## D07｜公共节点的空间识别
- Meaning：集会/院落/停留空间能帮助用户理解机构和彼此的关系。
- Trigger：确有公共聚集、识别、分流或共享诉求。
- Spatial Operation：把聚集节点置于通行与功能转换的可达位置，画坐、等、集会使用方案。
- Boundary：不得自动假设露天圆形院或雕塑。
- Failure Mode：戏剧性空场，不舒适且不可运营。
- Trace：公共节点活动面积、日照/声学/疏散与运营图。
- Evidence：Pritzker Florey 中的院/回廊/入口历史空间说明。

## D08｜任务决定光与剖面
- Meaning：环境和工作过程优先决定剖面关系。
- Trigger：特定工作活动具有可验证的采光、眩光、通风条件。
- Spatial Operation：按活动测试方向、遮阳和剖面深度，与人工环境系统协调。
- Boundary：不强制北向玻璃顶、不直接复制 Leicester。
- Failure Mode：玻璃顶导致过热、漏水、维护和能耗问题。
- Trace：剖面采光分析、热工/眩光/排水/维护验证表。
- Evidence：Historic England Leicester 工坊北向采光记录。

## DNA Selection Logic｜硬锁
1. 从 PRIMARY Route 的主要 DNA 中挑选满足 KNOWN Trigger 且能形成可检验空间痕迹的最小集合，必要时从其余 DNA 添加一个有明确依据的补充 DNA。
2. 任一 DNA 触发条件 UNKNOWN → 候选待核实，**不得作为已选进入策略/Prompt**。
3. 将 Selected DNA ID 与其理由、验证证据写入输出；列明 Unselected DNA (仅内部排除记录，不传入正向概念/Prompt)。
4. A/B/C 分别使用同一组已选 DNA 作为约束、但以不同主导因果解法应对；禁止把未选 DNA 偷塞到一个策略来制造差异。
5. 重新选 Route 或用户改变关键事实时，重新筛选 DNA；Rejected Strategy 和未选 DNA 都不得回流最终推荐、图像 Prompt 或 Handoff。
