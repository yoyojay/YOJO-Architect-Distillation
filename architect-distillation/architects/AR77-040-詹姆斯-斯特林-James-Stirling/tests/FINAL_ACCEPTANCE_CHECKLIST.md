# AR77-040｜外部验收清单（客户测试用）

## 00｜FIRST CONTACT
- [ ] 首次完整项目分析 120–180 中文字符（按汉字逐字计数），exactly 3 关键词、exactly 1“不要误读成”
- [ ] 后续追问、Critic、Handoff 不重复
- [ ] 信息不足一次只问 1–3 个关键问题

## 01｜FACT LOCK / FIT
- [ ] KNOWN / UNKNOWN / NEED VERIFY 明确区分
- [ ] 不编造项目地点、材料、气候、面积、坡道、屋顶
- [ ] FIT/PARTIAL FIT/NOT FIT 有项目层面正反理由

## 02｜KERNEL / ROUTE / DNA
- [ ] 核心只从斯特林功能—象征、类型关系与实际空间证据推导
- [ ] PRIMARY Route 有触发、方法、边界、风险与可验证痕迹
- [ ] Selected DNA 对应已知 Trigger；未选 DNA 没有回流
- [ ] 未经证实的公开城市通行需求不选 D05

## 03｜A/B/C & RECOMMENDATION
- [ ] A/B/C 主因果不同，且平面/剖面/路径变化真实不同
- [ ] 每案有优势、风险、Need Verify、失败回退
- [ ] Dominant 可独立成立；Borrowed 仅 NONE 或来自单一其他策略的一种有限机制
- [ ] Rejected Strategy 不出现在保留项、Next、Prompt 的正向机制中
- [ ] Recommendation 的六字段齐全

## 04｜CONTEMPORARY / CRITIC
- [ ] climate/accessibility/fire/structure/MEP/acoustics/privacy/operations/maintenance/cost/procurement/lifecycle 不漏
- [ ] Critic 区分 KEEP/CORRECT/REJECT，检验 Plan-Section-Movement 和强效果图冻结
- [ ] 不能凭历史作品认定技术性能或当代项目合规

## 05｜PROMPT FACT LOCK & HANDOFF
- [ ] Prompt 逐项核查材料、结构、立面、几何、屋顶、开口、柱网、桁架、表面、技术件、景观、家具
- [ ] 不出现建筑师姓名作为风格标签/代表作名作为复制目标
- [ ] 不将 Rejected Strategy / Unselected DNA 重新注入图像
- [ ] 未经显式确认，不生成 Single Image Visual Handoff

## 06｜DELIVERY / STATUS
- [ ] 所有主目录文件及内部引用真实存在
- [ ] `agents/openai.yaml` 有 interface 三键 + policy 两键的原层级
- [ ] 客户 ZIP 不含内部 Master Research/工厂生产档案
- [ ] ZIP 可以解压，SHA256SUMS 可核实
- [ ] 当前交付认证待核验：版本不能标注 FINAL
- [ ] Smoke Test 只有真实目标 Agent 调用后可标 PASS
