# AR77-040｜完整项目分析输出模板

> 这是直接填写的输出框架。UNKNOWN 保持未知；资料不足每轮仅问 1–3 个关键问题。没有确认的策略不得进入 Visual Handoff。

## 00｜MASTER FIRST IMPRESSION｜大师初印象
**仅首次完整分析：** 读取 `assets/MASTER_FIRST_IMPRESSION.md` 的 120–180 中文字符正文、exactly 三关键词、exactly 一句“不要误读成”。

## 01｜INPUT VALIDATION / FACT LOCK
- KNOWN: `[用户事实 + 来源]`
- UNKNOWN: `[未获事实]`
- NEED VERIFY: `[会改变路线或方案的关键核实项]`
- Sufficiency: SUFFICIENT / INSUFFICIENT；不足时只问 1–3 个问题。

## 02｜PROJECT FIT
FIT / PARTIAL FIT / NOT FIT。依据用户问题与 040 Method 的因果适配，不依据外观。

## 03｜CORE CONFLICTS
主要冲突 1 条，次要冲突最多 2 条；解释各方利益、规模/法规/环境限制。

## 06｜A / B / C: THREE CAUSALLY DISTINCT STRATEGIES
分别写：
- 主导因果 / route-DNA 来源
- 空间机制与功能相邻
- 平面变化 / 剖面变化 / 行走路径变化
- 优势 / 风险 / NEED VERIFY / 失败后的回退
- 禁止只换材料、形式或强弱

## 07｜COMPARISON
按：用户活动、城市及门槛、平面/剖面、无障碍及安全、环境、运维、成本与可实施性。对未知项标 UNKNOWN。

## 09｜CONTEMPORARY CORRECTIONS
逐项检查 climate/accessibility/fire/structure/MEP/acoustics/privacy/operations/maintenance/cost/procurement/lifecycle，分别输出风险、责任专家和拟验证图纸。

## 10｜SCHEME CRITIC (如有既有方案)
KEEP / CORRECT / REJECT，至少依据 Method、Route、Selected DNA、Plan/Section/Movement、实际性能与 Anti-Copy。

## 11｜ARCHITECT CONFIRMATION
请求用户确认 Dominant Strategy、唯一可借机制（如有）、Primary Route、Selected DNA、未决事实；此处**不自动执行 Handoff**。

## 12｜NEXT DRAWINGS / TESTS
优先 2–4 项：功能矩阵 / 城市路径端点图 / 总平-剖面-动线同图 / 光热与运营测试等；责任与决策问题清楚。

## 13｜建筑初印象 Prompt｜复制到你的图像生成工具即可
一个只含 KNOWN + 已选 Route/Method + Dominant + 一个有限 Borrowed + Selected DNA + verified site/climate/light 的关系/性能型 Prompt；明确“仅概念验证、不得增添建筑细节”。只用必要的负约束；**Prompt Fact Lock 逐类审计通过后**输出。它并非经确认 Handoff。
