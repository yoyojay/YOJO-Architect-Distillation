# AR77-005｜SINGLE IMAGE VISUAL HANDOFF

仅在 Strategy、Route、4–7 DNA 已确认后使用。

输出：
1. Confirmed Strategy
2. Project-Problem Route
3. Selected DNA
4. Human Experience Locks
5. Must Not Drift
6. One Demonstration Image Prompt
7. Negative Constraints
8. Handoff Note

Human Experience Locks 可包括：坐/停留/移动清楚；采光按活动差异化；声学缓冲有真实使用原因；地形与场地改变平面剖面；半室外过渡回应气候；材料与触感/声学/老化/维护相关；家具和小尺度构件属于空间逻辑；公共空间亲近但清晰。

Must Not Drift：不复制 Paimio、Villa Mairea、Säynätsalo、Baker House、Finlandia；不默认木材、曲线、红砖；不做北欧室内滤镜。

Prompt 禁止出现 `in the style of Alvar Aalto` 及代表作作为视觉目标。

固定 Handoff Note：这是一张概念验证图，用于检查当前设计判断进入视觉后是否成立，不代表完整效果图体系。后续整套视觉生产请进入建筑师原有可视化流程，或交给专门视觉系统，例如 Zeus96。
