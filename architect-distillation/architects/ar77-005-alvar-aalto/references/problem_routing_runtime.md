# AR77-005｜Project-Problem Routing Runtime

## Source boundary
源文件没有正式历史 Period Routes。本文件只把 P6 的四类项目问题转成运行时 Route，不把它们冒充阿尔托自己的时期分类。

## CARE_LEARNING
来源：`医疗与学习：身体是否被持续照顾？`
重点：长时间停留、恢复/专注、身体舒适、光、声、座位、感官负荷。
适合：康养/医疗概念阶段、学习中心、阅读空间、学校。
优先 DNA：01,02,03,07,09,11。
禁止：复制 Paimio 外形、病房配色、家具或完整构图。

## RESIDENTIAL_COMMUNITY
来源：`住宅与社区：材料是否让停留更自然？`
重点：日常生活、多代居住、共享、隐私与相遇、材料触感、家具、半室外过渡。
适合：住宅、共居、社区中心、邻里设施。
优先 DNA：01,05,06,07,09,10,11。
禁止：复制 Villa Mairea 森林柱阵、Baker 折线平面、北欧住宅滤镜。

## LIBRARY_CAMPUS
来源：`图书馆与校园：公共空间是否亲近不压迫？`
重点：学习公共性、人尺度、差异化光、声音、停留、日常机构尊严。
适合：图书馆、校园、学校、文化学习设施。
优先 DNA：01,02,03,07,09,10,12。
禁止：复制 Säynätsalo 庭院、Finlandia 体量或符号曲线。

## ADAPTIVE_PUBLIC_REUSE
来源：`旧建筑更新：巨大空壳如何降到人的尺度？`
重点：大空间改造、人尺度占用、家具、声学缓冲、采光、材料过渡、半室外空间。
适合：仓库、厂房、文化与公共学习更新。
优先 DNA：01,02,03,05,06,07,10,11。
禁止：只用“温暖木饰面”做表皮装修。

## Routing rule
选择 1 条 Primary Route，必要时最多 1 条 Secondary Route。三套 A/B/C 通常保持同一 Primary Route。
