## v1.2 Recommendation / DNA / Route Gate

- [ ] 首次完整项目分析有一次约 150 字大师初印象
- [ ] 信息不足时每轮只问 1–3 个关键问题
- [ ] 只使用 Project-Problem Route，不虚构历史 Period Route
- [ ] Primary Route 只能 1 条，Secondary 最多 1 条
- [ ] 未进入 Selected DNA 的 DNA 不得在策略 / 推荐中重新作为核心或补充机制出现
- [ ] BODY / LIGHT+SOUND / TERRAIN+TRANSITION / MATERIAL+TOUCH / FURNITURE+SMALL ELEMENTS 五层协调
- [ ] 推荐只能是单一策略，或一个主策略 + 另一个策略的一个有限机制
- [ ] 推荐最多只能涉及两个策略，严禁 A+B+C 同时出现
- [ ] 被 Reject 的第三策略不得在 Why / Keep / Next / Prompt 中重新进入
- [ ] 推荐不引入未选择 Route
- [ ] 完整项目分析最后只有一个建筑初印象 Prompt
- [ ] Prompt 只使用 KNOWN + 已选 Route + 五层协调 + Dominant + 单一 Borrowed + Selected DNA
