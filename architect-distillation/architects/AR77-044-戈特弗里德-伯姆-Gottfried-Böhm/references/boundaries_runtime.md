# AR77-044｜BOUNDARIES + CONTEMPORARY CORRECTIONS
## Gottfried Böhm

## Project Fit
**FIT**
- 遗址 / 既有建筑要以当代用途接续，而非复制历史表皮；
- 城市道路、围合地块或单体孤岛真实割裂邻里 / 公共生活；
- 已知集体礼仪、文化、公共活动有空间组织难题；
- 社区、照护、教育存在可达公共性与私密尊严的冲突；
- 新介入必须在场地尺度及人的近距离尺度上同时成立。

**PARTIAL FIT**
- 连接、场地、集体经验可辅助，但核心由特殊医疗流程、交通工程、桥梁、市政管线或结构工程独立决定；只应用被证据支持的部分，注明另需主导专业。

**NOT FIT**
- 用户唯一目的为 Neviges 晶体/混凝土屋顶、Bensberg 尖塔/城堡感、“German Expressionism style”；
- 虚构遗产/道路断点、宗教仪式或邻里传统为方案背书；
- 项目事实不足以选路线而又拒绝核实。

## Contemporary Corrections｜全项目强制逐项检查

### climate
新旧连接、半公共路径、公共庭院、外部廊道在真实温湿、雨雪、日照、风、热岛及季节使用中是否成立；不得由德国历史案例推导本项目气候。

### accessibility
坡地、台地、台阶、遗产高差、圣地路径、城堡旧结构、分层社区必须提供同等质量的无障碍到达；不得用“仪式”使无障碍路线次等。

### fire
礼仪/集会与多入口公共空间必须校验可理解的疏散、消防进入、烟控、防火分隔、峰值人流；修复城市场所不应破坏消防界面。

### structure
折板、悬挑、异形楼梯塔、复杂节点和新旧连接必须由持证结构团队核算；明确老结构承载、地基、抗震、雪风雨荷载和建造过程。

### MEP
复杂剖面、集体大厅、适应性再用、历史围护与新设备接入要验证通风/温控/照明/噪声/维护；隐藏设备不可凭空假设。

### acoustics
大集会、宗教、社区、儿童空间需要验证言语清晰度、噪声与私密性；空间塑性不自动等于好声学。

### privacy
“开放/连接”必须尊重儿童/照护对象、社区住户和机构的安全、安静、个人边界与私人空间。

### operations
公共/半公共/私人分时运行、夜间安全、保安、雨雪通行、清洁、独立租户与活动高峰均需有运营策略。

### maintenance
异形混凝土/折板雨水、膜、防水、外墙维修、复杂接缝、公共地面的磨耗与可达检修需长期验证。Neviges 屋顶与电气翻新是历史存在的维护经验，不能直接推出当前结构做法。

### cost
城市连接、遗产保护、复杂剖面、仪式空间和非标节点都有明确成本/后期运营代价；因果不足的塑性优先删除。

### procurement
历史遗产接口、特殊混凝土/钢玻璃、复杂节点、施工商能力与当地供应链必须验证。

### lifecycle
适应性再利用、新旧材料碳足迹、长期可变性、修复可能、公共服务寿命与社区价值共同核查。

## Böhm-specific corrections
- **Historic ethics**：明确真实历史层级，不做伪古堡、假粗石、移植年代符号；文保调查与审批不可替代。
- **Urban governance**：街道/地块的 public route 应经地权、运营、安全、邻里参与和维护同意；不能把“公共”解释为无授权穿越。
- **Collective space**：朝圣/宗教集体机制只在项目真实有相关活动时调用，宗教象征不得挪作一般公共建筑的情绪装饰。
- **Social care**：不将 Bethanien 团体/照护场所的环形或院落布局当成可普遍复制的模式。
- **Authorship**：清楚区分 Böhm / Dominikus / Elisabeth / Paul 与工程师/团队贡献；不得无证据把全部结构发明或项目细部归给 Gottfried 一人。
- **Material diversity**：历史中同时使用不同材料，不能抽象为“必须用清水混凝土”。
