## D01｜HUMAN_DIGNITY_CONTEXT｜人的尊严与环境关系
**判断含义**：建筑是人的空间与尊严的背景，须承担当代用途并与具体邻里联系。
**Trigger**：所有完整项目分析。
**Spatial Operation**：绘制真实用户—邻居—活动—可达关系图；选择 1–2 个必须被空间保障的尊严需求。
**适用边界**：全部真实项目；具体精神体验不能凭空指定。
**Failure Mode**：“人本”空话，视觉标志压过使用、服务/无障碍被忽略。
**可验证空间痕迹**：总平/平面/剖面能将用户的活动、进入与空间边界连至周边事实。

## D02｜URBAN_TIE_REPAIR｜修复街区联系
**判断含义**：新建不应进一步割断已有城市关系，能修复公共连通时优先修复。
**Trigger**：现状实测显示 pedestrian/social/parcel continuity 有断点。
**Spatial Operation**：绘制 blocked-link / desired-link / accessible route / public stay overlay；择有限连接优先修复。
**适用边界**：公共/城市更新/园区。
**Failure Mode**：只“打开一层”，人流无目标；忽略夜间安全/地权/气候/维护。
**可验证空间痕迹**：步行链路、出入口、公共层与可运营分时图有改进。

## D03｜HISTORICAL_CONTINUITY_NO_QUOTE｜历史连续而非引用
**判断含义**：旧建筑、遗址、尺度/空间纹理有价值时以关系延续，不借外形制造伪历史。
**Trigger**：真实 existing heritage / context 的遗存或规范。
**Spatial Operation**：preserve / new / joint map → address scale/levels/access → explicit contemporary intervention boundary。
**适用边界**：遗产更新/老城扩建。
**Failure Mode**：古堡塔楼仿形、假石材、遗存变展品/失去使用。
**可验证空间痕迹**：旧与新的结构/路径/空间交接点，在图纸中分别可读。

## D04｜BOUNDARY_AS_LINK｜边界既分隔又连接
**判断含义**：外/内、公共/半公共/私密之间的边界要同时处理防护与接近。
**Trigger**：存在真实公私、安保、照护或邻里连接冲突。
**Spatial Operation**：access gradient + threshold / shared node + privacy/security check。
**适用边界**：公共机构、社区、复杂用地界面。
**Failure Mode**：开放口号压过安全或隐私；围合把社区切断。
**可验证空间痕迹**：路径、分区、视线、时段和控制层级可验证。

## D05｜EXTERIOR_REFLECTS_CONTENT｜外部回应内在用途
**判断含义**：外部表达必须可以追溯到实际空间用途、集体活动和构造需要；不是外形复制。
**Trigger**：建筑核心活动需要清楚的公共可读性或集体表达。
**Spatial Operation**：program/collective node → spatial hierarchy/section → test what exterior articulation communicates without extra motif。
**适用边界**：公共、文化、宗教、政府、机构。
**Failure Mode**：通过尖顶、晶体、粗混凝土假装“深刻”；仪式性无对应活动。
**可验证空间痕迹**：体量/剖面/入口/使用图能说明每个主要表达决策。

## D06｜DETAIL_CLOSE_READING｜细部承载近尺度发现
**判断含义**：细部使人靠近时能读出建筑与用途/接缝/人尺度的关系。
**Trigger**：高频近距离使用、旧新连接、关键入口/扶手/坐靠/节点重要。
**Spatial Operation**：identifiable touch/view/service detail → material/assembly test → maintenance and accessibility。
**适用边界**：全部项目，但细部不是附加装饰的许可。
**Failure Mode**：不必要繁复或贵重纹理；节点易损、难清洁。
**可验证空间痕迹**：节点详图和人的观看/使用位置能够相互解释。

## D07｜COLLECTIVE_SPACE_SEQUENCE｜集体空间序列
**判断含义**：集体聚合、仪式和城市活动要通过可使用的到达/阈值/共享焦点与剖面成立。
**Trigger**：已验证的 civic/religious/social event / assembly。
**Spatial Operation**：approach → gathering / shared focus → support/backstage → movement/egress + acoustic/light section。
**适用边界**：文化、宗教、社区、集会。
**Failure Mode**：把 Neviges 的折板大厅/仰望感复制；排斥日常使用与无障碍。
**可验证空间痕迹**：平面/剖面/人流图显示正常与活动高峰状态都能运行。

## D08｜COMMUNITY_CLUSTER_PRIVACY｜共同体—私人层级
**判断含义**：群体空间可围绕有实际用途的共同服务组织，同时保留个人尊严和受控安宁。
**Trigger**：团体照护/居住/机构中存在已核实的 shared/private needs。
**Spatial Operation**：users & safeguarding → shared anchor(s) → semi-public thresholds → group/private rooms → services / operation。
**适用边界**：社区照护、教育、住宅、机构。
**Failure Mode**：复制 Bethanien 的环形布局；弱势群体失去隐私、安全或自主权。
**可验证空间痕迹**：不同用户群的可达路径和公共/受控空间平面分层清楚。
