# AR77-044｜DECISION RULES
## Gottfried Böhm｜Operational, Conditional

统一：`当… → 优先… → 因为… → 通过…验证 → 若失败则…`。以下是 AR77 项目执行规则，而非假称 Böhm 原文。

01｜**Fact Lock**  
当用户未给历史、地形、材料或结构条件 → 优先标 UNKNOWN/NEED VERIFY → 因为历史案例不得变成当前项目事实 → 通过来源/图纸核对 → 若失败则撤回具体形式。

02｜**Fit**  
当项目主诉是城市割裂、真实遗存、公私梯度或集体聚合 → 优先进入本 Skill 的 Fit 判断 → 因为都可与经验证的“连接”机制对应 → 通过明确一个主冲突和一个可验证空间改进 → 若失败则标 PARTIAL / NOT FIT。

03｜**Route**  
当行人连通被道路/地块阻断 → 优先 R1 → 因为城市联系与共同生活优先于单体形象 → 通过 before/after connection map → 若失败则退回事实采集和路线重选。

04｜**Route: heritage**  
当遗址/历史建筑真实存在 → 优先 R2 → 因为历史连续必须基于可辨认的原有物 → 通过 preserve/new/joint diagram 与文保审核 → 若失败则不能借用城堡或“中世纪感”。

05｜**Route: gathering**  
当宗教/文化/公共集会事件明晰 → 优先 R3 → 因为人与集体行为应塑造空间而非晶体形状 → 通过 plan-section-route + crowd/acoustic/egress validation → 若失败则删除表现主义轮廓。

06｜**Route: community**  
当共享与私密/照护需求同时为真 → 优先 R4 → 因为连接不应牺牲个人尊严 → 通过 controlled/public access gradient + safeguarding test → 若失败则不采用聚落式组织。

07｜**DNA selection**  
当未选 DNA 被方案文字“顺手带入” → 优先删除该机制或先正式重选 → 因为选择逻辑要可靠 → 通过 selected DNA ledger scan → 若失败则 DNA Consistency FAIL。

08｜**Plan–Section–Movement**  
当造型被声称“表达用途” → 优先画功能—体量—剖面—路径因果图 → 因为外部应回应内部内容 → 通过真实用户/活动/路线验证 → 若失败则不保留该体量表情。

09｜**Details**  
当想加入复杂纹理/节点 → 优先 D06 且核查真实 touch/view/service 需求 → 因为近尺度发现不是装饰叠加 → 通过 mock-up/repair/cleaning + cost 检查 → 若失败则简化。

10｜**Materials/structure**  
当先提出 exposed concrete / crystal roof / pointed tower → 优先回到 KNOWN performance/program → 因为 Böhm 在不同项目选择不同材料 → 通过 structural/waterproofing/embodied carbon/procurement test → 若失败则删除历史外貌。

11｜**A/B/C**  
当三案只是尖顶高低、混凝土纹理或公共空间强弱 → 优先重建不同因果机制 → 因为策略必须因果独立 → 通过每案不同 primary spatial dependency 验证 → 若失败则 Strategy FAIL。

12｜**Recommendation**  
当试图 A+B+C 混搭 → 优先一个可独立成立的 Dominant；另案最多一处 Borrowed Mechanism → 因为推荐必须可追溯且可负责 → 通过 rejected/unselected ledger 查回流 → 若失败则 Recommendation FAIL。

13｜**Contemporary performance**  
当公共连续性/开放与安全、隐私或消防冲突 → 优先共同检查分时运行、无障碍及消防 → 因为“连接”不高于当代生命安全与尊严 → 通过 day/night/peak plans + professional review → 若失败则缩减开放程度而非忽略风险。

14｜**Scheme Critic**  
当提交尖锐混凝土模型但无空间因果 → 优先问其支撑的 known program / relation → 因为 Böhm 的塑性不能抽离人的空间 → 通过 plan-section-structure trace → 若失败则 REJECT 形式，保留可证实的关系。

15｜**Prompt Fact Lock**  
当 prompt 自带折板、尖塔、混凝土、彩窗、石墙、花园、家具 → 优先逐项追溯 KNOWN/selected Route/Dominant/one Borrowed/Selected DNA/verified site-climate-light → 因为视觉事实不得推断 → 若失败则删除或改成关系/性能语言。

16｜**Failure return**  
当唯一已选 Route 不成立、结构不可能、维护不可承担或审批受阻 → 优先 STOP → return to Conflicts/Route Selection → 因为被否证的方法不能靠效果图保留 → 通过下一张判别性图纸/测试重新验证 → 若失败则标 NOT FIT 或 NEED VERIFY。

17｜**Authorship correction**  
当把与 Elisabeth / Paul /工程师等合作归功于单一建筑师 → 优先改为 collaboration or verify → 因为真实研究要保留分工 → 通过官方档案/项目署名 → 若失败则删去不实发明归属。
