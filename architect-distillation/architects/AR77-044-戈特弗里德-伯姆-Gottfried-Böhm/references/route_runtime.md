# AR77-044｜PROBLEM ROUTES
## Gottfried Böhm｜证据支持的 Project-Problem Routing

**类别声明**：下述 R1–R4 是 AR77 自建的项目冲突路由，并非 Gottfried Böhm 的历史阶段、本人命名系统或固定方案流派。不能因为某个历史作品外貌“像”某路由而触发。

## R1｜URBAN_FABRIC_REPAIR｜城市联系修复
**Trigger**：街道/公共空间被交通、封闭用地、单体孤岛、断裂街区切开，日常社区联系真实受损。
**核心问题**：怎样恢复相邻片区的步行可达、可使用公共空间与社区联系，而不是加造一个孤立标志物？
**Method**：existing routes / barriers → adjacent activities → broken links → choose public connectors → edges / pauses / services → safety / climate / governance test。
**主要 DNA**：D01 / D02 / D04 / D07。
**适用边界**：城市更新、公共设施、园区与街道界面、被切割地块。
**风险**：把“缝合”说成拆墙口号；忽略交通工程、产权、社区意见、气候、夜间安全；公众使用被私人经营吞噬。
**与其他 Route 差异**：以**城市网络与邻里凝聚力**为主因，而非遗产材料或朝圣空间情绪。
**依据**：Böhm 1986 Pritzker 演讲城市创伤/修复；Pritzker 生平关于 city ties；Bergisch Gladbach 公共空间。

## R2｜OLD_NEW_CONTINUITY｜遗存—新建连续性
**Trigger**：项目与实际遗址、重要历史建筑或必须保留的既有城市组织有紧密空间关系。
**核心问题**：怎样让新用途与历史实体彼此支持、同时明确新的时代，不做仿古也不抹掉历史？
**Method**：heritage evidence → preserve / intervene / new zones → scale / connection map → new access and program fit → reversible interfaces where possible → conservation / structure / approval。
**主要 DNA**：D01 / D03 / D04 / D06。
**适用边界**：城市历史改造、文保遗产旁扩建、公共文化机构、既有建筑再用。
**风险**：将旧物景观化；用假石墙、假塔等复制历史；结构连接对遗产造成不可逆伤害；新旧邻接造成无障碍问题。
**与其他 Route 差异**：由**具体旧建/遗存与新介入关系**驱动。
**依据**：Bensberg Castle–Town Hall；Bad Kreuznach 废墟重建；Pritzker speech against decontextualised historicism。

## R3｜COLLECTIVE_RITUAL_SPACE｜集体活动—空间序列
**Trigger**：宗教、纪念、公共议事、文化或集会活动具有真实的集体路径、聚合与意义层级。
**核心问题**：怎样让参与者的进入、聚集、转向、注视与仪式/集体行为在空间中清楚发生？
**Method**：known collective event → arrival / threshold → gathering / focus → section / light / acoustics → structure / crowd / inclusive access → ordinary/day-event test。
**主要 DNA**：D01 / D05 / D06 / D07。
**适用边界**：宗教与文化集会、市民公共大厅、纪念/活动空间。
**风险**：用 Neviges 水晶屋顶替代集体关系；复杂形体先行；采光/声学/消防/结构/运营失败；宗教空间符号侵入非宗教项目。
**与其他 Route 差异**：由**人的集体行为与时间性路径**驱动，不由历史遗产或城市道路断裂驱动。
**依据**：Neviges 室内祭坛周围集体聚合、参拜路径；1986 Pritzker 演讲小礼拜堂中“内在核心 / 外部回应”。

## R4｜COMMUNITY_BOUNDARY_GRADIENT｜公私边界—社区关系
**Trigger**：儿童与青少年、社区住宅、机构、综合公共服务或校园存在共享生活与安静/受控领域之间的真实矛盾。
**核心问题**：如何在 public / semi-public / controlled / private 之间安排清晰、受尊重、可运营的过渡，而不让每个单元孤立或完全敞开？
**Method**：users / care & privacy → shared civic anchor → intermediate thresholds → private zones / service access → daily/night operation → safeguarding / accessibility / acoustic testing。
**主要 DNA**：D01 / D04 / D07 / D08。
**适用边界**：教育/照护、社区住宅、综合服务、机构/园区。
**风险**：把 Bethanien 的环状“村庄布局”照搬；弱势使用者的隐私与安全被“开放”口号覆盖；过度中心化。
**与其他 Route 差异**：由**机构内部的共同体—个人/受控活动过渡**驱动，尺度小于 R1 网络修复。
**依据**：Bergisch Gladbach 市政府对 Bethanien 园区的层级说明；Pritzker biography 关于 private / semi-public / public connections。
