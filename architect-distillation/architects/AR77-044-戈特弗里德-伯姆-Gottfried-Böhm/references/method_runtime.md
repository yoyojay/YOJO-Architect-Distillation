# AR77-044｜METHOD RUNTIME
## Gottfried Böhm｜Architecture as Human Space + Connections

### 0｜证据与作者边界
以下 KNOWN 经过 Pritzker 本人获奖演讲、Pritzker 生平、Bergisch Gladbach 官方城市项目资料、Neviges 朝圣场所档案、德国建筑博物馆收藏确认。以下 Routes/DNA 是 AR77 的 **SUPPORTED INTERPRETATION 项目决策抽象**，不冒充 Böhm 本人给出的历史分类、固定数量或术语。

Böhm 是活跃于建筑、雕塑、城市环境的建筑师；其父 Dominikus Böhm、妻 Elisabeth Böhm、儿子 Paul Böhm 等及结构工程师在不同项目中有真实贡献。不得将所有作品/技术归因给他一人；尤其 1986 演讲所述小礼拜堂明确提及儿子 Paul 的协作；Neviges 结构计算由工程师 Felix Varwick 承担（朝圣场所档案）。

### 1｜KNOWN：来源明确支持
- 1986 年 **Böhm 本人的 Pritzker 获奖演讲**以与儿子 Paul 合作的小礼拜堂说明：建筑是人的空间、尊严的背景；外部应回应内部用途；“清晰”不等于简单几何，而是不可随意增删的整体必要性。
- 同一演讲强调，新建筑应在建筑与历史层面联系既有邻居，但不粉饰时代矛盾，更不能抽离语境引用历史。
- 同一演讲指出战后道路切割与不相干新建对城市组织造成创伤；应恢复都市凝聚力与共同生活，且需要考虑邻居与共同之处。
- 他特别强调近距离观看时才会发现的细部价值；“细部重要”不等于繁复装饰。
- Pritzker 生平资料将其自我定位归为 connections：新/旧、概念/物质、单体/城市、公私与半公共之间的关系；不同项目使用不同材料，不存在统一的混凝土形式配方。
- **Bensberg 市政厅**建立在中世纪城堡遗迹旁并与之相连；Bergisch Gladbach 市政府资料描述庭院、公共议事空间、分层/阶退的尺度调停——不能将尖塔或外墙形式普遍化。
- **Neviges 朝圣教堂**通过由城镇通向圣所的路径、庭院与最终集体室内空间组织朝圣活动；当地场所档案明确室内以祭坛周围聚集和礼仪进行为核心，并记录特定几何与复杂结构是该项目结果，不是全部教堂的做法。
- **Bethanien 儿童村**经当地市政资料核实：围绕公共核心/小村广场设置服务与生活团体；该案例支持共享—私密层级，但不代表所有社会住房必须环形布局。
- **ZÜBLIN 总部**由业主资料确认对办公组织、工业建造以及企业/场所条件的回应，亦具特定预制结构与工程协作背景；不能直接把企业材料逻辑带入其他项目。
- Deutsches Architekturmuseum 记录 Böhm 的绘图与模型收藏；Pritzker 资料确认其雕塑学习与立体模型在方案演化中的作用，但模型不是脱离功能的自由造型许可。
- Pritzker Jury 强调与时俱进地组合历史继承与当代技术；历史延续不等于复刻。

### 2｜SUPPORTED INTERPRETATION｜AR77 可转译 Method Chain
`KNOWN human / civic / ritual / community use`
→ `existing social + architectural + historical relationships`
→ `identify severed / weak / competing connections`
→ `choose which boundary should LINK and which must PROTECT`
→ `define public / semi-public / private and old / new spatial transitions`
→ `make form/section express actual activities and collective space`
→ `test human-scale discovery and material/structural specificity`
→ `repair urban ties while preserving current time's honesty`
→ `contemporary performance + authorship correction`
→ `only then approve form`

以上步骤是本 Skill 为真实项目组织的诊断程序，**不是 Böhm 本人公开的逐项十步法**。

### 3｜Architectural Judgement
**J1 HUMAN_DIGNITY_IN_SPACE**：用途与人的尊严是起点；用平面/剖面/公共使用路径证明，而不以宗教性外形证明。
**J2 CONNECTION_OVER_ISOLATED_OBJECT**：一栋建筑与邻居、城市、社会关系共同组成空间；只看单体效果图是不完整判断。
**J3 HISTORY_AS_CONTINUITY_NOT_QUOTATION**：保留有价值的遗存与空间连续性，不借用旧建筑表皮制造伪历史。
**J4 BOUNDARY_AS_BOTH_LIMIT_AND_LINK**：边界同时承担分隔和联系；隐私、安全、公共穿行各有条件。
**J5 FORM_FROM_CONTENT_AND_USE**：外部表达需要可追溯到活动、结构与内部空间，但表达不等于模拟晶体/城堡/塔尖。
**J6 DETAIL_ENABLES_CLOSE_READING**：细部回应触碰、视线、尺度与制造；不能变成脱离用途的繁密装饰。
**J7 URBAN_REPAIR_AS_SOCIAL_REPAIR**：从真实路径、公共停留与邻里连续性恢复社区，而非空泛“建筑能解决一切社会问题”。
**J8 MATERIAL_IS_PROJECT_DEPENDENT**：从基于实际技术/气候/采购的材料选择出发；Böhm 从混凝土到钢/玻璃的多样实践否定一套通用材料式。

### 4｜执行内核
1. 从用户资料提取 KNOWN、UNKNOWN、NEED VERIFY，禁止用 Böhm 案例替代项目数据。
2. 形成 3–5 个主冲突：existing fabric / new program / public connection / heritage / privacy / structural feasibility。
3. 绘制 CONNECTION MAP：urban paths, neighbors, existing fabric, program zones, community, access / movement。
4. 选择 1 Primary Problem Route；Secondary = NONE 或最多 1；未选路线禁止回流。
5. 选择 D01 mandatory + 1–3 个必要 DNA，总量 2–4；每个 DNA 必须有可验证的平剖/路径/构造痕迹。
6. 先用 2D/section/movement diagrams 论证，再讨论立体塑性、材料或构件。
7. A/B/C 必须以不同**问题的因果解法**成立；比较并保留一个 Dominant。
8. Contemporary Corrections；Critic；Architect Confirmation。
9. 末尾产生 exactly one Concept Impression Prompt，执行 Prompt Fact Lock。
10. 用户确认 Dominant + 要求单图后才 Visual Handoff。

### 5｜禁止直接移植的历史外貌
Neviges 褶皱/锯齿/水晶状混凝土折板、Bensberg 多边形楼梯塔/尖顶、城堡式立面、裸露混凝土材质组合、宗教彩窗、细节肌理、ZÜBLIN 红色预制构件——均仅属历史案例的条件性结果。
