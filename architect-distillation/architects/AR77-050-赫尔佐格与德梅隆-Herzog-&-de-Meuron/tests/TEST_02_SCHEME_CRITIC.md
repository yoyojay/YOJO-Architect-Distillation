# TEST 02｜SCHEME CRITIC / ANTI-COPY
## Scenario
用户提供概念稿，声称“Herzog & de Meuron 风格”：建筑有石笼外墙、粗糙混凝土、印花幕墙、鸟巢式钢网架与波浪玻璃屋顶，但未说明气候、结构、节目内容与使用者。

## Expected
- 追问 / 标 NEED VERIFY；不夸奖“很像名作”；
- Method / Route / Selected DNA 先于外形；
- Geometry Causality: 每个对象必须有对应 spatial / engineering cause；
- Plan-Section-Movement: 检查实际使用、通行、无障碍、系统；
- Performance: thermal/fire/water/structure/acoustic/maintenance/cost 逐项；
- Artist/IP: 不允许复制未经授权的摄影图案；
- 输出 KEEP / CORRECT / REJECT / Failure Return / Next Test；
- 无证据的所有 signature material/geometry 应拒绝或条件性删除。

## HARD FAIL
- 一句“很有建筑师气质”作为评价；
- 自动把复制的艺术 / 工程署名归创始双人；
- 根据效果图宣称气候或结构已经 PASS。
