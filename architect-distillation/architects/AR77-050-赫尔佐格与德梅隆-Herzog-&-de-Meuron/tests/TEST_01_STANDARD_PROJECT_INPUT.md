# TEST 01｜STANDARD PROJECT INPUT
## Scenario
虚构训练 brief（仅作测试，不代表任何真实用户或场地）：
某社区拥有一栋等待技术评估的旧公共设施；希望增加文化活动与可能的公众通行。承重能力、消防分区、开放时间、预算和现状采光未验证。

## Expected Runtime
- [ ] Input Validation: KNOWN / UNKNOWN / NEED VERIFY 分离，不能把承重能力认定已通过；
- [ ] Fit 明确理由；Project Conflicts 3–5 条；
- [ ] Primary Route R1（若证据支持）；Secondary NONE or one justified route；
- [ ] D01 mandatory；只选确有必要的额外 DNA，总 3–4，未选不可借入；
- [ ] A/B/C 由**不同因果组织**产生，不得仅材料或建筑表皮换壳；
- [ ] 三策略都写 Plan / Section / Movement / Use / Performance / Risk / Need Verify / Next Test；
- [ ] Comparison 针对公共通行、既有潜能、技术边界；
- [ ] Recommendation 完整：
Dominant Strategy:
Borrowed Mechanism: NONE / one mechanism from one other strategy
Rejected for Recommendation:
Why:
Unresolved:
Need Verify:
- [ ] Dominant 单独成立；Borrowed 最多 1；Rejected 不能回流 Keep / Next / Prompt；
- [ ] Corrections: climate, accessibility, fire, structure, MEP, acoustics, privacy, operations, maintenance, cost, procurement, lifecycle；
- [ ] Architect Confirmation + 1–2 下一步最有判别力图纸；
- [ ] Exactly one `建筑初印象 Prompt｜复制到你的图像生成工具即可`；
- [ ] Prompt Fact Lock 删除未知石材 / 网架 / 钢 / 玻璃 / 立面 / 开口的具体补写；
- [ ] 用户未确认 Dominant 不进入 Single Image Handoff。

## HARD FAIL
- 以“工业遗产”自动指定砖墙 / 屋顶 / 巨大涡轮大厅；
- 把待核结构安全写成 KNOWN；
- 因为想要丰富效果把 R2-R5、D01-D09 全部选入；
- Borrowed 同时来自 B 和 C；
- 以未选 DNA 的图像作为“辅助”回流。
