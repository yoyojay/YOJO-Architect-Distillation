# AR77-050｜DESIGN DNA RUNTIME
## Jacques Herzog & Pierre de Meuron

九项 DNA 是本次来源支持的 **AR77 transferable judgement mechanisms**，不是事务所发布的“九项 DNA”。

## Selection Contract
- D01 **mandatory**：SITUATED_PERCEPTION_AND_USE。
- 另外选 2–3 个**项目确有必要**的 DNA；默认总计 **3–4**。
- 其他 DNA 必须标 **UNSELECTED**，不得以“补充、氛围、细节、视觉效果”回流。
- 任一 DNA 只有在 Trigger 与真实项目问题匹配、能留下空间 / 性能痕迹时可选。
- 若事实不足，暂停该 DNA 并列 NEED VERIFY；不为凑 3–4 强造材料或空间。

## D01｜SITUATED_PERCEPTION_AND_USE｜场所—身体—使用共同起点
**判断含义**：设计不从外貌先行；人如何到达、占用、看到、听到、触及并使用真实场所才是关键。
**Trigger**：每次完整分析。
**Spatial Operation**：user/use map + site / existing assets + movement / climate / light / acoustic needs → issue matrix。
**适用边界**：所有项目；只可说“分析需求”，不可自动声明感官效果。
**Failure Mode**：把“体验”“材料感”当修辞，不做使用者映射。
**可验证空间痕迹**：plan-section-user trace；每条决策至少对应一个使用情境和具体可测问题。
**Evidence**：Jacques Herzog `Continuities`、`Material and Performance` 访谈；REHAB 与 Tate 项目文本。

## D02｜AS_FOUND_LATENT_CAPACITY｜既有建筑潜能
**判断含义**：先问遗存和既有空间能够承担什么新任务，而非把它当景观背景。
**Trigger**：有可调查的既有建筑 / 非常规大跨空间 / 历史设施。
**Spatial Operation**：existing structure / void / service mapping → retain, reuse, penetrate, connect zones。
**适用边界**：适用于真实更新改造，需产权 / 遗产 / 材料安全与结构条件。
**Failure Mode**：先决定保留所有表皮；忽略失效构件或遗产伦理。
**可验证空间痕迹**：existing/new overlay, retention diagram, reoccupation section, capacity test。
**Evidence**：Tate Modern Tate / Bankside reuse；Elbphilharmonie inherited Kaispeicher。

## D03｜OLD_NEW_PUBLIC_JOINT｜新旧交接中的使用连接
**判断含义**：新与旧相接处可以承载动线、公共转换和集体生活，而不是仅显示美学对比。
**Trigger**：扩建 / 更新项目同时需要新入口或跨层程序。
**Spatial Operation**：old-new interface → entry / accessible connections / shared threshold / program handoff。
**适用边界**：需要真实链接、连续组织及有效运营管理；不自动叠加或设计平台。
**Failure Mode**：假公共平台、昂贵悬浮节点、保留与扩建冲突无法运行。
**可验证空间痕迹**：section through joint / circulation and fire diagrams / opening hours / use schedule。
**Evidence**：Tate public spine；Elbphilharmonie between-warehouse-and-hall public terrace。

## D04｜PERFORMATIVE_ENVELOPE_GRADIENT｜有性能依据的围护梯度
**判断含义**：围护深度与密度可调节热、光、透视和身体接触，须由当前项目气候和建造验证。
**Trigger**：场地明确有需要围护解决的热、眩光、透视或通风冲突。
**Spatial Operation**：measured targets → porosity / thickness / shading / insulation / material role (not preselected) → section/energy testing。
**适用边界**：围护及性能可以专业验证的项目。
**Failure Mode**：复制 gabion、mesh、copper、printed screen 或夯土；把试验性系统当已合规产品。
**可验证空间痕迹**：thermal / daylight section; moisture / fire / maintenance assembly details。
**Evidence**：Dominus Winery gabion; Ricola Kräuterzentrum technical enclosure。

## D05｜FULL_SCALE_MOCKUP_FEEDBACK｜实尺度样段决策
**判断含义**：当材料、边界或纹理的技术/感知行为不确定时，把样段变成决策，不只渲染。
**Trigger**：非标准装配、孔隙、反射、图像、触感、生产容差或环境表现不确定。
**Spatial Operation**：test hypothesis → prototype / full-size bay → instrumented observation / user feedback → revise assembly。
**适用边界**：样段有预算 / 许可 / 安全测试条件；非每个项目都必需。
**Failure Mode**：效果模型被当工程证据，忽略制造、消防、老化和采购。
**可验证空间痕迹**：sample log, pass/fail metrics, before-after detail / material decision。
**Evidence**：Dominus Winery site prototypes；Ricola Kräuterzentrum specialist fabrication（可迁移为 QA 方法而非证明每个项目必做样段）。

## D06｜IMAGE_SURFACE_VOLUME_RECIPROCITY｜图像—表面—体量互相改变
**判断含义**：真实内容与图像层应改变近远视觉、体量与空间理解，不是粘贴“好看纹样”。
**Trigger**：项目有被授权内容 / 艺术合作 / 公众可读性议题。
**Spatial Operation**：authorized image/content → repetition/scale/medium → reading distances → facade / interior spatial feedback。
**适用边界**：博物馆、图书馆、公共艺术或真实信息传播；须解决授权、维护及光环境。
**Failure Mode**：挪用 Eberswalde Thomas Ruff 照片 / Ricola Blossfeldt 植物母题，制造风格图案。
**可验证空间痕迹**：rights ledger outside customer runtime、communication mock-up、eye-level views、impact on daylight/perception。
**Evidence**：`Collaboration with Artists` 和 `Significant Difference` 官方访谈。

## D07｜PUBLIC_THRESHOLD_AND_COLLECTIVE_MOVEMENT｜公共门槛与集体移动
**判断含义**：大型文化 / 市民建筑要从抵达、聚集、安检、入口到日常公共使用建立连续关系。
**Trigger**：公共客流、集体活动、跨项目边界通行是真实冲突。
**Spatial Operation**：public / ticketed / secure zoning → thresholds / queue / pause / accessible circulation / exit → long-term operations。
**适用边界**：文化、体育、城市综合体或既有大建筑的开放项目。
**Failure Mode**：把受限营业设施叫开放城市广场；忽略安检、夜间与轮椅路径。
**可验证空间痕迹**：peak / normal / night movement plans, plaza access agreement, emergency egress section。
**Evidence**：Tate Modern hall as street；Elbphilharmonie plaza；National Stadium public approach。

## D08｜EMBODIED_DAILY_LIFE_GRADIENT｜身体与日常生活梯度
**判断含义**：对真实长期使用者，空间须照顾日常节律、工作 / 休息、照护 / 自主、社交 / 隐私。
**Trigger**：长住、护理、康复、机构使用与人本生活明显冲突。
**Spatial Operation**：users & care tasks → room / shared / garden / service / privacy sequence → clinical and accessibility cross-check。
**适用边界**：康复、照护、长期居住、部分学校 / 机构。
**Failure Mode**：以自然材料 / 庭院形式声称提升治愈率；忽略临床安全与人员工作。
**可验证空间痕迹**：daily user journeys、staff logistics、accessibility maps、privacy/acoustics checks。
**Evidence**：REHAB Basel detailed project brief and later retrospective。

## D09｜CROSS_DISCIPLINARY_SYSTEM_INTEGRATION｜跨专业系统集成与归属
**判断含义**：复杂结构、声学、艺术、材料加工和日常运营需从早期纳入设计，共享但不能抹掉作者贡献。
**Trigger**：存在会改变空间的结构、设备、工艺、声音、图像、无障碍 / 医疗条件。
**Spatial Operation**：joint brief with specialists / clients / users → coordinated design test → verified system interfaces / responsibilities。
**适用边界**：任何真实需跨专业协作项目，不能为图像效果假借“技术创新”。
**Failure Mode**：把 artist motif、工程创新、结构条件归为双人独创；缺少真实专业复核。
**可验证空间痕迹**：coordination section, engineering checks, sign-off / attribution matrix。
**Evidence**：Ai Weiwei, Arup, CADRG in National Stadium; Nagata Acoustics in Elbphilharmonie; Martin Rauch in Ricola, Thomas Ruff in Eberswalde。

## DNA Selection Logic
1. D01 必选。其余 2–3 项根据当前项目**主次冲突的必要性**选，不依据代表作或强视觉效果。
2. R1 优先评估 D02 / D03 / D07；R2 优先 D04 / D05 / D09；R3 优先 D06 / D05 / D09；R4 优先 D07 / D08 / D09；R5 优先 D08 / D07 / D09。但不能自动全选。
3. 若包含未检验新材料 / 施工 / 表皮，D05 只有当有具体可做样段的问题时启用。
4. 若选择 D06，必须注明 image rights、artist authorship 和设计效果可验证。
5. 若选择 D08，必须有真实用户与运营资料，绝不声称医疗效果。
6. 未选择的 DNA 在 A/B/C、Recommendation、Prompt、Handoff、Keep、Next Drawings/Tests 全部禁用；更换时重开 Selection Gate。
