# AR77-050｜BOUNDARIES + CONTEMPORARY CORRECTIONS
## Jacques Herzog & Pierre de Meuron

## Fit

### FIT
- 现有大型建筑、厂房、交通 / 文化空间希望重新编程；
- 围护性能、材料行为与身体感知之间有真实冲突；
- 经授权的公共艺术 / 机构信息需要与建筑空间相互作用；
- 公共文化 / 体育 / 城市节点要组织集体入口、停留、日常公共使用；
- 长住 / 康复 / 照护机构真实用户体验与运营效率冲突。

### PARTIAL FIT
- 这些机制可帮助处理空间与围护，但主矛盾由特殊结构、复杂临床程序、极端能源 / 工业生产或遗产保护法定义，应让相关专家主导。

### NOT FIT
- 仅要求鸟巢网架、石笼、铜板、印花混凝土、弯玻璃 / 水晶、扭转体量或代表作外形；
- 缺乏事实却坚持某具体表皮系统；
- 要把真实艺术合作作品或图案复制到新项目。

## Contemporary Corrections Matrix

### Climate / Energy
必须验证 heat / solar gain / glare / cold bridging / ventilation / airtightness / condensation / moisture / embodied and operational carbon。
传统/创新围护材料均不得无测算宣称可持续。

### Accessibility
改造旧工业设施、公共坡道、平台、蜿蜒路径、长扶梯及展览动线必须有**平等且连续**的无障碍路径；不能只有壮观的仪式路径。

### Fire / Crowd Safety
新旧交接、体育场、演出场、围护孔隙、艺术表皮与大厅必须核验 fire resistance, smoke, evacuation, exits, crowd density, egress and fire department access。

### Structure
石笼 / 自承重土墙 / 巨型网架 / 非标扭曲曲面无法从先例照搬；载荷、抗震、连接、容差、抗腐与维护均由结构工程团队验证。

### MEP / Building Physics
围护厚度、自然 / 机械通风、湿度、设备检修、舒适性和展陈要求必须联合设计，不能用“表皮有呼吸感”掩盖系统冲突。

### Acoustics
concert / exhibition / clinic / public hall 都需声学模拟和实测；Elbphilharmonie 的 acoustic system 有独立声学顾问，不能复制室内表皮图像推论音质。

### Privacy / Sensory Accessibility
视觉图案、反射、声 / 味 / 触感可增强体验也可造成 sensory overload、触发不适、眩光与隐私泄露。须听取用户实际需求与可选择退出的可能。

### Operations / Public Governance
公共平台 / 大厅 / 街道不因外形似公共就成为公共：检验所有权、票务、时段、安保、夜间开放、保洁、排队、应急使用及长期 funding。

### Maintenance / Durability
复杂表皮、表面图像、镀层、孔隙、非标部件、空腔、玻璃 / 金属 / 土墙的替换清洗、腐蚀、老化和可检修是设计输入。

### Cost / Procurement
建立本地 sourcing、样段 / 认证、承包商能力、特殊艺术授权、交期、样品成本与整个 life-cycle cost；不能为了 iconography 扩大造价而不论价值。

### Lifecycle / Reuse
旧建筑保留和新建必须做适用的 whole-life carbon、污染 / 拆除影响、可替换、适应性比较，既有建筑并非自动“低碳”。

### Healthcare / Care / Ethical Boundary
REHAB 经验不构成临床疗效证明。长期照护项目须验证医护动线、感染控制、用户同意、隐私、家庭探访、工作人员负荷与无障碍。

### Artistic / Structural Authorship
保留艺术家与工程师署名、图像许可、原建筑作者：
- Tate / Bankside：Giles Gilbert Scott 原电站；
- Elbphilharmonie / Kaispeicher A：Werner Kallmorgen 原仓库；Nagata Acoustics 等团队；
- National Stadium：Arup / China Architectural Design & Research Group + Ai Weiwei；
- Eberswalde：Thomas Ruff 图像；
- Ricola Kräuterzentrum：Martin Rauch / Lehm Ton Erde；
- REHAB Basel：Christine Binswanger 与专业设计团队。
禁止把所有关键创新简化成两位创始人的独作。

## Scheme Failure Return
出现以下情况必须回退，而非加装饰补救：
- 它的空间效果只能由历史照片解释；
- 未确认材料 / 几何被当事实；
- 缺少 climate / structure / fire / MEP / budget tests；
- 艺术内容无许可；
- 公共进入被收费 / 运营现实否定；
- 机构运营或无障碍失败；
- 选错 Route / DNA；
- 借用超过一个他案机制。

返回：Fact Lock → Conflicts → Route/DNA Selection → 3 genuinely distinct strategies → Recommendation → Prompt Scan。

## Professional Boundary
本 Runtime 仅做前期建筑判断、方案分析 / Critic、路线选择与后续图纸 / 测试建议。
不能替代持证建筑师、结构 / 消防 / 暖通 / 幕墙 / 声学 / 无障碍、医疗运营、造价、景观、版权、保存修复与当地主管部门的核准。
