# AR77-050｜PROJECT-PROBLEM ROUTES
## Herzog & de Meuron

这五条是 **AR77 的证据约束型问题路由**，不是事务所命名的五种创作阶段。由当前项目冲突触发，而非由代表作相似度触发。

## R1｜AS_FOUND_PUBLIC_REPROGRAMMING｜既有空间再编程

**Trigger**：有需保留 / 再利用的工业、文化或公共建筑；新用户 / 新公共活动与原设施秩序冲突。
**核心问题**：哪些现有体量、承重潜能、空隙与通路可以变为新的公共与功能资源？
**Method**：as-found survey → integrity / load / heritage mapping → latent large / residual spaces → new program and access → vertical / horizontal connections → energy / code / lifecycle validation。
**主要 DNA**：D01 / D02 / D03 / D07。
**适用边界**：真实存在可识别、可勘察的既有建筑，且项目有再利用任务。
**风险**：把保留本身当美德；忽略污染 / 抗震 / 负荷 / 无障碍 / 消防 / 既有作者归属；过度商业化原公共价值。
**与其他 Route 差异**：由 inherited building + new program 的冲突驱动，不依赖特殊表皮。
**Evidence Trace**：Tate Modern 原 Bankside Power Station、Turbine Hall / tanks；Elbphilharmonie 原 Kaispeicher 的复合再使用。
**Failure Return**：若遗存无可复用空间 / 结构价值或成本不可接受，停止“遗产奇观化”，返回 program / feasibility。

## R2｜ENVELOPE_AS_CLIMATE_AND_SENSORY_FILTER｜围护作为气候—感知媒介

**Trigger**：场地有可核验的冷热 / 眩光 / 日照 / 视线 / 渗透需求；材料体系能够对其作用。
**核心问题**：如何让围护同时承担环境过滤、边界阅读和真实建造功能？
**Method**：climate/use dataset → desired permeability / thermal and light gradient → assembly logic → sample / simulation / maintenance → plan-section consistency。
**主要 DNA**：D01 / D04 / D05 / D09。
**适用边界**：围护与气候是真正主冲突的工厂、工作场所、文化或公共建筑。
**风险**：把石笼 / 金属网 / 双层皮 / 印花当默认；夸大被动性能、忽视防火、水密、冷凝、能耗和供应链。
**与其他 Route 差异**：由 environmental interface 的性能驱动，而不是图像与传播问题。
**Evidence Trace**：Dominus Winery gabion 的温差 / 透光与实样；Ricola Kräuterzentrum 土墙 / 工序 / 环境协同。
**Failure Return**：性能和组装测试不成立，则转为合规、简单、耐久的中性围护；不保留视觉语言。

## R3｜IMAGE_SURFACE_VOLUME_DIALOGUE｜图像—表面—体量对话

**Trigger**：项目确实存在信息、艺术作品、机构内容或公众阅读问题，需要与建筑围护 / 空间交互。
**核心问题**：图像 / 表面如何改变体量、深度、近远观察和使用，而不是在盒子上贴花？
**Method**：content / artist rights → audience / viewing distance → scale / repeat / substrate → surface-volume interaction → glare / daylight / maintenance / intellectual-property test。
**主要 DNA**：D01 / D06 / D05 / D09。
**适用边界**：档案、图书馆、展陈、公共艺术协作或有真实 communication brief 的项目。
**风险**：挪用他人图像、装饰主题化、眩光 / 褪色 / 污损、费用上涨、视觉冲突与作者隐形。
**与其他 Route 差异**：由 image / communicative content 与体量 / 空间之间的相互作用驱动，不由能源效率本身驱动。
**Evidence Trace**：Eberswalde Library 的 Thomas Ruff 图像；Jacques Herzog 对 Ricola 图案与体量 / 空间的本人论述。
**Failure Return**：若内容、版权、尺度或空间作用无证据，删除图像层而不是硬贴装饰。

## R4｜CIVIC_FIELD_AND_PUBLIC_THRESHOLD｜公共场域 / 集体门槛

**Trigger**：体育、演出、文化设施或大型综合体具有进入、聚集、观看 / 听、公共地面与日常城市关系。
**核心问题**：怎样把集体事件与普通城市生活衔接，而不让大项目只剩远景地标？
**Method**：public user/time map → arrival / queue / access and exits → threshold / public platform / gathering → audience-event relation → acoustics / structure / crowd / security / maintenance。
**主要 DNA**：D01 / D07 / D08 / D09。
**适用边界**：公共文化、体育、演艺与有真实 civic interface 的大型项目。
**风险**：以视觉地标替代公共可达、安保 / 营业时间排斥、巨型高维护结构、演出 / crowd 设备未验。
**与其他 Route 差异**：由 collective use + event thresholds 驱动；不需要网架或波浪屋顶。
**Evidence Trace**：Elbphilharmonie Plaza / hall；Beijing National Stadium 公共 approach / bowl 与结构共同组织。
**Failure Return**：若公共使用在时段、费用和安全上不成立，不能称其“公共平台”；重做 ground operation。

## R5｜EVERYDAY_CARE_AS_ARCHITECTURAL_ENVIRONMENT｜长期照护 / 日常体验

**Trigger**：使用者长期居住 / 康复 / 工作；一般机构效率与人的尊严、独立、家庭联系、身体体验冲突。
**核心问题**：如何组织真正可居住、可辨识、可照护的连续环境，保持临床与运营功能？
**Method**：patient / staff / family journey → therapies / privacy / daily rhythms → room / shared / outdoors / wayfinding → comfort / clinical safety → life-cycle operations / after-use assessment。
**主要 DNA**：D01 / D08 / D07 / D09。
**适用边界**：有相应真实长期停留用户群和专业运营团队的康复、医疗、照护与教育机构。
**风险**：用自然材料 / 庭院外貌声称治疗效益；侵犯隐私；无障碍、感染控制 / MEP / 工作流程不足。
**与其他 Route 差异**：由 embodied long-stay daily life 与 care workflow 驱动；并非公共地标路线。
**Evidence Trace**：REHAB Basel 官方 brief、空间理念与项目团队。
**Failure Return**：若医疗 / 运营功能不成立，返回专家流程与用户安全；不得用氛围补偿。

## Route Selection / Anti-Reentry
1. 先给 3–5 条 verified / NEED VERIFY 项目冲突。
2. Primary **exactly 1**。Secondary **NONE** 或最多 1；只能解决真实不同的次级冲突。
3. R1 必须有实在既有建筑；R2 必须有环境/围护数据；R3 必须有真实 content / rights / user reading；R4 必须有集体活动与 public-access brief；R5 必须有真实 long-stay / care workflow。
4. 没证据时不能借象征性故事强选路线；标 NEED VERIFY，必要时停在问题确认。
5. 未选 Route 不得通过细节、借用、照片提示回流；要改变必须重新声明 Route Selection 并重新生成 A/B/C。
6. 保留项目原作者、艺术家、声学与结构团队归属；不可自动把其贡献归为双人独创。
