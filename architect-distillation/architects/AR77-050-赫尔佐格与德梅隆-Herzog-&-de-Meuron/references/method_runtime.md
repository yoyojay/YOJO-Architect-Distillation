## 1｜AR77 Method Kernel（SUPPORTED INTERPRETATION）
不是事务所自己命名的固定设计阶段。

1. **SITUATE**：先界定当前项目用户、场地、既有资源、社会与日常使用，以及材料 / 技术现实。
2. **FIND THE HIDDEN TASK**：识别外观背后的主要矛盾：既有建筑与新公共功能、围护与热光性能、图像与空间、城市与集体入口、临床效率与居住体验。
3. **COUPLE PERCEPTION + CONSTRUCTION**：把身体感知、光、声、触感、围护深度、结构、路线放在同一因果链里，而非只画立面。
4. **OPERATE ON SPECIFIC EVIDENCE**：从问题选择最小必要 spatial / environmental / artistic mechanism，明确 project-specific 并能在平面、剖面与样段上检验。
5. **TEST THE UNKNOWN**：把样段、气候 / 结构 / 声学 / 防火 / 维护 / 使用测试放在形式冻结之前。
6. **RETURN TO PUBLIC LIFE**：检查体验究竟改善了谁的使用；包括日常、夜间、无障碍和治理成本。
7. **CORRECT NOW**：当代气候、碳、能源、安全、可达、运营、采购、知识产权与作者署名必须重新验证。
8. **LOCK ONLY CONFIRMED FORM**：最后才由可验证因果确定图像 / 造型 / 材料；如形体只是作品图像回放则回到步骤 1。

## 2｜Repeated Architectural Judgements
- J1 **Material is not palette**：不是“喜欢某材料”，而是试验其感知、光热、围护、建造与具体场所作用。
- J2 **Surface is not only decoration**：图像 / 纹样必须改变人如何理解空间、体量或周围环境；艺术作者独立署名。
- J3 **As-found is an active constraint**：既有建筑的空间、遗存、结构潜力可能生成新的公共组织；需要调查而非浪漫化保留。
- J4 **An envelope is an active mediator**：围护可调节光、热、视线及触觉，但不预先指定屏幕、双层表皮、石笼。
- J5 **Public access must be real**：公共平台、大厅、连接与街道要能在运营、时段、收费、安全和无障碍中实际成立。
- J6 **The body occupies, not just sees**：体验包括走、停、看、听、触、温度及日常工作 / 照护；避免建成大图标却忽视使用者。
- J7 **Prototype where uncertainty matters**：涉及非标材料、光学、施工、结构或耐久就做真实样段；样段不是效果图。
- J8 **Authorship is shared**：事务所共同创作；工程、艺术、景观、原建筑、项目团队及用户的实际贡献均须归属。
- J9 **No signature material or form**：不能从双塔、蜂窝、晶体、编织网架、印花玻璃、石笼等外貌归纳统一答案。

## 3｜Project Decision Protocol
1. 输入核验：KNOWN / UNKNOWN / NEED VERIFY。
2. 3–5 Project Conflicts，并写出主冲突由谁承受。
3. Route primary exactly 1; secondary NONE or at most 1 for a genuinely different issue。
4. DNA D01 mandatory, plus 2–3 distinct necessary DNA: total 3–4. 这是本证据集的 AR77 运行选择，不是 HdM 官方 DNA 数。
5. 每个 DNA 输出 Trigger → Spatial Operation → Boundaries → Failure Mode → Observable Trace。
6. 在同一 selected DNA 集合内生成因果不同 A/B/C，且不得偷渡未选机制。
7. 逐案记录 Plan / Section / Movement / Envelope / Construction / Performance / Operation / Risks / Need Verify。
8. Comparison 排序依据项目冲突与可验证性能，不依据“最像 Herzog & de Meuron”。
9. Recommendation exactly one Dominant; optional one limited Borrowed Mechanism from one other strategy; reject the rest。
10. Contemporary Corrections、Critic、Architect Confirmation → Next Tests。
11. Prompt Fact Lock → exactly one Concept Impression Prompt；用户确认 Dominant 后才允许 Single Image Visual Handoff。

## 4｜Anti-Evidence-Laundering / Anti-Copy
禁止把以下已建项目特定的形式转成当前项目事实：
- Dominus 的石笼 / basalt；
- Ricola 的夯土、植物印花、圆窗；
- Tate Modern 的涡轮大厅、烟囱或砖电站比例；
- Elbphilharmonie 的波浪玻璃、曲线扶梯、屋顶；
- Beijing National Stadium 的编织网架、鸟巢意象；
- Eberswalde 的摄影印花；
- REHAB 的木材或庭院布局；
- de Young 的金属表皮。
可以迁移的只有对应的 **使用机制 / 性能问题 / 协作方式 / 验证逻辑**。
