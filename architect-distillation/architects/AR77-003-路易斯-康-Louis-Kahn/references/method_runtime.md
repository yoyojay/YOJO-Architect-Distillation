# AR77-003｜Runtime Method

## Core reasoning chain

The existing 003 source defines the transferable method as:

`institutional wish → room society → served / service order → structure → natural light → public core / threshold → contemporary correction`

This is the method kernel.

---

## Method 01｜Institution before shape

Ask:

- Who uses the institution?
- What shared activity gives it meaning?
- What should happen collectively?
- What requires concentration?
- What should remain stable over time?

Only then discuss spatial organization.

---

## Method 02｜Room as a meaningful unit

A room is not just an enclosed rectangle.

For each room type, define:

- activity;
- proportion;
- adjacency;
- threshold;
- service dependency;
- structural logic;
- daylight character.

---

## Method 03｜Room society

A building gains institutional character from relationships among rooms.

Test:

- which rooms belong together;
- where the collective core sits;
- how thresholds mediate entry;
- whether outdoor rooms matter;
- how users move from individual to collective space.

---

## Method 04｜Served / service coordination

Service space is not leftover.

Coordinate:

- stairs;
- toilets;
- shafts;
- plant;
- storage;
- loading;
- maintenance;
- service access.

But service order must support contemporary flexibility rather than freeze it.

---

## Method 05｜Structure as room order

Structure should help explain:

- room size;
- span;
- rhythm;
- collective space;
- section;
- daylight opening.

Do not add a structural image after spatial planning.

---

## Method 06｜Natural light by activity

Different room types should not all receive identical daylight.

Test:

- side vs top light;
- direction;
- depth;
- reflection;
- contrast;
- control;
- glare;
- heat.

Natural light should be paired with environmental verification.

---

## Method 07｜Three orders must agree

Every strategy must coordinate:

- ROOM ORDER
- SERVICE ORDER
- LIGHT + STRUCTURE ORDER

If they conflict, reorganize the project.

Do not decorate the conflict away.

---

## Method 08｜Institutional dignity through threshold

Dignity can come from:

- approach;
- forecourt;
- porch;
- arcade;
- threshold;
- public hall;
- court;
- calibrated scale.

It does not require oversized monumentality.

---

## Method 09｜Stable order, adaptable use

Stability can live in:

- structure;
- light;
- collective relationships;
- service logic.

Change can live in:

- occupation;
- furniture;
- partitions;
- selected service distribution.

This balance must be project-specific.
