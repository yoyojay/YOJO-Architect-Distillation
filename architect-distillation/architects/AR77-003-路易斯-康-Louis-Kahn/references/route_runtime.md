# AR77-003｜Route Runtime

The original 003 Skill defines six project routes.

These are **problem frames**, not style presets.

---

## LEARNING_ROOMS

### Core concerns
- learning;
- reading;
- individual concentration;
- shared intellectual life;
- room relationships;
- public core;
- natural light by room type.

### Strong project families
- schools;
- libraries;
- learning centers;
- educational institutions.

### Priority DNA
01, 02, 03, 07, 08, 09, 12

Do not copy Exeter's brick cube or giant circular openings.

# Routing rule

1. Choose one primary route.
2. Add one secondary route only if the project genuinely needs it.
3. State why it answers the institutional wish.
4. Explicitly state which historical mechanisms are not being borrowed.
5. Strategies A/B/C should remain coherent with the primary route.
6. Historical works explain **problems and operations**, never visual targets.
