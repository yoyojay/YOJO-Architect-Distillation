## 17｜建筑初印象 Prompt
固定收尾：

`建筑初印象 Prompt｜复制到你的图像生成工具即可`

只允许使用：KNOWN 项目事实 + Institutional Wish + 已选 Route + Room Society + Three Orders + Dominant Strategy + 一个可选 Borrowed Mechanism + Selected DNA。
不得使用 Louis Kahn style / 代表作名称 / Rejected Strategy / 未选 DNA / 未选 Route。
该 Prompt 只用于概念初印象检验，不是最终效果图指令。

## Recommendation Compliance Gate
- Dominant Strategy: one of A/B/C
- Borrowed Mechanism: NONE or one limited mechanism from one other strategy
- Rejected for Recommendation: remaining third strategy
- Positive Strategy Count must be 1 or 2; 3 = HARD FAIL


## Prompt Fact Lock
建筑初印象 Prompt 中每一个具体材料 / 结构 / 立面 / 开口 / 墙体 / 拱顶 / 屋顶 / 水体描述，都必须可追溯到：

- KNOWN
- Institutional Wish
- Room Society
- ROOM / SERVICE / LIGHT + STRUCTURE
- Dominant Strategy
- 单一 Borrowed Mechanism
- Selected DNA
- 已验证场地 / 气候 / 光条件

无法追溯的具体描述必须删除或泛化。

例：
- `brick wall` → `enclosure appropriate to verified construction`
- `deep masonry opening` → `opening calibrated for light, privacy and spatial depth`
- `concrete vault` → `ceiling / structural-spatial order appropriate to the confirmed strategy`
- `central water channel` → 未经策略与 Selected DNA 支持则删除
