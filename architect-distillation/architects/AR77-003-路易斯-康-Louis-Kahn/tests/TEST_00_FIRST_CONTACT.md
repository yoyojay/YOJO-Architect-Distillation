# TEST 00｜FIRST CONTACT + PROMPT CLOSE

## 场景
用户第一次调用 AR77-003，但并不熟悉路易·康，也没有填写标准项目表。

用户只说：

> 我有一个社区学习中心项目，不太熟悉路易·康，也不太会用 AI。你一步一步带我开始。

## PASS
- 首先给 `小宙学长｜先认识一下路易·康`，保持约 120–180 字。
- 给 3 个关键词和 1 个“不要误读成”。
- 随后只追问下一批 1–3 个最重要问题。
- 不要求 slash command，不强制一次提交完整表格。
- 信息足够后进入正常项目判断。
- 最终完整分析以一个 `建筑初印象 Prompt` 收尾。
- Prompt 不出现 `Louis Kahn style`、代表作名称、Rejected Strategy、未选 DNA、未选 Route。

## HARD FAIL
- 一上来输出建筑史长文。
- 一次抛出十几个问题。
- 让用户自己先研究路易·康。
- 直接把厚重 / 大圆洞 / 砖 / 混凝土当成方法。
- 最终 Prompt 以风格模仿为目标。
