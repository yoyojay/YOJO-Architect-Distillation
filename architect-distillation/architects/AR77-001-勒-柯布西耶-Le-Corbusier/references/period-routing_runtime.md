# AR77-001｜Period Routing Runtime

The original 001 method requires selecting a historical problem-frame rather than mixing all Le Corbusier phases into one visual filter.

---

## EARLY_RATIONAL

### Core concerns
- structural liberation;
- free plan;
- free façade;
- roof as recovered ground;
- architectural promenade;
- rational prototype.

### Strong source-fit project families
- small housing;
- exhibition;
- gallery;
- prototype studies.

### Priority DNA
01, 03, 04, 05, 06

### Avoid
Do not reduce this route to a white box + pilotis + ribbon window.

# Routing rule

1. Choose one primary route.
2. Add one secondary route only if the project genuinely requires it.
3. Explicitly state what is not being borrowed.
4. Strategies A/B/C should remain coherent with the primary route.
5. Historical references explain **problems and operations**, not visual targets.
