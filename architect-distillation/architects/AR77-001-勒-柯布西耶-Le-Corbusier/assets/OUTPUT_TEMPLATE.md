## 10｜推荐方向

必须使用固定格式：

### Dominant Strategy
A / B / C 中只能选一个。

### Borrowed Mechanism
`NONE`，或只从另外一个策略借用 **一个有限机制**。

### Rejected for Recommendation
明确写出剩余第三个策略。

### Recommendation Compliance
- Positive Strategy Count：1 / 2
- 如为 3 → HARD FAIL，必须重写
- 被 Reject 的第三策略不得在后续 Keep / Next / Prompt 中重新正向出现
- Dominant / Borrowed 必须符合已选 Period Route
- 只允许使用 Selected DNA

## 14｜建筑初印象 Prompt
固定收尾：

`建筑初印象 Prompt｜复制到你的图像生成工具即可`

只允许使用：
- KNOWN 项目事实
- 已选 Period Route 的空间关系
- Dominant Strategy
- 一个可选 Borrowed Mechanism
- Selected DNA

不得使用：
- `Le Corbusier style`
- 代表作名称
- Rejected Strategy
- 未选 DNA
- 未选 Period Route
- 未经判断支持的白盒、架空柱、横向长窗、清水混凝土、屋顶形式等图像符号

该 Prompt 只用于概念初印象检验，不是最终效果图指令。


## Prompt Fact Lock
建筑初印象 Prompt 里的每一个具体材料 / 结构 / 立面 / 开口 / 屋顶描述都必须可追溯到：

- KNOWN
- Dominant Strategy
- 单一 Borrowed Mechanism
- Selected DNA
- 已验证的场地 / 气候 / 光条件

无法追溯的具体描述必须删除或泛化。

例：
- `old masonry` → `retained existing fabric`
- `deep reveals` → `openings calibrated for shade, glare and privacy`
