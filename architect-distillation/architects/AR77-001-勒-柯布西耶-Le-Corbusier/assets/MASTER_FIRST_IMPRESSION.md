# MASTER FIRST IMPRESSION｜Le Corbusier

## 小宙学长｜先认识一下勒·柯布西耶

第一次接触勒·柯布西耶，可以先抓住一个核心：真正值得借用的不是白盒、架空柱和横向长窗，而是他如何用结构释放平面，再用建筑漫游、剖面关系、气候界面和公共层次组织现代生活。早期偏向理性结构与自由平面，战后转向集体生活、气候深度与材料，晚期又允许光、声、地平线带来有限的诗性偏差。接下来先判断你的项目该进入哪条时期路线，再把方法放进项目，不复制作品。

**三个关键词**：结构释放｜建筑漫游｜理性秩序 + 诗性偏差

**不要误读成**：白盒 + 架空柱 + 横向长窗 + 清水混凝土的形式套餐。
