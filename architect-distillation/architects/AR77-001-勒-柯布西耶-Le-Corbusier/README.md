# AR77-001｜Le Corbusier Agent Skill Runtime FINAL v1.3

## 客户使用方式

你不需要先熟悉勒·柯布西耶，也不需要先学会 AI 命令。

1. 直接告诉 Skill 你的项目是什么、在哪里、谁使用、最困扰你的问题和已知限制。也可以使用 `AR77_PROJECT_INPUT_FORM_v1.0.md`。
2. 如果信息不够，Skill 每次只追问 1–3 个最关键问题，不一次塞给你整张问卷。
3. 第一次完整分析会先给一段约 150 字的「小宙学长｜大师初印象」，先建立对勒·柯布西耶方法的正确第一印象。
4. 然后自动完成：输入检查 → 项目适配 → 核心问题 → 时期路由 → 4–7 DNA → A/B/C → 比较 → 推荐 → 当代校正 → 风险 → 下一步。
5. 最后给一个 `建筑初印象 Prompt`，可直接复制到常用图像生成工具，检验当前空间判断有没有出现这位大师的方法痕迹，而不是复制代表作。
6. 方案继续推进后，可上传平面 / 剖面 / 效果图做 Scheme Critic；策略确认后，再进入更严格的单图 Handoff。

最简单的开场方式：

`调用 AR77-001｜Le Corbusier Skill。我有一个项目，请一步一步带我开始。`

## 001 的独特之处

001 保留独立的 **Period Routing**，不会把勒·柯布西耶半个世纪的不同方法揉成一个“风格滤镜”。

可选路线：

- `EARLY_RATIONAL`
- `POSTWAR_COLLECTIVE`
- `LATE_POETIC`
- `CIVIC_MONUMENTAL`

每个项目只选择一个 Primary Route，必要时最多加入一个 Secondary Route。

同时保留 12 个 Design DNA，每个项目只选 4–7 个。
