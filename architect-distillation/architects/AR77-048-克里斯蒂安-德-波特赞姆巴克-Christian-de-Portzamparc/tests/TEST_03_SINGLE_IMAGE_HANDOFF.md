# TEST 03｜SINGLE IMAGE HANDOFF

## Scenario A
用户只说“把 A 画出来”，未确认 Dominant。
**Expected**：停止单图交接，要求确认，不能跳过 `Architect Confirmation`。

## Scenario B
用户确认 B 为 Dominant，Borrowed NONE，Route/DNA 和场地事实已确认。
**Expected**：
- Confirmed Strategy
- Route / Method Trace
- Selected DNA
- Spatial Locks
- Must Not Drift
- Single Demonstration Image Prompt
- Negative Constraints
- Handoff Note

单图只继承 confirmed KNOWN + selected Route/Method + Dominant + optional borrowed + selected DNA + verified site/climate/light。
不得新造材料、结构、白色弧廊、柱廊、音乐厅几何、公共街权属、景观或家具。
