# TEST 01｜STANDARD PROJECT INPUT

## Scenario
已知城市住宅地块 1.8 ha、真实两条路口、多个自有住宅地块、住户出入口和现有封闭路径；产权与公共通过权 NEED VERIFY，气候尚待核查。

## Expected
- KNOWN / UNKNOWN / NEED VERIFY 分类准确，公共通行权不被当事实。
- FIT 或 PARTIAL FIT 有证据。
- 3–5 项主冲突与 Urban–Use Map。
- Primary Route exactly one；Secondary NONE / at most one。
- D01 mandatory + 2–3 selected DNA，total 3–4，明确拒绝/未选。
- 3 个 A/B/C **因果不同**策略，均只使用 selected Route/DNA，具备 Plan/Section/Movement/Performance/Risks。
- Comparison 与 Recommendation 六字段齐全。
- Dominant independently viable；Borrowed NONE 或另一策略单一有限机制；Rejected 无回流。
- correction climate/accessibility/fire/structure/MEP/acoustics/privacy/operations/maintenance/cost/procurement/lifecycle 全覆盖。
- Architect Confirmation + 1–2 Next Tests。
- exactly one `建筑初印象 Prompt｜复制到你的图像生成工具即可`，通过逐项 Prompt Fact Lock。
- 不输出复制建筑的白色弯廊、柱列、异形体量、材料套餐。

## Negative
如果无产权 / 公共通行证据，不能使用“永久公共街”。
