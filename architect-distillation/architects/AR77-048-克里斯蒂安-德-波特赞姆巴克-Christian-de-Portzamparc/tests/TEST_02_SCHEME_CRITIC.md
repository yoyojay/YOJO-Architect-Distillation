# TEST 02｜SCHEME CRITIC

## Scenario
用户提交一个错动、明亮、沿街开放的群楼渲染图，自称“开放街区”，但没有公共访问权、光照 / 风分析和住宅隐私处理。

## PASS
- 必须识别建筑形式不等于开放街区机制；
- 要求 urban access, public rights, day/night management, resident privacy, solar/wind study；
- 只用 selected Route/DNA 审查；
- 区分有现成图纸时的 KEEP / CORRECT / REJECT / Failure Return；
- 不能把 Hautes Formes 后来围栏的例证忽略；
- 不因漂亮渲染冻结体量；
- 不把 Georgia Benamo 或 Masséna 各团队的贡献归为单人；
- 不自动补历史作品几何。
