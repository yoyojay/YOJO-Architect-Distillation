# AR77-048｜BOUNDARIES + CONTEMPORARY CORRECTIONS
## Christian de Portzamparc

## PROJECT FIT

### FIT
- 真正存在多建筑之间的 void、密度、街道、采光、通达与邻里的冲突；
- 多地块城市更新需要既统一又容纳建筑差异的街区规则；
- 住宅共享空间需要在穿行、隐私、管理、日照之间进行判断；
- 音乐 / 文化 / 教育建筑存在功能自治与内部公共路径的矛盾；
- 公共地标需要与城市集体生活、入口和集散建立关系。

### PARTIAL FIT
- 主要问题部分包含城市界面 / 路径或节目分层，但项目必须由特殊医疗、极端保密、重工业、基础设施、安全关键工艺或高度限定产权法规主导；此 Method 仅作空间关系补充。

### NOT FIT
- 只要求“Portzamparc style”、错动立方体、弧形屋顶、异形塔楼、白色立面 / 玻璃 / 色块；
- 在无真实场地、用户、密度、通达数据时要求给出完整开放街区布局；
- 要求复制 Hautes Formes / Masséna / Cité de la Musique / Philharmonie Luxembourg / Cidade das Artes 的体量、柱列、布局或材料。

## CONTEMPORARY CORRECTIONS｜每项标 PASS / RISK / NEED VERIFY / N/A

### Climate
开放街区、庭园、退距、建筑间隙、全方位采光需按真实太阳角、冬夏热舒适、风廊、冷负荷、雨水和遮阴测试。不能把“多面受光”当作能源合格证据。

### Accessibility
公共穿行、户外小广场、垂直/水平内部街与 foyer 都需有连续的通用无障碍入口、等效路径、清晰导向和夜间安全。

### Fire / Life Safety
街区穿行 / 建筑间距 / 防火分区、音乐厅观众容量、演出后台分离、多层 foyer、疏散与消防通道必须进行专业代码校核。

### Structure
错动体量、连桥、场馆大跨、悬置形体、自由开口不得从历史案例推定结构系统；要明确承重、侧向力、施工和场地容量。

### MEP
独立功能单元、大跨音乐厅、室外过滤阈值、不同声学/热工需求、多个体量间的设施连接必须保证设备区划、检修、排烟、通风与设备寿命。

### Acoustics
乐厅、排练室、音乐学校必须由声学顾问验证声隔离、混响、背景噪声、观众体验和设施运行；不能以形态 / 阳台位置替代技术性能。

### Privacy
住宅的多面开口、街道开放、公共通廊、教育活动可见性都必须核查住户与研究参与者的视觉 / 声音隐私、个人安全和门禁需求。

### Operations
开放街区、共有庭园、内部公共廊、文化活动场所必须有权属、管理人、夜间模式、活动排期、清洁及公共使用规则。

### Maintenance
多建筑界面、外部细碎空隙、屋顶、遮阳、柱列、过滤层、屋面排水、户外绿化和声学构件需有可检修 / 更换方案。

### Cost
空间变化、街区退距、穿越公共空间、多厅独立系统和复杂幕墙需证实带来大于全生命周期成本的真实使用价值；优先精简非必要形态复杂性。

### Procurement
特殊结构、定制玻璃、遮阳、声学系统、桥梁、立面构件均应检查当地供应、技能、容差和可替代性。

### Lifecycle
建筑热工升级、夏季舒适、街区公共使用权、可改造性、能耗、碳、绿地管理、水耗和长周期材料/设施替换都必须纳入。

## ARCHITECT-SPECIFIC CORRECTIONS

1. **Open block ≠ public access guarantee**。Hautes Formes 官方档案指出后期通行出现围栏；开放须由实际管理 / 法律保证。
2. **Open street ≠ every plot must separate every volume**。城市密度、消防、微气候、隐私与沿街联系决定是否采用间距。
3. **Void ≠ automatically useful**。没有活动、产权、步行路径或生态价值的留白必须接受反证。
4. **Different heights ≠ automatically better daylight**。必须太阳 / 遮挡 / 眩光 / 热舒适验证。
5. **Program village ≠ exotic formal puzzle**。功能分化需要室内声学 / 服务 / 运营证据。
6. **Music foyer ≠ monumental row of white columns**。空间过滤可以在不同尺度 / 材料中实现，历史 827 柱列不是当代项目事实。
7. **Public art ≠ unchecked artistic freedom**。Portzamparc 自己在 1994 speech 强调建筑师的公共责任。
8. **High density ≠ planned social success**。居住舒适、物业、人群接受度与治理需要回访，不以效果图替代。
9. **Attribution boundary**：Hautes Formes 在 Georgia Benamo 协作下完成；Masséna 城市规则由 Christian de Portzamparc 统筹但各单体有多建筑师；Cité de la Musique 西翼室内设计由 Elizabeth de Portzamparc 担任，音乐厅声学 / 执行 / 工程有独立顾问；2Portzamparc 为多合伙人团队。
