# AR77-048｜PROJECT-PROBLEM ROUTES
## Christian de Portzamparc｜证据有界的问题路由

这 5 条是 **AR77 project-problem abstractions**，不是 Portzamparc 本人命名的五个时期或作品类型。
Route 必须由本项目 KNOWN 冲突触发；未选 Route 无法经由策略、推荐或 Prompt 回流。

## R1｜OPEN_BLOCK_URBAN_RULES｜开放街区的可变规则
**Trigger**：真实的街区 / 多地块更新中，密度、混合功能、日照与多建筑师差异需要共同治理；街区道路 / 庭园使用权可实施。
**核心问题**：如何让多主体、多建筑、不同高度与项目阶段保持城市街道连续性和受控开放。
**Method**：existing streets + ownership survey → density / solar / public access matrix → setbacks/spacing/permeability as contingent rules → allow architectural diversity → test phasing/maintenance/management。
**主要 DNA 候选**：D01 / D02 / D03 / D04 / D06。
**适用边界**：中高密街区更新、多地块住房、城市混合功能规划。
**风险**：街区缝隙太小产生风道 / 私密性恶化；通行权不稳定；“开放”日后围栏化；密度目标受损；把自由外形当规则。
**与其他 Route 的差异**：城市尺度、多建筑师与规则治理是主因，不是单栋住宅开一条缝。
**证据**：2Portzamparc Quartier Masséna；2012 SEMAPA *L'îlot ouvert*；Hautes Formes 源流。

## R2｜HOUSING_VOID_AND_STREET｜密集住宅的内部街与共享空隙
**Trigger**：既有高密居住用地存在尽端、切断街道、日照 / 视线 / 户外活动矛盾，必须使 housing 可达且仍保护住户安全。
**核心问题**：如何把住宅之间的 void 变成有权属、有通达、有居民利益的公共 / 共享空间。
**Method**：housing user map + site dead ends → street / square / access alternative → separate shared-private territories → daylight/views → resident-management/security and wind tests。
**主要 DNA 候选**：D01 / D02 / D05 / D06 / D09。
**适用边界**：城市社会住宅、住宅更新、狭窄复合用地。
**风险**：开放街变成私有封闭死路；未验证的公共活动；住户噪声 / 隐私与夜间安全；空地缺乏维护。
**与其他 Route 的差异**：住宅尺度、生活权利和公共通达是主因，不是完整街区规则套用。
**证据**：Hautes Formes + 文化部档案中后来围栏事实。

## R3｜PROGRAM_AS_URBAN_QUARTER｜复合机构像街区一样组织
**Trigger**：文化、教育或复合机构有多种自治功能、人员、后台 / 前台和共享节点。
**核心问题**：不同程序如何拥有独立场所，又由清楚的公共路径组织成整体。
**Method**：program-autonomy matrix → user/service networks → shared vertical/horizontal street → exchange nodes + alternate routes → acoustic/privacy/fire/MEP tests。
**主要 DNA 候选**：D01 / D05 / D07 / D08 / D09。
**适用边界**：高校、文化综合体、教育 / 研究机构、部分公共服务设施。
**风险**：形式复杂削弱导向；公众与后台交叉；长距离 / 混响 / 疏散失败；误把所有功能暴露给公众。
**与其他 Route 的差异**：功能单元自治与共享交互为主，不是城市住宅的地块开放。
**证据**：Cité de la Musique 西翼、东翼官方项目。

## R4｜PERFORMANCE_FOYER_AUDIENCE｜音乐演出与观众过渡
**Trigger**：真实音乐 / 演出项目需处理从街道到声学大厅的过渡、观众分流、观演接近性与多层 foyer。
**核心问题**：如何通过可读的分层阈值连接城市体验与声学隔离的演出空间。
**Method**：audience/service flows + acoustic envelope requirements → public arrival/filter/foyer → seating/visibility/egress → section of shared areas → acoustic/MEP/fire and crowd tests。
**主要 DNA 候选**：D01 / D05 / D07 / D08 / D09。
**适用边界**：音乐厅、剧院、专业表演与具有强声学分区的文化设施。
**风险**：象征性柱廊 / 阳台被照搬；过热眩光、声学薄弱、入口拥堵；舞台机械与维护困难。
**与其他 Route 的差异**：观众—演出体验与声学/疏散是主因；不把大厅当普通中庭。
**证据**：Philharmonie Luxembourg；Cité de la Musique，声学顾问独立贡献。

## R5｜CIVIC_REFERENCE_AND_PUBLIC_GROUND｜城市地标与公共场所
**Trigger**：公共设施 / 重要节点需识别性，但公共可达、周边生活与微气候更关键。
**核心问题**：如何让城市标志成为可以进入、停留、穿行的公共场所，而非孤立雕塑。
**Method**：city movement + user activities → view / recognition and entrance tests → grounded public threshold / street access → program/urban-fit tests → climate/structure/cost/civic governance。
**主要 DNA 候选**：D01 / D02 / D05 / D08。
**适用边界**：文化枢纽、公共场馆、地标性机构 / 城市节点。
**风险**：iconic object 抢走 street life；高维护异形壳；缺少公共开放承诺；无障碍 / 消防 / 集散不足。
**与其他 Route 的差异**：可被公众识别并实际使用的城市节点是主因，不是音乐建筑特定功能。
**证据**：Portzamparc 官方项目与个人关于建筑作为城市符号 / 公共艺术的说明。

## ROUTE SELECTION｜操作硬规则
1. 先写项目的 KNOWN 主冲突，不先选“开放街区”或“地标”。
2. 输出 Primary exactly 1；Secondary = NONE / max 1；说明为什么其他 Route 未选。
3. R1 需要 **街区级规划/多地块**与治理数据；单栋不自动使用。
4. R2 需要真实 residential users, permeability/privacy contradiction；空地不能凭空宣称公共。
5. R3 需要多自治功能与 shared route；没有多功能则不画“功能村落”。
6. R4 需要 performance / acoustic / crowd requirements；声学壳由专业顾问验证。
7. R5 需要具体公共可识别性 / 场所矛盾；只想“雕塑性”不得触发。
8. Secondary 必须补充**另一种已证实的次级问题**，不能把第二条当新形式来源。
9. Selected Route 必须实际输出 Trigger / Problem / Method / Main DNA / Boundary / Risk / Difference / Project Test。
10. 未选 Route 不能通过 Recommendation、Prompt、Handoff 或“细节优化”回流。重选则重算 Strategy。
