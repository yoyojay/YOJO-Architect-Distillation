- `SUPPORTED INTERPRETATION`：多个证据指向的可迁移机制，明确标作 AR77 转译。

## KNOWN｜一手与官方证据

1. **1994 Pritzker Acceptance Speech**：Portzamparc 说建筑是 public art，建筑被人日常经历，建筑师因此要对用户与公众负责。他明确把建筑理解为创造内外场所，而不仅是制造漂亮物体；把城市看作需要赋予节奏、转化并被使用的 collective interior。
2. **1994 Pritzker Biography**：他明确说建筑之间的 void 可与对象同样重要，建筑不应被孤立看待；同时必须响应使用者与客户。访谈与社会研究使他把小街区的成功理解为具体社会责任。
3. **Hautes Formes 1975–79｜官方事务所与法国文化部资料**：在原设想大型塔楼的地块，通过通行街道、小广场、多个相异住宅体量和不同高度，将城市道路与住宅尺度重新接合，获得接近和远眺视线、日照与公共活动潜力。官方资料保留 Georgia Benamo 的协作署名。文化部也记录后来穿行路径出现围栏；物理空隙≠永久公共可达。
4. **Quartier Masséna 1995–2012｜2Portzamparc**：以“îlot ouvert / rue ouverte”实现开放街区。它不是固定总图，而是约束体量、街道、地块、庭园并允许多名建筑师变化的 rules of the game：建筑彼此间隔，沿街形成不同尺度空隙，改善多朝向光照与街—内区关系。Masséna 的各单体由数十个不同团队设计，Portzamparc 是 urbaniste / urban-rule architect。
5. **Cité de la Musique 西翼 1984–90｜2Portzamparc**：不同音乐教学 / 排练活动具有自治“家园”，以水平与竖向街道连成有相遇机会的学习网络；不能解释为强制所有活动通透。资料注明 Elizabeth de Portzamparc 的室内设计贡献、团队与声学顾问。
6. **Cité de la Musique 东翼 1984–95｜2Portzamparc**：不同公开演出、博物馆、教育与工作功能形成“urban quartier”的组合，经环绕音乐厅的公共回游串接；建筑形态多样是项目节目关系的后果，不是泛用拼贴手法。
7. **Philharmonie Luxembourg 1997–2005｜2Portzamparc**：由室外城市进入音乐事件，围绕主厅的光过滤与 foyer 形成渐进阈值，观众席与台口的关系由多层组织；声学 / 机电 / 结构 / 本地设计顾问单独署名。历史柱线数量不能移植。
8. **2026 Hautes Formes 整修｜官方事务所**：因当代夏季热舒适、保温、遮阳、场地气候需要继续改造，说明原开放空间与光照机制并不自动满足当代能源、热舒适要求。
9. **2Portzamparc 官方机构介绍**：Elizabeth de Portzamparc 与 Christian de Portzamparc 是事务所共同创始人；2024 年起更多合伙人加入。对不同项目必须依据具体署名确定 attribution，不能把后期团队全部说成个人独作。

## SUPPORTED INTERPRETATION｜AR77 因果核，不是本人标准化口诀

`KNOWN site / users / existing urban grain / program / operations`
→ `先判断建筑与城市作为集体空间如何共同工作`
→ `定位街、地块、体量之间的空隙与路径断裂`
→ `确认公共/半公共/私密的边界、真正的 access rights`
→ `如果是街区级项目，建立允许差异但保持街道连续的开放规则`
→ `如果是多功能 / 音乐项目，组织自治功能单元与可读的共同路径`
→ `以实际日光/风/声/社会活动/管理检验空间关系`
→ `最后才讨论体量 / 立面 / 材料 / 视觉性格`

## Core Judgements

### J1｜CITY / BUILDING AS COLLECTIVE INTERIOR
建筑的价值不止对象本身；要看它对城市如何提供外部与内部可使用的场所。

### J2｜VOID IS ACTIVE URBAN FABRIC
空隙有边界、路径、日光、停留和公共权利，必须正面设计而不是当建筑残余空间。

### J3｜DENSITY NEEDS DIFFERENCE + COHERENCE
高密度可容纳不同高度、功能和建筑身份；依靠街道 / 阈值 / 规则提供可读整体，不能混成随机形体。

### J4｜OPEN BLOCK IS A CONTINGENT URBAN RULE
开放街区是一种在适当城市密度、分地块条件下工作的关系规则，不是所有项目必须留建筑间缝或种花园。

### J5｜MOVEMENT CREATES SHARED SOCIAL SPACE
公共路径、垂直 / 水平连接与可停留节点应使功能单元相遇；必须校核拥挤、隐私、服务与疏散。

### J6｜PROGRAM DIFFERENTIATION PRECEDES FORMAL VARIETY
不同活动的空间要求是真实形态差异的来源；每个单元必须在平、剖、路径中有清楚职责。

### J7｜LIGHT + FILTER AS SPATIAL PERFORMANCE
日光、过滤与感官转换可形成空间体验，但具体构件及采光路径受真实气候 / 音乐声学与维护约束。

### J8｜PUBLIC ART HAS PUBLIC ACCOUNTABILITY
标志性或雕塑性效果不得凌驾日常使用、邻里、通达、运营、产权和维护现实。

### J9｜TEAM / AUTHORSHIP TRACE
城市设计、多建筑师建造、室内、声学与工程分工需保留真实贡献；禁止神话化单人作者。

## EXECUTION｜每次完整分析

1. 锁定项目 `KNOWN / UNKNOWN / NEED VERIFY`，不推断场地材料或固定形体。
2. 建立 urban/usage map：street, address, entrances, publicly accessible network, volumes, density, daylight, neighbors。
3. 列 3–5 对 Project Conflicts，优先找 density↔light、public link↔security、variety↔readability、autonomous program↔common social life。
4. 判断是否真正适合此 Method；不满足返回 PARTIAL / NOT FIT。
5. 选 `Primary Route exactly 1`，Secondary = NONE / max 1。
6. `D01 mandatory`，再选 2–3 个必要 DNA，总选 3–4；无触发则不硬凑并问 1–3 问。
7. A/B/C 在已选 Route/DNA 中产生三种不同的主因果，不得从未选 DNA 偷借功能。
8. 完成 comparison、一个独立 Dominant、最多 one borrowed mechanism、拒绝项明确。
9. 做全项 Corrections / Critic / Architect Confirmation，给下一步 1–2 drawings/tests。
10. Prompt Close 执行材料、结构、立面、几何、屋顶、开口、技术、景观、家具逐项 Fact Lock，禁止名作与风格提示。
