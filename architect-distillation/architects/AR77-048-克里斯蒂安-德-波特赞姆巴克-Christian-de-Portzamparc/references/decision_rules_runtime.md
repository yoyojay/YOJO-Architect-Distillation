# AR77-048｜DECISION RULES
## Christian de Portzamparc｜When → Prefer → Because → Verify → If failed

本规则用来改变执行动作，不是理论格言。以 **项目实证**而非历史造型触发。

1. **Fact Lock**：当用户只给“巴黎式开放街区”而无街道 / 地块数据 → 优先标 UNKNOWN / NEED VERIFY → 因为形象不是场地事实 → 通过调查图 / 红线 / 法定通行权查证 → 失败则不确定形体。
2. **Fit**：当只有“雕塑性造型 / 明亮体量”需求 → 优先 NOT FIT 或 PARTIAL FIT → 因为判断核心是建筑—城市—人关系 → 通过 public ground / program conflicts 验证 → 失败不生成风格。
3. **Route**：当真实多地块开发需要一致开放规则 → 优先 R1 + D03（仅入选时）→ 因为需要变体和城市连续 → 通过 buildable envelope + street/permeability rule matrix → 失败则退回 R2 或城市规划重做。
4. **Housing**：当居住地块的尽端 / 空隙与公共性冲突 → 优先 R2 + D02/D05（实际择选）→ 因为穿行和街区生活应有明确管理 → 通过住户、产权、日夜使用评估 → 失败则不承诺无条件开放。
5. **Program**：当自治学科 / 文化单元需要共同使用 → 优先 R3 + D07/D08 → 因为内部街区来自功能分工 → 通过 program/flow/backstage matrix → 失败则改写连接而不是拼体块。
6. **Auditorium**：当演出观众需过滤外界与声学厅 → 优先 R4 + D09 → 因为 foyer 是过渡而非默认柱廊 → 通过 acoustic / crowd / fire / MEP → 失败则简化过渡、保留高性能声学边界。
7. **Landmark**：当公共设施需要远近认知 → 优先 R5 + D01/D05 → 因为标志必须承担 civic life → 通过 accessible public ground + program/wayfinding tests → 失败则撤掉标志性形体。
8. **Void**：当建筑之间留空却无用途 → 优先 D02 → 因为 void 需要 positive program or climate/social value → 通过 sun / wind / rights / use study → 失败则缩减/重分配空地。
9. **Light**：当高低变化被说成增加采光 → 优先 D06，仅有 orientation data 才进入事实 → 因为不同高度不保证日照 → 通过冬夏日照与隐私图 → 失败则调体量而非保留造型。
10. **Diversity**：当多建筑被赋予随机外形 → 优先 D04 → 因为差异必须与街道整体共存 → 通过街道剖面 / 导向和人眼视点检验 → 失败则降低多样性强度。
11. **A/B/C**：当三案只是体块折线、屋顶、色彩变化 → 优先从选中 DNA 中重做不同因果 → 因为差异必须在 site/plan/section/movement/performance 中体现 → 通过 causal table 验证 → 失败 Strategy FAIL。
12. **Recommendation**：当想混合 A+B+C → 只允许一个 Dominant + 最多借另一策略一个局部机制 → 因为主体要独立可实施 → 通过 gene-trace + rejected/unselected exclusions → 失败 Recommendation FAIL。
13. **Contemporary Correction**：当开放路径合法性 / 夜间封闭风险不清楚 → 优先项目治理与公众参与 → 因为空间开放不可替代法律 / 物业 → 通过 access agreements / management plan → 失败则标 NEED VERIFY 并不承诺永久公共街。
14. **Scheme Critic**：当 rendering 很有空间变化但计划无法走通 → 优先退回 plan-section-ground route trace → 因为建筑空间在使用中成立 → 通过 accessible path / shadow / fire / use tests → 失败则重路由。
15. **Anti-Copy**：当出现白色弧线、三角场馆、数百柱列、悬空大板或异形塔尖 → 删除无因果要素 → 因为名作形态不代表方法 → 通过 selected DNA / current function trace → 失败则不保留。
16. **Prompt Fact Lock**：当 Prompt 出现材料、结构、立面、几何、屋顶、开口、柱网、桁架、幕墙、园林或家具 → 必须逐项追溯 KNOWN / selected Route / Dominant / max one Borrowed / Selected DNA / verified site-climate-light → 无法追溯即删除或关系化。
17. **Authorship**：当把 Hautes Formes 全说成独作、Masséna 单体都算本人、Cité 的室内和音乐厅声学称其个人创新 → 优先核对 Georgia Benamo / Masséna 多团队 / Elizabeth de Portzamparc / acousticians → 因为协作证据明确 → 未校正则 Attribution FAIL。
18. **Failure Return**：任何 required Runtime / Strategy / Prompt gate 失效 → STOP → 定位 Fact/Route/DNA/Strategy/Prompt → FIX CANDIDATE → RE-AUDIT；不能用效果图给无证据机制背书。
