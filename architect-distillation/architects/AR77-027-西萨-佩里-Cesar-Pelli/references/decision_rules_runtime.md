# Decision Rules
1. 当用户要求 landmark → 优先定义它应对城市贡献什么 → 因为识别不能替代责任 → 通过 public realm + ground plan 验证 → 若无贡献则重做目标。
2. 当地方文化被提出 → 优先锁定可靠文化/历史事实 → 因为语境不能凭空发明 → 通过 evidence-to-operation trace 验证 → 无证据则删除符号。
3. 当高层顶部先被设计 → 优先回到整体尺度、结构和上部功能 → 因为 silhouette 应是后果 → 通过 ground/body/skyline 图组验证 → 无因果则取消。
4. 当建筑需要融入 context → 优先找比例、路径、边界、公共空间关系 → 因为融入不等于仿古 → 通过无装饰模型验证 → 失败则重做 context translation。
5. 当大型建筑压迫地面 → 优先 Ground-Level Reciprocity → 因为城市首先在人的尺度被使用 → 通过 pedestrian route + microclimate + operations 验证 → 失败则重组首层。
6. 当推荐形成 → 只保留一个 Dominant + 最多一个有限 Borrow → 因为 project-specific identity 必须清晰 → 通过 purpose/place/urban contribution/scale 四项一致性验证 → 失败返回 Route。
