# Design DNA Runtime
默认选择 3–5 个必要 DNA；未选不得回流。

## D1｜Purpose-and-Place Reading
判断: 设计从项目用途与具体地点共同出发。
Trigger: context/identity 冲突。
Operation: 建 purpose-place matrix。
边界: 只用可验证语境。
Failure: 地域符号拼贴。
痕迹: 每个主要语境动作可追溯到项目事实。

## D2｜Urban Citizenship
判断: 建筑应对城市/社区产生明确正向空间贡献。
Trigger: 大型/公共/高层项目。
Operation: 定义 ground interface、public route、usable edge。
边界: 不把私有景观自动称公共。
Failure: icon 取代城市价值。
痕迹: figure-ground 和运营图能指出贡献。

## D3｜Multi-scale Calibration
判断: 同一建筑在步行、街区、城市远景尺度都需成立。
Trigger: 高层/大型体量。
Operation: 分别测试 ground/body/skyline 与视距。
边界: 不预设塔冠。
Failure: 只优化渲染远景。
痕迹: 多尺度图组有一致逻辑。

## D4｜Context without Imitation
判断: 语境通过比例、空间、界面或秩序转译，不复制图像。
Trigger: 历史/文化敏感场地。
Operation: evidence → relation → architectural operation。
边界: 文化事实未知则不使用。
Failure: motif skin。
痕迹: 删除符号后语境关系仍成立。

## D5｜Ground-Level Reciprocity
判断: 大建筑必须在接地处与城市发生真实交换。
Trigger: 高层/综合体/公共项目。
Operation: 入口、穿越、停留、边界、活动与后勤共同校正。
边界: 安保/运营必须真实。
Failure: 巨大 lobby 或 plaza 只供观看。
痕迹: ground plan 可验证公共路径与活动。

## D6｜Silhouette as Consequence
判断: 轮廓来自体量、结构、功能和城市尺度关系，而非先画标志。
Trigger: skyline significance。
Operation: 从 massing/structure/upper program 推导 termination。
边界: crown/spire 不是默认。
Failure: logo building。
痕迹: 顶部变化有平剖/结构理由。

## D7｜Project-Specific Identity
判断: 每个项目形成自己的身份，不套事务所模板。
Trigger: 客户要求 landmark/identity。
Operation: 从 purpose/place/urban role 生成有限识别机制。
边界: 识别不等于奇形。
Failure: 重复已知 Pelli 图像。
痕迹: identity 可用项目事实解释。

## D8｜Ensemble over Object
判断: 多建筑/大项目先检查整体场所，再优化单体。
Trigger: campus/mixed-use complex。
Operation: figure-ground、公共路径、视线、入口层级。
边界: 单体功能仍需独立成立。
Failure: 多个 icon 竞争。
痕迹: 去掉立面细节后群体秩序仍清晰。
