# Problem Routes
## R1｜URBAN_CITIZENSHIP
Trigger: 项目对街区、公共空间、城市连续性有显著影响。
核心问题: 建筑如何在满足自身开发/功能目标同时给城市返还价值。
Method: urban reading → public contribution → ground interface → building identity → operations.
主要 DNA: D1 D2 D5.
边界: 公共性必须是真实可使用/可达关系。
风险: “城市贡献”只剩景观包装。
差异: 从建筑对城市的责任起步。

## R2｜MULTISCALE_TALL_BUILDING
Trigger: 高层/大型建筑在近、中、远尺度上同时被感知。
核心问题: 如何协调人的地面体验、建筑整体尺度与天际线身份。
Method: ground → middle/body → skyline → approach/view → structural/envelope correction.
主要 DNA: D2 D3 D6.
边界: 不预设 crown/spire。
风险: 只为远景设计。
差异: 从多尺度观看与高度起步。

## R3｜CONTEXTUAL_IDENTITY
Trigger: 地方文化、历史或城市语境重要，但项目又需要独立身份。
核心问题: 如何回应 context 而不复制历史或符号。
Method: evidence → abstract relation → spatial/proportional/interface translation → anti-symbol check.
主要 DNA: D1 D4 D7.
边界: 文化线索必须 KNOWN。
风险: 文化图案贴皮。
差异: 从 belonging 与 identity 张力起步。

## R4｜PUBLIC_REALM_CAMPUS
Trigger: 多栋/大型综合体、文化商业园区、公共广场与开放空间共同构成项目。
核心问题: 建筑群如何通过空地、路径、入口和集会空间形成城市场所。
Method: figure-ground → public circuit → building placement → thresholds → program activation.
主要 DNA: D2 D5 D8.
边界: 不默认 plaza/sky garden。
风险: 剩余空地被命名为公共空间。
差异: 从群体与公共场所系统起步。
