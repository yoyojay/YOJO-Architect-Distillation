# AR77-049｜PROJECT-PROBLEM ROUTES
## Rafael Moneo

这些是 AR77 对 Moneo 一手项目资料建立的**证据约束项目问题路由**，不是建筑师本人发表的 Route 名称或历史时期。六条路由不是永远都要选；依据真实冲突，Primary exactly 1，Secondary 最多 1。

## R1｜HISTORIC_URBAN_DIALOGUE｜历史城市的具体性协商
**Trigger**：历史广场、传统街区、重要建筑相邻，且新建会改变现有街道边界 / 公共空间。

**核心问题**：尊重场所与新用途之间如何建立具体关系，而不是古典外观模仿。

**Method**：测绘真实城市边界、视线、比例与可达关系 → 区分必须保持/可以改变 → 建立入口、体量、城市地面的关系 → 反证 / 审查。

**主要 DNA（候选，仍需选择）**：D01 / D03 / D05 / D09

**Evidence Trace**：Murcia City Hall，事务所官方项目说明。

**适用边界**：历史广场、市政机构、街区插入；仅有真实历史形态和公共场地事实时成立。

**风险 / Failure Mode**：历史装饰复制、任意显眼地标、破坏视线 / 遮阳、公众路径受阻。

**与其他 Route 差异**：由历史建成环境的具体城市协商驱动，区别于纯遗址保护 R2。

## R2｜HERITAGE_PROGRAM_RESTRUCTURE｜遗产中的新功能重组
**Trigger**：遗址、保存建筑、博物馆或公共机构需在保护中增加功能，并解决原建筑承压过重。

**核心问题**：如何让历史结构被看见 / 被使用，同时把新功能安排进今天的空间与运营。

**Method**：遗产价值分级 → 活动 / 服务负荷 → 保留与干预边界 → 新旧路线 / 展厅组织 → 结构 / 文保 / MEP / 运营验证。

**主要 DNA（候选，仍需选择）**：D01 / D02 / D03 / D06 / D07

**Evidence Trace**：National Museum of Roman Art；Prado Museum Enlargement；Thyssen-Bornemisza Museum。

**适用边界**：受保护建筑、遗址、博物馆及研究机构；必须有可信遗产调查。

**风险 / Failure Mode**：假历史、遗址受损、保护与消防冲突、用展陈戏剧化替代保管与研究。

**与其他 Route 差异**：由 heritage asset + new institutional use 的共存驱动，不等于单纯历史街道。

## R3｜URBAN_FABRIC_CONTINUITY｜大型综合体的城市接续
**Trigger**：长体量 / 大地块 / 混合用途可能切断街道连续性、行人体验或社区界面。

**核心问题**：如何让项目作为城市一部分，而非一个封闭超级对象。

**Method**：street and edge map → pedestrian desire lines / program fronts → segment / align / pass-through only if justified → ground use + maintenance / access test。

**主要 DNA（候选，仍需选择）**：D01 / D05 / D07 / D09

**Evidence Trace**：L’Illa Diagonal（与 Manuel de Solà-Morales 共同设计）。

**适用边界**：混合用途、城市综合体、大型机构；必须有街道 / 所有权 / 公共通行数据。

**风险 / Failure Mode**：空的穿堂、消防与安防矛盾、物业不开放、体量分段只做立面伪装。

**与其他 Route 差异**：由 large-program mass vs city continuity 的冲突驱动。

## R4｜INFRASTRUCTURE_FLOW_ADAPTATION｜交通与机构系统的流线重组
**Trigger**：换乘 / 到发 / 人流 / 多标高 / 日后扩容造成既有系统冲突。

**核心问题**：怎样在城市与既有建筑之间建立清晰新路线，并为未来变化留空间。

**Method**：users / volume / arrivals-departures map → vertical segregation / transfer sequence → old-new interfaces → time-peak / evacuation / future-phase stress test。

**主要 DNA（候选，仍需选择）**：D01 / D06 / D07 / D10

**Evidence Trace**：Atocha Station Enlargement（部分阶段与 Peio Elcuaz 及团队合作）。

**适用边界**：交通、校园、复杂大型公共机构；需真实流量、运营和结构资料。

**风险 / Failure Mode**：导向混乱、距离过长、不可达、保留旧建筑但运营失效。

**与其他 Route 差异**：由动态程序和多期系统增长驱动，不以博物馆展示或立面关系为核心。

## R5｜GEOGRAPHIC_PUBLIC_IDENTITY｜地理边界中的公共建筑
**Trigger**：河口、海岸、山体边缘或特别地理位置对项目身份和公众抵达影响重大。

**核心问题**：什么时候建筑应延续街区，什么时候应对地理条件作有意义的独立回应。

**Method**：geo-site / horizon / urban axis → test continuity vs differentiation → room / public approach → wind / glare / salt / acoustics / structure test。

**主要 DNA（候选，仍需选择）**：D01 / D04 / D08

**Evidence Trace**：Kursaal Auditorium and Congress Center，事务所官方说明。

**适用边界**：地理边界显著的公共文化项目；必须有真实场地、气候和使用依据。

**风险 / Failure Mode**：复制双盒子、玻璃海岸符号、能耗与维护失败。

**与其他 Route 差异**：由 geographic setting vs conventional urban extension 的选择驱动。

## R6｜TYPOLOGICAL_REWORK_IN_EXISTING_FABRIC｜类型重构与既有建筑
**Trigger**：既有用途或历史类型需变为新的公共 / 机构程序，常规空间模型与真实用途冲突。

**核心问题**：怎样理解 type 的组织关系并改造它，而不是复制某种类型形象。

**Method**：type relation map → classify what survives and what changes → reorganize room / circulation / light / service → buildability / reversibility test。

**主要 DNA（候选，仍需选择）**：D01 / D02 / D03 / D06 / D07

**Evidence Trace**：《On Typology》、Thyssen-Bornemisza Museum。

**适用边界**：改造、再利用、功能转化；需有实测结构 / program / 历史依据。

**风险 / Failure Mode**：把类型变成古典原型、无法适应新用途、过度拆除。

**与其他 Route 差异**：由功能与空间类型转化驱动，区别于以保护价值为主的 R2。

## Route Selection Logic
1. 先锁定 3–5 个 project conflicts，再选择 Primary exactly 1；Secondary NONE / ≤1。
2. R1 的历史街道/广场是真正主矛盾才可选择；不可用“有古迹”自动触发。
3. R2 要有保护 / 考古 / 旧主体新程序的现实冲突；必须先请文保专业调查。
4. R3 要有可证明的城市界面 / 长体量 / 行人连续问题，公共路径还需业权及管理核实。
5. R4 要有真实流量、多层到发或扩容冲突，不能先画柱厅或圆筒天窗。
6. R5 要有强地理边界、公共性质与现场资料，不能仅因海边就复制玻璃双体。
7. R6 要有 type / old program / new program 的结构矛盾；类型是认知工具不是造型。
8. Secondary 必须解决与 Primary 不同的真实次级冲突；若不满足，设 NONE。
9. Selected Route 的 Trigger / Method / DNA / 适用边界 / 风险要在输出中展开。未选 Route 全程不得回流 A/B/C、推荐、Prompt、Handoff。
