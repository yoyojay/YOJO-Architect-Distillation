# AR77-049｜DNA RUNTIME
## Rafael Moneo｜Evidence-Bounded Design Judgement DNA

以下是 AR77 从《On Typology》、1996 普利兹克演讲及事务所项目文本提炼的可迁移机制，**不是建筑师本人命名、不是年代分期、也不是必选套餐**。

## DNA Selection Hard Lock
- D01 `SPECIFICITY_BEFORE_SIGNATURE`：所有完整项目 mandatory。
- 默认再选 2–3 项由项目实际冲突触发的 DNA，总共 **3–4**。
- 若事实不足以支持，先问最多 3 个关键问题；不得凑数。
- 未选 DNA 在 A/B/C / Recommendation / Keep / Next / Prompt / Handoff **不得回流**。
- 每个 Selected DNA 需至少一个可测试的平/剖/路径/城市/建造空间痕迹。

## D01｜SPECIFICITY_BEFORE_SIGNATURE｜具体性先于形式签名
**判断含义**：每个项目从真实场地、用途、气候、历史与建设条件出发；不是换皮复用同一方案。

**Trigger**：所有完整项目判断。

**Spatial Operation**：Project facts / conflicts ledger → 列出不可绕过的必要性 → 检验每项几何决策的事实链。

**适用边界**：全部项目；数据不足先 ASK / NEED VERIFY。

**Failure Mode**：“回应场地”停留在口号，提前决定砖拱或石材。

**可验证空间痕迹**：至少一条平剖或城市空间决策可回溯到 KNOWN 事实。

## D02｜TRANSFORMABLE_TYPE｜可转化的类型知识
**判断含义**：类型是理解空间组织共同结构的工具，不是平面模板或风格分类。

**Trigger**：真实的既有类型、改造或 program 组织问题。

**Spatial Operation**：比较 program relations / existing structure / patterns → 列变化与不变 → 转为新组织。

**适用边界**：改造、博物馆、机构、住宅、城市类型研究。

**Failure Mode**：直接临摹历史院落 / 廊道 / 基本平面。

**可验证空间痕迹**：type diagram 对照新功能后仍有明确理由的变化。

## D03｜HISTORY_PRESENT_NEGOTIATION｜历史与当代的协商
**判断含义**：把遗存和历史建筑看成持续作用的实体；同时承认当代生活有独立要求。

**Trigger**：真实遗产/历史环境，或与新功能发生保护冲突。

**Spatial Operation**：asset hierarchy → preservation / intervention zones → interface / program / structure test。

**适用边界**：遗产、古城、博物馆扩建；须文保数据。

**Failure Mode**：伪古董、过度修复、删除不可替代遗存。

**可验证空间痕迹**：保存与新增部分在图纸上可分清并可通过专业文保评估。

## D04｜BEAUTY_NECESSITY_CONSTRUCTION｜美与必要性经由建造检验
**判断含义**：形态的价值应经现实 program / technique / construction 验证，不是设计师任意姿态。

**Trigger**：几何、材料或结构方案存在“图上成立、建成难以实现”风险。

**Spatial Operation**：necessity ledger → construction options → lifecycle / procurement → form refinement。

**适用边界**：所有有结构、围护、维护重要性的项目。

**Failure Mode**：将“持久性”简化为厚重或指定石材。

**可验证空间痕迹**：剖面 / 节点 / cost / buildability 有可审查对应关系。

## D05｜URBAN_CONTINUITY_WITH_DIFFERENCE｜差异中的城市连续
**判断含义**：通过街道边界、对齐、穿行、公共地面连接城市，而非对每个项目复制街区表皮。

**Trigger**：项目影响城市边界、公共空间、行人路径。

**Spatial Operation**：read alignments / routes / scale → connect or strategically differentiate → verify public access。

**适用边界**：市政、综合体、交通、历史街道。

**Failure Mode**：空洞通道、私有广场冒充公共、任意历史复制。

**可验证空间痕迹**：街道—入口—公共空间连续路径与权属/运营可验证。

## D06｜PROGRAM_RELIEF_AND_REASSIGNMENT｜通过功能重分配释放空间
**判断含义**：把新旧建筑的功能 / 服务 / 人流负荷重新分配，改善核心空间而不仅加面积。

**Trigger**：建筑扩建、用途转化、多重机构或新旧负担不均。

**Spatial Operation**：program load → relocation matrix → front/back-of-house → circulation / services / access。

**适用边界**：大型机构、博物馆、交通站、改造。

**Failure Mode**：展厅漂亮但保管 / MEP / 疏散失败。

**可验证空间痕迹**：功能矩阵、新旧面积 / 活动 / 服务图均可核对。

## D07｜SECTION_MOVEMENT_LOGIC｜剖面与行走组织
**判断含义**：建筑通过入口、层次、路线与房间序列建立可感知秩序。

**Trigger**：到达 / 离开、跨层、展览回游或人流分离是冲突。

**Spatial Operation**：user journeys → plan/section transitions → accessibility / fire / peak testing。

**适用边界**：交通、大型公共、博物馆、学校。

**Failure Mode**：复杂动线、过多叙事折返、实际人流被阻。

**可验证空间痕迹**：跨层路线 / 用户停留 / 视线和疏散可在剖面验证。

## D08｜GEOGRAPHY_AS_DECISION_EVIDENCE｜地理条件形成设计判断
**判断含义**：将地形、河口、气候、地平线等当作真实选择条件，有时应与街区网格保持差异。

**Trigger**：地理格局确实影响建筑入口、体量或公众身份。

**Spatial Operation**：site geography map → options: urban continuity vs geography differentiation → climate test。

**适用边界**：强地理边界公共项目。

**Failure Mode**：海边 = 玻璃双盒子的粗暴类比。

**可验证空间痕迹**：各选项能具体说明视线、风、城市边界与使用差异。

## D09｜CONTEXTUAL_FACADE_RELATIONS｜立面作为城市关系结果
**判断含义**：开口、尺度、对齐与节奏应回应真实场地，而不是用历史立面纹样包装。

**Trigger**：建筑面对重要广场、线性街或邻接建筑。

**Spatial Operation**：human eye / urban view map → edge rhythm + daylight / program / envelope test。

**适用边界**：城市公共界面、历史街道、街区更新。

**Failure Mode**：复制 Murcia 的柱式或 L’Illa 的开口节奏。

**可验证空间痕迹**：街景剖面与视线 / 采光 / 街道活动能交叉说明。

## D10｜LONG_TERM_ADAPTABILITY｜可长期使用的生长与调整
**判断含义**：建成建筑必须允许维修、运营改变与增量适应，持久性不是视觉永恒。

**Trigger**：未来扩容、不同期工程、寿命和设备维护重要。

**Spatial Operation**：phasing / reserve capacity → adaptable access / core → operation and lifecycle review。

**适用边界**：交通、医院、学校、大型机构与综合体。

**Failure Mode**：以未来名义过度建造；无法维护。

**可验证空间痕迹**：分期图、容量假设、服务干预和长期成本可以验证。

## DNA Selection Logic｜禁止自动套装
1. `D01` 必选；它要求事实追溯，不授权具体形式。
2. `D02` 需明确类型/功能转化；不把它当古典母题。
3. `D03` 需历史资产或文保具体事实；没有历史资产不选。
4. `D04` 需真实 construction / form tension，必须测试；其高层建造审查也可能由 universal correction 承担，不自动选。
5. `D05` 需真实城市路径/公共界面/连续问题。
6. `D06` 需 program 重组或新旧负荷冲突。
7. `D07` 需真实剖面 / 人流 / 到发或展陈序列问题。
8. `D08` 需具有支配性的地理条件，有气候和视线数据。
9. `D09` 需特定城市立面阅读问题；不可自动指定柱式 / 石材。
10. `D10` 需多期 / 扩容 / 长期运营真实条件。
11. 默认只保留解决前 3–5 个冲突中因果最强的必要 DNA，其他全部在下游禁用。
12. 若新增 DNA 必须重做 Selection → affected Strategies → Comparison → Recommendation → Prompt Fact Lock；不能在 Prompt 偷补。
