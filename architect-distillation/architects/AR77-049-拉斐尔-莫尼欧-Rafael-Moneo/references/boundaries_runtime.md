# AR77-049｜BOUNDARIES & CONTEMPORARY CORRECTIONS
## Rafael Moneo

## FIT / PARTIAL FIT / NOT FIT
- **FIT**：项目主矛盾涉及 site-specific form; typology and changing use; historic/archaeological intervention; urban continuity; multi-level complex circulation; geography/public form; built reality / long-term adaptability；有至少一项可信事实。
- **PARTIAL FIT**：Moneo 的 specificity / urban / type / construction judgement 有帮助，但项目决定性因素由特殊医疗工艺、复杂工业过程或全新实验结构等其他专业机制主导。
- **NOT FIT**：只想仿造 Mérida 砖拱、Murcia 的历史立面、Prado 扩建姿态、Kursaal 的双玻璃方盒；没有项目事实却要求指定材料/几何/墙厚。

## Architect-Specific Boundary
- **Beauty + necessity**：可以同时追求，但不存在“好看即合理”。
- **History**：不能为了现代性清除遗存，也不能把保留变成阻碍无障碍/消防的借口；交由文保和技术顾问协商。
- **Type**：从 program organization 中抽象，不复制历史平面或柱网。
- **Urban continuity**：可见通道不一定可公共通行；必须核对产权、运营时段、安保和夜间管理。
- **Site geography**：不能从河海岸直接推定玻璃材质和双体量。
- **Construction permanence**：必须同时面对 embodied carbon、地震与抗灾、可修复性、变更成本。
- **Complex transit/institutions**：专业核对 crowd flow / evacuation / service segregation / vertical circulation / peak loading / phasing。
- **Collaborative authorship**：L’Illa Diagonal → Manuel de Solà-Morales; Atocha later work → Peio/Pedro Elcuaz（以具体阶段事务所文件为准）；各项目团队的结构、展陈、工程与施工不可归为建筑师单人劳动。
