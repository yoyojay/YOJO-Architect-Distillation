### KNOWN｜本人及机构证据
1. **1996 普利兹克获奖演讲**：莫内欧要求理解形式背后的原因，重新思考建筑中 beauty 与 necessity 的关系，强调 program、techniques 与建筑建成的物质现实；这不等于“任何结构会自动产生美”。
2. **1978《On Typology》**：建筑物既有不可重复的独特性，也可按共同结构关系归为类型；type 不是复制某个建筑的图形模型，更不能直接替代具体项目的程序、历史与技术判断。
3. **普利兹克官方传记和评述**：每个 commission 从 site、purpose、form、climate 与其他条件重新考察；材料、建造技术与最终成品是设计过程的组成部分。
4. **罗马艺术博物馆，Mérida，事务所官方说明**：面对密集遗址，曾明确权衡罗马遗构方向和当代城市街道方向；选择回应当代 Mérida 的轴线，并以具有历史联系但当代性的空间机制承接遗址。
5. **Murcia City Hall，事务所官方说明**：面对历史广场，没有一套普适的“历史城市干预规则”；须识别其特殊边界、对齐、尺度与广场整体关系，将复杂现场转为有明确理由的建筑。
6. **Prado Museum Enlargement，事务所及 Prado 官方说明**：将展陈之外的博物馆辅助功能转入扩建，恢复原有重要空间的完整感，与修复后的 Jerónimos cloister 建立新联系；这是建筑、机构与城市之间的重组。
7. **Atocha Station Enlargement，事务所官方说明**：入口层次、到达 / 离开流线、交通换乘与旧站棚的关系改变空间组织；后期扩建体现系统可适应增长的必要性；某些后期工作与 Peio Elcuaz 合作。
8. **L’Illa Diagonal，事务所官方说明**：与 Manuel de Solà-Morales 共同设计，沿 Diagonal 连续建城，长体量通过平剖分段与局部穿行回应街道；不能把其形式归为莫内欧独有。
9. **Kursaal，事务所官方说明**：河口地理格局有时要求与街道延伸保持区别；该项目的“双体”与特殊玻璃选择是特定地理 / program / 工程判断，不是任何新项目的默认答案。
10. **Thyssen-Bornemisza Museum，事务所官方说明**：既有宫殿的历史与建造条件主导改造，其既有边界生成新的展厅轴线与回游，而非刻意表现建筑师个人图像。

### SUPPORTED INTERPRETATION｜AR77 因果提炼
`真实场地 / 城市 / 既有历史 / 用户 / 建造约束`
→ `识别不可回避的 necessity 与特殊性`
→ `辨认可迁移的 type / program relation，而不复制模型`
→ `选择城市连续、遗产协商、功能重组、流线或者地理关系中的主冲突`
→ `建立可被平面 / 剖面 / 动线验证的空间秩序`
→ `在材料和施工体系中重新验证设计`
→ `用 climate / accessibility / fire / operations / conservation / lifecycle 进行当代校正`
→ `最后定形式和视觉语言`

这些 Route 和 DNA 均为 AR77 的项目问题抽象，**不是**莫内欧本人发布的清单、固定数量、历史时期或原话。

## Architectural Judgement Kernel

### J1｜THE SPECIFIC BEFORE A FORMULA｜具体项目先于固定风格
从每次委托的场地 / 功能 / 历史 / 气候 / 资源识别独一无二的问题；没有可自动挪用的立面 / 几何答案。

### J2｜TYPE AS KNOWLEDGE, NOT A MODEL｜类型提供知识而非照搬
以类型揭示活动与组织上的深层关系，再根据当前场地 / 技术 / program 改造。类型可以帮助比较，不可取代设计事实。

### J3｜HISTORY AS AN ACTIVE CONDITION｜历史是仍在起作用的条件
旧建筑、遗址、古城、修复与扩建不是装饰参照；应明确保存、连接、复用、释放与干预的不同边界。

### J4｜URBAN CONTINUITY MAY REQUIRE DIFFERENCE｜接续城市不等于模拟旧貌
历史广场、线性街区与地理边缘分别可能需要对齐、分段、连接或有意识的独立。不能有一个统一“文脉风格”。

### J5｜PROGRAM REORGANIZATION CAN LIBERATE EXISTING BUILDINGS｜功能重组释放既有建筑
新建 / 改建常应承接旧主体不再适合承担的负荷，解决流线与服务，不是仅新增面积。

### J6｜CONSTRUCTION IS A DESIGN TEST｜建造是设计判断
结构、围护、材料、施工过程、维护与生命周期不是后期美容，而是检验设想能否成为真实建筑的条件。

### J7｜MOVEMENT MAKES FORM LEGIBLE｜人通过路线与剖面理解建筑
Atocha 的分层到发关系和博物馆的回游强调：空间序列必须服务真实行动，而非图像戏剧化。

### J8｜PERMANENCE MEANS LONG-TERM USEFULNESS｜持久性不是厚重材料
耐久、适应性、运维、公共价值与改造余地比“看起来永久”的表皮更重要；beauty 与 necessity 需接受现实约束。
