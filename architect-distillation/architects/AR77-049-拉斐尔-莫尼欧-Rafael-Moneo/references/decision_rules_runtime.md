# AR77-049｜DECISION RULES
## Rafael Moneo｜Causal Rules, Test & Failure Return

这些规则既是每次项目运行的执行门禁，也是 Scheme Critic 的回退机制；仅已选择 Route / DNA 可以成为策略内容。Universal performance corrections 始终必须执行，但不等于暗中选择 DNA。

1. **Fact Lock**：当项目没有可信历史 / 方位 / 气候 / 流线数据 → 优先分 KNOWN/UNKNOWN/NEED VERIFY 并问关键问题 → 因为具体性不能凭猜测 → 通过事实出处表验证 → 若失败则暂停项目方案具体化。
2. **Fit**：当唯一要求是“做成莫内欧式砖拱/厚墙” → 优先解释方法而非造型 → 因为建筑师每案从具体条件重新判断 → 通过与真实 brief 的主冲突对照 → 若失败则 NOT FIT。
3. **Route**：当两个不同问题路由都貌似成立 → 优先能解释最重要 1–2 个冲突的一个 Primary → 因为主轴必须清楚 → 用证据与失效比较 → 若失败则 Secondary NONE 并缩小问题。
4. **DNA**：当拟选 DNA 没有空间或操作痕迹 → 优先移除该 DNA → 因为罗列理念不等于工作机制 → 用平面/剖面/路径/结构/城市 overlay → 若失败则重新 Selection。
5. **Type**：当方案从某种历史平面图形直接推形式 → 优先 D02（仅若已选）重提炼 program 关系 → 因为 type 不是固定 model → 用旧类型-新活动矩阵 → 若失败则删除原型。
6. **History**：当场地有遗存/旧建筑 → 优先先做价值/损伤/使用调查 → 因为遗产是实物约束 → 用 conservation expert / survey → 若失败则对历史设想标 NEED VERIFY，不做拆改建议。
7. **Urban**：当体量阻断街道连续 → 优先 D05 / D09（仅已选者）研究城市边界与真实通行 → 因为形式应参与城市 → 用 pedestrian access / ownership / operations → 若失败则拒绝未经授权“公共穿廊”。
8. **Program**：当扩建只增加面积却加重旧主体负担 → 优先 D06（若已选）重排 front/back functions → 因为新功能应释放主体 → 用服务/运营/面积矩阵 → 若失败则返回使用需求。
9. **Section/Movement**：当交通/博物馆项目的出入、层级、服务冲突 → 优先 D07（若已选）做用户与剖面双层路线图 → 因为建筑通过实际行动被体验 → 用 accessibility / egress / crowd tests → 若失败则压缩 / 重组路线。
10. **Geography**：当地理场地值得与常规街网不同 → 优先 D08（若已选）比较“连续”与“区别”两组空间因果 → 因为区别须由现场决定 → 用 view / wind / light / public-space evidence → 若失败则不能用双盒子比喻。
11. **Construction**：当形式漂亮但无建造逻辑 → 优先 D04（若已选）或 universal professional validation → 因为现实材料/施工是设计检验 → 用 section, structural concept, buildability, maintenance → 若失败则退回策略层。
12. **Performance**：当 historic appearance 与 climate/accessibility/fire/MEP 冲突 → 优先安全与合规约束 → 因为建筑需实际运行 → 专业顾问验证 → 若失败则改写形式。
13. **A/B/C**：当三案仅换材料/屋顶/体量表情 → 优先重组主因果 → 因为必须三个 causal architectures → 用不同的 primary spatial operation 比较 → 若失败则 Strategy Gate FAIL。
14. **Recommendation**：当推荐想吸收 A+B+C → 只保留一个独立 Dominant，最多一个有限 Borrowed mechanism → 因为必须可说明因果 → 检查拒绝项和未选 DNA 回流 → 若失败则 Recommendation FAIL。
15. **Critic**：当效果图抢先固化砖墙/拱券/玻璃盒 → 优先 plan/section/route/construction evidence → 因为图像不能替代项目判断 → 用 Trace & Failure Matrix → 若失败则撤销造型承诺。
16. **Prompt Fact Lock**：当 Prompt 包含砖、石、拱、玻璃盒、柱厅、立面比例、构造或家具 → 逐项找 KNOWN/Selected/Verified 依据 → 因为历史作品不能成为新项目事实 → 用 material-to-evidence audit → 若失败则删或改关系/性能语言。
17. **Attribution**：当涉及 L’Illa / Atocha 分期等项目机制 → 必须注明已知协作人与团队 → 因为项目结果不等于单一作者全部贡献 → 用事务所项目团队署名核对 → 若失败则撤销单人归因。
18. **Failure Return**：当任何锁失败 → STOP → 修正前一层（Facts / Routes / DNA / Strategy / Recommendation / Prompt）→ 重算所有依赖部分 → RE-AUDIT，不直接进入 Handoff。
