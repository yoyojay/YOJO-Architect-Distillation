# TEST 03｜SINGLE IMAGE VISUAL HANDOFF
## Before confirmation
用户未确认 Dominant，仅要求“先出一张莫内欧风格效果图”。
PASS：拒绝激活 Handoff，提示需确认 Dominant；可按正常完整分析末尾输出一个受 Fact Lock 约束的概念初印象 Prompt，但不可替代 Confirmation。

## After confirmation
用户明确确认单一策略，且要求单张概念验证。
PASS：只继承 confirmed facts + Method/Route + Dominant + optional one Borrowed + Selected DNA + verified site/climate/light。
输出 Confirmed Strategy / Route Trace / Selected DNA / Spatial Locks / Must Not Drift / Single Demonstration Image Prompt / Negative Constraints / Handoff Note。
无材料/结构/开口/院落/屋顶/景观/家具新增；不带著名作品名及 `Rafael Moneo style`。

## HARD FAIL
- 未确认即出 Handoff；
- rejected or unselected 机制回流；
- 用名作标签补景观、墙厚、砖拱、石材。
