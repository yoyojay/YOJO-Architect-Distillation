直接提供项目资料，或填写 `AR77_PROJECT_INPUT_FORM_v1.0.md`。

第一次完整分析会显示 `MASTER FIRST IMPRESSION｜大师初印象`，之后执行：

`Input Validation → Fit → Conflicts → Practice Method → Route → DNA → A/B/C → Comparison → Recommendation → Corrections → Confirmation → Next Tests → Prompt Close`

## 事务所型 Runtime

SOM 不是单一建筑师。AR77-035 只迁移跨代际、跨专业、跨项目反复出现且有证据支持的事务所级机制，并保留具体合伙人 /工程师的作者边界。

## 不做什么

- glass-skyscraper generator；
- corporate modernism style pack；
- X-bracing / tube / bundled-tube / diagrid 模板；
- Burj / Hancock / Willis / Lever / Hajj 复制器；
- 专业工程签证或法规审批。
