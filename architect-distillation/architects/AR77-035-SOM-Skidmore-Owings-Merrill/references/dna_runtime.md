- 再选 1–3 个必要 DNA。

---

## D01｜INTEGRATED_PROBLEM_FRAME｜跨专业问题框架
**判断含义**：建筑、结构、机电、围护、交通、城市和运营共同定义问题。
**Trigger**：全部完整项目分析。
**Spatial Operation**：建立 discipline dependency map，找出决定平面 /剖面 /系统的关键接口。
**适用边界**：全部项目。
**Failure Mode**：所谓“整合”只是把各专业结果叠在一起，没有共同改变方案。
**可验证空间痕迹**：至少一个设计决策同时响应两个以上真实约束，并能画出因果链。

## D02｜STRUCTURE AS ARCHITECTURAL ORDER｜结构作为建筑秩序
**判断含义**：结构系统参与空间、尺度与形体，但必须由荷载和效率支持。
**Trigger**：跨度、高度、风 /地震、柱网或材料效率显著影响设计。
**Spatial Operation**：比较结构体系对 floorplate / section / facade / construction 的影响。
**适用边界**：高层、大跨、复杂形体。
**Failure Mode**：复制 X-brace / tube / diagrid 作为表皮。
**可验证空间痕迹**：结构路径、柱网、核心与空间在图纸中一致。

## D03｜PROGRAM–FLOORPLATE FIT｜程序—楼层系统匹配
**判断含义**：面积、深度、净高、核心、租赁 /使用灵活性共同决定楼层组织。
**Trigger**：办公、混合用途、高层、重复层、转换项目。
**Spatial Operation**：用 program stack / floorplate matrix / core-to-perimeter relation 验证。
**适用边界**：重复楼层和高密度项目。
**Failure Mode**：先有标志性轮廓，功能被迫塞入。
**可验证空间痕迹**：典型层与不同功能层都有可解释的面积 /深度 /交通关系。

## D04｜PERFORMANCE BY MEASUREMENT｜性能量化校准
**判断含义**：关键工程 /环境判断必须有指标、基线和测试。
**Trigger**：风、地震、能耗、碳、日光、热舒适、流量、材料等关键变量。
**Spatial Operation**：baseline → target → option test → iteration。
**适用边界**：全部性能敏感项目。
**Failure Mode**：用“高性能 /绿色 /高效”代替数据。
**可验证空间痕迹**：设计版本变化能对应测试结果。

## D05｜PUBLIC_REALM CONTINUITY｜公共领域连续
**判断含义**：地面公共空间、交通和建筑入口共同定义城市价值。
**Trigger**：城市综合体、总部、公共项目、TOD、复杂街区。
**Spatial Operation**：优先画 movement / public-space network / ground interface。
**适用边界**：城市尺度项目。
**Failure Mode**：广场只是剩余地或私人商业前厅。
**可验证空间痕迹**：公共路径连续、可达，且与街道 /交通 /建筑入口真实连接。

## D06｜SYSTEM EFFICIENCY + CONSTRUCTABILITY｜系统效率 / 可建造性
**判断含义**：结构、模块、施工、材料和重复逻辑共同决定效率。
**Trigger**：规模大、重复度高、工期 /成本 /供应链重要。
**Spatial Operation**：比较 bay / module / component repetition / transfer / erection sequence。
**适用边界**：高层、大型基础设施、重复型建筑。
**Failure Mode**：为了“精密感”做过度定制。
**可验证空间痕迹**：施工序列、模数、结构和空间不互相打架。

## D07｜FLOW + INFRASTRUCTURE COORDINATION｜流线 / 基础设施协调
**判断含义**：人员、物流、交通、安全、服务和基础设施必须共同组织。
**Trigger**：机场、车站、商业综合体、超大人流、城市上盖。
**Spatial Operation**：分层 /分时组织不同流，避免关键交叉。
**适用边界**：高流量与复杂运营项目。
**Failure Mode**：动线图漂亮但高峰容量、安检、货运、疏散失效。
**可验证空间痕迹**：高峰状态与日常状态都能运行。

## D08｜LOAD / CLIMATE RESPONSIVE FORM｜荷载 / 气候响应形态
**判断含义**：形体变化只有在风、地震、日照、热、材料或结构效率真实驱动时成立。
**Trigger**：环境 /荷载会显著改变几何。
**Spatial Operation**：用模拟 /分析结果改变 massing / section / envelope relation。
**适用边界**：高层、气候敏感项目。
**Failure Mode**：事后用“风塑形 /气候响应”包装任意造型。
**可验证空间痕迹**：几何变化与可重复测量的性能变化相对应。

## D09｜LIFECYCLE ADAPTABILITY + CARBON｜生命周期适应 / 碳
**判断含义**：保留、减材、适配、更新和寿命是设计变量。
**Trigger**：低碳、更新、长期适应、材料效率目标。
**Spatial Operation**：whole-life carbon / reuse / replacement / flexibility scenario。
**适用边界**：新建与改造。
**Failure Mode**：只优化运营能耗，忽略建造、替换、拆除和用途变化。
**可验证空间痕迹**：保留 /替换边界、适配策略和碳基线清楚。

# DNA Selection Logic

1. D01 mandatory。
2. 再选 1–3 个，总量 2–4。
3. D02 必须有真实结构问题。
4. D04 必须有可获得或需建立的指标。
5. D05 必须有真实公共领域责任。
6. D07 只有复杂流线 /基础设施存在时启用。
7. D08 只有荷载 /气候数据能改变几何时启用。
8. D09 只有生命周期 /碳 /适应性进入项目目标时启用。
9. 未选 DNA 不得作为“次要优点”回流。
