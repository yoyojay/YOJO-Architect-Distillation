# AR77-035｜DECISION RULES
## SOM

1. **当**建筑师先画标志性轮廓  
   **→ 优先**D01 建立跨专业依存图  
   **→ 因为**SOM Runtime 先解决系统关系  
   **→ 通过**plan / section / structure / MEP / flow trace 验证  
   **→ 若失败则**删除轮廓预设。

2. **当**结构可能塑造建筑  
   **→ 优先**D02  
   **→ 因为**结构只有在真实荷载 /跨度 /效率下才是建筑秩序  
   **→ 通过**load path + spatial consequence 验证  
   **→ 若失败则**禁止 X-brace / tube / diagrid 风格化。

3. **当**高层项目出现退台 /收分 /异形平面  
   **→ 优先**R1 + D03 / D08  
   **→ 因为**几何必须来自 program / wind / structure / core  
   **→ 通过**floorplate matrix + wind/structure test 验证  
   **→ 若失败则**删除几何主张。

4. **当**城市项目只优化塔楼  
   **→ 优先**R2 + D05  
   **→ 因为**公共空间与连通性是系统的一部分  
   **→ 通过**ground-level network / transit / access 验证  
   **→ 若失败则**重做总平与地面关系。

5. **当**项目以“高性能”为目标  
   **→ 优先**D04  
   **→ 因为**性能必须有 baseline / target / test  
   **→ 通过**量化指标验证  
   **→ 若失败则**把性能声明降级为 NEED VERIFY。

6. **当**极端峰值人流 /跨度主导  
   **→ 优先**R3 + D07 / D02  
   **→ 因为**结构与流量必须共同收敛  
   **→ 通过**peak-flow + span + fire / security test 验证  
   **→ 若失败则**返回布局层。

7. **当**既有建筑改造  
   **→ 优先**R4 + D09  
   **→ 因为**保留结构 /围护 /基础设施可能具有碳和成本价值  
   **→ 通过**reuse-value + new-program-fit 验证  
   **→ 若失败则**只拆除确有必要的部分。

8. **当**形体被说成“风 /气候塑造”  
   **→ 优先**D08  
   **→ 因为**必须证明几何变化与性能变化有关  
   **→ 通过**simulation / comparative test 验证  
   **→ 若失败则**撤销气候因果声明。

9. **当**A/B/C 只是同一体系换幕墙或造型  
   **→ 优先**重做  
   **→ 因为**三个策略必须有不同 causal system  
   **→ 通过**不同 primary mechanism 验证  
   **→ 若失败则**Strategy Gate FAIL。

10. **当**Recommendation 想合并三案  
    **→ 优先**保留一个 Dominant  
    **→ 因为**Dominant 必须独立成立  
    **→ 通过**最多一个 Borrowed Mechanism 验证  
    **→ 若失败则**Recommendation Gate FAIL。

11. **当**Prompt 自动补 glass / steel / concrete / curtain wall / X-bracing / tube / setback  
    **→ 优先**Prompt Fact Lock  
    **→ 因为**历史常见做法不是当前项目事实  
    **→ 通过**KNOWN / selected Route / Dominant / Borrowed / Selected DNA / verified site-climate-light 追溯  
    **→ 若失败则**删除或泛化。

12. **当**事务所级规则被归因给某一创始人 /合伙人  
    **→ 优先**Authorship Boundary  
    **→ 因为**SOM 是多代际协作机构  
    **→ 通过**来源归属验证  
    **→ 若失败则**改写为“事务所长期实践”或明确个人贡献。
