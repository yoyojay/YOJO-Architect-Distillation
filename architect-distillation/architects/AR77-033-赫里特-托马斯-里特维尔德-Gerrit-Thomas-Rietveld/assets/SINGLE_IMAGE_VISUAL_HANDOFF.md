# SINGLE IMAGE VISUAL HANDOFF
## AR77-033｜Gerrit Thomas Rietveld

### 定位
只把**已经确认的设计判断**交给一张概念验证图。
不是完整效果图生产系统，不是风格复制器。

### 启动条件
- 已完成项目分析；
- Dominant Strategy 已由用户确认；
- Route / Selected DNA 已确认；
- 用户明确要求一张概念验证图。

### 允许继承
- confirmed KNOWN facts
- confirmed Primary / Secondary Route
- confirmed Dominant Strategy
- optional one Borrowed Mechanism
- Selected DNA
- verified site / climate / light

### 禁止新增
- 未确认材料
- 未确认结构
- 未确认颜色
- 未确认屋顶 / 开口 / 柱网 / 桁架
- 未确认家具 / 景观 / 技术构件
- Rejected Strategy
- unselected Route / DNA

## 04｜Spatial Locks
只写必须在图中看见的空间关系，例如：
- space continuity or transformation state;
- fixed vs transformable boundary;
- construction layer only where confirmed;
- light path where verified;
- actual user activity.

## 05｜Must Not Drift
- 不复制 Schröder House；
- 不复制 Red Blue Chair / Zig-Zag Chair；
- 不复制 Sonsbeek Pavilion；
- 不自动加入红黄蓝、黑线、白灰平面；
- 不把“可变分隔”自动写成某种具体 sliding-wall 构造；
- 不新增未经确认的悬挑板、窗带、平屋顶或材料组合。

## 06｜Single Demonstration Image Prompt
描述：
- current project type;
- confirmed spatial relation;
- actual users / activities;
- confirmed transformation / boundary behavior;
- verified climate / light;
- a viewpoint that reveals plan-section causality;
- realistic architectural observation.

禁止：
`Rietveld style`
`De Stijl style`
`like Schröder House`
任何代表作名作为视觉目标。

## 07｜Negative Constraints
只写与当前设计判断直接相关的负向约束。

## 08｜Handoff Note
> 这是一张概念验证图，只用于检查当前空间判断进入视觉后是否成立，不代表完整效果图体系。后续视觉生产应进入项目原有的专业可视化流程。
