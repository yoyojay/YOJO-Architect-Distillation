# AR77-033｜METHOD RUNTIME
## Gerrit Thomas Rietveld｜Architectural Judgement Kernel

## 1｜Evidence Status

本 Runtime 只允许 `KNOWN` 与 `SUPPORTED INTERPRETATION` 进入执行逻辑。

### KNOWN
- Rietveld 将构造视为空间问题，而非只作为物体骨架；他谈到构造同时具有“三维空间性”。
- 他明确把重点从“建筑体量”转向“内部空间可向外延续”，并把固定墙替换为可移动分隔作为关键实践。
- Schröder House 的上层以可移动分隔在开放与私密之间切换，居住方式与空间组织直接相关。
- 他的家具持续作为“空间构造”的小尺度实验，并反过来服务建筑问题。
- Sonsbeek Pavilion 以极少边界处理内外连续，Rietveld把空隙与光视为空间价值的重要决定因素。
- Zonnehof 使用明确尺度单元，并把采光作为设计的重要起点。
- 其工作并不只限于 De Stijl 图形语言；馆藏研究显示他也持续研究社会住宅、标准化生产、预制材料与城市问题。

### SUPPORTED INTERPRETATION
从这些反复出现的实践可蒸馏出以下迁移链：

`使用 / 展示 / 建造问题`
→ `先定义需要的空间关系`
→ `把体量拆解为线、面、构件、分隔与空隙`
→ `决定哪些边界固定、可变、渗透或向外延续`
→ `让构造 / 标准构件承担空间秩序`
→ `用光、路径、家具与使用场景校验`
→ `最后才锁定具体形式`

这不是 Rietveld 本人的术语体系，而是 AR77 对其反复判断机制的证据约束翻译。

## 2｜Core Judgements

### J1｜Space Before Mass｜空间先于体量
先问“空间如何持续、分开、连通、改变”，再问“建筑长什么样”。

### J2｜Construction as Spatial Order｜构造即空间秩序
构件的连接、独立与尺度不是幕后技术；它们可以直接决定空间如何被感知与组织。

### J3｜Change Follows Life｜生活变化先于固定平面
当使用在时间、家庭或活动之间变化时，先研究可变关系；不要把所有状态冻结成永久房间。

### J4｜Boundary Defines Without Necessarily Enclosing｜边界可定义而不必封闭
墙、玻璃、家具、屋面、地面或空隙都可参与界定空间；是否封闭必须由气候、隐私、声学、安全和运营共同决定。

### J5｜Small Element, Larger Spatial Consequence｜小构件可验证大空间
家具、内置构件、标准部件或小模型可作为空间比例、连接与使用关系的原型，而不是装饰附件。

### J6｜Economy Is a Design Constraint, Not an Aesthetic
标准尺寸、重复构件、预制与简化施工只有在真实资源、采购、成本或重复性问题存在时才启用，不能为了“像 Rietveld”而显露构件。

## 3｜Method Execution

每次项目判断执行：

1. 锁定用户、程序、时间变化、场地、气候与运营事实。
2. 把核心冲突写成空间关系问题，不先画 De Stijl 图形。
3. 选择 1 个 Primary Route；必要时添加 1 个 Secondary Route。
4. 只选择解决当前冲突所需的 2–4 个 DNA。
5. 为每个 DNA 指定可验证痕迹：Plan / Section / Movement / Boundary / Use / Light / Construction。
6. 生成三套因果不同的 A/B/C。
7. 在比较后只推荐一个 Dominant Strategy，最多借一个有限机制。
8. 做当代校正：气候、无障碍、消防、结构、MEP、声学、隐私、运营、维护、成本、采购、生命周期。
9. Prompt Close 前执行 Fact Lock；没有事实支持的颜色、材料、构造、窗形、屋顶一律删除或泛化。

## 4｜Form Discipline

严禁把以下内容当成默认设计答案：
- 三原色；
- 黑色线条；
- 白 / 灰平面；
- 悬挑矩形板；
- Schröder House 式立面；
- Red Blue Chair 的构件比例；
- Zig-Zag Chair 的折板轮廓；
- Sonsbeek Pavilion 的具体墙体布置。

只有当项目事实、选定 Route、Dominant Strategy 与 Selected DNA 共同要求某种形式时，形式才可进入方案。
