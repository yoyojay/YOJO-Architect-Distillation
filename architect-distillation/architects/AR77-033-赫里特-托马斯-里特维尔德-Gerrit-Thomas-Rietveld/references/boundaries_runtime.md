# AR77-033｜BOUNDARIES + CONTEMPORARY CORRECTIONS

## Fit

### FIT
- 项目核心涉及空间连续、可变使用、边界强度、构件系统、标准化、光与展示；
- 用户愿意从空间 / 构造 / 使用关系出发，而不是复制视觉符号。

### PARTIAL FIT
- 方法可用于局部空间系统，但项目主要问题是超高层核心筒、复杂基础设施、极端性能建筑等其他专业逻辑；
- 需要与其他方法或专业系统共同工作。

### NOT FIT
- 唯一目标是复制 Schröder House / Red Blue Chair / De Stijl 图形；
- 用户要求直接生成“Rietveld style”外观；
- 项目事实不足以判断真实使用，却要求具体材料 / 构造 /形式结论。

## Contemporary Corrections

### Climate
开放 / 渗透边界必须校正热、风、雨、结露、遮阳、能耗与室内舒适。

### Accessibility
可变分隔、家具原型、地面高差与路径不得降低无障碍连续性。

### Fire / Life Safety
移动墙、开放连通、展厅空隙与多状态平面必须重新验证防火分区、疏散、烟控与消防设施。

### Structure
“独立线面”“轻”“悬”“薄”只是空间语言，结构系统必须由工程条件确认。

### MEP
可移动空间必须确认送回风、喷淋、照明、插座、控制与检修在不同状态下仍成立。

### Acoustics
视觉开放与可移动墙不会自动带来声学隔离；需要独立声学指标。

### Privacy
开放平面与内外连续必须明确视觉、声音、数据与行为隐私。

### Operations
移动分隔必须有人维护、操作、收纳并有清楚的日常切换规则。

### Maintenance
轨道、五金、标准部件、外露连接与高频移动构件必须评估磨损和替换。

### Cost / Procurement
标准化只有在本地供应链、数量、施工方式与成本真实成立时才有意义。

### Lifecycle
可拆换、修复、升级优先于一次性视觉完整度；长期适应性必须验证。

### Heritage / Existing Fabric
若为历史建筑更新，不得用 De Stijl 图形覆盖既有价值；只迁移空间与构造判断。

## Professional Boundary

本 Skill 可做前期空间判断、方案比较与 Critic；不能替代持证建筑师、结构、机电、消防、声学、幕墙、造价或当地法规专业意见。
