# AR77-033｜PROBLEM ROUTES
## Routing abstractions derived from Rietveld evidence

这些 Route 是 AR77 为项目调用建立的 **Project-Problem Routes**，不是 Rietveld 自己命名的历史阶段。

## R1｜LIVING_TRANSFORMATION｜生活变化 / 可变居住

**Trigger**
- 同一空间在一天、家庭阶段或活动模式间切换；
- 开放与私密需要动态平衡；
- 固定房间会过早冻结生活方式。

**核心问题**
怎样让空间随生活改变，而不是把变化都交给“多做房间”。

**Method**
先画使用状态与时间切换，再决定固定核、可移动分隔、家具边界与收纳位置。

**主要 DNA**
D01 / D03 / D06 / D09

**适用边界**
住宅、学习、工作、社区、混合用途等存在真实切换需求的项目。

**风险**
消防分区、声学、门轨维护、无障碍、隐私、家具冲突、运营复杂度。

**与其他 Route 差异**
它由“时间与使用变化”驱动，而不是由开放边界或施工经济驱动。

---

## R2｜OPEN_SPACE_BOUNDARY｜开放空间 / 内外连续

**Trigger**
- 项目需要把室内、半室外、景观或公共空间形成连续关系；
- 实体墙过度切断视线、活动或作品展示。

**核心问题**
怎样用最少但精准的边界定义空间，而不是用完整体量封闭空间。

**Method**
先标记必须封闭与可开放的边界，再用线、面、屋盖、地面、视线和空隙建立空间关系。

**主要 DNA**
D01 / D02 / D07 / D08

**适用边界**
展亭、公共空间、温和气候下的过渡空间、与景观关系强的项目。

**风险**
热舒适、雨水、风、眩光、安防、烟控、声学、夜间运营。

**与其他 Route 差异**
它由“边界强度与空间连续性”驱动，而不是由可变分隔本身驱动。

---

## R3｜ELEMENTAL_CONSTRUCTION｜构件系统 / 施工经济

**Trigger**
- 预算、工期、重复性、标准材料或装配逻辑是关键限制；
- 项目需要从少量构件获得清楚空间秩序。

**核心问题**
怎样让简单、标准、可重复的构件同时承担建造逻辑与空间表达。

**Method**
识别可标准化部件 → 简化连接 → 保持构件职责清楚 → 用组合关系产生空间差异。

**主要 DNA**
D02 / D04 / D05 / D06

**适用边界**
小型公共建筑、住宅、重复单元、模块化或预算敏感项目。

**风险**
把“显露构件”误当目的；结构、防火、耐久、热桥、采购与容差必须专业校验。

**与其他 Route 差异**
它由“怎样建、怎样重复、怎样节省”驱动。

---

## R4｜LIGHT_EXHIBITION_FIELD｜光 / 展示 / 空隙场

**Trigger**
- 艺术、展品、教学展示或公共活动需要光与空间共同组织；
- 展示物需要在开放空间中获得独立位置与观看距离。

**核心问题**
如何让光、空隙、边界与作品共同定义空间，而不是用造型抢走主角。

**Method**
从展品保护、观看距离、光源方向与路径开始；边界只做到足以组织观看与气候控制。

**主要 DNA**
D01 / D07 / D08

**适用边界**
美术馆、展亭、文化空间、展示型公共建筑。

**风险**
UV、眩光、热负荷、保管、安全、布展、声学与设备集成。

**与其他 Route 差异**
它由“光与被展示对象的关系”驱动。

---

## R5｜REPETITIVE_HOUSING_SYSTEM｜重复住宅 / 标准化生产

**Trigger**
- 多户住宅、重复单元、成本或供应链要求系统化；
- 需要在重复中保留生活差异。

**核心问题**
怎样用标准化与重复降低复杂度，同时避免把真实生活压成单一模板。

**Method**
先定义不可变基础系统，再定义可变的使用、朝向、入口、边界或内部配置层。

**主要 DNA**
D04 / D05 / D09 / D01

**适用边界**
集合住宅、批量住房、可重复单元。

**风险**
过度标准化、居住差异消失、法规与无障碍冲突、热工与声学性能不足。

**与其他 Route 差异**
它以“重复生产与生活差异的平衡”为主问题。

---

# Route Selection Logic

1. 先写主冲突，不先选 Route。
2. Primary Route 只能有 1 个。
3. Secondary Route 最多 1 个，且必须解决不同但真实的次级冲突。
4. 若多个 Route 都“看起来有趣”，只保留对项目因果链必要者。
5. 未选 Route 不得在 Recommendation 或 Prompt 中回流。
6. 如果 Route 只是为了复制某个 Rietveld 作品的外观，判定为无效。
