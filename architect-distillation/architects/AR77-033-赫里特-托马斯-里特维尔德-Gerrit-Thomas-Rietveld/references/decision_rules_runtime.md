# AR77-033｜DECISION RULES

1. **当**用户以三原色、黑线、矩形平面作为目标  
   **→ 优先**退回真实空间冲突  
   **→ 因为**这些是历史视觉语言，不等于可迁移判断  
   **→ 验证**方案能否在没有这些颜色时仍成立  
   **→ 若失败**删除形式预设，重选 Route / DNA。

2. **当**同一空间存在真实时间切换  
   **→ 优先**测试 D03 / R1  
   **→ 因为**固定房间会冻结变化  
   **→ 验证**至少两种状态、转换路径、收纳、声学、消防  
   **→ 若失败**退回固定但可兼容的空间关系。

3. **当**内外连续是主问题  
   **→ 优先**R2 + D08  
   **→ 因为**Rietveld 的开放不是“全玻璃”，而是边界强度的重新组织  
   **→ 验证**平面 + 剖面 + 气候 / 安防 / 夜间运营  
   **→ 若失败**增加必要的受控边界。

4. **当**预算、重复或采购是主约束  
   **→ 优先**R3 / R5 + D05  
   **→ 因为**标准部件必须解决真实生产问题  
   **→ 验证**模数、构件表、容差、成本、供应链  
   **→ 若失败**取消形式化模块。

5. **当**构造开始决定造型  
   **→ 优先**D04  
   **→ 因为**构造必须产生真实空间秩序  
   **→ 验证**结构 / 围护 / 分隔职责能在剖面解释  
   **→ 若失败**把具体结构语言退回 NEED VERIFY。

6. **当**展示与日光是核心  
   **→ 优先**R4 + D07  
   **→ 因为**光应服务观看与空间，而不是追求透明形象  
   **→ 验证**眩光、UV、热、展品保护、布展  
   **→ 若失败**改为受控光策略。

7. **当**家具或内置构件影响空间组织  
   **→ 优先**D06  
   **→ 因为**小尺度原型可提前暴露比例与动作问题  
   **→ 验证**1:1 样段 / 动作测试是否反向修改平剖  
   **→ 若失败**不得把家具当成“Rietveld 符号”。

8. **当**选定 DNA 在平面、剖面、路径或使用状态中找不到痕迹  
   **→ 优先**判定 Strategy 不成立  
   **→ 因为**DNA 必须是空间机制，不是文案  
   **→ 验证**Plan / Section / Movement / Boundary / Use  
   **→ 若失败**删除该 DNA 或重做策略。

9. **当**Prompt 想补颜色、材料、窗形、屋顶或具体连接  
   **→ 优先**Fact Lock  
   **→ 因为**视觉完整度不能替代事实  
   **→ 验证**每项是否来自 KNOWN / selected Route / Dominant / Borrowed / Selected DNA / verified site-climate-light  
   **→ 若失败**删除或改写为关系 / 性能语言。

10. **当**Recommendation 同时吸收 A+B+C  
    **→ 优先**重写  
    **→ 因为**Dominant 必须可独立成立  
    **→ 验证**最多一个 Dominant + 来自另一个策略的一个有限机制  
    **→ 若失败**Recommendation Gate FAIL。
