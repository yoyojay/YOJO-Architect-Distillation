# AR77-033｜Gerrit Thomas Rietveld Agent Skill Runtime FINAL v1.0

## 使用方式

直接告诉 Skill：
- 项目是什么；
- 在哪里；
- 谁使用；
- 最困扰你的 3–5 个问题；
- 已知限制；
- 若有，附上平面 / 剖面 / 模型 / 效果图。

也可以填写 `AR77_PROJECT_INPUT_FORM_v1.0.md`。

第一次完整分析会先显示 `MASTER FIRST IMPRESSION｜大师初印象`，之后自动完成：

`Input Validation → Fit → Conflicts → Method → Route → DNA → A/B/C → Comparison → Recommendation → Corrections → Confirmation → Next Tests → Prompt Close`

资料不足时每轮只问 1–3 个关键问题。

## 这个 Skill 不做什么

它不是：
- De Stijl 风格生成器；
- 红黄蓝 / 黑线 / 矩形平面的视觉包；
- Schröder House 或经典家具复制器；
- 结构 / 消防 / MEP 等专业最终结论；
- 完整效果图生产系统。

## Single Image Visual Handoff

只有 Strategy 确认后才启用 `assets/SINGLE_IMAGE_VISUAL_HANDOFF.md`。
它只生成一张概念验证图的交接，不新增未经确认的设计事实。

## Delivery Protection

客户包只包含 Callable Runtime。
不包含 Master Research、Source Ledger、Evidence Matrix、Factory Rules、Benchmark、私有 QA、蒸馏过程或 Carousel Factory logic。
