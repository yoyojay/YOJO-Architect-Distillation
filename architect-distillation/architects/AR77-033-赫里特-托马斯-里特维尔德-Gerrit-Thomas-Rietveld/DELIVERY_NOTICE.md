# AR77 Runtime Delivery Notice

这是 AR77-033 Gerrit Thomas Rietveld 的客户运行版。

建议正式销售协议至少覆盖：
- 指定购买人 / 组织使用；
- 禁止转售；
- 禁止再分发；
- 禁止重新包装为竞争 Skill；
- 禁止提取运行指令并公开销售。

本 Notice 不是针对特定司法辖区的法律意见。

## Protection Model
1. Master Research 不交付；
2. 只交付可调用 Runtime；
3. 可按订单写入 Buyer ID / Runtime Serial；
4. Source Ledger、蒸馏过程、Factory 与 Publishing System 留在卖方。

任何需要在客户本地被 Agent 读取的文件，都无法保证文件持有人绝对无法查看内容。
