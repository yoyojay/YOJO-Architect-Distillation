## Core Method Chain

`Fact Lock → Relational Conflicts → Primary Route → 4–7 DNA → A RULE MODIFICATION / B INFRASTRUCTURE FIELD / C PUBLIC-NATURAL NETWORK → Plan + Section + Structure/System Evidence → Performance Translation → Recommendation → Critical Fail Check → Architect Confirmation`

## Method Kernel

1. Start from project conditions, not a personal visual language.
2. Rewrite rules rather than preserve a recognizable form.
3. Let structure / infrastructure participate in public-space organization when the project needs it.
4. Treat nature as a dynamic relationship model, not a natural-looking shape.
5. Translate light, fluidity, openness, and sensory language into verifiable performance.
6. Public freedom requires technical, operational, accessibility, acoustic, and fire support.
7. Technical innovation must survive use, maintenance, lifecycle, and collaboration.
8. Ask why build, for whom, who operates, and who carries responsibility when community is involved.

## Unique Runtime Rules

- exactly 1 Primary Route;
- at most 1 Secondary Route;
- select 4–7 DNA;
- D01 is mandatory;
- public buildings must include at least two of D02 / D03 / D10;
- nature / organic arguments require D09;
- lightness / transparency arguments require D11;
- community / post-disaster work requires D12;
- Strategy A = RULE MODIFICATION;
- Strategy B = INFRASTRUCTURE FIELD;
- Strategy C = PUBLIC / NATURAL NETWORK;
- every strategy must show Plan + Section + Structure/System evidence;
- sensory language must become performance language;
- Critical Fail and Anti-Icon Audit are mandatory.
