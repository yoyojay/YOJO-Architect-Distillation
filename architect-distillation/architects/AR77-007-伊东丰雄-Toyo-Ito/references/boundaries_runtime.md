# AR77-007｜Boundaries Runtime

## Strong Fit

Useful when the project must rethink:

- fixed / flexible public program;
- standard grid / modified rule;
- structure / infrastructure as spatial organizer;
- physical / information overlap;
- public openness with technical support;
- linear circulation / topological connection;
- environmental / sensory continuity that can be translated into performance;
- community responsibility and operation.

## Partial Fit / Caution

Use with explicit verification when the project depends on:

- unconventional structure / integrated structure-skin systems;
- large transparent or lightweight envelopes;
- complex cross-level public networks;
- high acoustic sensitivity;
- strong media / digital infrastructure;
- complex geometry;
- climate-sensitive open public space;
- post-disaster / community participation claims.

Required checks may include:

- structure;
- fire / smoke / egress;
- accessibility;
- acoustics;
- climate / energy;
- maintenance / replacement;
- cost / buildability;
- operations;
- collaboration / responsibility;
- community decision rights.

## Not Fit

Do not use this runtime when the user only wants:

- a Toyo Ito visual style;
- Sendai-like tubes;
- branch façades;
- repeated arches;
- cave-like walls;
- glowing cylinders;
- hut aesthetics;
- an organic-form shortcut without project evidence.

## Professional Boundary

This Runtime does not provide final professional determinations for:

- structure;
- MEP;
- fire;
- statutory code;
- accessibility compliance;
- environmental engineering;
- detailed acoustics;
- cost;
- procurement;
- construction;
- final professional responsibility.

When these affect concept judgement, mark them `NEED VERIFY`.

## Critical Boundary

A recommendation must be blocked when:

- only renderings exist with no Plan / Section / Structure-System evidence;
- public openness lacks fire / accessibility / acoustic / operations correction;
- “natural / fluid / light / open” remains untestable poetic language;
- known Toyo Ito iconography is used as the main design instruction;
- technical collaboration or community responsibility is erased.
