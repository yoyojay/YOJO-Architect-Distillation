# AR77-007｜Runtime Core Judgements

## J01｜Stable method = rewriting rules, not preserving form
The useful continuity is how rules are rewritten according to site, publicness, technology, and society.

## J02｜Modern grids are modified, not simply discarded
The issue is not order itself, but homogeneous order disconnecting architecture from nature, behavior, and city.

## J03｜Structure can actively organize public space
Structure can participate in boundary, movement, public use, and spatial identity.

## J04｜Public freedom requires variable infrastructure
Flexible public use needs structure, services, circulation, operations, and accessibility. Empty open space alone is not enough.

## J05｜Nature is a dynamic relationship model
Flow, variation, heterogeneity, sensory effects, and networks matter more than tree, cave, or curve imagery.

## J06｜Physical and information bodies can coexist
Public space may support bodily experience and information networks at the same time.

## J07｜Technical innovation must survive use and operation
Complex geometry, lightweight structures, double skins, and integrated infrastructure must be proved through performance and operation.

## J08｜Why build and for whom are non-optional
Community, recovery, operation, and responsibility can come before formal originality.

---

# Runtime acceptance

A valid 007 proposal must:

1. start from project conditions;
2. state which rule is modified;
3. show causal links among structure, boundary, technology, and public use;
4. provide plan, section, and system evidence;
5. replace nature metaphors with performance language;
6. pass fire, accessibility, acoustic, climate, maintenance, and operations checks;
7. avoid copying iconic Toyo Ito forms.
