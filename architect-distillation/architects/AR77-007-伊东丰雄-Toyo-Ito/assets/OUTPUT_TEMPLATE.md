## 15｜建筑初印象 Prompt
固定收尾：

`建筑初印象 Prompt｜复制到你的图像生成工具即可`

只允许使用：KNOWN 项目事实 + 已选 Route + Dominant Strategy + 一个可选 Borrowed Mechanism + Selected DNA + 已通过 PLAN/SECTION/STRUCTURE-SYSTEM 证据 + 已转换的性能条件。
不得使用 Toyo Ito style / 代表作名称 / Rejected Strategy / 未选 DNA / 未选 Route。
不得自动加入管柱、树状立面、重复拱、洞穴曲面、发光圆柱、小屋意象。
该 Prompt 只用于概念初印象检验，不是最终效果图指令。

## Recommendation Compliance Gate
- Dominant Strategy: one of A/B/C
- Borrowed Mechanism: NONE or one limited mechanism from one other strategy
- Rejected for Recommendation: remaining third strategy
- Positive Strategy Count must be 1 or 2; 3 = HARD FAIL


## Prompt Fact Lock

建筑初印象 Prompt 中每一个具体材料 / 结构 / 立面 / 开口 / 屋顶 / 壳体 / 柱网描述，都必须可追溯到：

- KNOWN
- Dominant Strategy
- 单一 Borrowed Mechanism
- Selected DNA
- 已通过的 Plan / Section / Structure-System evidence
- 已验证的场地 / 气候 / 光条件

无法追溯的具体描述必须删除或泛化。

例：
- `transparent glass skin` → `a boundary calibrated for visibility, climate and operation`
- `slender white columns` → 只有在已确认结构系统支持时才能出现
- `tree-like columns` → 未被 Route / DNA / 结构证据明确支持则删除
- `double-curved roof` → 只有在剖面与系统证据支持时才可转译为具体形式

不得为了让画面更“像伊东丰雄”而自动补玻璃皮肤、管柱、树状柱、流动屋顶、媒体立面等图像符号。
