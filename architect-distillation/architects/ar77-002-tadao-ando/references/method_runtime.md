# AR77-002｜Runtime Method

## Core reasoning chain

The existing 002 source can be summarized as:

`project conflict → boundary → geometry → movement → weather / light → body perception → terrain / nature → material → contemporary correction`

This is the method kernel.

---

## Method 01｜Boundary before object

Do not begin by shaping an object.

Ask first:

- what needs to be blocked?
- what should remain visible?
- where should outside re-enter?
- what should remain open to weather?
- what must stay public?

Boundary is a filter, not a wall fetish.

---

## Method 02｜Movement prepares perception

Route can:

- slow;
- turn;
- compress;
- reveal;
- separate;
- reconnect.

A detour is justified only when it improves spatial understanding, transition, or perceptual intensity.

---

## Method 03｜Weather can enter architecture

Court, void, light well, semi-open passage, and exterior threshold can make:

- sun;
- wind;
- rain;
- humidity;
- temperature

part of the experience.

But weather exposure must remain a **choice** where accessibility, safety, elderly users, children, or daily operation require protection.

---

## Method 04｜Light has direction and time

Natural light can be:

- cut;
- delayed;
- framed;
- reflected;
- filtered;
- contrasted.

Use light to structure attention.

Do not reproduce famous light symbols.

---

## Method 05｜Geometry controls complexity

Pure geometry can organize:

- site;
- path;
- void;
- program;
- structure;
- relation to landscape.

Geometry is a control frame.

It must not become a logo.

---

## Method 06｜Section carries body and terrain

Especially for slopes, museums, and public buildings:

test:

- entry level;
- descent / ascent;
- concealment;
- view release;
- terrain cut;
- courtyard depth;
- roof relationship.

Section is often more important than façade.

---

## Method 07｜Nature is selected, not decorated

Do not simply add landscape.

Decide:

- which sky?
- which tree?
- which horizon?
- which water?
- which slope?
- when is it visible?
- when is it withheld?

---

## Method 08｜Material supports perception

Material should work with:

- light;
- touch;
- scale;
- construction;
- maintenance;
- climate.

Concrete is not the method.

---

## Method 09｜Silence is an attention strategy

Reduction can help:

- art;
- ritual;
- introspection;
- landscape;
- daily bodily awareness.

But minimal visual stimulus must not erase:

- wayfinding;
- social life;
- safety;
- inclusivity.
