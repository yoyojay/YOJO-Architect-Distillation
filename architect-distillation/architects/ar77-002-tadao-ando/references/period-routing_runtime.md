# AR77-002｜Period Routing Runtime

The original 002 source defines five project routes.

The routes are **problem frames**, not style presets.

---

## URBAN_INWARD

### Core concerns
- dense urban context;
- noisy surroundings;
- privacy;
- inner focus;
- courtyard / open weather layer;
- indoor–outdoor–indoor sequence.

### Strong project families
- compact urban housing;
- small private / semi-private urban buildings.

### Priority DNA
01, 02, 03, 04, 05, 12

### Avoid
Do not copy the Azuma House three-part plan or force exposed concrete.

---

## COLLECTIVE_TOPOGRAPHY

### Core concerns
- slope;
- grouped living;
- repeated units;
- shared platforms;
- terrain;
- sectional circulation.

### Strong project families
- hillside housing;
- collective residential / campus clusters;
- stepped community projects.

### Priority DNA
07, 08, 09, 03, 06

### Avoid
Do not turn a slope into a generic stepped concrete megastructure.

---

## SPIRITUAL_LIGHT

### Core concerns
- concentration;
- ritual;
- memorial;
- silence;
- sequence;
- compressed threshold;
- directional natural light.

### Strong project families
- worship;
- memorial;
- contemplation;
- small cultural / ceremonial spaces.

### Priority DNA
02, 03, 05, 06, 12

### Avoid
Do not copy the cross opening of Church of the Light or other iconic religious devices.

---

## ART_NATURE

### Core concerns
- art;
- landscape;
- hidden mass;
- natural light;
- movement as curation;
- selective views;
- terrain / water relation.

### Strong project families
- museums;
- galleries;
- cultural buildings;
- landscape-integrated art facilities.

### Priority DNA
05, 07, 08, 09, 10, 12

### Avoid
Do not copy Chichu triangular courtyards, Benesse massing, or landmark visual compositions.

---

## URBAN_REUSE

### Core concerns
- existing building;
- retained shell;
- new intervention;
- clear old / new relation;
- controlled geometry;
- selective cuts and movement.

### Strong project families
- adaptive reuse;
- heritage-adjacent intervention;
- cultural retrofit;
- urban renewal.

### Priority DNA
01, 02, 03, 07, 08, 11

### Avoid
Do not erase the existing building's history with an oversized new object.

---

# Routing rule

1. Choose one primary route.
2. Add one secondary route only if the project genuinely requires it.
3. Explicitly state what is not being borrowed.
4. Strategies A/B/C should remain coherent with the primary route.
5. Historical projects explain **problems and operations**, never visual targets.
