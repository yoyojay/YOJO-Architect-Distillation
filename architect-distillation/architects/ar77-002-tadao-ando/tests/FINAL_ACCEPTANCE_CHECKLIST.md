# AR77-002｜FINAL 外部验收

## First Contact PASS
- [ ] 首次完整项目分析先出现约 150 字大师初印象
- [ ] 大师初印象来自 packaged method / DNA / Routing，不写百科传记
- [ ] 有 3 个关键词 + 1 条“不要误读成”
- [ ] 不要求用户预先熟悉安藤忠雄或 AI 命令
- [ ] 信息不足时每轮最多追问 1–3 个关键问题
- [ ] Critic / Handoff 不重复大师初印象

## Project Analysis PASS
- [ ] 先做输入检查，UNKNOWN 不补写
- [ ] 有 FIT / PARTIAL FIT / NOT FIT
- [ ] 3–5 个核心空间冲突
- [ ] 只选 1 个 Primary Route，Secondary 最多 1 个
- [ ] 选择 4–7 DNA
- [ ] 未选 DNA 不得后门回流
- [ ] A/B/C 因果不同
- [ ] 推荐最多正向使用 2 个策略
- [ ] 推荐使用 Dominant / Borrowed / Rejected 固定结构
- [ ] 推荐保持 Route 一致
- [ ] 有高温高湿 / 天气暴露 / 等价保护路径 / 材料 / 内向安全 / 自然光校正
- [ ] 有专业边界
- [ ] 有建筑师确认点
- [ ] 有下一步 1–2 张图 / 测试
- [ ] 不复制代表作

## Prompt Close PASS
- [ ] 每次完整项目分析最后只有 1 个建筑初印象 Prompt
- [ ] Prompt 只使用 KNOWN + 已选 Route + Dominant + 单一 Borrowed + Selected DNA
- [ ] 不使用 Rejected Strategy
- [ ] 不使用未选 DNA / 未选 Route
- [ ] 不出现 `Tadao Ando style` / 代表作名称
- [ ] 不自动补入未经判断支持的清水混凝土 / 斜墙 / 十字光 / 三角庭院 / 莲花楼梯 / 水面
- [ ] 定位为概念初印象检验，不冒充最终效果图

## Visual Handoff PASS
- [ ] 只有一个单图 Handoff
- [ ] Strategy 与 Route 已确认
- [ ] 有 Selected DNA
- [ ] 有 Spatial Locks
- [ ] 有 Must Not Drift
- [ ] Prompt 不出现 Tadao Ando style
- [ ] 不扩展成整套效果图
- [ ] 后续完整视觉生产转入独立工作流

- 斜墙 / 光缝 / 三角庭院等成为默认形式
- 五条 Route 混成一个滤镜
- 三案只是换造型
- A+B+C 全部进入推荐
- UNKNOWN 当事实
- 全 DNA 堆叠
- 天气体验牺牲无障碍 / 儿童 / 老人 / 基本安全
- 跳过当代校正 / 风险 / 专业边界


## Prompt Fact Lock PASS
- [ ] Prompt 中每一个具体材料 / 结构 / 立面 / 开口 / 墙体 / 屋顶描述都有可追溯依据
- [ ] 不把 UNKNOWN 写成具体物质事实
- [ ] 未确认材料使用中性表达
- [ ] 未确认开口 / 墙体构造使用性能或空间关系表达，而不是具体几何
- [ ] 不为了“更像安藤”自动补 concrete / masonry / timber / steel / glass / deep reveals / water plane / roof form
