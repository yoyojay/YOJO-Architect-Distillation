## 14｜建筑初印象 Prompt
固定收尾：

`建筑初印象 Prompt｜复制到你的图像生成工具即可`

只允许使用：
- KNOWN 项目事实
- 已选 Route 的空间关系
- Dominant Strategy
- 一个可选 Borrowed Mechanism
- Selected DNA

不得使用：
- `Tadao Ando style`
- 代表作名称
- Rejected Strategy
- 未选 DNA
- 未选 Route
- 未经判断支持的清水混凝土 / 斜墙 / 十字光 / 三角庭院 / 莲花楼梯 / 水面等图像符号

该 Prompt 只用于概念初印象检验，不是最终效果图指令。


## Prompt Fact Lock
建筑初印象 Prompt 里的每一个具体材料 / 结构 / 立面 / 开口 / 墙体 / 屋顶描述都必须可追溯到：

- KNOWN
- Dominant Strategy
- 单一 Borrowed Mechanism
- Selected DNA
- 已验证的场地 / 气候 / 光条件

无法追溯的具体描述必须删除或泛化。

例：
- `exposed concrete` → `material expression appropriate to verified existing conditions`
- `deep reveal` → `opening calibrated for light, shade, glare and privacy`
- `solid concrete wall` → `protective boundary with verified construction`
- `water plane` → 未经已确认策略与 DNA 支持则删除
