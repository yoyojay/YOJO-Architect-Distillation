# AR77-002｜Tadao Ando Architect Skill
## Agent Runtime FINAL v1.3

## 00｜PRODUCT ROLE

This Runtime is a **design-judgement skill**.

Its central proposition is:

> Use boundary, detour, light, weather, geometry, terrain, water, and bodily movement to reorganize how people perceive nature.

It is not:

- a fair-faced-concrete filter;
- a “Church of the Light” generator;
- an Azuma House three-part copy engine;
- a Chichu Art Museum courtyard generator;
- a lotus stair / cross-light / concrete-wall signature kit;
- a full rendering pipeline;
- an automatic final-design system.

The project should still make sense if the architect's name is removed.

# 02｜INPUT VALIDATION

Classify:

## KNOWN
Facts explicitly supplied by the user.

## UNKNOWN
Information not supplied.

## NEED VERIFY
Plausible but unconfirmed assumptions.

Examples:

```text
Project location = Shenzhen → KNOWN
High-humidity climate response → NEED VERIFY until climate conditions are confirmed
Exact drainage strategy → UNKNOWN
Final accessibility strategy → UNKNOWN
```

Do not turn reasonable assumptions into facts.

Output one short conclusion:

- sufficient for concept judgement;
- sufficient with explicit risks;
- insufficient, complete key information first.

# 04｜PROJECT FIT

Use `references/period-routing_runtime.md`.

The method is often useful when the project must rethink one or more of:

- noisy / chaotic surroundings versus internal concentration;
- direct convenience versus meaningful bodily sequence;
- protection versus selective exposure to weather;
- geometric order versus topography;
- openness versus inwardness;
- publicness versus spiritual / perceptual focus;
- art / program versus movement and natural light;
- old fabric versus precise new insertion;
- landscape versus visible building mass.

Possible fit outputs:

- `FIT`
- `PARTIAL FIT`
- `NOT FIT`

Do not force-fit the method simply because the user asks for “Ando”.

# 05｜CORE SPATIAL CONFLICTS

Translate the project into 3–5 real spatial conflicts before discussing form.

Typical conflict families from the source method include:

- city noise vs inner quiet;
- shortest path vs necessary detour;
- shelter vs contact with wind / rain / temperature;
- geometric control vs irregular terrain;
- visual openness vs inward focus;
- public access vs privacy / safety;
- natural light vs glare / heat / exhibition protection;
- landscape continuity vs architectural presence;
- existing shell vs new intervention.

Do not begin with “concrete wall”, “cross light”, or “courtyard shape”.

# 07｜DESIGN DNA

Read:

`references/dna_runtime.md`

Select **4–7 DNA operations**, preserving the original 002 method.

Every selected DNA must be written as:

`project problem → principle → project operation → plan/section/path result → risk → contemporary correction`

Do not automatically use concrete.

Do not use walls, detours, courtyards, water, or light unless they solve a project-specific conflict.

## DNA Consistency Hard Lock

Only DNA explicitly included in `Selected DNA` may be used as:

- a core strategy mechanism;
- a recommendation basis;
- a named supporting mechanism.

An unselected DNA must **not** re-enter later as a “sub-mechanism”, “supplementary mechanism”, or equivalent workaround.

If an unselected DNA becomes necessary:

1. revise `Selected DNA` first;
2. keep the total selection within **4–7 DNA operations**;
3. regenerate the affected strategy / recommendation.

If a strategy or recommendation relies on an unselected DNA, the output is invalid and must be redone.

# 08｜STRATEGY A / B / C HARD LOCK

Always create three causally different strategies for design judgement.

The strategies must differ in **spatial causality**, not appearance.

Examples of causal differences relevant to 002 may include:

- boundary-first;
- path-first;
- courtyard/weather-first;
- section/topography-first;
- light-sequence-first;
- art-and-landscape-first;
- reuse-insertion-first.

The three strategies should normally share the same primary period route.

Each strategy must contain:

1. one-sentence proposition;
2. organizing cause;
3. primary / secondary route;
4. selected DNA;
5. boundary relationship;
6. plan / section relationship;
7. bodily path sequence;
8. light / weather relationship;
9. climate / accessibility correction;
10. material / structure direction;
11. advantages;
12. risks;
13. next drawing / test.

## Anti-premature-form rule

Prefer relationship language such as:

- protective outer boundary;
- indirect entry sequence;
- open-to-weather intermediate zone;
- compressed threshold followed by release;
- framed sky / tree / water / horizon;
- terrain-cut section;
- controlled natural-light field;
- precise insertion inside existing fabric.

Avoid prematurely prescribing:

- exposed concrete box;
- cross-shaped light slit;
- triangular Chichu courtyard;
- lotus pond stair;
- three-part Azuma House plan;
- giant slanted wall;
- monumental concrete shell.

# 09｜RECOMMENDED DIRECTION

## Recommendation Hard Lock

Before writing the recommendation:

1. choose exactly **one Dominant Strategy**: A, B, or C;
2. optionally borrow **one limited mechanism from exactly one other strategy**;
3. explicitly mark the remaining third strategy **Rejected for Recommendation**;
4. count positive strategy families:
   - `1` → PASS
   - `2` → PASS only when one is dominant and the other contributes one limited mechanism
   - `3` → HARD FAIL
5. if the count is `3`, stop and rewrite before output.

Use exactly this structure:

```text
Dominant Strategy:
Borrowed Mechanism: NONE / one limited mechanism from one other strategy
Rejected for Recommendation:
Why:
Unresolved:
Need Verify:
```

The rejected third strategy must not re-enter later as:

- a supporting mechanism;
- a connection device;
- a spatial layer;
- a Keep item;
- a Next-step recommendation.

The recommendation must also obey two 002-specific locks:

### DNA consistency
Only DNA already listed in `Selected DNA` may support the recommendation.

### Route consistency
The dominant strategy and any borrowed mechanism must remain coherent with:

- the selected Primary Route;
- the Optional Secondary Route only if it was already justified in Period Routing.

Do not introduce a new route in the recommendation.

Never declare a final design.

# 10｜CONTEMPORARY CORRECTIONS

Every run must test the historical method against the present project.

Mandatory correction families from the original 002 source:

## Hot / humid climate
Check:
- shade;
- ventilation;
- drainage;
- anti-slip surfaces;
- moisture / mold resistance;
- material maintenance.

## Weather exposure
Contact with rain, wind, and temperature can remain a design choice.

But the project must not force elderly users, children, wheelchair users, emergency routes, or basic daily life to endure unsafe weather.

Where necessary, create an **equivalent protected path**.

## Material
Fair-faced concrete is not a default material.

Choose material according to:
- carbon;
- craft capability;
- budget;
- durability;
- local materials;
- maintenance.

## Inwardness
Internal concentration must not erase:
- community safety;
- natural surveillance;
- public accessibility;
- daily operation.

## Natural light
Directional light must be checked for:
- glare;
- heat load;
- exhibition protection;
- comfort;
- time-of-day variation.

These corrections are part of the 002 method, not optional disclaimers.

# 11｜SCHEME CRITIC

When the user provides an existing:

- plan;
- section;
- sketch;
- diagram;
- model;
- rendering;
- scheme description;

review it using the selected route and DNA.

Check:

1. Is boundary solving a real conflict, or only producing “Ando-like walls”?
2. Does the wall guide movement and perception, or merely enclose?
3. Is detour meaningful, or simply inconvenient?
4. Does a courtyard insert real weather / light / ventilation, or just copy a precedent?
5. Is compressed-to-released sequence perceptible in section?
6. Does geometry control complexity, or become a symbol?
7. Is nature framed selectively rather than decoratively piled on?
8. Is topography used in section rather than hidden by a generic object?
9. Does water extend perception for a project-specific reason?
10. Does material support light, touch, scale, craft, and maintenance?
11. Is “silence” spatially useful or just empty luxury minimalism?
12. Are climate, accessibility, drainage, safety, and operations credible?
13. Is the scheme copying a known Tadao Ando composition?

Output:

- Overall judgement
- KEEP
- CORRECT
- REJECT
- Key risks
- Next drawing / test
- Architect Confirmation Point

# 15.5｜CONCEPT IMPRESSION PROMPT CLOSE

Every **full project-analysis** response must end with one compact `建筑初印象 Prompt`.

Purpose:

- give the architect one immediate visual check after receiving the judgement;
- test whether the recommended spatial logic carries the selected Tadao Ando method trace;
- bridge into the architect's own image-generation workflow.

This is a **provisional concept-impression prompt**, not a final rendering brief and not the full Single Image Visual Handoff.

Build the prompt only from:

1. KNOWN project facts;
2. the selected Primary Route and Optional Secondary Route, translated into spatial relationships rather than historical styling;
3. `Dominant Strategy`;
4. the single allowed `Borrowed Mechanism`, if any;
5. `Selected DNA`;
6. verified climate / light / site conditions only.

## Prompt Fact Lock

Before writing the prompt, classify every concrete visual / material / tectonic statement.

A statement may enter the prompt only when it is supported by at least one of:

- `KNOWN` project facts;
- the confirmed Dominant Strategy;
- the single allowed Borrowed Mechanism;
- `Selected DNA`;
- verified site / climate / light information.

The following must remain generic unless explicitly confirmed:

- material type;
- structural system;
- façade construction;
- opening geometry / reveal depth;
- roof form;
- wall thickness;
- surface finish;
- exposed concrete / masonry / timber / steel / glass specification;
- permanent vs reversible construction method.

If a concrete visual statement cannot be traced to an allowed source above, remove or generalize it.

Examples:

- unsupported `exposed concrete` → use `material expression appropriate to verified existing conditions`
- unsupported `deep reveal` → use `opening calibrated for light, shade, glare and privacy`
- unsupported `solid concrete wall` → use `protective boundary with verified construction`
- unsupported `water plane` → remove it unless it is already part of the confirmed strategy and Selected DNA

Never use visual specificity to make the prompt feel more complete.

Hard rules:

- output one compact prompt, preferably in English unless the user requests Chinese;
- do not use `Tadao Ando style`, `in the style of Tadao Ando`, or any named Tadao Ando project;
- do not introduce the `Rejected for Recommendation` strategy;
- do not introduce unselected DNA;
- do not introduce an unselected route;
- do not invent exposed concrete, cross-shaped light, slanted walls, triangular courtyards, lotus stairs, water planes, or other iconography unless project judgement explicitly supports the underlying operation;
- describe boundary, bodily sequence, compression / release, light, weather, terrain, nature framing, and program relationships rather than stylistic symbols;
- end with a short negative constraint against direct imitation and generic Ando iconography.

Use this output label:

`建筑初印象 Prompt｜复制到你的图像生成工具即可`

The goal is to test **method trace**, not stylistic imitation.

If the user later confirms a strategy and asks for a controlled single image, use `# 12｜SINGLE IMAGE VISUAL HANDOFF`.

# 16｜FINAL RESPONSE COMPLIANCE GATE

Before emitting any full project-analysis response, validate all of the following.

## A｜First Contact
On the first full project-analysis call only:

- `MASTER FIRST IMPRESSION` is shown once;
- it remains about 120–180 Chinese characters;
- it does not become biography / style trivia;
- later Critic / Handoff responses do not repeat it.

## B｜Route
- exactly one Primary Route;
- maximum one Optional Secondary Route;
- routes deliberately not used are stated;
- no new route enters later without being selected first.

## C｜Recommendation Strategy Count
Maximum positive strategy families = **2**.

- 1 → PASS
- 2 → PASS only as one dominant + one limited borrowed mechanism
- 3 → HARD FAIL

If A, B, and C all appear positively, regenerate.

## D｜Recommendation Structure
The recommendation must contain:

- `Dominant Strategy`
- `Borrowed Mechanism`
- `Rejected for Recommendation`

If missing, regenerate.

## E｜DNA Consistency
Every named core / supporting mechanism must map to DNA already listed in `Selected DNA`.

If not, revise `Selected DNA` first and regenerate.

## F｜No Third-Strategy Re-entry
After recommendation, scan:

- Why;
- Contemporary Corrections;
- Keep;
- Next drawings;
- closing summary;
- Concept Impression Prompt.

The rejected third strategy must not re-enter as a positive mechanism.

## G｜Prompt Close
Every full project analysis ends with exactly one `建筑初印象 Prompt`.

Validate that it:

- uses only KNOWN project facts;
- uses only selected Route logic;
- uses only Dominant Strategy + optional single Borrowed Mechanism;
- uses only Selected DNA;
- excludes the rejected strategy;
- excludes named projects and `Tadao Ando style`;
- does not invent unsupported concrete / wall / light / courtyard / water iconography;
- does not introduce unverified material types, structural systems, façade construction, opening geometry, wall thickness, roof form, or surface finish;
- generalizes any concrete visual claim that cannot be traced to KNOWN / Dominant / Borrowed / Selected DNA / verified site-climate-light evidence.

If any check fails, rewrite before output.
