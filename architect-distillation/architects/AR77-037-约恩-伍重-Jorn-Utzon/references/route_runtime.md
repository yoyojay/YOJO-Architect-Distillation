# AR77-037｜PROBLEM ROUTES
## Project-Problem Routing

这些 Route 是 AR77 依据证据建立的问题路由，不是历史 Period。

## R1｜SITE_PLATFORM_PROCESSION
**Trigger**：地形 / 远景 / 主次程序 / 到达序列显著。
**核心问题**：怎样通过地面层级与路径重组体验，而不是做纪念性基座。
**Method**：topography/views → primary-secondary split → ground/platform → approach/ascent/arrival → accessibility/service validation。
**主要 DNA**：D01 / D02 / D05 / D06
**适用边界**：文化、公共、景观强场地。
**风险**：无障碍失败、巨大台阶浪费、后勤效率差。
**差异**：由 terrain + program hierarchy + approach 驱动。

## R2｜COURTYARD_COMMUNITY_CLUSTER
**Trigger**：privacy 与 community、日照、避风和共享空间同时重要。
**核心问题**：怎样用院落 / 聚落建立个人与共同体的层级。
**Method**：resident scenarios → privacy/community gradient → microclimate/view → unit-court relation → shared path/common room。
**主要 DNA**：D01 / D03 / D07
**适用边界**：住宅、社区、低层教育 / 疗养。
**风险**：院落形式化、密度 / 隐私 / 声学失败。
**差异**：由日常生活 + 社区关系 + 微气候驱动。

## R3｜ADDITIVE_GROWTH_SYSTEM
**Trigger**：真实扩展、分期、模块、预制或重复需求。
**核心问题**：怎样用有限兼容构件获得可增长、可变化但统一的系统。
**Method**：future scenarios → component family → addition/connection rules → site adaptation → procurement/tolerance → phase test。
**主要 DNA**：D01 / D04 / D08
**适用边界**：住宅、校园、机构、模块化项目。
**风险**：模块僵化、接口 / MEP / 消防失败、预留增长浪费。
**差异**：由 repeatability + growth + construction logic 驱动。

## R4｜ROOF_LIGHT_COLLECTIVE_ROOM
**Trigger**：宗教、文化、礼堂等需要特殊集体氛围。
**核心问题**：怎样让屋顶 / 天花与光成为空间秩序，而不是复制云形或壳体。
**Method**：collective activity → acoustic/light need → roof spatial role → structural options → daylight → services/maintenance。
**主要 DNA**：D01 / D05 / D06 / D08
**适用边界**：宗教、文化、会议、集会。
**风险**：曲面先行、声学 / 结构 / 设备 / 防水失效。
**差异**：由 special interior + roof/light performance 驱动。

## R5｜LIFE_EVENT_SITE_FRAME
**Trigger**：住宅 / 小型机构与具体地形、视野、风、日照和当地建造高度相关。
**核心问题**：怎样让建筑成为生活事件的框架并精确适配场地。
**Method**：daily rituals → site observation / 1:1 checking → room clusters → view/light/wind → threshold → construction feasibility。
**主要 DNA**：D01 / D05 / D07 / D08
**适用边界**：住宅、小型文化 / 公共、场所密集型项目。
**风险**：复制 Can Lis、以“现场感”代替工程控制。
**差异**：由具体生活事件 + site fit 驱动。

## Route Selection Logic
1. Primary exactly 1；Secondary = NONE / max 1。
2. Secondary 必须解决不同真实冲突。
3. R1 需要真实 terrain / approach / program hierarchy。
4. R2 需要真实 community/privacy + microclimate。
5. R3 需要真实 growth / prefab / repetition。
6. R4 需要 roof/light/acoustic 真正决定集体空间。
7. R5 需要 verified site + life patterns。
8. 未选 Route 不得回流 Recommendation / Prompt / Handoff。
