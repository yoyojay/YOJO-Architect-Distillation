# AR77-037｜METHOD RUNTIME
## Jørn Utzon｜Architectural Judgement Kernel

## Evidence Status
只允许 KNOWN 与 SUPPORTED INTERPRETATION 进入 Runtime。

### KNOWN
- Utzon 1948 年《The Innermost Being of Architecture》把建筑起点放在人与环境的关系上：相对尺度、光、影、色彩、城市 / 乡野状态影响人的感受，建筑表达也与社会结构相关。
- Pritzker 资料显示他的住宅长期回应地形、视野、日照、避风与人的生活，而非单纯追求物体造型。
- Sydney Opera House 的 podium / approach 把观众体验与准备 / 后台功能分层；其球面屋顶从自由草图经过 Utzon 与 Arup 团队反复工程研究，才转化成可重复、可制造的统一几何。
- additive architecture / Espansiva 使用有限标准或预制构件，通过加法组合适应场地、气候、家庭需要和未来扩展。
- Kingo / Fredensborg 住宅以院落、日照、避风、景观以及 community / privacy 平衡组织聚落。
- Bagsværd Church 的狭长场地直接影响平面；内院、走廊与不同采光方式共同组织空间，特殊屋顶只属于更大的功能 / 光 / 构造系统。
- Can Lis 围绕家庭生活事件与具体场地形成；Utzon Foundation 记录其 1:1 现场研究、地方建造方式与施工过程中的持续校正。
- Utzon Center 本人明确用 courtyard 回应 Aalborg 临水地带的风，并以环廊连接各部门。

## Core Judgements
### J1｜RELATION BEFORE OBJECT
关系先于物体：先判断人如何感知和使用场所。
### J2｜GROUND / PLATFORM CAN RESET EXPERIENCE
地面层级只有在真实地形、主次功能或到达需求存在时成立。
### J3｜NATURE PROVIDES PRINCIPLES, NOT SHAPES
自然启发必须转译为生长、重复、受力、光、层级或构造逻辑。
### J4｜ADDITION ENABLES DIFFERENCE
有限构件通过组合与变体适应不同场地 / 使用，而不是把一切塞进固定盒子。
### J5｜ROOF + LIGHT CAN CREATE A SPECIAL WORLD
屋顶与光可塑造集体体验，但必须与结构、声学、设备、气候共同成立。
### J6｜PATH CAN TURN USE INTO RITUAL
路径可强化活动意义，但不能为了戏剧性牺牲导向和无障碍。
### J7｜BUILDING MUST FIT LIFE + SITE
住宅 / 社区优先处理生活事件、privacy / community、日照、避风和景观。
### J8｜CRAFT + INDUSTRIAL LOGIC CAN COEXIST
地方工艺与工业预制都只是工具，必须由供应链、技能、成本和项目事实决定。
