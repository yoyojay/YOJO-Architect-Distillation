# AR77-037｜DESIGN DNA RUNTIME
## Selection
D01 mandatory；再选 1–3 个；总量 2–4。未选 DNA 不得回流。

## D01｜RELATION_TO_SURROUNDINGS
**判断含义**：从人与环境的相对尺度、光影、地形、风、视野和社会关系开始。
**Trigger**：所有完整分析。
**Spatial Operation**：建立 Site–Life Map。
**适用边界**：全部项目。
**Failure Mode**：“尊重自然”只有口号。
**可验证空间痕迹**：总平 / 剖面 / 气候 / 使用图能解释关键决策。

## D02｜PLATFORM_PRIMARY_SECONDARY_SPLIT
**判断含义**：用地面层级区分主要体验与准备 / 后勤。
**Trigger**：主次功能存在真实冲突。
**Spatial Operation**：primary-secondary → vertical relation → approach/accessibility → service routes。
**适用边界**：文化 / 公共。
**Failure Mode**：纪念性平台、巨大台阶、无障碍边缘化。
**可验证空间痕迹**：剖面清楚显示主次功能和等效可达路径。

## D03｜COURTYARD_PRIVACY_COMMUNITY
**判断含义**：院落协调个体生活、社区、气候与景观。
**Trigger**：privacy/community/sun/shelter 同时重要。
**Spatial Operation**：unit–court–shared path–common room。
**适用边界**：住宅 / 社区。
**Failure Mode**：复制 L 形户型；院落只剩视觉。
**可验证空间痕迹**：privacy gradient、日照 / 风与共享路径成立。

## D04｜ADDITIVE_COMPONENT_LOGIC
**判断含义**：少量兼容构件通过重复 / 变体 / 增长形成整体。
**Trigger**：预制、模块、扩建、重复性有现实价值。
**Spatial Operation**：component family → connection rules → variation → phase states。
**适用边界**：模块住宅、校园、机构。
**Failure Mode**：模块视觉化，接口 / 容差 / MEP / 消防失败。
**可验证空间痕迹**：构件表、连接图、阶段方案对应空间变化。

## D05｜PATH_TO_SPECIAL_PLACE
**判断含义**：到达、上升、转折、开敞和远景使活动获得意义。
**Trigger**：公共 / 宗教 / 文化或强场地中到达过程重要。
**Spatial Operation**：approach → threshold → ascent/turn → arrival → focus/view。
**适用边界**：公共 / 文化 / 住宅场所。
**Failure Mode**：为戏剧性拉长动线。
**可验证空间痕迹**：movement 与 plan-section 和使用节点一致。

## D06｜NATURAL_PRINCIPLE_TO_BUILDABLE_GEOMETRY
**判断含义**：从自然学习生成 / 受力 / 重复 / 层级，再转成统一可制造几何。
**Trigger**：复杂几何需要结构 / 制造理性化。
**Spatial Operation**：natural/structural principle → abstract geometry → repeated component rules → engineering test。
**适用边界**：复杂屋顶、重复构件。
**Failure Mode**：直接复制贝壳 / 云 / 叶片 / 翅膀。
**可验证空间痕迹**：复杂形态可由少数几何 / 构件规则解释。

## D07｜LIFE_EVENT_FRAMING
**判断含义**：建筑组织真实生活 / 集体事件，不制造独立物体。
**Trigger**：用户活动与习惯已知。
**Spatial Operation**：KNOWN events → room / threshold / view / light relations。
**适用边界**：住宅、社区、宗教、文化。
**Failure Mode**：虚构用户仪式。
**可验证空间痕迹**：关键空间可追溯到 KNOWN event。

## D08｜CRAFT_INDUSTRY_INTERFACE
**判断含义**：地方工艺、标准构件和预制可组合，但由建造条件决定。
**Trigger**：本地技能与工业系统同时相关。
**Spatial Operation**：local skill/material availability → standard component potential → interface/tolerance → mock-up。
**适用边界**：住宅、公共、预制 / 场所型项目。
**Failure Mode**：自动用石材 / 木材或强行预制。
**可验证空间痕迹**：节点 / 样段说明两类系统真实交接。

## DNA Selection Logic
D01 mandatory。D02 需真实主次程序；D03 需 privacy/community + microclimate；D04 需 growth/repetition；D05 需真实路径意义；D06 需复杂几何理性化；D07 只用 KNOWN user events；D08 需 verified skill/supply chain。未选 DNA 禁止回流。
