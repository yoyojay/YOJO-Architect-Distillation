# AR77-037｜BOUNDARIES + CONTEMPORARY CORRECTIONS

## Fit
### FIT
场地 / 地形 / 光 / 风 / 视野与人的使用关系重要；community/privacy 关键；有真实 additive/growth 条件；roof/light/collective room 是主问题；生活事件与场所适配高于图标式造型。
### PARTIAL FIT
方法可处理场所与体验，但决定性问题由超高层、特殊医疗 / 工艺 / 基础设施等其他系统主导。
### NOT FIT
唯一目标是复制 Sydney shells、Bagsværd cloud ceiling、Can Lis 石墙 / 窗洞、Kingo / Fredensborg courtyard houses，或只要求 “Utzon / Nordic organic” 外观。

## Contemporary Corrections
- **Climate**：平台、庭院、半室外、天窗 / 高侧光校正热、眩光、雨、风、结露、遮阳、能耗。
- **Accessibility**：仪式到达、平台、高差提供等效且不边缘化的无障碍体验。
- **Fire**：大屋顶、庭院群、模块增长、复杂路径验证防火分区、疏散、烟控、消防覆盖。
- **Structure**：壳体、曲面屋顶、预制肋、模块体系不得由历史类推。
- **MEP**：特殊屋顶 / 天花、模块扩展验证风管、喷淋、电气、检修与未来接入。
- **Acoustics**：宗教 / 演出 / 集会屋顶与混响、语言清晰度、背景噪声共同校正。
- **Privacy**：院落住宅 / 社区校验视线、声音、共享路径。
- **Operations**：平台分层、公共路径、院落、分期支持日常 / 高峰 / 夜间 / 后勤。
- **Maintenance**：高位屋顶、天窗、曲面、表皮、庭院排水、预制节点必须有维护路径。
- **Cost**：非标准几何、模具、预制、平台土建、复杂屋面进入成本比较。
- **Procurement**：地方工艺 / 材料与工业预制匹配供应链、技能、容差、工期。
- **Lifecycle**：additive/adaptable 系统比较扩展概率、闲置预留、替换周期、embodied carbon。

## Utzon-Specific Corrections
nature-inspired ≠ biomorphic image；platform ≠ monumental stairs；courtyard ≠ L-shaped copy；additive ≠ visible grid；roof/light ≠ cloud-vault；local craft ≠ automatic stone/timber；ritual path ≠ inconvenient circulation；site response ≠ picturesque composition。

## Collaboration Boundary
Sydney Opera House 的 shell geometry / engineering 是 Utzon 与 Ove Arup / Arup teams 的协作历史；Utzon 离开后的完成阶段包含 Peter Hall 等。客户 Runtime 不得把已完成的所有工程 / 室内 / 玻璃墙细节归给 Utzon。

## Professional Boundary
本 Skill 不能替代持证建筑师、结构、消防、MEP、声学、幕墙 / 屋面、防水、造价、景观、当地法规与施工专业责任。
