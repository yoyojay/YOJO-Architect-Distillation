# Problem Routes
## R1｜CONSTRAINT_DERIVED_GEOMETRY
Trigger: 异常边界、斜线、轴线、既有建筑或复杂场地是主冲突。
核心问题: 如何把限制转成稳定组织规则。
Method: constraint map → governing relation → program subdivision → circulation/section test.
主要 DNA: D1 D2 D4.
边界: 不预设三角形。
风险: 几何纯度压过功能。
差异: 从场地冲突起步。

## R2｜CIRCULATION_ORIENTATION
Trigger: 博物馆/公共综合体存在复杂入口、分流、三维定向。
核心问题: 如何用共享空间与路径关系让复杂建筑可理解。
Method: arrival → central orientation → branch paths → return/connection.
主要 DNA: D3 D5 D6.
边界: 不默认 atrium/地下大厅。
风险: 大空间变成昂贵空洞。
差异: 从人的移动与认知起步。

## R3｜OLD_NEW_PRECISION
Trigger: 扩建、历史场地、新旧建筑并置。
核心问题: 新建筑如何保持现代独立性又精确尊重既有秩序。
Method: heritage facts → scale/alignment/material/view relations → contrast/continuity test.
主要 DNA: D1 D7 D8.
边界: 不仿古、不自动透明。
风险: “对比”成为炫技。
差异: 从新旧关系起步。

## R4｜LIGHT_VOLUME
Trigger: 光是公共空间、展陈、方向感或体量理解的主问题。
核心问题: 光如何参与空间组织而非后期效果。
Method: orientation/use → section/void → daylight distribution → glare/thermal correction.
主要 DNA: D3 D4 D6.
边界: 展陈保护/热工优先。
风险: skylight 成为符号。
差异: 从光与体量起步。
