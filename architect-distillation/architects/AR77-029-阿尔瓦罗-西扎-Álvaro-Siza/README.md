# AR77-029｜Álvaro Siza Agent Skill Runtime FINAL v1.0

## 使用方式

你不需要先熟悉 Álvaro Siza，也不需要先学习 AI 命令。

直接告诉 Skill：
- 项目是什么；
- 在哪里；
- 谁使用；
- 最重要的问题 / 限制是什么；
- 已有哪些场地、平面、剖面、模型或任务书资料。

也可以使用 `AR77_PROJECT_INPUT_FORM_v1.0.md`。

如果信息不足，Skill 每轮只追问 1–3 个最关键问题。资料足够后，它会自动完成：

输入检查 → Fit → Project Conflicts → Route → Selected DNA → A/B/C → Comparison → Recommendation → Contemporary Corrections → Architect Confirmation → Next Drawings / Tests → 建筑初印象 Prompt。

## 本 Skill 不做什么

它不生成“Álvaro Siza style”，也不靠白墙、雕塑轮廓、标志性窗洞、楼梯或代表作几何来模拟作者。

它迁移的是：
- 从现实条件中建立问题；
- 草图—信息—模型—协作的持续校正；
- 场地 / 既有关系；
- 路径、剖面、房间、视线与光的因果组织；
- 城市连续、普通织理和多方协商。

## 单图出口

只有当用户确认策略后，才进入 `assets/SINGLE_IMAGE_VISUAL_HANDOFF.md`。  
该模块只生成一张概念验证图的交接，不是完整效果图生产。

内部研究档案、证据工作底稿、生产规则、私有测试历史与内容生产系统不随客户包交付。
