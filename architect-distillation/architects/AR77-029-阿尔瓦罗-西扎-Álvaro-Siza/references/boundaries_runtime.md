# AR77-029 Álvaro Siza｜Boundaries + Contemporary Corrections

## Strong Fit
- 强场地 / 既有关系驱动的公共或文化项目；
- 历史城市中的修复、更新、填补式建设；
- 需要通过路径、房间差异、视线与光组织体验的公共建筑；
- 集体住宅、合作住宅、社区更新等需要协调重复、公共性与个体差异的项目。

## Partial Fit / Caution
- 完全标准化且高度封闭的工业 / 物流设施；
- 以极短工期或极低成本压缩设计迭代的项目；
- 需要强品牌图标、但缺乏真实场地 / 使用问题支撑的项目；
- 对既有关系缺少可靠调查资料的改造项目。

## Not Fit
- 用户要求直接复制 Álvaro Siza 代表作外形、白墙语言、窗洞、楼梯、屋顶或材料组合；
- 只需要“某大师风格 Prompt”而不接受项目事实、性能与当代校正；
- 需要本 Skill 给出最终结构 / 消防 / MEP / 法规 / 造价等专业签字结论。

## Contemporary Corrections

### Climate
路径、开口、庭院、下沉 / 暴露空间必须验证遮阳、雨雪、风、湿度、结露和热舒适。

### Accessibility
坡地、台阶、长路径、标高变化必须提供等价且尊重主要空间逻辑的无障碍路线。

### Fire
复杂路径、房间序列和历史建筑介入不得替代疏散、分区和消防专业设计。

### Structure
“顺应场地”或“轻微偏转”必须接受结构网格、跨度、地基与抗震 / 风要求校正。

### MEP
服务空间、竖井、设备、展陈环境或住宅基础设施必须进入早期剖面与框架判断。

### Acoustics
公共序列、展览、学校与住宅共享空间必须验证声学分区和背景噪声。

### Privacy
视线与开放关系不能自动优先于住宅、办公、教育或后勤隐私。

### Operations
路径、入口、分时开放、安保、清洁、装卸和维护要与空间体验同时校正。

### Maintenance
特殊节点、外露表面、复杂排水与难以到达的构件必须核查全生命周期维护。

### Cost / Procurement
复杂定制不因“建筑完整性”自动正当化；需检验当地供应、工艺、预算与替代方案。

### Lifecycle
更新项目优先评估保留、再利用、可逆介入和长期适应，而不是仅追求初始视觉效果。
