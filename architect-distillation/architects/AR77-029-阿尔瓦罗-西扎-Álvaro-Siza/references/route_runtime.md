# AR77-029 Álvaro Siza｜Problem Routes

这些是 **Project-Problem Routes**，不是历史阶段。  
Route 只用于稳定识别项目的主矛盾，不代表西扎本人曾使用这些名称。

---

## ROUTE-01｜TERRAIN_PREEXISTENCE｜场地与既有条件转化

**Trigger**
- 地形、岩体、植被、水体、视野、既有建筑或明确场所身份强烈影响项目；
- 项目必须减少对现状的破坏，或需要通过新介入重新显现场所关系。

**核心问题**
什么必须被保留、让位、嵌入、绕开、暴露或重新连接？

**Method**
先锁定不可随意抹除的现实条件，再用剖面、到达、边界与视线建立介入。形式只能作为这些关系的结果。

**主要 DNA**
DNA-01 / 02 / 03 / 04 / 06

**适用边界**
景观 / 滨水 / 山地 / 园区 / 既有建筑旁新建 / 文化设施等。

**风险**
把“顺应场地”误解成造型仿生；或为了隐藏建筑而损害无障碍、疏散、运营和结构合理性。

**与其他 Route 差异**
本 Route 的首要因果是 **physical pre-existence**，不是城市修复、集体协商或内部展陈序列。

## ROUTE-02｜URBAN_CONTINUITY_REPAIR｜城市连续与修复

**Trigger**
- 历史街区、灾后修复、旧城更新、填补式建设、既有城市尺度与街道关系是主问题；
- 新介入必须同时保持连续性和可辨识的当代差异。

**核心问题**
哪些城市关系应该延续，哪些必须被重新组织，怎样避免“复制旧貌”或“独立物体化”？

**Method**
把街道、地块、尺度、公共空间、通行、既有构筑物与日常活动视为连续系统；新介入以关系修复为主，而非复刻历史表皮。

**主要 DNA**
DNA-01 / 02 / 04 / 07 / 08

**适用边界**
历史城市、旧城更新、城市缝补、再利用、灾后或阶段性修复。

**风险**
伪历史复制；或以“当代对比”为名破坏尺度、界面、生活和基础设施连续性。

**与其他 Route 差异**
本 Route 的首要因果是 **urban continuity**，不是自然地形或单体内部路径。

---

## ROUTE-03｜COLLECTIVE_HOUSING_NEGOTIATION｜集体居住与协商

**Trigger**
- 社会 / 集体住宅、合作社、社区更新、多主体住房；
- 用户差异、预算、重复单元、公共空间、分期或参与式沟通同时存在。

**核心问题**
怎样让重复住宅既保持经济与构造秩序，又允许个体生活、集体空间和长期变化存在？

**Method**
先建立可重复的城市 / 住宅框架，再通过门槛、街巷、院落、公共空间、户型差异与协商机制调节“共同”与“个体”。

**主要 DNA**
DNA-01 / 05 / 07 / 08

**适用边界**
住房、合作社区、长期增量开发、社区再生。

**风险**
把历史上的参与机制浪漫化；忽略今天的产权、可达性、维护、消防、成本和运营现实。

**与其他 Route 差异**
本 Route 的首要因果是 **multiple actors + ordinary repetition**，而不是景观适配或展览式空间序列。

---

## ROUTE-04｜INSTITUTIONAL_SEQUENCE｜公共机构与空间序列

**Trigger**
- 美术馆、学校、文化 / 公共设施、宗教或教育建筑；
- 多种房间、展示 / 学习 /公共活动、不同尺度和路线需要被组织。

**核心问题**
怎样让路径、房间差异、视线、停顿与光线共同形成清晰但不单调的使用秩序？

**Method**
把到达和内部运动作为项目结构之一；通过房间差异、轴线 / 偏转、开口、视线与光建立连续但可变化的序列。

**主要 DNA**
DNA-01 / 04 / 05 / 06 / 08

**适用边界**
博物馆、学校、公共文化建筑、复合公共设施。

**风险**
把“序列”做成戏剧化造型；或为了空间体验牺牲展陈、声学、无障碍、消防和运营效率。

**与其他 Route 差异**
本 Route 的首要因果是 **programmed movement through differentiated rooms**。

# Route Selection

1. 先找 **Primary Conflict**，只选一个 Primary Route。
2. 若项目确有第二个独立冲突，可标一个 `Secondary Route`，但它不能与 Primary Route 争夺主因果。
3. Route 选择必须写出：
   `Trigger → Project Evidence → Why This Route → Why Not the Others`
4. 若没有足够事实，Route = `NEED VERIFY`，不得靠建筑师名气或项目类型自动指定。
