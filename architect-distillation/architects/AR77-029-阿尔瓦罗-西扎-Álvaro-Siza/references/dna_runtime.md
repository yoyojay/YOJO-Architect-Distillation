# AR77-029 Álvaro Siza｜Runtime DNA

DNA 是可迁移的空间判断机制，不是形式部件。  
没有固定“全部使用”的要求；每次只选择解决当前项目冲突所必需的 DNA。

---

## DNA-01｜现实转化｜Situation Transformation
**判断含义**：设计从现有问题和限制出发，不从独立造型出发。  
**Trigger**：项目有明确场地、程序、既有、城市或运营矛盾。  
**Spatial Operation**：把关键条件转成位置、边界、邻接、尺度、路径或剖面约束，再生成空间。  
**适用边界**：所有 Route。  
**Failure Mode**：把“回应”做成文字解释，空间仍是预设造型。  
**可验证空间痕迹**：至少有一项主要空间关系能追溯到一个真实项目条件。

## DNA-02｜保留—显现既有｜Preserve and Reveal
**判断含义**：不是保存一切，而是识别哪些现状关系值得继续发挥作用。  
**Trigger**：存在地形、植被、旧建筑、街巷、视线、城市尺度或其他高价值既有。  
**Spatial Operation**：保留、绕开、嵌入、让位、框取、连接或重新暴露关键既有。  
**适用边界**：Terrain / Urban Repair。  
**Failure Mode**：形式化“尊重场地”，实际大量清除；或把所有现状都冻结。  
**可验证空间痕迹**：总图 / 剖面能看出既有与新介入的明确关系。

## DNA-03｜剖面贴合｜Sectional Fit
**判断含义**：地面高差、城市标高和视野通过剖面解决，而非仅靠平面几何。  
**Trigger**：坡地、复杂标高、视线保护、半地下、分层公共关系。  
**Spatial Operation**：移动层高、入口、平台、坡道、局部下沉或抬升，使建筑与地面形成可读关系。  
**适用边界**：Terrain / Urban Repair / Institutional。  
**Failure Mode**：为了“嵌入”制造不必要的高差和无障碍冲突。  
**可验证空间痕迹**：剖面可说明到达、地面、视线与主要空间的因果关系。

## DNA-04｜路径编排｜Path as Project
**判断含义**：路径承担空间实体化作用，而非完成平面后再补交通。  
**Trigger**：到达、游览、学习、公共使用或场地体验存在时间序列。  
**Spatial Operation**：组织压缩 / 展开、转折 / 停顿、看见 / 暂时遮蔽、分流 / 汇合。  
**适用边界**：Terrain / Urban Repair / Institutional。  
**Failure Mode**：把路径做成戏剧化迷宫或低效绕行。  
**可验证空间痕迹**：路径图与剖面能标出至少三个因功能或场所需要而产生的序列节点。

## DNA-05｜差异化房间｜Differentiated Rooms
**判断含义**：空间不必等质化；不同房间可因使用、尺度、方向和联系产生差异。  
**Trigger**：多种公共 / 展示 / 学习 / 居住需求需要不同强度的空间。  
**Spatial Operation**：调整房间尺度、邻接、方向、层高、入口关系和连接方式。  
**适用边界**：Institutional / Collective Housing。  
**Failure Mode**：无理由地制造形状差异；或为“灵活”牺牲明确房间性能。  
**可验证空间痕迹**：房间差异与具体使用需求一一对应。

## DNA-06｜视线与光校准｜Calibrated View and Light
**判断含义**：视线、开口和光只在有明确空间任务时被引入。  
**Trigger**：需要方向感、景观关系、展陈光、遮阳、视觉联系或重点空间。  
**Spatial Operation**：通过位置、朝向、遮挡、采光深度和视线终点调节光与观看关系。  
**适用边界**：Terrain / Institutional；其他 Route 仅在项目事实支持时。  
**Failure Mode**：自动生成“西扎式窗口”、天窗或白色采光空间。  
**可验证空间痕迹**：每个主要开口 / 采光动作都能说明其功能、气候或空间理由。

## DNA-07｜普通城市织理 + 精确差异｜Ordinary Fabric, Precise Difference
**判断含义**：重复、日常和普通城市元素可以承担建筑质量，不必转成图标。  
**Trigger**：住房、街区、填补式建设、重复模块或城市更新。  
**Spatial Operation**：保持尺度、街道、重复与连续性，同时在门槛、公共空间、转折、局部体量或使用关系上做必要差异。  
**适用边界**：Urban Repair / Collective Housing。  
**Failure Mode**：沦为无差别复制；或反过来用夸张造型证明“新”。  
**可验证空间痕迹**：重复系统可读，差异位置与实际城市 / 使用问题相对应。

## DNA-08｜可协商的稳固框架｜Negotiated Robust Framework
**判断含义**：在多方约束中先建立稳定空间秩序，再容纳使用、展陈、住户或时间变化。  
**Trigger**：多利益主体、变化程序、分期、可变展陈、居住差异或运营复杂。  
**Spatial Operation**：固定必须稳定的通行、结构性邻接、公共空间和服务逻辑；让可变部分保持调整余地。  
**适用边界**：Collective Housing / Institutional / Urban Repair。  
**Failure Mode**：把“可变”误解成一切都可移动；或把协商简化成平均化。  
**可验证空间痕迹**：图纸可区分“必须稳定”与“允许变化”的空间层。

# DNA Selection Logic

1. 先选一个 `Primary DNA`，它必须直接回应 Primary Conflict。
2. 其余 DNA 只有在解决**不同的独立冲突**时才可加入。
3. 不设统一固定数量；使用“最小充分集”。若两个 DNA 解决同一问题，保留因果更直接者。
4. 每条 Selected DNA 必须输出：
   `Project Trigger → Spatial Operation → Expected Trace → Boundary / Risk`
5. 未选 DNA 不得在 Strategy、Recommendation、Prompt、Critic 的正向建议中回流。
6. 若后续证明某未选 DNA 必需，先更新 Selected DNA，再重算受影响的 Strategy 与 Recommendation。
