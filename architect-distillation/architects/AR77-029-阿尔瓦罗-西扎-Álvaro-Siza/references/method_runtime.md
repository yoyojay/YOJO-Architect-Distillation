# AR77-029 Álvaro Siza｜Runtime Method

## 1｜Method Kernel

本 Runtime 把 Álvaro Siza 可迁移的方法压缩为一条判断链：

**现实处境 → 早期草图搜索 → 场地 / 既有关系读取 → 信息与协作校正 → 路径 / 剖面 / 房间组织 → 光与视线校准 → 细部与性能验证 → 再次修正**

核心不是先确定形式，而是把项目当作一个正在变化的现实处境。设计从不完整信息中启动，但不能停留在直觉；草图、测量、模型、协作者信息和专业条件必须不断交叉，直到空间关系变得具体且可检验。

## 2｜Repeated Judgements

### 2.1 Situation before signature
先问：这个项目真正面对什么问题、什么地方、什么既有关系、什么限制？  
差异来自项目与场所，而不是建筑师主动追求“每次换一种造型”。

### 2.2 Transform rather than invent from zero
新建筑不是清空背景后的独立对象。优先识别哪些现状、城市关系、地形、使用方式或日常结构值得保留、转化、连接或重新显现。

### 2.3 Start early, then correct rigorously
草图可以早于完整分析启动，它的角色是搜索，不是宣布答案。随着资料进入，初始想法必须允许被推翻、缩减、移动、旋转、切开或重新组织。

### 2.4 Movement materializes the project
路径不是后加的交通线。抵达、停顿、转折、压缩、展开、视线出现与消失，都可以成为空间组织的因果链。

### 2.5 Spatial difference serves program and experience
房间、尺度、层高、位置和联系不需要被统一成一个抽象系统。差异应来自使用、序列、光线、视线、邻接和场地关系。

### 2.6 Light and view are calibrated decisions
需要遮阳就处理遮阳；需要视线就建立视线。开口、天光、窗、遮蔽都必须对应明确问题，不能作为“西扎符号”自动出现。

### 2.7 Architecture coordinates knowledge
建筑判断必须协调场地、程序、使用者、城市、结构、环境、法规、施工和运营。建筑师不是用造型覆盖冲突，而是把冲突转成可验证空间关系。

### 2.8 Ordinary fabric matters
住宅、街道、重复单元、日常城市组织不低于“纪念性建筑”。重复与普通可以通过尺度、门槛、公共空间、转折和细部获得质量，而不需要靠图标化造型。

## 3｜What Transfers

可迁移：
- 从现实条件和矛盾中建立问题；
- 通过草图快速提出假设，再用精确信息修正；
- 用场地、剖面和既有关系限制形式任意性；
- 用路径和时间序列组织体验；
- 让房间差异、视线与光服务具体使用；
- 在城市连续性与必要差异之间建立关系；
- 在多方参与 / 多专业输入中持续协调。

不可迁移：
- 固定白色材料；
- 特定窗洞、曲墙、屋顶、楼梯或雕塑轮廓；
- 代表作的平面几何或空间构图；
- 把“极简”当作默认结果；
- 把任何具体材料或结构体系当作无条件偏好。

## 4｜Contemporary Correction Principle

历史方法进入今天必须继续接受：
climate / accessibility / fire / structure / MEP / acoustics / privacy / operations / maintenance / cost / procurement / lifecycle 的校正。

若校正改变原始直觉，优先保留**方法因果**，而不是保留视觉结果。
