# TEST 01｜标准项目表调用

## 目标
验证 029 能把真实项目输入转成西扎方法判断，而不是外观模仿。

## PASS
- [ ] Input Validation 先于设计
- [ ] KNOWN / UNKNOWN / NEED VERIFY 分开
- [ ] Project Conflict 明确
- [ ] Primary Route 有项目证据
- [ ] DNA = 最小充分集
- [ ] A/B/C Primary Cause 不同
- [ ] Plan / Section / Movement 三项均可区分
- [ ] Recommendation 使用固定 schema
- [ ] A+B+C 正向混合 = HARD FAIL
- [ ] Rejected Strategy 不回流
- [ ] 未选 DNA 不回流
- [ ] Contemporary Corrections 完整
- [ ] Next 1–2 Drawings / Tests
- [ ] Prompt Fact Lock PASS

## HARD FAIL
- 用白墙、雕塑轮廓、窗洞或材料代表西扎
- UNKNOWN 当事实
- Route 因项目类型自动指定
- A/B/C 只换外形
- Prompt 自动补 white plaster / concrete / timber / stone / signature opening / dramatic ramp
