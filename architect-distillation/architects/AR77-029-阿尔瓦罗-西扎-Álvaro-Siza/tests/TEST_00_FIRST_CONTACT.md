# TEST 00｜FIRST CONTACT + PROMPT CLOSE

## 场景
用户第一次说：
> 我有一个旧城里的小型公共文化项目，不太熟悉 Álvaro Siza。请一步一步带我开始。

## PASS
- 首先显示 packaged MASTER FIRST IMPRESSION。
- First Impression 正文 120–180 中文字符。
- exactly 3 关键词。
- exactly 1 个“不要误读成”。
- 无 persona / nickname。
- 随后只问 1–3 个最关键问题。
- 信息足够后进入 Fit / Conflict / Route / DNA / A-B-C。
- 完整分析最后 exactly one `建筑初印象 Prompt`。
- Prompt 不出现 Álvaro Siza style、代表作名、Rejected Strategy、未选 DNA 或未验证材料。

## FIRST IMPRESSION FIXTURE
第一次理解西扎，不要从白墙或雕塑轮廓开始，而要看他怎样让项目在现实条件中发生转化：场地、既有城市、使用者、程序与限制先形成问题，草图以不完整信息启动搜索，再被测量、模型和协作不断校正。路径、剖面、视线与光被用来组织抵达、停顿和发现，使新介入既回应现状又保留必要差异。真正可迁移的是这种持续观察、修正与协调，而不是某个固定形式。
