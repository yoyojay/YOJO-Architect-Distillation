# SINGLE IMAGE VISUAL HANDOFF
## AR77-029｜Álvaro Siza 单张概念视觉验证

### 定位
只把**已经确认的建筑判断**交给一张概念验证图。  
不是整套效果图，不是多视角系统，不是新的设计阶段。

### 启动条件
- 已完成项目分析；
- 用户已确认 Dominant Strategy；
- Selected DNA 已确认；
- Spatial Locks 已确认；
- 用户明确要求单张概念视觉验证。

## 01｜Confirmed Strategy
仅写已确认 Dominant Strategy。

## 02｜Route / Method
仅写已选择的 Primary Route；Secondary Route 只有在已确认时进入。

## 03｜Selected DNA
只列已确认 DNA。

## 04｜Confirmed Facts
只继承 KNOWN + verified site / climate / light。

## 05｜Spatial Locks
必须在图中可见的关系，例如：
- 新介入与既有场地 / 城市关系；
- 到达与路径序列；
- 平面 / 剖面必须维持的关系；
- 房间差异或公共 / 私密边界；
- 已验证视线 / 光任务。

不得把关系翻译成未经确认的材料、结构或几何事实。

## 06｜Must Not Drift
- 不使用 `Álvaro Siza style`；
- 不引用任何代表作作为视觉目标；
- 不复制已知窗洞、屋顶、楼梯、墙体、几何、材料组合或空间构图；
- 不新增未确认材料、结构、立面、开口、屋顶、景观、家具；
- Rejected Strategy 与未选 DNA 不得回流。

## 07｜Single Demonstration Image Prompt
只使用：
confirmed facts + selected Method / Route + Dominant Strategy + optional one Borrowed Mechanism + Selected DNA + verified site / climate / light。

Prompt 必须展示**空间因果**，而不是作者风格。

## 08｜Negative Constraints
只写与当前项目判断直接相关的负向约束。

## 09｜Handoff
> 这是一张概念验证图，用于检查已确认的空间判断进入视觉后是否成立。它不代表完整效果图体系，也不得新增设计事实。后续完整视觉生产应进入项目原有可视化流程或专门视觉系统。
