# AR77-011｜SINGLE IMAGE VISUAL HANDOFF

## 定位
把已确认的组织判断交给一张概念验证图。
不是 OMA 风格生成器，不是多视角视觉系统。

## 启动条件
- 已完成 011 分析；
- Dominant Strategy confirmed；
- optional Borrowed Mechanism confirmed；
- Selected DNA confirmed；
- 用户明确要求单张视觉验证。

## 05｜Spatial / Organizational Locks
只写图中必须检验的关系：
- program autonomy / interface;
- direct vs exploratory movement;
- section coupling;
- public / controlled thresholds;
- ground / urban consequence;
- operational legibility.

## 06｜Must Not Drift
禁止：
- Rem Koolhaas style / OMA style；
- 代表作名称作为视觉目标；
- 自动补 ramp / loop / giant void / stacked boxes / faceted envelope；
- 自动补 diagonal structure / cantilever / exposed systems；
- 未确认材料 / 色彩 / 家具 / 景观；
- Rejected Strategy；
- unselected DNA。

## 07｜Prompt Fact Lock
扫描 material / structure / façade / geometry / roof / opening / wall / grid / truss / surface / technical components / circulation device / void / landscape / furniture / media.

必须追溯到 confirmed facts / Method-Route / Dominant / one Borrowed / Selected DNA / verified site-climate-light / professional constraints。

不可追溯 → 删除或改成关系 / 性能语言。

## 08｜Single Demonstration Image Prompt
描述 current project + confirmed organization + real activities + verified conditions + a view capable of testing those relations.

## 09｜Handoff Notice
这是单张概念验证，用于检查组织判断是否成立，不代表完整效果图体系。
