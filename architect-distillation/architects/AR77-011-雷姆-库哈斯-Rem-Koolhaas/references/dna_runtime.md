# AR77-011｜Design DNA Runtime

Select 3–5. D02 normally mandatory in full analysis.

## D01｜PROGRAM INVENTORY
Meaning: treat program as activities with behavior, not room labels.
Trigger: mixed brief.
Operation: classify publicness/time/acoustics/privacy/logistics/change.
Boundary: do not invent behavior.
Failure: room list simply gets recolored.
Trace: program matrix changes adjacency decisions.

## D02｜CONFLICT MAP
Meaning: identify real incompatibilities and useful simultaneities.
Trigger: competing demands.
Operation: map must-separate / may-overlap / should-connect.
Boundary: conflict is not automatically positive.
Failure: manufactured complexity.
Trace: strategy clearly answers named conflicts.

## D03｜AUTONOMY + CONNECTION
Meaning: distinct programs can remain autonomous while sharing selected interfaces.
Trigger: different users/hours/security.
Operation: stable zones + shared connectors / interfaces.
Boundary: fire/privacy/security.
Failure: everything becomes one continuous field.
Trace: access and operational diagrams show independent and shared use.

## D04｜IN-BETWEEN CAPACITY
Meaning: transitions can carry social / public / informal program.
Trigger: major autonomous zones need exchange.
Operation: assign thresholds / lobbies / terraces / circulation zones actual programmatic roles.
Boundary: does not imply atrium or leftover space.
Failure: residual circulation marketed as public space.
Trace: in-between zones have users, time patterns and performance requirements.

## D05｜TRAJECTORY AS ORGANIZER
Meaning: movement can structure program sequence.
Trigger: exhibition/learning/civic routes.
Operation: connect meaningful destinations in deliberate order.
Boundary: direct everyday access remains available where needed.
Failure: forced detour.
Trace: route map demonstrates actual adjacency / experience gain.

## D06｜SECTIONAL COUPLING
Meaning: vertical relation can connect uses that flat zoning separates.
Trigger: dense site / multi-level program.
Operation: stack, overlap, reveal or bridge programs according to conflict map.
Boundary: structure/fire/acoustics/accessibility.
Failure: dramatic section with no program benefit.
Trace: section names every useful vertical relation.

## D07｜TYPOLOGY MUTATION
Meaning: challenge an inherited type when its assumptions fail.
Trigger: conventional type produces conflict.
Operation: identify failed assumption and replace organizational rule.
Boundary: do not mutate merely for novelty.
Failure: strange form, same old operation.
Trace: type before/after diagram shows measurable functional change.

## D08｜SYSTEM / OBJECT REVERSAL
Meaning: sometimes infrastructure / organization should dominate object composition.
Trigger: large mixed project / urban system.
Operation: define flows, shared systems, ground, void or service logic before object silhouette.
Boundary: public legibility and local scale remain required.
Failure: architecture becomes infrastructural abstraction.
Trace: system diagram predicts building relation and ground behavior.

## D09｜OPERATIONAL LEGIBILITY
Meaning: complexity must remain usable.
Trigger: multiple users/times/routes.
Operation: distinguish direct / exploratory / service / emergency routes and operating zones.
Boundary: signage cannot rescue a fundamentally confusing plan.
Failure: “productive confusion.”
Trace: user scenarios work without hidden assumptions.

## D10｜MULTIPLE SPEEDS
Meaning: different users can move through the same project at different speeds / purposes.
Trigger: destination + browsing / event + everyday.
Operation: provide direct and optional extended paths.
Boundary: no penalty to accessibility or essential access.
Failure: everyone forced into spectacle.
Trace: movement map shows optionality.

## D11｜URBAN CONSEQUENCE
Meaning: large architecture changes public ground, flows and density.
Trigger: civic / campus / district / transport project.
Operation: test ground continuity, edges, access, publicness, infrastructure.
Boundary: equity / ecology / displacement.
Failure: iconic object ignores city.
Trace: site diagram shows effect outside parcel boundaries.

## D12｜STRATEGIC NON-INTERVENTION
Meaning: not every existing condition requires redesign.
Trigger: reuse / ordinary fabric / limited budget.
Operation: preserve capable areas and intervene at bottlenecks.
Boundary: neglect is not strategy.
Failure: aestheticized rawness or unresolved defects.
Trace: retained/altered/added map with performance rationale.
