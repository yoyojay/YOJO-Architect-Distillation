# AR77-011｜Decision Rules Runtime

## Fact Lock
When a program or site fact is absent → keep UNKNOWN → because diagram confidence is not factual confidence → verify with brief/user → if unresolved, use conditional language.

## Fit
When complexity is real and organizational → test FIT → because this Method works through program/conflict/system → verify actual incompatibilities → if complexity is invented, downgrade.

## Conflict
When two demands compete → state what must remain separate / may overlap / should connect → because conflict mapping precedes form → verify with user/operations → if unclear, do not design the interface.

## Route
When one conflict dominates → choose one Primary Route → because routes must stabilize causality → verify trigger/boundary → if mismatch, reroute.

## DNA
When a DNA lacks a spatial trace → remove it → because concepts without evidence invite style imitation → verify in plan/section/movement/system.

## Strategy
When strategies differ only by form → FAIL → because causality must differ → identify which organizational rule carries each → if same, regenerate.

## Plan–Section–Movement
When a diagram claims organization → prove all three → because a graphic abstraction is not architecture → if one contradicts the others, return to Method.

## Operations
When exploratory movement conflicts with direct access/service/security → keep direct operational route → because everyday use cannot depend on spectacle → verify user scenarios.

## Performance
When programmatic ambition conflicts with fire/accessibility/climate/acoustics/structure → prioritize contemporary performance → verify professionally → mark NEED VERIFY.

## Recommendation
When one strategy solves the dominant conflict most coherently → choose it alone → because recommendation is not collage → if it needs both other strategies, return to Comparison.

## Critic
When a scheme looks OMA-like → ignore resemblance → test program/conflict/device causality → if absent, reject style evidence.

## Failure Return
When Prompt contains unsupported ramp/loop/void/facet/structure/material → delete/generalize → rerun Fact Lock.
