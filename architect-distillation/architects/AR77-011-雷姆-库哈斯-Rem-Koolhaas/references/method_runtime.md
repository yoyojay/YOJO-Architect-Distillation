# AR77-011｜Rem Koolhaas Method Runtime

## Evidence Basis
Customer runtime uses only distilled mechanisms supported by authoritative project / institutional evidence.

### KNOWN
- OMA identifies Rem Koolhaas as a founder and as co-head of OMA and AMO, with AMO operating beyond architecture.
- OMA describes Seattle Central Library as five stable program platforms plus four flowing in-between planes.
- OMA describes Educatorium as two folded planes interlocking into a single trajectory connecting distinct university programs.
- OMA describes CCTV Headquarters as an alternative to the traditional skyscraper typology.
- OMA describes Euralille as a masterplan coordinating an enormous mixed program of station, shopping, offices, parking, hotels, housing, concert and congress uses.
- OMA describes Maison à Bordeaux through three differentiated levels connected by a moving platform that becomes part of occupation.
- Pritzker's jury citation emphasizes the intensity of thought behind different scales and programs rather than one universal formal model.

### SUPPORTED INTERPRETATION
Across these sources, a transferable design chain is:

`conditions / forces`
→ `program inventory`
→ `conflict + simultaneity`
→ `question type`
→ `organizational device`
→ `plan + section + movement`
→ `urban / operational consequence`
→ `retain useful contradiction`
→ `contemporary correction`

This chain is a Factory interpretation, not a quotation.

## Runtime Tests

### Condition Scan
List actors, activities, timing, access, logistics, infrastructure, inherited form and city pressures.

### Program Matrix
Classify every major use by:
- publicness;
- duration;
- acoustic intensity;
- privacy;
- service dependence;
- change frequency;
- adjacency;
- conflict.

### Typology Challenge
Write:
`The inherited type assumes ________.`
`This project contradicts that because ________.`
If no meaningful contradiction exists, do not mutate the type.

### Device Test
Name one organizational device in relational terms.
If it can only be named as a shape, it is premature.

### Diagram-to-Space Test
Prove the device in plan + section + movement + operation.

### Urban Consequence Test
For public / large projects, state impact on ground, edge, access, density and infrastructure.

### Contradiction Test
Identify which differences should remain visible rather than be homogenized.
