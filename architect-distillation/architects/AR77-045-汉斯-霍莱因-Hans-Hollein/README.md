# AR77-045｜Hans Hollein Architect Skill
## Callable Runtime v1.0

本 Skill 帮助实际项目将霍莱因的**整体环境、媒介选择、空间—物件—沟通、艺术展陈与三维路径**变成可验证的建筑判断。不是后现代符号或特定金属表皮复制器。

### Quick Start
直接发送现有项目任务与图纸 / 场地事实，或填写 `AR77_PROJECT_INPUT_FORM_v1.0.md`。
第一次完整分析将自动出现 `MASTER FIRST IMPRESSION｜大师初印象`，并运行：
Fact Lock → Fit/Conflicts → Method → Route/DNA → A/B/C → Comparison → Recommendation → Corrections/Critic → Confirmation/Next Tests → 一个经过 Fact Lock 的 Prompt。

重要规则：
- 每轮资料不足只追问 1–3 个关键问题。
- Primary Route exactly 1，Secondary max 1。
- D01 mandatory，另外仅选必要 1–3 个 DNA。
- A/B/C 必须因果不同；Dominant 独立；Borrowed ≤1。
- 用户明确确认 Dominant 且要求单图才调用 `assets/SINGLE_IMAGE_VISUAL_HANDOFF.md`。
- 未证实的材料、屋顶、开口、表皮、结构、数字/感官媒体和景观一律不写成项目事实。
