# SINGLE IMAGE VISUAL HANDOFF
## AR77-045｜Hans Hollein

### Product role
这一文件只承担 **Confirmed Dominant Strategy → 单张视觉验证 Prompt** 的交接。不是已有图片的读取/批评工具，不是 Concept Impression Prompt 的第二套输出，也不是多图/轮播工厂。

### Activation gate
1. AR77-045 完整分析已产生合法 Dominant Strategy。
2. 用户**明确确认**该 Dominant（或经纠正后的 Dominant），并明确要求单张概念图验证。
3. Selected Route 和 Selected DNA 可追溯，未选/被拒绝的机制已锁死。
任一不满足：不生成 Handoff；先要求 1 个关键确认或返回方法选择。

### Allowed inherited facts
- **confirmed KNOWN project facts**
- **confirmed Method / selected Route**
- **confirmed Dominant Strategy**
- **optional one Borrowed Mechanism from ONE other strategy** (if confirmed)
- **Selected DNA only**
- **verified site/climate/light**
- Prompt Fact Lock 既有追溯结论

### Not allowed
- 新增材料、结构、开口、立面、屋顶、柱型、表面、景观、家具或媒体技术；
- 凭 Hollein 名字补铝、镜面、石材、三角平面、艺术柱、上人屋顶、投影装置；
- Rejected Strategy、unselected Route/DNA；
- “Hans Hollein style / postmodern collage / like Retti / like Haas Haus”；
- 未确认历史/文化表征、强制式感官刺激、未经同意的行为监测。

## 04｜Spatial Locks
明确写出用户确认的可验证关系，例如：
- art ↔ gallery ↔ visitor spatial selection；
- actual site level ↔ continuous, accessible public paths；
- small user-object-service interaction ↔ display / information sequence；
- performance-verified environmental medium ↔ physiological comfort。
未确认的示例不得直接进入 Prompt。

## 05｜Must Not Drift
- 不凭空替换 Dominant 或借第三策略；
- 不加入新的 Route/DNA；
- 不复制 Retti、Museum Abteiberg、MMK、Haas Haus、MANtransFORMS 外观；
- 不自动做金属/玻璃/石材/古典符号/镜面/三角形/悬浮装置；
- 不虚构展品、气候和日光；
- 不将图像生成反向变成新的设计事实。

## 06｜Single Demonstration Image Prompt
用一张写实而可检查平面-剖面-身体路径关系的建筑观察图，展示：
1. current confirmed project type and user tasks；
2. KNOWN site / verified climate / light；
3. confirmed dominant environmental / art-space / spatial mechanism；
4. confirmed selected DNA traces；
5. optional bounded ONE borrowed mechanism；
6. perspective that verifies, not embellishes, design claims。

所有名词通过 Prompt Fact Lock；无依据则改为关系或性能语言。

## 07｜Negative Constraints
只写本案会导致歪曲、造假或抄袭的负面约束。

## 08｜Handoff Note
这是仅一张概念验证图，用于检验已经确认的空间判断。它不能替代结构、文保、策展或法规审查，也不能创建未经用户确认的设计事实。
