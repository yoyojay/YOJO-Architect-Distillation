# TEST_01｜Standard Project Input / Conditional Runtime Trace

### Fictional test fixture (for QA only, not as historical fact)
用户：`某现有坡地文化建筑改造，现状入口和城市步行路径存在高差，需连接两处公共展厅。已测绘，但展品光敏性未核实。希望给出 A/B/C。`

### Expected
- KNOWN: 坡地、高差、公共展厅需求。NEED VERIFY: 明确坡度数据、藏品照度、结构/消防/文保。
- Project Fit 给可反驳理由；3–5 项冲突。
- R3 可作为 Primary；若博物馆/策展触发充分 R2 可作为 Secondary max1。
- D01 mandatory；另外只选必要 DNA，总量 2–4，选中例如 D07 与 D05 的前提须展示；未选 D06 不得偷返。
- 三案空间因果不同：地形公共连接/等效路线/空间序列的不同逻辑，不是三种表皮。
- 每案 Plan / Section / Movement / Medium / Performance trace + Benefits/Risks/Need Verify。
- 同维 Comparison，Recommendation 恰有：
  Dominant Strategy:
  Borrowed Mechanism:
  Rejected for Recommendation:
  Why:
  Unresolved:
  Need Verify:
- Dominant 独立成立；Borrowed max 1 mechanism from one other; third/rejected no reentry。
- Corrections 12 项 + art care / accessibility / public realm；Next Tests 1–2。
- exactly one `建筑初印象 Prompt`，只允许已知/选中/已验证事实，无 Retti 金属、Haas 曲线、Abteiberg 屋面默认。
- Handoff 不触发，除非用户明确确认 Dominant 并要求单图。

### Hard failures
未核实展品即给固定采光/吊挂；复制 Abteiberg；Prompt 拿已拒策略的构件；使用自动多图。
