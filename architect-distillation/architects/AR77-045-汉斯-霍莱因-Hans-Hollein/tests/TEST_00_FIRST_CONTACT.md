# TEST_00｜First Contact + First Impression

### Test fixture
用户：`我是做一个带展厅与小型零售入口的现有建筑改造，项目资料还不齐。想试试霍莱因。`

### Expected Runtime
- 不从“霍莱因风格”推断材料或媒体设备。
- 不足时只问 1–3 个最会改变 Fit/Route 的问题。
- 首次信息达到完整分析门槛时，输出 First Impression **正文 120–180 汉字**；**exactly 3** 关键词；**exactly 1** `不要误读成…`。
- 若已有完整项目输入，无须再次询问。
- 仅第一次综合分析展示 First Impression；Critic/第二轮不重复。

### Fail signals
空标题/摘要壳/造型包/未计数字数/多个误读句/4 个关键词。
