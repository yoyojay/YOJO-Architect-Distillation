# AR77-045｜DNA RUNTIME
## Hans Hollein｜可迁移判断机制（AR77 命名，非本人固定分类）

### DNA Selection Logic
- D01 `TOTAL_ENVIRONMENT_ORIENTATION` mandatory，理由：本人《Alles ist Architektur》的核心命题。
- 另外根据真实项目问题选择 1–3 个，总计 **2–4**；没有充分触发则先求证。
- 每个 Selected DNA 必须注明 `Name / Judgement / Trigger / Spatial Operation / Boundary / Failure Mode / Verifiable Trace`。
- 未选 DNA 与未选 Route 不得回流 Strategy / Recommendation / Keep / Next / Prompt / Handoff；若发生新证据，先重新选择，再重算策略。
- DNA 是候选机制，不是色彩、材质、外形的默认许可。

### D01｜TOTAL_ENVIRONMENT_ORIENTATION｜整体环境而非孤立造型
**判断含义**：以用户的身体、心理、信息与社会处境为设计问题，而不是先定义建筑物体。
**Trigger**：所有完整项目分析。
**Spatial Operation**：绘制 user/setting → physical, sensory, communication needs → spatial/performance map。
**适用边界**：任意项目；无法确定人群或问题时仅建立 NEED VERIFY。
**Failure Mode**：泛化口号“Everything is Architecture”，没有真实使用与性能目标。
**可验证空间痕迹**：至少一个平剖/路径/环境决策可追溯到已知人群需求。

### D02｜MEDIUM_FIT_TEST｜介入媒介适配测试
**判断含义**：建筑实体、光、声音、温度、信息与活动编排皆可能改变环境；应比较何者必要且适度。
**Trigger**：环境问题确实有多种解决媒介。
**Spatial Operation**：built vs non-built option matrix → interfaces → energy / maintenance / consent audit。
**适用边界**：公共室内、更新、临设；受专业法规与用户自主权限制。
**Failure Mode**：为追逐前卫而叠加不必要媒体、数据采集或感官刺激。
**可验证空间痕迹**：清楚标明各媒介对空间、设备、行为及能耗的贡献。

### D03｜MULTISENSORY_CALIBRATION｜多感官校准
**判断含义**：触觉、视觉、声学与体感不是图像后期效果，而是环境性能/认知组成。
**Trigger**：光、声、触感或热舒适显著影响人群。
**Spatial Operation**：sensory priorities → section / surfaces / light-source / acoustic-thermal zoning → tests。
**适用边界**：博物馆、零售、公共室内、教育文化；不鼓励无同意的刺激。
**Failure Mode**：眩光、噪声、过度嗅觉刺激、排斥神经多样性使用者。
**可验证空间痕迹**：照度、混响、可达、热舒适与使用路径有明确验证表。

### D04｜COMMUNICATIVE_RITUAL_SPACE｜沟通与仪式的空间职责
**判断含义**：建筑可传达意义并承载事件，但表达必须与身体使用和公共理解共同成立。
**Trigger**：识别、文化意义、公共仪式或产品传播是真正项目问题。
**Spatial Operation**：audience/message → arrival / focus / interaction → space/media signs → legibility test。
**适用边界**：文化、零售、展陈、纪念、公共机构。
**Failure Mode**：象征符号堆砌、文化挪用、使用者被迫参与仪式。
**可验证空间痕迹**：人能辨别入口/对象/事件，平面与动线可支撑活动。

### D05｜THREE_DIMENSIONAL_PATH_MATRIX｜立体路径与空间矩阵
**判断含义**：通过各层路径和多样空间给出参观选择，而非强迫单一路径。
**Trigger**：真实多层场地、展陈和跨层用户任务。
**Spatial Operation**：levels + nodes + accessible loops → cross-section links → orientation / capacity test。
**适用边界**：坡地建筑、博物馆、大型公共项目。
**Failure Mode**：迷路、多处高差阻挡、过度复杂、照搬 Abteiberg。
**可验证空间痕迹**：plan-section-movement map 可证明到达不同空间的多种且等效路径。

### D06｜COMPLEX_NEUTRALITY｜具有差异的展陈中性
**判断含义**：艺术与建筑互相作用；不以彻底均质或建筑压倒展品为唯一准则。
**Trigger**：馆藏、展品类型和策展目标可被确认。
**Spatial Operation**：artwork requirements → galleries of differentiated scale/light → flexible access → conservation test。
**适用边界**：博物馆、画廊；需馆方与策展/文保共同验证。
**Failure Mode**：假设所有作品都适宜天光/高亮；展厅过度个性化削弱布展。
**可验证空间痕迹**：展品-空间匹配矩阵和照度、温湿度、运输维护路径。

### D07｜CITY_TOPOGRAPHY_LINK｜城市地形连续
**判断含义**：建筑/屋面/公共地面与历史城市的层级与流线可一起被组织。
**Trigger**：坡地、历史边缘或公共连接是已知主约束。
**Spatial Operation**：terrain levels → public routes → occupied / landscaped surfaces → accessible entry and drainage。
**适用边界**：坡地公共项目、城市更新、文化建筑。
**Failure Mode**：用景观屋面名义制造高维护平台或非平等到达。
**可验证空间痕迹**：场地剖面、公共路径、坡度与雨排水连续。

### D08｜MICRO_MACRO_INTEGRATION｜小尺度空间—物件—信息协同
**判断含义**：货品、家具/陈列、流线、边界和信息可协同构成环境，但每项需真实任务。
**Trigger**：小型零售、服务或活动展示涉及物件直接接触/使用。
**Spatial Operation**：visitor-object-service journey → barrier removal → displays/interfaces → fabrication and operations test。
**适用边界**：小空间、展亭、零售/服务；不自动加入精工或任何特定材料。
**Failure Mode**：把 Retti 的铝制整体表皮与细节当模板。
**可验证空间痕迹**：平面可证明视线、产品接触、工作人员服务与包装/标识一体协调。

### D09｜OLD_NEW_CONTEXT_DIALOGUE｜历史与新介入的辩证
**判断含义**：新建筑可与既有文化尺度、城市纹理及公共生活对话，同时具有当前时代的身份。
**Trigger**：历史邻里、街道、建筑改扩建或有强文化语境。
**Spatial Operation**：existing scale + edges + circulation → continuity/difference map → material/structure only when verified。
**适用边界**：历史核心区、城市综合体、增建项目。
**Failure Mode**：随意拼贴古典元素、镜面曲线或“后现代”形象。
**可验证空间痕迹**：实测城市剖面、动线、边界和视线解释连接与差异。

### Selection Verification
逐 DNA 标出 `SELECTED / NOT SELECTED / NEED VERIFY`，列证据支持、route 归属、空间痕迹。未选 DNA 永久不得自动回流；新证据需重新审查。
