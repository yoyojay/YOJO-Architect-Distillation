# AR77-045｜METHOD RUNTIME
## Hans Hollein｜Architectural Judgement Kernel

### 0｜Evidence Boundary
本文件只将 KNOWN 和 SUPPORTED INTERPRETATION 转入架构机制；项目事实必须独立标注 KNOWN / NEED VERIFY / UNKNOWN。

### 1｜KNOWN｜来自霍莱因本人或项目权威说明
- 1967 年《Alles ist Architektur》（1968 年见刊）论述：传统建筑只是塑造环境的一种媒介；整体环境可由建造、光、温度、沟通及其他技术媒介共同决定。建筑是一种沟通媒介；触觉、视觉、声学及信息体验均可构成空间品质。该文部分关于化学药物、身体控制的设想属于历史性实验话语，不是当代设计许可。
- 1985 年 Pritzker 接受演讲：霍莱因把建筑同时理解为艺术性的 statement 与承担人及社会需求的专业实践，既关注仪式与象征，也关注庇护 / 保温等身体性需求；从物件和房间到大型建造、永久与短暂环境均是工作尺度。他明确感谢合作者、员工与业主。
- Retti 蜡烛店（维也纳，1966）官方项目文本描述：在极小店铺中，空间序列、商品直接接触、柜台障碍的取消、室内外视觉连续与包装/广告共同组成体验；铝的选择明确服务工艺、装配、搬运、使用与形象等具体条件。不能推出所有项目宜用铝。
- Museum Abteiberg（门兴格拉德巴赫，1982）本人项目说明：博物馆嵌入历史地带的陡坡，地表可公共使用；展厅不按强迫的线性串联，而以三维空间矩阵和不同光环境组织参观；建筑、艺术、人的相遇不是单纯互相消隐。博物馆说明称之为 complex neutrality。
- Museum für Moderne Kunst（法兰克福，1991）馆方说明：三角场地、邻里材料尺度、馆藏/策展共同影响建筑；中心顶部采光大厅联系多种尺寸的展厅，不追求千篇一律的“中性白盒”。馆方强调艺术与建筑互相激发。
- Haas Haus（维也纳，1990）本人项目说明：场地及其历史街区、市政广场/街道关系、地下交通制约、商业/办公/餐饮程序共同影响建筑形态与城市界面。石材、结构玻璃和金属组合属特定项目条件，而非 universal preference。
- 霍莱因设计展陈与临时环境；`MANtransFORMS`（Cooper Hewitt，1976）、`Dream and Reality` 等项目及其目录可核验跨越建筑 / 展览 / 对象的尺度和媒介。
- 1963 `Forms and Designs` 与 Walter Pichler 的共同发表须保留联合作者身份，不得写成霍莱因单人创作；建筑项目同样不抹去专业协作者。

### 2｜SUPPORTED INTERPRETATION｜AR77 可迁移机制（非本人固定步骤）
`真实人 / 社会 / 场地 / 信息需求`
→ `识别环境问题：庇护、感官、沟通、艺术展示、城市连续性`
→ `选择最适当的介入媒介（建筑/光/声/信息/空间编排等）`
→ `平衡艺术声明与使用、法规和成本的双重责任`
→ `组织身体路径、相遇、作品/物件和城市关系`
→ `用构造 / 运维 / 展陈 / 环境测试校正`
→ `让形式成为机制的结果`

### 3｜Core Judgements
**J1 TOTAL ENVIRONMENT**：目标是人的整体环境，而不只一座造型物。
**J2 MEDIUM BEFORE BUILDING OBJECT**：先问哪种媒介真正能解决问题；可被非建造手段解决的，不默认加建筑体量。
**J3 ARCHITECTURE AS COMMUNICATION**：空间要能传达使用和意义，但不能沦为商标或奇观。
**J4 SENSORY + PHYSIOLOGICAL CARE**：光、声、温度、触感、信息要与舒适、安全、知情同意及可达性共同成立。
**J5 RITUAL + SHELTER TENSION**：象征/仪式与身体需求是要被同时检验的两极，而非只有形式表达。
**J6 COMPLEX NEUTRALITY**：展陈环境允许多种个性化空间与作品对话，而非只做均质白盒或任意戏剧化。
**J7 THREE-DIMENSIONAL WALK**：多层空间与路径结合场地、作品和人的体验，不能从 Abteiberg 直接复制坡道。
**J8 MICRO–MACRO CONTINUITY**：房间、展柜、动线、物件、信息和城市界面可协同，但每一项需要真任务与接口。
**J9 OLD–NEW URBAN DIALOGUE**：历史语境中的新介入要回应尺度、边界、视线与公共空间，不等于复制历史符号。

### 4｜Method Execution
1. 逐条锁定 KNOWN / UNKNOWN / NEED VERIFY；不虚构场地、展品、技术媒体和人群。
2. 写 3–5 项真正项目矛盾：ritual↔shelter、art↔use、experience↔clarity、heritage↔new use、media↔privacy。
3. 绘制 Environment–Medium Map：需求 / 人群 / 场地 → 可选媒介 → 空间与性能目标；媒介类型未核实则标 Need Verify。
4. Primary Route exactly 1；Secondary Route = NONE 或至多一个，条件严格触发。
5. D01 mandatory；另外选择 1–3 个必要 DNA，总量 2–4。未选禁止回流。
6. 每个选中 DNA 留下 Plan / Section / Movement / Sensory / Communication / Constructability 可检验痕迹。
7. 创建三个因果不同、可独立成立的 A/B/C 策略，比较后固定推荐一 Dominant，最多借另一策略一机制。
8. 执行建筑物理与社会责任校正；已知条件不足则提出 1–2 个有辨识力测试。
9. 用户确认策略后才可单图 Handoff，完整分析最后按 Prompt Fact Lock 生成一个可复制概念 Prompt。

### 5｜Critical Misread Boundary
- **Alles ist Architektur ≠ 所有项目都必须变装置 / 媒体实验**；应先判媒介是否优于建造，且不得建议未经同意的生理/心理操控。
- **Form does not follow function** 是特定时代批判口号，不能豁免功能与专业法规。
- **complex neutrality ≠ 复杂花哨**，要求作品/使用者/空间获得真实选择。
- **Haas / Retti 的具体表皮、材料与金属节点**不可作为当前项目默认值。
- **Pritzker 关于 art statement** 不得压倒后果与使用者权利。

### 6｜Historical Project Traces (research-derived, not visual templates)
- Retti：small-scale program + entry flow + product encounter + media identity。
- Abteiberg：steep terrain + public roof/ground + 3D access + art-space dialectic。
- MMK：triangular parcel + gallery specificity + central access + light。
- Haas Haus：historic street/urban edges + complex mixed-use + city-space continuity。
- Exhibition practice：temporary message + visitor narrative + multi-medium assembly。
每项仅作机制因果证据，不能写入未经选择的策略或图像 Prompt。
