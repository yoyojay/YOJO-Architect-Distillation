# AR77-045｜PROBLEM ROUTES
## Hans Hollein｜Evidence-Bounded Project-Problem Routing

以下为 AR77 在霍莱因文本 / 项目证据上建立的 **问题路由**，不是他的历史阶段、代表作风格分类、也不是其本人发表的 route 名称。

### R1｜ENVIRONMENT_MEDIA_CHOICE｜整体环境 / 媒介选择
**Trigger**：项目主要矛盾是环境体验、信息、感官或人与技术互动；建筑实体未必是唯一答案。
**核心问题**：到底通过什么介入媒介，才能最小且负责地改善人在此处的完整环境？
**Method**：user+context evidence → physical/psychic needs → medium option matrix (built / light / sound / information / microclimate) → consent + regulation → plan-section-services test。
**主要 DNA**：D01 / D02 / D03 / D04。
**适用边界**：公共设施、公共室内、复杂机构、环境更新、临时设施。
**风险**：过度媒介化、噪声/眩光、数据追踪侵犯隐私、运维成本、科技炫耀。
**与其他 Route 差异**：不是要先形成复杂展厅 / 商业展示，而是决定**哪类媒介应该承担问题**。

### R2｜ART_SPACE_DIALECTIC｜艺术—空间对话
**Trigger**：馆藏 / 展品 / 观众路径与展厅空间彼此影响，均一白盒不能完全满足已知展陈需求。
**核心问题**：如何让艺术、观众和差异化的空间相互激发，同时保护作品与策展弹性？
**Method**：actual artwork + conservation needs → characteristic room spectrum → light/acoustic envelope → nonforced visitor network → curator+operations test。
**主要 DNA**：D01 / D05 / D06 / D03。
**适用边界**：艺术博物馆、画廊、机构展陈；没有展品/策展资料时只能提出待核实假设。
**风险**：建筑抢夺作品、作品保护不足、无障碍差、布展弹性差、维护复杂。
**与其他 Route 差异**：由艺术/陈列/观众关系而非媒介类型选择或城市界面驱动。

### R3｜TOPOGRAPHY_CITY_WALK｜地形—城市—立体路径
**Trigger**：地形高差、历史区公共连接、城市层级与人行系统真正决定建筑。
**核心问题**：建筑怎样成为能被经过和使用的地形/城市一部分，而不只是坡上的物体？
**Method**：verified levels + urban routes → public thresholds → three-dimensional movement options → building/landscape overlap → equitable access + ecology + maintenance test。
**主要 DNA**：D01 / D07 / D09 / D05。
**适用边界**：坡地文化建筑、城市连接、遗产边界、大型公共设施。
**风险**：迷路、无障碍绕行、屋面防水维护、过度开挖、历史语境被夺目装饰覆盖。
**与其他 Route 差异**：由 topography + street/public continuity 驱动，而非展厅性格或零售传播。

### R4｜SMALL_SCALE_TOTAL_IDENTITY｜小尺度 / 空间—物件—传播整合
**Trigger**：极有限空间的店铺、展示、服务与品牌沟通必须协作；使用体验被柜台、入口或陈列阻碍。
**核心问题**：如何用动线、接触、对象陈列与信息把小空间做成清晰的整体体验？
**Method**：verified user/product/service journeys → barrier audit → spatial compression/expansion → display+wayfinding → details only if construction and maintenance justified。
**主要 DNA**：D01 / D08 / D04 / D03。
**适用边界**：零售、服务点、展亭、小空间改造、访客中心。
**风险**：材料表情凌驾商品/功能；陈列更新困难；品牌过度占据公共空间；暗示全部铝制。
**与其他 Route 差异**：由有限尺度中 program / object / communication 的紧耦合驱动。

### R5｜RITUAL_TEMPORARY_ENVIRONMENT｜仪式 / 临时场景 / 展陈介入
**Trigger**：短期展览、文化活动、仪式或研究展示需要通过空间、声音、影像与物件共同组织公众体验。
**核心问题**：怎样让象征性陈述与身体安全、文化准确、退出/拆装相协调？
**Method**：purpose + audience → ritual/information map → media/storyline selection → visitor sequence → accessibility/fire/acoustics/privacy → installation+de-installation/lifecycle test。
**主要 DNA**：D01 / D04 / D03 / D08。
**适用边界**：临展、展陈、公共活动、仪式设施、文化教育。
**风险**：象征压倒解释，眩光/声干扰，认知操控，复制霍莱因展品/棕榈柱形象。
**与其他 Route 差异**：由短期事件与文化沟通驱动，不是永久小商店或馆藏长期适配。

### Route Selection Logic
1. 提取最会改变平剖/路径/环境的主冲突，**Primary exactly 1**。
2. Secondary = NONE / 至多另一个，需解决不同且真实的次冲突，不能跨 route 随意拼盘。
3. R1 只有介入媒介选择本身是问题才优先，不鼓励媒体层自动生成。
4. R2 必须有馆藏/艺术保护/展陈逻辑或 NEED VERIFY；未核实时不得许诺非线性展厅事实。
5. R3 必须有已知坡度、路径或城市连接；不得因为霍莱因而自动设计可上人屋面。
6. R4 必须有小尺度、陈列或服务传播约束，不默认铝或豪华工艺。
7. R5 必须有真实展览/仪式/暂时性需求，禁止把所有建筑作为舞台。
8. 选定 Route 必须写 `Trigger / Core Question / Method / Main DNA / Boundary / Risk / Difference`。
9. 未选 Route 不得进入 A/B/C、Recommendation、Prompt 或 Handoff。
