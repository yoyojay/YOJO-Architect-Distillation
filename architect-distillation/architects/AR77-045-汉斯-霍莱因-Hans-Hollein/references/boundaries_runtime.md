# AR77-045｜BOUNDARIES + CONTEMPORARY CORRECTIONS
## Hans Hollein

### Fit Decision
**FIT**：主要问题涉及整体环境媒介选择、艺术与空间互动、场地/城市多层路径、小尺度物件—流线—传播统合，或真实临时展陈与仪式。
**PARTIAL FIT**：霍莱因机制可帮助媒体/体验/空间编排，但项目首要决定受医疗、洁净工业、深技术工程、遗产法规或特定生态保护控制。
**NOT FIT**：唯一目标是 Retti 金属商店、Haas Haus 镜面曲线、Abteiberg 屋面拼贴、古典柱或所谓“后现代霍莱因风格”；未经验证即要求装置/感官刺激。
Fit 要给理由、反证和适用边界；NOT FIT 时可进行反复制的需求澄清，不假装专家签审。

### Contemporary Corrections — each PASS / RISK / NEED VERIFY / N/A with a reason
**Climate / energy**：临时或数字媒介、商业中庭、屋面平台、采光等需计算热、眩光、自然采光、遮阳与运营能耗。
**Accessibility**：非线性博物馆动线、坡地高差、台阶、媒体交互与临展导向需验证等效路线、无障碍观看和信息替代方案。
**Fire / life safety**：展厅、活动、临设、商业中庭、可进入屋面与装置需符合出口宽度、疏散、材料阻燃、烟控与消防操作。
**Structure**：特殊面层、复杂形体、可上人屋面、跨层廊道、吊挂展陈和设备载荷必须专业校验，不从案例推导结构形式。
**MEP / thermal**：人工环境必须验证通风、空气质量、热舒适、湿度、设备接入、可检修性、容量与备用策略。
**Acoustics**：多媒体、博物馆和公共仪式要检查音质、混响、噪声传播、安静空间及替代体验。
**Privacy / consent**：传感器、投影交互、行为追踪、定向声/光/嗅觉干预必须使用者知情、可退出、无非自愿刺激；不用化学/药物操控。
**Operations**：策展更替、物件补货、商业维护、活动撤场、夜间关闭、保安与清洁是空间方案的一部分。
**Maintenance / durability**：复杂节点、媒体、特殊表皮、展品/装置接口和可上人屋面要计划检查、零件替换、防水及寿命。
**Cost**：艺术 statement 不得覆盖预算真实性；比较 capital + fitout + operations + renewals。
**Procurement**：非标准金属工艺、玻璃、机械/媒体、展陈系统必须验证供应链、技能、容差、运输及备件。
**Lifecycle**：临时系统优先可拆/重复利用；数字媒体考虑能耗/电子废弃物；长期空间考虑更新和 embodied carbon。

### Specific Corrections
**Artifact Care**：作品类型、照度、紫外、温湿度、运输/卸货、收藏安全、策展同意须由馆方/文保评估；`complex neutrality`不能损坏作品。
**Heritage / Public Realm**：Haas 类邻里干预须验证历史价值、城市人行/街道/交通关系和公众公平使用，不能只模拟古典/镜面形象。
**Critical Historical Media**：1967 文本对激光、药物、化学、环境控制等的激进设想只记录为历史，不自动成为 contemporary route/DNA/Prompt；任何潜在健康风险媒介需退出，相关专业评估优先。
**Authorial Boundary**：1963 与 Walter Pichler 共同宣言不得归霍莱因单人；大型项目有团队/工程与策展协作，1985 演讲本人认可此点；不将场馆后续改建归功于原作者。
**Social Responsibility**：在“建筑作为艺术陈述”与“身体与社会需求”张力中，操作安全、公众通达及人的尊严优先于效果。

### Professional Boundary
可用：前期环境/建筑判断、问题路由、受限 DNA、A/B/C、方案诊断、下一步测试、用户确认后视觉交接。
