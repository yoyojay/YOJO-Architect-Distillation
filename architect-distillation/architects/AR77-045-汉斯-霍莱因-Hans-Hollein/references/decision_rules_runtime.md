# AR77-045｜DECISION RULES
## 当… → 优先… → 因为… → 通过…验证 → 若失败则…

DR01｜**当**项目事实不足，**优先**分离 KNOWN/UNKNOWN/NEED VERIFY，**因为**创作声明不能替代事实，**通过**证据矩阵核对，**若失败则**每轮仅问 1–3 个关键问题。

DR02｜**当**建筑形式被提前要求为“霍莱因式”，**优先**Fit + Environment–Medium Map，**因为**他探索的是环境定义而非造型标识，**通过**需求/媒介对应验证，**若失败则**NOT FIT/删除形象。

DR03｜**当**可通过多种媒介改善空间，**优先**R1+D02，**因为**建造不是唯一媒介，**通过**方案媒介成本/能耗/运维/同意对比，**若失败则**选简约且合规方案。

DR04｜**当**人群有感官冲突，**优先**D03，**因为**触觉/声/光/热是环境组成，**通过**眩光、声压、温度及可达验证，**若失败则**降低刺激并重选环境手段。

DR05｜**当**建筑要承载公共象征或仪式，**优先**D04，**因为**statement 与 shelter/社会需求必须一起成立，**通过**到达、服务、退出、体验与人群多样性验证，**若失败则**删除象征复杂化。

DR06｜**当**博物馆存在多种已知展品/策展目标，**优先**R2+D06，**因为**空间与艺术可以相互激发，**通过**artwork-galleries-conservation 矩阵，**若失败则**恢复高弹性中性空间。

DR07｜**当**项目有真实地形高差和城市连续任务，**优先**R3+D07，**因为**建筑可整合地形与城市公共路径，**通过**场地剖面/无障碍/排水验证，**若失败则**停止上人屋面/阶梯预设。

DR08｜**当**小型商业场所既需展品接触又需品牌表达，**优先**R4+D08，**因为**动线/物件/传播可形成整体，**通过**人流/陈列/后台/采购检验，**若失败则**改为功能清楚的局部改善。

DR09｜**当**短期活动/展览有实际仪式或叙事需求，**优先**R5+D04，**因为**临时环境是霍莱因证据中的真实研究领域，**通过**清楚的事件路径及防火/拆装/成本验证，**若失败则**取消多余媒体与符号。

DR10｜**当**历史核心区要求新介入，**优先**D09，**因为**旧与新需在街道与公共层级形成可读关系，**通过**edge/height/entry/heritage impact 验证，**若失败则**不做任何古典拼贴。

DR11｜**当**三案只是金属/拼贴/装置风格变化，**优先**重做 A/B/C，**因为**必须有三条不同因果，**通过**Route-DNA + plan-section-movement 检验，**若失败则**Strategy FAIL。

DR12｜**当**推荐试图合并全部三案，**优先**一个 Dominant（借用 NONE 或另一方案 1 个有限机制），**因为**Dominant 应独立成立，**通过**Rejected/未选 DNA 无回流核对，**若失败则**Recommendation FAIL。

DR13｜**当**任何 prompt 自动加入镜面、金属、石材、古典柱、展陈装置、屋面等，**优先**Prompt Fact Lock，**因为**历史形态不可自动移植，**通过**逐 token 来源追溯，**若失败则**删除/改写为空间关系或性能语。

DR14｜**当**在未获得用户授权下拟用嗅觉、热刺激、行为数据或沉浸感官控制，**优先**隐私/同意/安全校正，**因为**1967 的想象不是当代伦理许可，**通过**user consent / code / health review，**若失败则**停止该机制。

DR15｜**当**Critic 发现路线失配、展品受损、不可达或高维护，**优先**Failure Return 回到事实与 Route/DNA selection，**因为**形式不优于真实绩效，**通过**重算方案与 1–2 项关键测试，**若失败则**保持 NEED VERIFY 不进入视觉冻结。

DR16｜**当**用户确认了 Dominant 并要求单图验证，**优先**Single Image Visual Handoff，**因为**视觉应验证已锁定的空间机制，**通过**confirmed facts/Route/Dominant/DNA 与 Fact Lock 对照，**若失败则**不交接。
