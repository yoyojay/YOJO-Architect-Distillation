# AR77-001｜FINAL 外部验收

## First Contact PASS
- [ ] 首次完整项目分析先出现约 150 字大师初印象
- [ ] 大师初印象来自 packaged method / DNA / Period Routing，不写百科传记
- [ ] 有 3 个关键词 + 1 条“不要误读成”
- [ ] 不要求用户预先熟悉勒·柯布西耶或 AI 命令
- [ ] 信息不足时每轮最多追问 1–3 个关键问题
- [ ] Critic / Handoff 不重复大师初印象

## Project Analysis PASS
- [ ] 先做输入检查，UNKNOWN 不补写
- [ ] 有 FIT / PARTIAL FIT / NOT FIT
- [ ] 3–5 个核心空间问题
- [ ] 只选 1 个 Primary Period Route，Secondary 最多 1 个
- [ ] 选择 4–7 DNA
- [ ] 未选 DNA 不得后门回流
- [ ] A/B/C 因果不同
- [ ] 推荐最多正向使用 2 个策略
- [ ] 推荐使用 Dominant / Borrowed / Rejected 固定结构
- [ ] 推荐保持 Period Route 一致
- [ ] 有当代校正
- [ ] 有专业边界
- [ ] 有建筑师确认点
- [ ] 有下一步 1–2 张图 / 测试
- [ ] 不复制代表作

## Prompt Close PASS
- [ ] 每次完整项目分析最后只有 1 个建筑初印象 Prompt
- [ ] Prompt 只使用 KNOWN + 已选 Period Route + Dominant + 单一 Borrowed + Selected DNA
- [ ] 不使用 Rejected Strategy
- [ ] 不使用未选 DNA / 未选 Period Route
- [ ] 不出现 `Le Corbusier style` / 代表作名称
- [ ] 不自动补入未经判断支持的白盒 / 架空柱 / 横向长窗 / 清水混凝土 / 屋顶图像
- [ ] 定位为概念初印象检验，不冒充最终效果图

## Visual Handoff PASS
- [ ] 只有一个单图 Handoff
- [ ] Strategy 与 Period Route 已确认
- [ ] 有 Selected DNA
- [ ] 有 Spatial Locks
- [ ] 有 Must Not Drift
- [ ] Prompt 不出现 Le Corbusier style
- [ ] 不扩展成整套效果图
- [ ] 后续完整视觉生产转入独立工作流

## HARD FAIL
- 直接生成“勒·柯布西耶风格建筑”
- 复制 Villa Savoye / Ronchamp / Unité / Chandigarh 等代表作
- 机械套五点原则
- 四时期混成一个滤镜
- 三案只是换造型
- A+B+C 全部进入推荐
- UNKNOWN 当事实
- 全 DNA 堆叠
- 把 Modulor 当唯一人体标准
- 跳过当代校正 / 风险 / 专业边界


## Prompt Fact Lock PASS
- [ ] Prompt 中每一个具体材料 / 结构 / 立面 / 开口 / 屋顶描述都有可追溯依据
- [ ] 不把 UNKNOWN 写成具体物质事实
- [ ] 未确认材料用中性表达，例如 retained existing fabric
- [ ] 未确认构造几何用性能表达，例如 openings calibrated for shade / glare / privacy
- [ ] 不为了“画面完整”自动补充 masonry / concrete / timber / steel / glass / deep reveals / roof form
