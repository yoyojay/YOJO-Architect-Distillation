# AR77-001｜Runtime Method

## Core reasoning chain

The existing 001 Skill defines Le Corbusier's transferable value as:

`social / life problem → structural system → plan and section freedom → movement sequence → light and climate interface → human scale → material expression → urban or collective relation`

This chain is the method kernel.

---

## Method 01｜Structure before image

Structure should be tested as a spatial enabler.

Questions:

- Can structure release program?
- Does a grid or spanning strategy improve adaptability?
- Is structure being used only to create an iconic appearance?

---

## Method 02｜Ground as a project question

Lifting the building is not a default.

Ask:

- what does the ground need to do?
- public passage?
- flood / ventilation?
- landscape continuity?
- arrival?
- community use?

If none of these justify lifting, do not use pilotis as a symbol.

---

## Method 03｜Plan + section as different systems

Free plan is useful only when supported by:

- structure;
- service organization;
- privacy;
- acoustics;
- operations.

Section may build:

- double-height relation;
- shared layers;
- internal streets;
- cross-level visibility;
- public / private hierarchy.

---

## Method 04｜Promenade as understanding

Movement is not decoration.

Use sequence only when it helps:

- arrival;
- orientation;
- anticipation;
- view;
- transition;
- collective encounter;
- relation to landscape.

---

## Method 05｜Climate creates depth

Openings, shading, galleries, deep walls, and roofs must respond to:

- sun;
- rain;
- heat;
- glare;
- wind;
- local maintenance.

Historical devices are evidence of a question, not a universal detail.

---

## Method 06｜Standardization + diverse bodies

The method may use dimensional families and repetition.

But current projects must be checked for:

- children;
- elderly users;
- wheelchair users;
- different bodies;
- furniture;
- accessibility;
- actual local standards.

---

## Method 07｜Rational order + limited poetic deviation

Late work demonstrates that rational systems and poetic spatial intensity can coexist.

Keep a legible order.

Allow only a small number of deviations with a clear source in:

- site;
- horizon;
- light;
- sound;
- ritual;
- landscape;
- material.

Do not use free sculpture as a substitute for design logic.

---

## Method 08｜Individual + collective

For housing, education, institutional, or community projects:

do not design private units and shared space separately.

Test:

- what belongs to the individual?
- what belongs to a group?
- where does encounter happen?
- who operates the shared facilities?
- what happens at different times?
