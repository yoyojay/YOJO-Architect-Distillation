# AR77-001｜SINGLE IMAGE VISUAL HANDOFF

## 定位

001 的核心不是效果图 Prompt。

本模块只负责：

**把已经确认的 Le Corbusier 方法判断，交给一张概念验证图。**

它不是完整视觉生产系统。

---

# 启动条件

必须已经确认：

- Strategy
- Primary Period Route
- 4–7 Selected DNA

---

# 输出

## 01｜Confirmed Strategy

## 02｜Period Route

## 03｜Selected DNA

## 04｜Spatial Locks

只描述当前项目必须保留的关系，例如：

- structural field releases plan;
- ground strategy has a real public / climate reason;
- movement sequence is legible;
- section creates a defined relationship;
- climate depth is orientation-specific;
- scale is calibrated for actual users;
- one poetic deviation is justified, if used.

## 05｜Must Not Drift

必须检查：

- 不复制 Villa Savoye；
- 不复制 Ronchamp；
- 不复制 Unité Marseille；
- 不复制 Chandigarh；
- 不把 pilotis / ribbon window / rough concrete 当风格套件；
- 不新增未经建筑师确认的标志性造型；
- 不把历史项目名称当视觉目标。

## 06｜Single Demonstration Image Prompt

Prompt 应描述：

- current project type;
- actual site / climate facts;
- confirmed spatial strategy;
- structure / section / movement relationship;
- public / private or collective relation;
- material only when supported by the design judgement;
- camera angle that reveals the spatial logic;
- realistic architectural visualization.

禁止出现：

- `Le Corbusier style`
- `Villa Savoye inspired`
- `like Ronchamp`
- `Unité style`
- `Chandigarh style`

## 07｜Negative Constraints

只写与当前项目防漂移直接相关的约束。

## 08｜Handoff Note

固定说明：

> 这是一张概念验证图，用于检查当前设计判断进入视觉后是否成立，不代表完整效果图体系。后续整套视觉生产请进入建筑师原有可视化流程，或交给专门的视觉系统，例如 Zeus96。
